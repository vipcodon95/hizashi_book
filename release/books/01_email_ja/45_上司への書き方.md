# Rule 45 — <ruby>上司<rt>じょうし</rt></ruby><ruby>宛<rt>あて</rt></ruby> — <ruby>指示調<rt>しじちょう</rt></ruby>を<ruby>避<rt>さ</rt></ruby>け、<ruby>依頼形<rt>いらいけい</rt></ruby>にする
> **<ruby>要点<rt>ようてん</rt></ruby>.** 日本語には*指示調・<ruby>命令調<rt>めいれいちょう</rt></ruby>*の<ruby>響<rt>ひび</rt></ruby>きを持つ<ruby>表現<rt>ひょうげん</rt></ruby>がある。上司や<ruby>目上<rt>めうえ</rt></ruby>の方への文では、これらを**依頼形・<ruby>相談形<rt>そうだんけい</rt></ruby>**に変える必要がある。<ruby>一語<rt>いちご</rt></ruby>の違い（「ください」→「いただけますか」）が<ruby>敬意<rt>けいい</rt></ruby>の<ruby>温度<rt>おんど</rt></ruby>を大きく変える。
>
> キーワード：**「依頼形、<ruby>指示形<rt>しじけい</rt></ruby>を避ける」**。

## <ruby>対照表<rt>たいしょうひょう</rt></ruby>
| 指示調（上司にはNG） | 依頼形（上司に<ruby>適切<rt>てきせつ</rt></ruby>） |
|--------------------|------------------|
| 「木曜までに<ruby>承認<rt>しょうにん</rt></ruby>してください」 | 「木曜までにご承認いただけますでしょうか」 |
| 「この点を<ruby>明確<rt>めいかく</rt></ruby>にしてください」 | 「この点につきまして、お教えいただけますでしょうか」 |
| 「<ruby>添付<rt>てんぷ</rt></ruby>をご覧ください」 | 「添付をご<ruby>参照<rt>さんしょう</rt></ruby>いただければ<ruby>幸<rt>さいわ</rt></ruby>いです」 |
| 「知っておいてください」 | 「ご<ruby>認識<rt>にんしき</rt></ruby>いただければと<ruby>存<rt>ぞん</rt></ruby>じます」 |
| 「<ruby>理解<rt>りかい</rt></ruby>してください」 | 「ご<ruby>容赦<rt>ようしゃ</rt></ruby>いただけますと幸いです」 |
| 「すぐ<ruby>対応<rt>たいおう</rt></ruby>してください」 | 「お<ruby>手<rt>て</rt></ruby>すきの<ruby>際<rt>さい</rt></ruby>にご対応いただけますと幸いです、できれば金曜までに」 |

## 悪い例
> 「フオン<ruby>副部長<rt>ふくぶちょう</rt></ruby>、50万円の<ruby>追加<rt>ついか</rt></ruby><ruby>予算<rt>よさん</rt></ruby>を木曜までに承認してください。承認<ruby>結果<rt>けっか</rt></ruby>を私に<ruby>返送<rt>へんそう</rt></ruby>してください。」

→ 指示調 — <ruby>部下<rt>ぶか</rt></ruby>や<ruby>目下<rt>めした</rt></ruby>には問題ないが、上司には<ruby>不適切<rt>ふてきせつ</rt></ruby>。

## 良い例
> 「フオン副部長、ビンミンの追加予算50万円につきまして、5月15日（木）までにご承認いただけますと幸いです。ご承認後、結果をお<ruby>知<rt>し</rt></ruby>らせいただければ、次の<ruby>工程<rt>こうてい</rt></ruby>に<ruby>進<rt>すす</rt></ruby>めます。
>
> よろしくお願い<ruby>申<rt>もう</rt></ruby>し<ruby>上<rt>あ</rt></ruby>げます。」

同じ依頼、正しい<ruby>語調<rt>ごちょう</rt></ruby>。

## 明確さは<ruby>維持<rt>いじ</rt></ruby>、<ruby>卑屈<rt>ひくつ</rt></ruby>にならない
依頼形 ≠ 卑屈。<ruby>必須<rt>ひっす</rt></ruby><ruby>項目<rt>こうもく</rt></ruby>は明確に：
- <ruby>期限<rt>きげん</rt></ruby>。
- 必要な<ruby>行動<rt>こうどう</rt></ruby>。
- <ruby>遅延<rt>ちえん</rt></ruby>時の<ruby>影響<rt>えいきょう</rt></ruby>（<ruby>該当<rt>がいとう</rt></ruby>する場合）。

## 使えるフレーズ
> **「上司宛：『〜いただけますでしょうか』『〜いただけますと幸いです』。『〜してください』は避ける。」**
