# Rule 56 — トラブル報告 — <ruby>状況<rt>じょうきょう</rt></ruby> → <ruby>影響<rt>えいきょう</rt></ruby> → <ruby>対応中<rt>たいおうちゅう</rt></ruby> → <ruby>要支援<rt>ようしえん</rt></ruby>

>
> キーワード：**「4ブロック報告」**。

> **<ruby>関連<rt>かんれん</rt></ruby>：** Rule 53（<ruby>謝罪<rt>しゃざい</rt></ruby>メールの4ステップ）— インシデント<ruby>収束後<rt>しゅうそくご</rt></ruby>の<ruby>正式<rt>せいしき</rt></ruby>謝罪に。Rule 19（電話の3<ruby>兆候<rt>ちょうこう</rt></ruby>）— <ruby>通常<rt>つうじょう</rt></ruby>は電話が<ruby>先<rt>さき</rt></ruby>、メールは<ruby>後<rt>あと</rt></ruby>。

## 4ブロック<ruby>構造<rt>こうぞう</rt></ruby> — 「SITUATION → IMPACT → ACTION → SUPPORT」
### <ruby>状況<rt>じょうきょう</rt></ruby>

### <ruby>対応中<rt>たいおうちゅう</rt></ruby>

### <ruby>要支援<rt>ようしえん</rt></ruby>
<ruby>上司<rt>じょうし</rt></ruby>または<ruby>他者<rt>たしゃ</rt></ruby>から<ruby>具体的<rt>ぐたいてき</rt></ruby>に何が<ruby>必要<rt>ひつよう</rt></ruby>か。
