# Rule 18 — 繰り返し送るメールは個人テンプレート化する
> **<ruby>要点<rt>ようてん</rt></ruby>.** 同じ型のメールを **3回以上** 書いているなら — <ruby>週報<rt>しゅうほう</rt></ruby>、<ruby>日程<rt>にってい</rt></ruby><ruby>変更<rt>へんこう</rt></ruby><ruby>依頼<rt>いらい</rt></ruby>、<ruby>請求書<rt>せいきゅうしょ</rt></ruby>リマインド、<ruby>提案<rt>ていあん</rt></ruby>、<ruby>断<rt>ことわ</rt></ruby>り — 毎回ゼロから書くのは時間の無駄。Draftsもしくは Templates機能に**個人テンプレート**を保存する。<ruby>以降<rt>いこう</rt></ruby>は<ruby>複製<rt>ふくせい</rt></ruby>→3<ruby>箇所<rt>かしょ</rt></ruby><ruby>埋<rt>う</rt></ruby>める→<ruby>送信<rt>そうしん</rt></ruby>の作業だけ。
>
> キーワード：**「3回以上＝テンプレ化」**。

## <ruby>背景<rt>はいけい</rt></ruby>
ズンは毎週<ruby>月曜<rt>げつよう</rt></ruby>にフオン<ruby>副部長<rt>ふくぶちょう</rt></ruby>へ<ruby>週報<rt>しゅうほう</rt></ruby>を送っている。毎回ゼロから書いて20〜30分かけている。

## テンプレート化しない場合の<ruby>実費<rt>じっぴ</rt></ruby>
あなたが1週間に書く<ruby>量<rt>りょう</rt></ruby>：
- <ruby>週報<rt>しゅうほう</rt></ruby>1<ruby>通<rt>つう</rt></ruby>（20分）
- <ruby>日程<rt>にってい</rt></ruby><ruby>変更<rt>へんこう</rt></ruby><ruby>依頼<rt>いらい</rt></ruby>2通（5分×2）
- <ruby>請求書<rt>せいきゅうしょ</rt></ruby>リマインド3通（5分×3）
- <ruby>新規<rt>しんき</rt></ruby><ruby>提案<rt>ていあん</rt></ruby>2通（15分×2）

<ruby>合計<rt>ごうけい</rt></ruby>：**約1時間15分/週**、<ruby>構造<rt>こうぞう</rt></ruby>を書き直すだけの作業。<ruby>年間<rt>ねんかん</rt></ruby>約**65時間**、メールの型を書くために**8<ruby>営業日<rt>えいぎょうび</rt></ruby>**<ruby>消費<rt>しょうひ</rt></ruby>。

## <ruby>週報<rt>しゅうほう</rt></ruby>テンプレートの例
Draftsに `[TEMPLATE] 週報` という<ruby>名前<rt>なまえ</rt></ruby>で<ruby>保存<rt>ほぞん</rt></ruby>：

```

フオン副部長、

お疲れ様です、BDのズンです。

第__週のビンミンプロジェクト週報をお送りいたします。ご確認いただきたい__点：

1. [項目1] — [状態：順調/遅延/要注意]
   詳細: ...

2. [項目2] — [状態]
   詳細: ...

3. [項目3] — [状態]
   詳細: ...

今週ご判断いただきたい事項：
- [判断事項1 — 期限]
- [判断事項2 — 期限]

```

毎週<ruby>月曜<rt>げつよう</rt></ruby>、ズンの作業は：
1. このDraftを<ruby>複製<rt>ふくせい</rt></ruby>。
2. <ruby>週番号<rt>しゅうばんごう</rt></ruby>を入れる。
3. 3<ruby>項目<rt>こうもく</rt></ruby>と<ruby>状態<rt>じょうたい</rt></ruby>を入れる。
4. <ruby>要<rt>よう</rt></ruby><ruby>承認<rt>しょうにん</rt></ruby><ruby>事項<rt>じこう</rt></ruby>を入れる。
5. <ruby>送信<rt>そうしん</rt></ruby>。

<ruby>所要<rt>しょよう</rt></ruby>時間：**5〜7分**（<ruby>以前<rt>いぜん</rt></ruby>の20〜30分に<ruby>対<rt>たい</rt></ruby>し）。

## テンプレート<ruby>庫<rt>こ</rt></ruby>の<ruby>整理<rt>せいり</rt></ruby><ruby>方法<rt>ほうほう</rt></ruby>
### 方法1 — Drafts でプレフィックス
Draftsに<ruby>保存<rt>ほぞん</rt></ruby>、<ruby>全<rt>すべ</rt></ruby>て `[TEMPLATE]` で<ruby>始<rt>はじ</rt></ruby>める<ruby>名前<rt>なまえ</rt></ruby>：
- `[TEMPLATE] 週報`
- `[TEMPLATE] 日程変更`
- `[TEMPLATE] 請求書リマインド`

<ruby>利点<rt>りてん</rt></ruby>：ツール<ruby>不要<rt>ふよう</rt></ruby>、シンプル。
<ruby>欠点<rt>けってん</rt></ruby>：Draftsに<ruby>通常<rt>つうじょう</rt></ruby>の<ruby>下書<rt>したが</rt></ruby>きとテンプレが<ruby>混<rt>ま</rt></ruby>ざり<ruby>混乱<rt>こんらん</rt></ruby>しやすい。

### 方法2 — Templates<ruby>機能<rt>きのう</rt></ruby>を<ruby>使用<rt>しよう</rt></ruby>
- **Gmail：** Settings → Advanced → Templates → Enable。<ruby>作成<rt>さくせい</rt></ruby><ruby>画面<rt>がめん</rt></ruby>のMenu（3<ruby>点<rt>てん</rt></ruby>）→ Templates → Save draft as template.
- **Outlook（デスクトップ）：** 名前を<ruby>付<rt>つ</rt></ruby>けて保存 → *Outlook Template (.oft)* <ruby>形式<rt>けいしき</rt></ruby>。
- **Outlook Web / Microsoft 365：** *My Templates* アドイン<ruby>利用<rt>りよう</rt></ruby>。

<ruby>利点<rt>りてん</rt></ruby>：テンプレが<ruby>別<rt>べつ</rt></ruby><ruby>管理<rt>かんり</rt></ruby>、いつでも<ruby>挿入<rt>そうにゅう</rt></ruby><ruby>可能<rt>かのう</rt></ruby>。
<ruby>欠点<rt>けってん</rt></ruby>：<ruby>初期<rt>しょき</rt></ruby><ruby>設定<rt>せってい</rt></ruby>に2分<ruby>必要<rt>ひつよう</rt></ruby>。

### 方法3 — マシン<ruby>上<rt>じょう</rt></ruby>のテキストファイル
デスクトップに `mail_templates.md` を<ruby>作成<rt>さくせい</rt></ruby>、<ruby>全<rt>ぜん</rt></ruby>テンプレートを<ruby>格納<rt>かくのう</rt></ruby>。<ruby>必要時<rt>ひつようじ</rt></ruby>にファイルを<ruby>開<rt>ひら</rt></ruby>いてコピペ。

<ruby>利点<rt>りてん</rt></ruby>：メールクライアント<ruby>非依存<rt>ひいぞん</rt></ruby>（<ruby>複数<rt>ふくすう</rt></ruby><ruby>受信箱<rt>じゅしんばこ</rt></ruby><ruby>使用時<rt>しようじ</rt></ruby>に<ruby>便利<rt>べんり</rt></ruby>）。
<ruby>欠点<rt>けってん</rt></ruby>：ウィンドウを1つ<ruby>余計<rt>よけい</rt></ruby>に<ruby>管理<rt>かんり</rt></ruby>する必要。

## テンプレートを<ruby>更新<rt>こうしん</rt></ruby>すべきサイン
- ペーストの<ruby>度<rt>たび</rt></ruby>に*同じ<ruby>箇所<rt>かしょ</rt></ruby>*を書き<ruby>換<rt>か</rt></ruby>えている → その箇所をプレースホルダ `[...]` にする、もしくはテンプレ<ruby>本体<rt>ほんたい</rt></ruby>に<ruby>含<rt>ふく</rt></ruby>めてしまう。
- *<ruby>全<rt>まった</rt></ruby>く使わない*<ruby>部分<rt>ぶぶん</rt></ruby>がある → <ruby>削除<rt>さくじょ</rt></ruby>。
- 3ヶ月、同じテンプレに<ruby>対<rt>たい</rt></ruby>する<ruby>反応<rt>はんのう</rt></ruby>が<ruby>一様<rt>いちよう</rt></ruby>に<ruby>薄<rt>うす</rt></ruby>い → <ruby>文体<rt>ぶんたい</rt></ruby>が<ruby>飽<rt>あ</rt></ruby>きられた、<ruby>刷新<rt>さっしん</rt></ruby><ruby>時期<rt>じき</rt></ruby>。

## 使えるフレーズ
> **「3回以上書いたらテンプレ化。<ruby>設定<rt>せってい</rt></ruby>5分、<ruby>年間<rt>ねんかん</rt></ruby>8<ruby>営業日<rt>えいぎょうび</rt></ruby><ruby>節約<rt>せつやく</rt></ruby>。」**

*使うとき：* <ruby>次<rt>つぎ</rt></ruby>にメールを書き<ruby>始<rt>はじ</rt></ruby>める時、<ruby>自問<rt>じもん</rt></ruby>する *「このタイプのメールはもう3回書いたか？」*。YESなら<ruby>今回<rt>こんかい</rt></ruby>書き<ruby>終<rt>お</rt></ruby>わったらテンプレ化。<ruby>次回<rt>じかい</rt></ruby>からは「<ruby>埋<rt>う</rt></ruby>めるだけ」の作業。
