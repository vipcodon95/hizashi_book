# Rule 36 — <ruby>尊敬語<rt>そんけいご</rt></ruby>・<ruby>謙譲語<rt>けんじょうご</rt></ruby>・<ruby>丁寧語<rt>ていねいご</rt></ruby> — 3つの使い分け
> **要点.** 日本語<ruby>敬語<rt>けいご</rt></ruby>は**3<ruby>種類<rt>しゅるい</rt></ruby>**：(1) **尊敬語** — <ruby>相手<rt>あいて</rt></ruby>の<ruby>動作<rt>どうさ</rt></ruby>を<ruby>高<rt>たか</rt></ruby>める（いらっしゃる、お<ruby>越<rt>こ</rt></ruby>しになる）、(2) **謙譲語** — 自分の動作をへりくだる（<ruby>伺<rt>うかが</rt></ruby>う、<ruby>申<rt>もう</rt></ruby>し<ruby>上<rt>あ</rt></ruby>げる）、(3) **丁寧語** — <ruby>全体<rt>ぜんたい</rt></ruby>を<ruby>丁寧<rt>ていねい</rt></ruby>にする（です・ます）。<ruby>社内外<rt>しゃないがい</rt></ruby>、<ruby>上下関係<rt>じょうげかんけい</rt></ruby>によって<ruby>適切<rt>てきせつ</rt></ruby>な<ruby>組<rt>く</rt></ruby>み<ruby>合<rt>あ</rt></ruby>わせが<ruby>変<rt>か</rt></ruby>わる。
>
> キーワード：**「3種敬語の使い分け」**。

## <ruby>動詞別<rt>どうしべつ</rt></ruby>の<ruby>対応表<rt>たいおうひょう</rt></ruby>（よく使うもの）
| <ruby>普通形<rt>ふつうけい</rt></ruby> | 尊敬語（相手） | 謙譲語（自分） |
|-------|-------------|-------------|
| 行く／来る | いらっしゃる／お越しになる | 伺う／<ruby>参<rt>まい</rt></ruby>る |
| 言う | おっしゃる | <ruby>申<rt>もう</rt></ruby>す／申し上げる |
| 食べる／飲む | <ruby>召<rt>め</rt></ruby>し<ruby>上<rt>あ</rt></ruby>がる | いただく |
| 見る | ご<ruby>覧<rt>らん</rt></ruby>になる | <ruby>拝見<rt>はいけん</rt></ruby>する |
| 知る／知っている | ご<ruby>存<rt>ぞん</rt></ruby>じ（です） | <ruby>存<rt>ぞん</rt></ruby>じる／存じ<ruby>上<rt>あ</rt></ruby>げる |
| する | なさる | いたす |
| 受け取る | お受け取りになる | <ruby>頂戴<rt>ちょうだい</rt></ruby>する |
| 与える／くれる | くださる | <ruby>差<rt>さ</rt></ruby>し<ruby>上<rt>あ</rt></ruby>げる |
| 読む | お読みになる | <ruby>拝読<rt>はいどく</rt></ruby>する |

> 注：「もらう」<ruby>自体<rt>じたい</rt></ruby>は<ruby>元々<rt>もともと</rt></ruby>謙譲<ruby>側<rt>がわ</rt></ruby>の動詞（「いただく／頂戴する」）。相手の「受け取る」動作を尊敬する<ruby>場合<rt>ばあい</rt></ruby>は「お受け取りになる」を使う。「くれる／与える」の尊敬語は「くださる」。<ruby>混同<rt>こんどう</rt></ruby>しないこと。

## <ruby>悪<rt>わる</rt></ruby>い例 — <ruby>混用<rt>こんよう</rt></ruby>
> 「<ruby>松本<rt>まつもと</rt></ruby>様、<ruby>資料<rt>しりょう</rt></ruby>を**拝見してくださいましたか**？」

「拝見する」は自分の動作（謙譲語）。相手に使うなら「ご覧になる」「ご覧いただく」。

## <ruby>良<rt>よ</rt></ruby>い例
> 「松本様、資料を**ご覧いただけましたでしょうか**？」

## 使えるフレーズ — 5つのコア
1. 「<ruby>伺<rt>うかが</rt></ruby>います」（自分が行く）
2. 「おっしゃる<ruby>通<rt>とお</rt></ruby>りです」（相手の<ruby>言<rt>げん</rt></ruby>）
3. 「拝見いたしました」（自分が見た）
4. 「ご<ruby>確認<rt>かくにん</rt></ruby>いただけますでしょうか」（相手に確認を<ruby>依頼<rt>いらい</rt></ruby>）
5. 「かしこまりました」（<ruby>承知<rt>しょうち</rt></ruby>の<ruby>意<rt>い</rt></ruby>）

## <ruby>核心<rt>かくしん</rt></ruby><ruby>原則<rt>げんそく</rt></ruby>
> **「相手の動作 → 尊敬語。自分の動作 → 謙譲語。<ruby>迷<rt>まよ</rt></ruby>ったら『お〜する／させていただく』より『〜いたします』。」**
