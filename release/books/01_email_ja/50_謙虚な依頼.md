# Rule 49 — <ruby>自分<rt>じぶん</rt></ruby>の<ruby>都合<rt>つごう</rt></ruby>での<ruby>依頼<rt>いらい</rt></ruby> — <ruby>謙虚<rt>けんきょ</rt></ruby>さと<ruby>明確<rt>めいかく</rt></ruby>な<ruby>期限<rt>きげん</rt></ruby>、<ruby>相互<rt>そうご</rt></ruby><ruby>利益<rt>りえき</rt></ruby>

## 個人的依頼の<ruby>構造<rt>こうぞう</rt></ruby>
1. **個人的な依頼であることを<ruby>認<rt>みと</rt></ruby>める** — 業務ではない。
2. **<ruby>具体的<rt>ぐたいてき</rt></ruby>な依頼** ＋ 期限。
3. **なぜ<ruby>依頼者<rt>いらいしゃ</rt></ruby>が必要か**（<ruby>必須<rt>ひっす</rt></ruby>ではないが<ruby>推奨<rt>すいしょう</rt></ruby>）。
4. **相手への利益／<ruby>見返<rt>みかえ</rt></ruby>り**（<ruby>可能<rt>かのう</rt></ruby>なら）。
5. **<ruby>無理<rt>むり</rt></ruby>な<ruby>場合<rt>ばあい</rt></ruby>の明確な<ruby>逃<rt>に</rt></ruby>げ<ruby>道<rt>みち</rt></ruby>**（<ruby>重要<rt>じゅうよう</rt></ruby>）。
