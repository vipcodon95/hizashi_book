# Rule 26 — 「明日」「来週」は<ruby>罠<rt>わな</rt></ruby> — <ruby>具体的<rt>ぐたいてき</rt></ruby>な日付を書く
> **要点.** 「明日、5月15日（木）10:00」と書く。**「明日」だけは書かない**。水曜23:00に送ったメール — 「明日」は木曜？ それとも日付が変わって金曜？ 海外<ruby>宛<rt>あて</rt></ruby>なら<ruby>時差<rt>じさ</rt></ruby>はどう？ 必ず：曜日＋日付＋時刻＋（必要なら時差）を<ruby>明記<rt>めいき</rt></ruby>。
>
> キーワード：**「絶対日時」**。

## 悪い例
> 「明日までに<ruby>報告書<rt>ほうこくしょ</rt></ruby>を<ruby>提出<rt>ていしゅつ</rt></ruby>してよろしいでしょうか？」
> 「来週金曜日の午後にお会いしましょう。」

**問題点：**
- 「明日」は送信時？ 受信時？ 23:50に送ると大きく違う。
- 「来週金曜」— 今週末の<ruby>直後<rt>ちょくご</rt></ruby>の金曜？ それともその次？ <ruby>解釈<rt>かいしゃく</rt></ruby>が分かれる。
- 「午後」— 13:00? 17:00?

## 良い例
> 「**5月15日（木）17:00までに**<ruby>報告書<rt>ほうこくしょ</rt></ruby>を<ruby>提出<rt>ていしゅつ</rt></ruby>してよろしいでしょうか？」
> 「**5月23日（金）14:00（JST）**にお会いしましょう。」

## <ruby>推奨<rt>すいしょう</rt></ruby>フォーマット
| <ruby>種類<rt>しゅるい</rt></ruby> | フォーマット |
|------|------------|
| 日付＋曜日 | 5月20日（火） |
| <ruby>時刻<rt>じこく</rt></ruby>付 | 5月20日（火）14:00 |
| <ruby>時差<rt>じさ</rt></ruby>付（海外<ruby>宛<rt>あて</rt></ruby>） | 5月20日（火）14:00（JST） |
| <ruby>日没<rt>にちぼつ</rt></ruby><ruby>締切<rt>しめきり</rt></ruby> | 5月20日（火）23:59まで |
| 日初締切 | 5月21日（水）09:00まで |
| <ruby>時間帯<rt>じかんたい</rt></ruby> | 5月20日（火）14:00–15:30 |

## よくある<ruby>罠<rt>わな</rt></ruby>
- **「週明け」** — 月曜？ 火曜？ 水曜？
- **「<ruby>月末<rt>げつまつ</rt></ruby>」** — 月の28日？ 31日？ <ruby>最終<rt>さいしゅう</rt></ruby><ruby>営業日<rt>えいぎょうび</rt></ruby>？
- **「なるべく早く」** — 1時間<ruby>以内<rt>いない</rt></ruby>？ 1日？ 1週間？

<ruby>数値<rt>すうち</rt></ruby>で書かないと、10人に10<ruby>通<rt>とお</rt></ruby>りに<ruby>解釈<rt>かいしゃく</rt></ruby>される。

## 使えるフレーズ
> **「曜日＋日付＋<ruby>時刻<rt>じこく</rt></ruby>＋（<ruby>時差<rt>じさ</rt></ruby>）。4<ruby>項目<rt>こうもく</rt></ruby>、全て<ruby>埋<rt>う</rt></ruby>める。」**
