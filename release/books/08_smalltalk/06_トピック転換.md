# Rule 06 — Chuyển chủ đề mượt / トピック転換
> **Luận điểm.** Chuyển chủ đề = nghệ thuật. Có **3 từ chuyển cốt lõi** (ところで / そういえば / 話は変わりますが) — mỗi cái dùng đúng tình huống. Đổi chủ đề phũ = "không đọc không khí". Không đổi khi cần đổi = bị mắc kẹt ở chủ đề đã chết.

---

## Tâm lý JP (3 dòng)
- Người Nhật rất nhạy với **cách chuyển chủ đề** — từ chuyển đúng = chuyên nghiệp, sai = vụng.
- 3 từ chuyển chính có sắc thái RẤT KHÁC: ところで (ngắt trang trọng) / そういえば (liên tưởng) / 話は変わりますが (chuyển hẳn sang).
- Thời điểm chuyển: khi (a) chủ đề cũ đã cạn / (b) khách lộ dấu hiệu chán / (c) cần kéo về công việc.

---

## Bối cảnh
3 từ chuyển chính + 2 từ chuyển phụ:

| Từ chuyển | Sắc thái | Khi dùng |
|-----------|----------|---------|
| **ところで** | Ngắt trang trọng, hơi chính thức | Khi cần đổi chủ đề rõ, có khoảng cách |
| **そういえば** | Liên tưởng ("nhân tiện nhớ ra") | Khi chủ đề mới có liên kết nhẹ với cũ |
| **話は変わりますが** | Chuyển chủ đề rõ ràng nhất | Khi chủ đề mới hoàn toàn khác |
| **(そう)言えば** | Thân mật hơn そういえば | L3-L4 |
| **あ、そうそう** | Nhắc lại kiểu thân mật | L3-L4 |

## 4 Scenario — hội thoại thực chiến
### Scenario 1 — そういえば: Nhân tiện liên kết nhẹ
*そういえば — liên kết "読み聞かせ" → 本*

| Vai | Câu |
|---------|-----|
| **中村** | 「…で、<ruby>孫<rt>まご</rt></ruby>が3<ruby>歳<rt>さい</rt></ruby>になってね、もうペラペラなんだよ。」 |
|  | *...Cháu 3 tuổi rồi, nói trôi chảy lắm.* |
| **ズン** | 「3歳でペラペラはすごい!」 |
|  | *3 tuổi mà nói trôi chảy thì giỏi quá!* |
| **中村** | 「いやあ、<ruby>母親<rt>ははおや</rt></ruby>(<ruby>嫁<rt>よめ</rt></ruby>)がよく<ruby>読み聞かせ<rt>よみきかせ</rt></ruby>してくれるからね。」 |
|  | *À, vì mẹ (con dâu) hay đọc sách cho cháu mà.* |
| **ズン** | 「**そういえば中村さん、最近何か面白い本<ruby>読まれました<rt>よまれました</rt></ruby>か?**」【1】 |
|  | *À nhân tiện anh Nakamura, dạo này anh có đọc sách gì thú vị không ạ?* |
| **中村** | 「最近?ああ、<ruby>池井戸潤<rt>いけいどじゅん</rt></ruby>の<ruby>新刊<rt>しんかん</rt></ruby>、<ruby>銀行<rt>ぎんこう</rt></ruby>ものでね…」 |
|  | *Dạo này à? À, tiểu thuyết mới của Ikeido Jun, về ngân hàng...* |

【1】 「そういえば」 = "à mà nhân tiện nhớ ra" — chủ đề mới (sách) **có liên kết nhẹ** với chủ đề cũ (đọc sách cho cháu). Chuyển mượt.

 Khi nào dùng: chủ đề mới + chủ đề cũ có 1 từ khóa chung trong đầu.

### Scenario 2 — ところで: Đổi rõ ràng nhưng vẫn trang trọng
*thấy chủ đề bóng chày đã 5 phút, nên ngắt*

| Vai | Câu |
|---------|-----|
| **大垣** | 「…で、<ruby>阪神<rt>はんしん</rt></ruby>は今シーズン、本当によくやってるんよ。」 |
|  | *...Hanshin mùa này chơi hay thật.* |
| **ズン** | 「<ruby>素晴らしい<rt>すばらしい</rt></ruby>ですね。**ところで大垣さん、来週の<ruby>出張<rt>しゅっちょう</rt></ruby>、<ruby>新大阪<rt>しんおおさか</rt></ruby>からでしたっけ?**」【2】 |
|  | *Tuyệt quá. À mà anh Ōgaki, công tác tuần sau từ Shin-Osaka phải không ạ?* |
| **大垣** | 「ああ、そうそう、新大阪から<ruby>朝イチ<rt>あさイチ</rt></ruby>で。」 |
|  | *À đúng, từ Shin-Osaka chuyến sớm nhất.* |

【2】 「ところで」 = ngắt trang trọng, **không cần liên kết từ khóa**. Dùng khi cần đổi rõ — đặc biệt từ không khí thân mật sang công việc hoặc ngược lại.

 Khi nào dùng: chủ đề cũ đã cạn / cần kéo về vấn đề khác / khách lỏng nhịp.

### Scenario 3 — 話は変わりますが: Chuyển 180 độ — trang trọng nhất
*cần đổi sang vấn đề công việc nhạy cảm · chuyển sang tông nghiêm túc*

| Vai | Câu |
|---------|-----|
| **松本** | 「…ハロン<ruby>湾<rt>わん</rt></ruby>、本当に<ruby>綺麗<rt>きれい</rt></ruby>でね、また行きたいわ。」 |
|  | *...Vịnh Hạ Long thật sự đẹp, tôi muốn quay lại.* |
| **ズン** | 「ぜひ次回ご<ruby>案内<rt>あんない</rt></ruby>させてください。**話は変わりますが**、<ruby>先日<rt>せんじつ</rt></ruby>の<ruby>予算<rt>よさん</rt></ruby>の<ruby>件<rt>けん</rt></ruby>、少しだけお時間よろしいでしょうか?」【3】 |
|  | *Lần sau xin được đưa anh đi. À đổi chủ đề một chút, vụ ngân sách hôm trước, em xin một chút thời gian được không ạ?* |
| **松本** | 「ああ、はいはい、どうぞ。」 |
|  | *À vâng vâng, em nói đi.* |

【3】 「話は変わりますが」 = chuyển chủ đề rõ ràng nhất, trang trọng cao. Báo hiệu "chủ đề sau khác hoàn toàn". Dùng khi:
- Chuyển từ 雑談 → công việc nghiêm túc.
- Chuyển sang chủ đề nhạy cảm cần khách tập trung.
- Khi không có liên kết tự nhiên giữa 2 chủ đề.

 KHÔNG dùng「話は変わりますが」 quá thường — bị xem là cứng.

### Scenario 4 — XẤU: Chuyển phũ, không từ chuyển
*đang kể về 飛騨牛 say sưa · NG — cắt phũ · cứng*

| Vai | Câu |
|---------|-----|
| **加藤** | 「…で、<ruby>飛騨牛<rt>ひだぎゅう</rt></ruby>のあの<ruby>霜降り<rt>しもふり</rt></ruby>がね、口の中で<ruby>溶ける<rt>とける</rt></ruby>んですよ、もう…」 |
|  | *...Vân mỡ Hida-gyu tan trong miệng, ngon lắm...* |
| **ズン** | 「**そうですか。来週の<ruby>納期<rt>のうき</rt></ruby>どうなりましたか?**」 |
|  | *Vậy ạ. Hạn giao tuần sau thế nào rồi ạ?* |
| **加藤** | 「…え、ああ…(內心: cắt giữa câu chuyện?)」 |
|  | *...ơ, à... (trong lòng: bị cắt giữa câu chuyện?)* |

 **Vì sao XẤU:** Không từ chuyển = phá nhịp đột ngột. "そうですか" + nhảy thẳng = lạnh, vô cảm. Khách đang hứng kể bị vứt giữa chừng.

 **Đúng:**

*đóng chủ đề cũ + chuyển sang mềm mại*

| Vai | Câu |
|---------|-----|
| **加藤** | 「…で、飛騨牛のあの霜降りがね、口の中で溶けるんですよ、もう…」 |
|  | *...Vân mỡ Hida-gyu tan trong miệng, ngon lắm...* |
| **ズン** | 「いやもう、<ruby>想像<rt>そうぞう</rt></ruby>しただけで<ruby>唾<rt>つば</rt></ruby>が出ます(笑)。次回<ruby>岐阜<rt>ぎふ</rt></ruby>行く時、<ruby>絶対<rt>ぜったい</rt></ruby>食べたいです。」 |
|  | *Hà, chỉ tưởng tượng đã chảy nước miếng. Lần sau đến Gifu em phải ăn cho được.* |
| **ズン** | 「**そろそろお時間も<ruby>気<rt>き</rt></ruby>になってきましたので、話は変わりますが、来週の納期の件、少し<ruby>相談<rt>そうだん</rt></ruby>させていただけますか?**」 |
|  | *Em cũng đang để ý đồng hồ, đổi chủ đề một chút, vụ hạn giao tuần sau em xin trao đổi một chút được không ạ?* |
| **加藤** | 「ああ、もちろん、どうぞ。」 |
|  | *À, tất nhiên, em nói đi.* |

→ Đóng chủ đề cũ với phản ứng ấm + từ chuyển trang trọng + báo lý do (お時間も) = chuyển mượt + giữ tôn trọng.

## Câu vàng copy-paste
```
■ そういえば — liên kết nhẹ:
「そういえば、〜って」
「そういえば、先日おっしゃってた〜、その後…」

■ ところで — ngắt trang trọng:
「ところで、〜の件ですが」
「ところで、来週の〜どうですか?」

■ 話は変わりますが — chuyển hẳn rõ:
「話は変わりますが、先日の〜の件、少しお時間よろしいでしょうか?」
「話は変わりますが、ちょっとお伺いしたいのですが…」

■ Thân mật (L3-L4):
「あ、そうそう、〜って…」
「(言)えば、〜って」

■ Đóng chủ đề cũ trước khi chuyển:
「いやあ、楽しいお話ありがとうございます。[từ chuyển]…」
「そろそろお時間気になってきましたので、[từ chuyển]…」

■ Bắc cầu từ không khí thân mật → công việc:
「お話の途中恐縮ですが、一点だけ…」
```

## NG — tuyệt đối tránh
- **Cắt phũ giữa câu khách kể** (không từ chuyển, không phản ứng) → khách cứng mặt.
- **Dùng「話は変わりますが」 liên tục** → cứng, máy móc.
- **Đổi chủ đề ngay sau khi khách chia sẻ chuyện riêng tư** (gia đình, sức khỏe) → cảm giác "không quan tâm thật".
- **Chuyển chủ đề khi khách đang lên đỉnh cảm xúc** (đang kể vui, đang xúc động) → phá khoảnh khắc.
- **Từ chuyển + chủ đề mới quá tương đồng** ("そういえば" + chủ đề không liên quan) → khách bối rối.

## BJT
**J3 — 場面把握:** Chọn từ chuyển đúng cho ngữ cảnh (trang trọng hay thân mật, có liên kết hay không).
**J2 — 表現読解:** Phân biệt sắc thái 3 từ chuyển chính + nhận biết câu báo hiệu trước khi chuyển chủ đề.
**J1 — 発言聴解:** Bắt tín hiệu "chủ đề đã cạn" (im lặng dài, phản ứng cụt) → biết khi nào chuyển chủ đề.
