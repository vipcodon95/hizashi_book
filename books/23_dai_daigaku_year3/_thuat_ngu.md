# Bảng thuật ngữ — Sách 23: Đại Đại học Năm 3

| Viết tắt | Dạng đầy đủ | Nghĩa tiếng Việt |
|----------|-------------|------------------|
| AP | 応用情報技術者試験 (Applied Information Technology Engineer) | Chứng chỉ kỹ thuật CNTT ứng dụng (Nhật) |

| ARPU | Average Revenue Per User | Doanh thu trung bình mỗi người dùng |

| BFS | Breadth-First Search | Thuật toán tìm kiếm theo chiều rộng |
| CoT | Chain of Thought | Kỹ thuật prompt "suy nghĩ từng bước" |

| ER | Entity-Relationship | Sơ đồ quan hệ thực thể (thiết kế DB) |
| GPA | Grade Point Average | Điểm trung bình tích lũy |

| JSON | JavaScript Object Notation | Định dạng dữ liệu chuẩn |
| JWT | JSON Web Token | Token xác thực người dùng |
| LLM | Large Language Model | Mô hình ngôn ngữ lớn |
| LoC | Lines of Code | Số dòng mã nguồn |

| MPS | Metal Performance Shaders | Framework tăng tốc GPU trên chip Apple Silicon |

| MVP | Minimum Viable Product | Sản phẩm khả dụng tối thiểu |

| NSP | Next Sentence Prediction | Dự đoán câu kế tiếp (task pre-train BERT) |
| OAuth | Open Authorization | Giao thức ủy quyền mở (đăng nhập Google/GitHub) |

| SDK | Software Development Kit | Bộ công cụ phát triển phần mềm |
| SRS | Spaced Repetition System | Hệ thống ôn lặp cách quãng (kiểu Anki) |
| TTS | Text-to-Speech | Chuyển văn bản thành giọng nói |
| UI/UX | User Interface / User Experience | Giao diện / Trải nghiệm người dùng |
| XLM-R | Cross-lingual Language Model - RoBERTa | Mô hình đa ngôn ngữ mạnh hơn mBERT (xử lý tiếng Việt tốt) |
| XML | Extensible Markup Language | Ngôn ngữ đánh dấu mở rộng |
