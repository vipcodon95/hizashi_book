# Bảng thuật ngữ — Sách 23: Đại Đại học Năm 3

> Các viết tắt & thuật ngữ chuyên ngành CNTT/AI dùng trong sách. Tra theo bảng chữ cái.

| Viết tắt | Dạng đầy đủ | Nghĩa tiếng Việt |
|----------|-------------|------------------|
| AP | 応用情報技術者試験 (Applied Information Technology Engineer) | Chứng chỉ CNTT ứng dụng quốc gia Nhật (cấp trên FE, do IPA cấp) |
| API | Application Programming Interface | Giao diện lập trình ứng dụng |
| ARPU | Average Revenue Per User | Doanh thu trung bình mỗi người dùng |
| BERT | Bidirectional Encoder Representations from Transformers | Mô hình NLP hai chiều của Google (2018) |
| BFS | Breadth-First Search | Thuật toán tìm kiếm theo chiều rộng |
| CoT | Chain of Thought | Kỹ thuật prompt yêu cầu LLM suy luận từng bước trước khi trả lời |
| CUDA | Compute Unified Device Architecture | Nền tảng lập trình tính toán song song trên GPU NVIDIA; dùng huấn luyện AI |
| ER | Entity-Relationship | Sơ đồ quan hệ thực thể (thiết kế DB) |
| GPA | Grade Point Average | Điểm trung bình tích lũy |
| GPT | Generative Pre-trained Transformer | Mô hình sinh văn bản của OpenAI |
| JLPT | Japanese Language Proficiency Test | Kỳ thi năng lực tiếng Nhật |
| JSON | JavaScript Object Notation | Định dạng trao đổi dữ liệu gọn nhẹ, phổ biến trong API |
| JWT | JSON Web Token | Chuẩn token dùng xác thực và trao đổi thông tin giữa client và server |
| LLM | Large Language Model | Mô hình ngôn ngữ lớn |
| LoC | Lines of Code | Số dòng mã nguồn — chỉ số đo quy mô code |
| LRU | Least Recently Used | Thuật toán thay thế cache — loại bỏ mục ít dùng gần đây nhất |
| mBERT | Multilingual BERT | Phiên bản BERT huấn luyện đa ngôn ngữ trên 104 ngôn ngữ |
| MLM | Masked Language Model | Task huấn luyện BERT: dự đoán từ bị che trong câu |
| MPS | Metal Performance Shaders | Framework tăng tốc tính toán trên GPU Apple Silicon (thay thế CUDA cho Mac) |
| MRR | Monthly Recurring Revenue | Doanh thu định kỳ hàng tháng |
| MVP | Minimum Viable Product | Sản phẩm khả dụng tối thiểu |
| N2 / N3 / N5 | JLPT Level 2 / 3 / 5 | Cấp độ năng lực tiếng Nhật (N5 sơ cấp → N1 cao cấp) |
| NER | Named Entity Recognition | Nhận dạng thực thể có tên |
| NLP | Natural Language Processing | Xử lý ngôn ngữ tự nhiên |
| NSP | Next Sentence Prediction | Task huấn luyện BERT: dự đoán câu B có nối tiếp câu A không |
| OAuth | Open Authorization | Giao thức ủy quyền truy cập — cho phép đăng nhập bằng Google/GitHub mà không cần chia sẻ mật khẩu |
| RAG | Retrieval-Augmented Generation | Kỹ thuật cho LLM tra cứu tài liệu trước khi sinh câu trả lời |
| RNN | Recurrent Neural Network | Mạng nơ-ron hồi quy |
| SDK | Software Development Kit | Bộ công cụ phát triển phần mềm |
| SRS | Spaced Repetition System | Hệ thống ôn tập cách quãng — ôn đúng lúc sắp quên để nhớ lâu (vd Anki) |
| TTS | Text-to-Speech | Công nghệ chuyển văn bản thành giọng nói tự động |
| UI/UX | User Interface / User Experience | Giao diện / Trải nghiệm người dùng |
| XLM-R | Cross-lingual Language Model - RoBERTa | Mô hình đa ngôn ngữ của Meta, mạnh hơn mBERT; xử lý tiếng Việt tốt |
| XML | Extensible Markup Language | Ngôn ngữ đánh dấu mở rộng |
