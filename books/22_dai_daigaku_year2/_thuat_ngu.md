# Bảng thuật ngữ — Sách 22: Đại Đại học Năm 2

> Các viết tắt & thuật ngữ chuyên ngành CNTT dùng trong sách. Tra theo bảng chữ cái.

| Viết tắt | Dạng đầy đủ | Nghĩa tiếng Việt |
|----------|-------------|------------------|
| ACID | Atomicity, Consistency, Isolation, Durability | Bốn tính chất đảm bảo giao dịch DB an toàn: Nguyên tử — Nhất quán — Độc lập — Bền vững |
| AP | 応用情報技術者試験 | Kỳ thi kỹ thuật viên thông tin ứng dụng (cấp cao hơn FE) |
| API | Application Programming Interface | Giao diện lập trình ứng dụng |
| AWS | Amazon Web Services | Nền tảng điện toán đám mây của Amazon |
| BCNF | Boyce-Codd Normal Form | Dạng chuẩn Boyce-Codd — chặt hơn 3NF, loại bỏ mọi phụ thuộc hàm ngoại lệ |
| BERT | Bidirectional Encoder Representations from Transformers | Mô hình ngôn ngữ tiền huấn luyện của Google |
| CI/CD | Continuous Integration / Continuous Delivery | Tích hợp liên tục / Triển khai liên tục |
| CSS | Cascading Style Sheets | Ngôn ngữ tạo kiểu dáng cho trang web |
| DB | Database | Cơ sở dữ liệu |
| DNS | Domain Name System | Hệ thống phân giải tên miền |
| DOM | Document Object Model | Mô hình đối tượng tài liệu — dùng JS để thao tác HTML |
| EC2 | Elastic Compute Cloud | Dịch vụ máy chủ ảo của AWS |
| ER | Entity-Relationship | Mô hình thực thể - quan hệ (dùng trong thiết kế DB) |
| ES6 | ECMAScript 6 | Phiên bản JavaScript chuẩn (2015+), còn gọi ES2015 |
| FE | 基本情報技術者試験 (Fundamental IT Engineer exam) | Kỳ thi kỹ thuật viên thông tin cơ bản Nhật Bản |
| FTP | File Transfer Protocol | Giao thức truyền tệp |
| GPA | Grade Point Average | Điểm trung bình tích lũy |
| HCI | Human-Computer Interaction | Tương tác người - máy tính |
| HTML | HyperText Markup Language | Ngôn ngữ đánh dấu siêu văn bản — cấu trúc trang web |
| HTTP | HyperText Transfer Protocol | Giao thức truyền siêu văn bản |
| HTTPS | HyperText Transfer Protocol Secure | HTTP được mã hóa qua TLS |
| ICMP | Internet Control Message Protocol | Giao thức kiểm soát thông điệp mạng |
| IP | Internet Protocol | Giao thức liên mạng |
| JLPT | Japanese Language Proficiency Test | Kỳ thi năng lực tiếng Nhật |
| JS | JavaScript | Ngôn ngữ lập trình web (phía trình duyệt và Node.js phía server) |
| JSON | JavaScript Object Notation | Định dạng trao đổi dữ liệu gọn nhẹ, phổ biến trong API |
| LLM | Large Language Model | Mô hình ngôn ngữ lớn — sinh văn bản (vd GPT, Claude, Gemini) |
| LT | Lightning Talk | Bài trình bày nhanh ~5 phút tại buổi meetup kỹ thuật |
| MAC | Media Access Control | Địa chỉ phần cứng của giao diện mạng |
| NLP | Natural Language Processing | Xử lý ngôn ngữ tự nhiên |
| OOM | Out of Memory | Hết bộ nhớ RAM — hệ thống buộc dừng tiến trình |
| OS | Operating System | Hệ điều hành |
| OSI | Open Systems Interconnection | Mô hình OSI 7 tầng cho giao tiếp mạng |
| OSS | Open Source Software | Phần mềm mã nguồn mở |
| PR | Pull Request | Yêu cầu gộp code vào nhánh chính trên GitHub |
| RAG | Retrieval-Augmented Generation | Kỹ thuật cho LLM tra cứu tài liệu trước khi sinh câu trả lời |
| RDBMS | Relational Database Management System | Hệ quản trị cơ sở dữ liệu quan hệ |
| RDS | Relational Database Service | Dịch vụ DB quan hệ của AWS |
| RPC | Remote Procedure Call | Cơ chế gọi hàm trên máy chủ từ xa như thể gọi hàm cục bộ |
| S3 | Simple Storage Service | Dịch vụ lưu trữ đối tượng của AWS |
| SDK | Software Development Kit | Bộ công cụ phát triển phần mềm |
| SMTP | Simple Mail Transfer Protocol | Giao thức gửi thư điện tử |
| SQL | Structured Query Language | Ngôn ngữ truy vấn cơ sở dữ liệu |
| SRS | Spaced Repetition System | Hệ thống ôn tập cách quãng — ôn đúng lúc sắp quên để nhớ lâu (vd Anki) |
| SSL | Secure Sockets Layer | Giao thức bảo mật (tiền thân TLS) |
| TCP | Transmission Control Protocol | Giao thức truyền dữ liệu đáng tin cậy, đảm bảo thứ tự gói tin |
| TLS | Transport Layer Security | Giao thức bảo mật lớp vận chuyển |
| TTS | Text-to-Speech | Công nghệ chuyển văn bản thành giọng nói tự động |
| UDP | User Datagram Protocol | Giao thức truyền nhanh, không kết nối, không đảm bảo thứ tự gói tin |
| UI | User Interface | Giao diện người dùng |
| URL | Uniform Resource Locator | Địa chỉ tài nguyên trên mạng |
| UX | User Experience | Trải nghiệm người dùng |
| VPS | Virtual Private Server | Máy chủ ảo riêng |
