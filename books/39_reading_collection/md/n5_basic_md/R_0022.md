## Bài 22 · 好きなゲーム — _Game yêu thích_

### Bài đọc

私はゲームが好きです。毎日家でゲームをします。好きなゲームはRPGです。RPGは冒険のゲームです。友達のたけしさんもゲームが好きです。週末にたけしさんと一緒にゲームをします。とても楽しいです。

### Câu hỏi

**Q1. 好きなゲームは何ですか。**

- A. サッカーのゲームです。
- B. RPGです。冒険のゲームです。
- C. パズルのゲームです。
- D. レースのゲームです。

**Q2. だれとゲームをしますか。**

- A. 一人でします。
- B. 家族とします。
- C. 友達のたけしさんとします。
- D. 先生とします。

---

### Bản dịch

Tôi thích game. Mỗi ngày tôi chơi game ở nhà. Game yêu thích của tôi là RPG. RPG là game phiêu lưu. Bạn tôi là Takeshi cũng thích game. Cuối tuần tôi chơi game cùng Takeshi. Rất vui.

### Đáp án & giải thích

**Q1.** 好きなゲームは何ですか。
  _Game yêu thích là gì?_

- **Đáp án đúng**: **B**. RPGです。冒険のゲームです。
  - A. サッカーのゲームです。 — *Là game bóng đá.*
  - **B. RPGです。冒険のゲームです。 — Là RPG. Là game phiêu lưu.**
  - C. パズルのゲームです。 — *Là game xếp hình.*
  - D. レースのゲームです。 — *Là game đua xe.*

- **Giải thích**: Câu 3 nói 「好きなゲームはRPGです」và câu 4 giải thích 「RPGは冒険のゲームです」→ game yêu thích là RPG, game phiêu lưu.

**Q2.** だれとゲームをしますか。
  _Chơi game với ai?_

- **Đáp án đúng**: **C**. 友達のたけしさんとします。
  - A. 一人でします。 — *Chơi một mình.*
  - B. 家族とします。 — *Chơi với gia đình.*
  - **C. 友達のたけしさんとします。 — Chơi với bạn là Takeshi.**
  - D. 先生とします。 — *Chơi với giáo viên.*

- **Giải thích**: Câu 6 nói 「たけしさんと一緒にゲームをします」→ と chỉ đối tác = chơi cùng bạn Takeshi.

### Phân tích từng câu

**Câu 1.** 私はゲームが好きです。

- **Văn**: 私は / ゲームが / 好きです
- **Dẫn**: は chủ đề 'tôi' → が chỉ đối tượng yêu thích → 好きです khẳng định sở thích
- **Dịch**: Tôi thích game.

**Câu 2.** 毎日家でゲームをします。

- **Văn**: 毎日 / 家で / ゲームを / します
- **Dẫn**: 毎日 thời gian → で chỉ nơi hành động 'ở nhà' → を đối tượng → します hành động
- **Dịch**: Mỗi ngày tôi chơi game ở nhà.

**Câu 3.** 好きなゲームはRPGです。

- **Văn**: 好きなゲームは / RPGです
- **Dẫn**: は chủ đề 'game yêu thích' → です khẳng định = RPG
- **Dịch**: Game yêu thích của tôi là RPG.

**Câu 4.** RPGは冒険のゲームです。

- **Văn**: RPGは / 冒険のゲームです
- **Dẫn**: は chủ đề 'RPG' → の liên kết 'phiêu lưu' + 'game' → です khẳng định
- **Dịch**: RPG là game phiêu lưu.

**Câu 5.** 友達のたけしさんもゲームが好きです。

- **Văn**: 友達のたけしさんも / ゲームが / 好きです
- **Dẫn**: の liên kết 'bạn' + 'Takeshi' → も 'cũng' giống tôi → が đối tượng → 好きです khẳng định
- **Dịch**: Bạn tôi là Takeshi cũng thích game.

**Câu 6.** 週末にたけしさんと一緒にゲームをします。

- **Văn**: 週末に / たけしさんと / 一緒に / ゲームを / します
- **Dẫn**: に chỉ thời gian 'cuối tuần' → と chỉ đối tác 'cùng Takeshi' → を đối tượng → します hành động
- **Dịch**: Cuối tuần tôi chơi game cùng Takeshi.

**Câu 7.** とても楽しいです。

- **Văn**: とても / 楽しいです
- **Dẫn**: とても nhấn mạnh → 楽しいです khẳng định cảm xúc vui. Câu kết thúc bằng cảm nhận
- **Dịch**: Rất vui.
