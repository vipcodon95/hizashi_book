# Bảng thuật ngữ — Sách 25: Đại BrSE Năm 1

> Các viết tắt & thuật ngữ chuyên ngành BrSE/CNTT/startup dùng trong sách. Tra theo bảng chữ cái.

| Viết tắt | Dạng đầy đủ | Nghĩa tiếng Việt |
|----------|-------------|------------------|
| AI | Artificial Intelligence | Trí tuệ nhân tạo |
| API | Application Programming Interface | Giao diện lập trình ứng dụng — cầu nối để các hệ thống phần mềm giao tiếp với nhau |
| ARR | Annual Recurring Revenue | Doanh thu định kỳ hàng năm (ARR = MRR × 12) |
| AWS | Amazon Web Services | Dịch vụ điện toán đám mây của Amazon |
| BD | Business Development | Phát triển kinh doanh — tìm kiếm khách hàng và đối tác mới |
| BGE-M3 | BAAI General Embedding Multilingual v3 | Mô hình nhúng văn bản đa ngôn ngữ — dùng để tìm kiếm theo nghĩa trong hệ thống AI |
| BrSE | Bridge System Engineer | Kỹ sư cầu nối — phụ trách dịch tài liệu kỹ thuật JP↔VN và điều phối giữa khách hàng Nhật và đội dev Việt |
| CAC | Customer Acquisition Cost | Chi phí để có được một khách hàng mới (marketing + sales / số khách mới) |
| CEO | Chief Executive Officer | Giám đốc điều hành |
| CPU | Central Processing Unit | Bộ xử lý trung tâm; trong ngữ cảnh sách dùng để chỉ mức tải tính toán của server |
| CTO | Chief Technology Officer | Giám đốc công nghệ |
| ECS | Amazon Elastic Container Service | Dịch vụ chạy container Docker trên AWS — Fargate là chế độ serverless (không cần quản lý server) của ECS |
| GPT | Generative Pre-trained Transformer | Kiến trúc mô hình ngôn ngữ lớn của OpenAI (GPT-4o xuất hiện trong đề xuất tech stack của sách) |
| HCI | Human-Computer Interaction | Tương tác người-máy tính (Aiko học M1 tại Watanabe HCI Lab) |
| JLPT | Japanese Language Proficiency Test | Kỳ thi năng lực tiếng Nhật (N5→N1) |
| KPI | Key Performance Indicator | Chỉ số đo lường hiệu suất then chốt |
| LLM | Large Language Model | Mô hình ngôn ngữ lớn (vd Claude, GPT-4o) |
| LTV | Lifetime Value | Tổng doanh thu kỳ vọng thu được từ một khách hàng trong suốt thời gian sử dụng dịch vụ |
| MRR | Monthly Recurring Revenue | Doanh thu định kỳ hàng tháng — chỉ số tăng trưởng cốt lõi của SaaS |
| PM | Project Manager | Quản lý dự án |
| QA | Quality Assurance | Đảm bảo chất lượng — kiểm thử và kiểm soát chất lượng phần mềm |
| RAG | Retrieval-Augmented Generation | Kiến trúc AI kết hợp tra cứu tài liệu với sinh văn bản — nền tảng AI Tutor của Hizashi |
| ROI | Return on Investment | Tỷ suất hoàn vốn đầu tư |
| SaaS | Software as a Service | Phần mềm dạng dịch vụ — mô hình thuê bao trả phí định kỳ (mô hình kinh doanh của Hizashi) |
| SRS | Spaced Repetition System | Hệ thống ôn tập cách quãng (kiểu Anki) — thuật toán ôn từ vựng khoa học |
| TTS | Text-to-Speech | Chuyển văn bản thành giọng nói — tính năng phát âm trong app Hizashi |
| UI | User Interface | Giao diện người dùng |
