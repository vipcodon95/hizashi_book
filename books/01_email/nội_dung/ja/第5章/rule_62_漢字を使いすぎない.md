# Rule 62 — 漢字を使いすぎない、ひらがなで読みやすく

> **要点.** 連続する漢字の<ruby>塊<rt>かたまり</rt></ruby>は視覚的に重く、読み<ruby>疲<rt>づか</rt></ruby>れを<ruby>誘<rt>さそ</rt></ruby>う。同じ意味でも**ひらがなに開く**ことで軽くなる場合が多い。ただし<ruby>専門用語<rt>せんもんようご</rt></ruby>や<ruby>公式文書<rt>こうしきぶんしょ</rt></ruby>では<ruby>適切<rt>てきせつ</rt></ruby>な漢字使用が<ruby>望<rt>のぞ</rt></ruby>ましい — 場面に<ruby>応<rt>おう</rt></ruby>じた<ruby>判断<rt>はんだん</rt></ruby>が必要。
>
> キーワード：**「漢字を開く」**。

## 漢字→ひらがな対照例

| 漢字表記（重い） | ひらがな（軽い） |
|----------------|--------------|
| <ruby>出来<rt>でき</rt></ruby>る／<ruby>出来<rt>でき</rt></ruby>ません | できる／できません |
| <ruby>致<rt>いた</rt></ruby>します | いたします |
| <ruby>宜<rt>よろ</rt></ruby>しく | よろしく |
| <ruby>於<rt>お</rt></ruby>いて | において |
| <ruby>様々<rt>さまざま</rt></ruby> | さまざま |
| <ruby>事<rt>こと</rt></ruby>／<ruby>物<rt>もの</rt></ruby>／<ruby>時<rt>とき</rt></ruby> | こと／もの／とき |
| <ruby>下<rt>くだ</rt></ruby>さい | ください |
| <ruby>御礼<rt>おれい</rt></ruby>／<ruby>御願<rt>おねが</rt></ruby>い | お礼／お願い |
| <ruby>有難<rt>ありがと</rt></ruby>う | ありがとう |
| <ruby>何卒<rt>なにとぞ</rt></ruby> | ※正式な場面では漢字も可 |

## 悪い例（漢字過多）

> 「<ruby>此度<rt>このたび</rt></ruby>の<ruby>件<rt>けん</rt></ruby>に<ruby>於<rt>お</rt></ruby>きましては、<ruby>下記事項<rt>かきじこう</rt></ruby>を<ruby>宜<rt>よろ</rt></ruby>しく<ruby>御願<rt>おねが</rt></ruby>い<ruby>致<rt>いた</rt></ruby>します。」

## 良い例（バランス）

> 「この<ruby>度<rt>たび</rt></ruby>の<ruby>件<rt>けん</rt></ruby>につきまして、<ruby>下記事項<rt>かきじこう</rt></ruby>をよろしくお願いいたします。」

同じ<ruby>内容<rt>ないよう</rt></ruby>、読みやすさが<ruby>大幅<rt>おおはば</rt></ruby><ruby>向上<rt>こうじょう</rt></ruby>。

## 漢字を使うべき場面

- <ruby>専門用語<rt>せんもんようご</rt></ruby>（<ruby>法務<rt>ほうむ</rt></ruby>、<ruby>金融<rt>きんゆう</rt></ruby>）。
- <ruby>公式文書<rt>こうしきぶんしょ</rt></ruby>（<ruby>契約書<rt>けいやくしょ</rt></ruby>、公式レター）。
- ひらがなが見た目に<ruby>幼稚<rt>ようち</rt></ruby>すぎる<ruby>文脈<rt>ぶんみゃく</rt></ruby>。

## 使えるフレーズ

> **「ひらがなで書ける<ruby>事<rt>こと</rt></ruby>は、ひらがなで。メールが軽く、読みやすくなる。」**
