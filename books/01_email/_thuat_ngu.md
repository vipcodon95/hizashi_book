# Bảng thuật ngữ — Sách 01: Email công việc tiếng Nhật

> Các viết tắt chuyên ngành dùng trong sách. Tra theo bảng chữ cái.

| Viết tắt | Dạng đầy đủ | Nghĩa tiếng Việt |
|----------|-------------|------------------|
| API | Application Programming Interface | Giao diện lập trình ứng dụng |
| BCC | Blind Carbon Copy | Gửi ẩn danh — người nhận ở dòng To/Cc không thấy tên người được BCC |
| BD | Business Development | Phát triển kinh doanh (chức danh) |
| CC | Carbon Copy | Gửi đồng kính — tên người được CC hiển thị công khai cho tất cả người nhận |
| CISSP | Certified Information Systems Security Professional | Chứng chỉ bảo mật thông tin quốc tế |
| CRM | Customer Relationship Management | Phần mềm quản lý quan hệ khách hàng |
| CS | Customer Support / Customer Service | Bộ phận hỗ trợ / chăm sóc khách hàng |
| CTA | Call to Action | Yêu cầu hành động — phần email nêu rõ người nhận cần làm gì và trước khi nào |
| CTO | Chief Technology Officer | Giám đốc Kỹ thuật |
| DAST | Dynamic Application Security Testing | Kiểm thử bảo mật ứng dụng theo phương pháp động |
| DB | Database | Cơ sở dữ liệu |
| FE | Front-End | Kỹ thuật giao diện người dùng (lập trình phía trình duyệt) |
| FW | Forwarded | Chuyển tiếp email — tiêu đề email chuyển tiếp thường bắt đầu bằng "FW:" |
| FYI | For Your Information | Để bạn biết — thường dùng trong tiêu đề email thông báo, không yêu cầu phản hồi |
| GMT | Greenwich Mean Time | Giờ quốc tế (múi giờ gốc UTC+0) |
| HTML | HyperText Markup Language | Ngôn ngữ đánh dấu siêu văn bản — dùng để định dạng email dạng rich text |
| ISO | International Organization for Standardization | Tổ chức Tiêu chuẩn Quốc tế — trong sách dùng cụ thể "ISO 27001" (tiêu chuẩn bảo mật thông tin) |
| IT | Information Technology | Công nghệ thông tin (bộ phận hoặc lĩnh vực) |
| JST | Japan Standard Time | Giờ chuẩn Nhật Bản (UTC+9) |
| MVP | Minimum Viable Product | Sản phẩm khả dụng tối thiểu — phiên bản đủ dùng để ra mắt sớm |
| PDF | Portable Document Format | Định dạng tài liệu cố định — dùng cho hợp đồng, báo giá, biên bản họp |
| PII | Personally Identifiable Information | Thông tin định danh cá nhân — dữ liệu có thể dùng để nhận dạng một người cụ thể |
| PM | Project Manager | Quản lý dự án |
| PO | Purchase Order | Đơn đặt hàng chính thức từ bên mua gửi bên bán |
| QA | Quality Assurance | Đảm bảo chất lượng |
| SAST | Static Application Security Testing | Kiểm thử bảo mật ứng dụng theo phương pháp tĩnh |
| UI | User Interface | Giao diện người dùng |
| UTF | Unicode Transformation Format | Chuẩn mã hóa ký tự Unicode — thường gặp dạng UTF-8, đảm bảo hiển thị đúng tiếng Việt và tiếng Nhật |
| UX | User Experience | Trải nghiệm người dùng |
