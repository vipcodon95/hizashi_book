# Bảng thuật ngữ — Sách 19: Đại Năm 1

> Các viết tắt & thuật ngữ chuyên ngành (du học, thi cử) dùng trong sách. Tra theo bảng chữ cái.

| Viết tắt | Dạng đầy đủ | Nghĩa tiếng Việt |
|----------|-------------|------------------|
| CV | Curriculum Vitae / 履歴書 (りれきしょ) | Sơ yếu lý lịch / hồ sơ xin việc |
| EJU | Examination for Japanese University Admission / 日本留学試験 (にほんりゅうがくしけん) | Kỳ thi tuyển sinh đại học Nhật Bản dành cho du học sinh (2 đợt/năm: tháng 6 & 11) |
| GPA | Grade Point Average | Điểm trung bình học tập (hệ 4.0 hoặc %) |
| ICOCA | IC Operating CArd | Thẻ IC giao thông của JR West (Kansai); dùng tàu, xe buýt, mua sắm tại cửa hàng |
| IG | Instagram | Mạng xã hội Instagram |
| JLPT | Japanese Language Proficiency Test / 日本語能力試験 (にほんごのうりょくしけん) | Kỳ thi năng lực tiếng Nhật (5 cấp: N5 → N1; 2 đợt/năm: tháng 7 & 12) |
| JR | Japan Railways / 日本旅客鉄道 | Hệ thống đường sắt quốc gia Nhật Bản |
| LINE | LINE (ứng dụng nhắn tin) | Ứng dụng nhắn tin / gọi video phổ biến tại Nhật Bản và Đông Nam Á |
| N1 | JLPT Level N1 | Cấp độ N1 — cao nhất trong kỳ thi JLPT |
| N2 | JLPT Level N2 | Cấp độ N2 — tương đương tiếng Nhật thực dụng trung-cao |
| N3 | JLPT Level N3 | Cấp độ N3 — tương đương tiếng Nhật sơ-trung cấp |
| N4 | JLPT Level N4 | Cấp độ N4 — tương đương tiếng Nhật sơ cấp |
| N5 | JLPT Level N5 | Cấp độ N5 — thấp nhất trong kỳ thi JLPT |
| POS | Point of Sale | Hệ thống thanh toán tại quầy thu ngân (máy tính tiền tích hợp) |
| PPT | PowerPoint | Phần mềm / file trình chiếu Microsoft PowerPoint |
| Q&A | Questions and Answers | Phần hỏi đáp sau thuyết trình |
| QR | QR Code / Quick Response Code | Mã vạch 2 chiều dùng để thanh toán hoặc truy cập thông tin |
| SV | Sinh viên | Học viên / sinh viên (viết tắt thông dụng trong tiếng Việt) |
