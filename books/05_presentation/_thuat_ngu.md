# Bảng thuật ngữ — Sách 05: Presentation

> Các viết tắt chuyên ngành dùng trong sách. Tra theo bảng chữ cái.

| Viết tắt | Dạng đầy đủ | Nghĩa tiếng Việt |
|----------|-------------|------------------|
| API | Application Programming Interface | Giao diện lập trình ứng dụng |
| B2B | Business to Business | Mô hình kinh doanh giữa doanh nghiệp với doanh nghiệp (đối lập với B2C — bán trực tiếp cho người tiêu dùng) |
| BD | Business Development | Phát triển kinh doanh (chức danh nhân sự) |
| BJT | Business Japanese Test | Kỳ thi tiếng Nhật thương mại (do JETRO tổ chức; cấp J5 thấp nhất đến J1 cao nhất) |
| CFO | Chief Financial Officer | Giám đốc tài chính |
| CTA | Call to Action | Lời kêu gọi hành động (bước tiếp theo rõ ràng) |
| CTO | Chief Technology Officer | Giám đốc công nghệ |
| HDMI | High-Definition Multimedia Interface | Cổng kết nối hiển thị độ phân giải cao |
| ISO 27001 | ISO/IEC 27001 | Tiêu chuẩn quốc tế về bảo mật thông tin |
| JST | Japan Standard Time | Giờ chuẩn Nhật Bản (UTC+9) |
| KPI | Key Performance Indicator | Chỉ số hiệu suất chính |
| MP4 | MPEG-4 Part 14 | Định dạng file video phổ biến |
| OAuth 2.0 | Open Authorization 2.0 | Giao thức ủy quyền truy cập mở phiên bản 2.0 — cho phép đăng nhập bên thứ ba mà không chia sẻ mật khẩu |
| PDF | Portable Document Format | Định dạng tài liệu cố định — giữ nguyên bố cục khi in hoặc gửi (do Adobe phát triển) |
| PM | Project Manager | Quản lý dự án (chức danh) |
| PMO | Project Management Office | Phòng / bộ phận quản lý dự án |
| Q&A | Questions and Answers | Phiên hỏi đáp |
| REST | Representational State Transfer | Kiến trúc API dựa trên HTTP, phổ biến trong tích hợp hệ thống |
| ROI | Return on Investment | Tỷ suất hoàn vốn đầu tư |
| SKU | Stock Keeping Unit | Đơn vị lưu kho (mã sản phẩm) |
| SME | Small and Medium Enterprise | Doanh nghiệp vừa và nhỏ |
| SOAP | Simple Object Access Protocol | Giao thức truyền dữ liệu dựa trên XML — thường gặp trong các hệ thống doanh nghiệp cũ |
| TBD | To Be Determined | Chưa xác định (nên tránh dùng trong roadmap) |
| UAT | User Acceptance Testing | Kiểm thử chấp nhận người dùng — người dùng thực tế xác nhận hệ thống đáp ứng yêu cầu trước khi bàn giao |
| URL | Uniform Resource Locator | Địa chỉ đường dẫn trên internet |
| USB | Universal Serial Bus | Cổng kết nối / thiết bị lưu trữ USB |
| VGA | Video Graphics Array | Cổng kết nối màn hình cũ (D-Sub 15 pin) |
