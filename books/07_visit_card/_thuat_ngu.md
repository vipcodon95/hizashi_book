# Bảng thuật ngữ — Sách 07: Visit Card

> Các viết tắt chuyên ngành dùng trong sách. Tra theo bảng chữ cái.

| Viết tắt | Dạng đầy đủ | Nghĩa tiếng Việt |
|----------|-------------|------------------|
| API | Application Programming Interface | Giao diện lập trình ứng dụng |
| ATM | Automated Teller Machine | Máy rút tiền tự động |
| BCC | Blind Carbon Copy | Ẩn người nhận trong email (đại kỵ trong email cảm ơn kinh doanh Nhật) |
| BD | Business Development | Phát triển kinh doanh |
| BJT | Business Japanese Test | Kỳ thi tiếng Nhật thương mại (tương đương TOEIC của JP) |
| CC | Carbon Copy | Sao chép email — gửi kèm cho người liên quan |
| CFO | Chief Financial Officer | Giám đốc tài chính |
| CRM | Customer Relationship Management | Hệ thống quản lý quan hệ khách hàng |
| CTO | Chief Technology Officer | Giám đốc công nghệ |
| DB | Database | Cơ sở dữ liệu |
| IC | Integrated Circuit (card) | Thẻ IC (Suica/Pasmo — thẻ giao thông thông minh Nhật) |
| IP | Intellectual Property | Sở hữu trí tuệ |
| JR | Japan Railways | Tập đoàn đường sắt Nhật Bản |
| NDA | Non-Disclosure Agreement | Thỏa thuận bảo mật thông tin (kể cả dạng ngầm hiểu khi tham quan nhà máy/văn phòng Nhật) |
| PDF | Portable Document Format | Định dạng tài liệu điện tử (thường dùng cho agenda, biên bản họp) |
| PM | Project Manager | Quản lý dự án |
| PMO | Project Management Office | Văn phòng / bộ phận điều phối quản lý dự án |
| PR | Public Relations | Quan hệ công chúng |
| RFP | Request for Proposal | Văn bản yêu cầu đề xuất / mời thầu |
| SNS | Social Networking Service | Mạng xã hội (thuật ngữ phổ biến ở Nhật: Facebook, LinkedIn, LINE...) |
| TEL | Telephone | Số điện thoại (ký hiệu trên danh thiếp) |
| VND | Vietnamese Dong | Đồng Việt Nam |
