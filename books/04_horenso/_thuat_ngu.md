# Bảng thuật ngữ — Sách 04: Horenso

> Các viết tắt chuyên ngành dùng trong sách. Tra theo bảng chữ cái.

| Viết tắt | Dạng đầy đủ | Nghĩa tiếng Việt |
|----------|-------------|------------------|
| API | Application Programming Interface | Giao diện lập trình ứng dụng |
| ASAP | As Soon As Possible | Càng sớm càng tốt |
| AWS | Amazon Web Services | Dịch vụ đám mây Amazon |
| BD | Business Development | Phát triển kinh doanh |
| BJT | Business Japanese Test | Kỳ thi tiếng Nhật thương mại |
| BU | Business Unit | Đơn vị kinh doanh |
| CC | Carbon Copy | Người nhận sao (email) |
| CEO | Chief Executive Officer | Tổng giám đốc điều hành |
| CFO | Chief Financial Officer | Giám đốc tài chính |
| CI/CD | Continuous Integration / Continuous Delivery | Tích hợp liên tục / Phân phối liên tục |
| CTO | Chief Technology Officer | Giám đốc công nghệ |
| DB | Database | Cơ sở dữ liệu |
| DDBN | Done / Doing / Blocked / Next | Format báo cáo tiến độ 4 block (khái niệm trong sách) |
| DM | Direct Message | Tin nhắn riêng (Slack/chat) |
| DR | Decision Register | Sổ ghi quyết định (lưu vết tham vấn) |
| EOD | End of Day | Cuối ngày làm việc |
| ETA | Estimated Time of Arrival | Thời điểm / thời hạn dự kiến hoàn thành (trong công việc dùng nghĩa "dự kiến xong lúc nào") |
| FE | Front-End | Lập trình phía giao diện người dùng |
| GRCA | Goal / Result / Cause / Action | Framework báo cáo kết quả 4 bước (khái niệm trong sách) |
| HR | Human Resources | Phòng nhân sự |
| ICT | Indochina Time | Múi giờ Đông Dương, UTC+7 (Việt Nam, Thái Lan, Campuchia) |
| IT | Information Technology | Công nghệ thông tin |
| JST | Japan Standard Time (UTC+9) | Múi giờ Nhật Bản |
| KPI | Key Performance Indicator | Chỉ số đánh giá hiệu suất |
| KPT | Keep / Problem / Try | Framework retrospective 3 nhóm |
| NPS | Net Promoter Score | Chỉ số đo mức độ hài lòng khách hàng |
| OKR | Objectives and Key Results | Mục tiêu và kết quả then chốt |
| PDF | Portable Document Format | Định dạng tài liệu chuẩn (file PDF) |
| PFIPA | Predict / Fact / Impact / Plan / Ask | Framework báo cáo tin xấu 5 bước (khái niệm trong sách) |
| PIC | Person In Charge | Người phụ trách / chịu trách nhiệm |
| PM | Project Manager | Quản lý dự án |
| PMO | Project Management Office | Văn phòng quản lý dự án |
| PR | Pull Request | Yêu cầu merge code (Git) |
| RCA | Root Cause Analysis | Phân tích nguyên nhân gốc rễ |
| SLA | Service Level Agreement | Thỏa thuận mức độ dịch vụ |
| SMART | Specific / Measurable / Achievable / Relevant / Time-bound | Tiêu chí đặt mục tiêu rõ ràng, đo được |
| SOD | Start of Day | Đầu ngày làm việc |
| TL;DR | Too Long; Didn't Read | Tóm tắt ngắn (đặt đầu email/tin) |
| UAT | User Acceptance Testing | Kiểm thử nghiệm thu người dùng |
| URL | Uniform Resource Locator | Đường dẫn / link trang web |
| UTC | Coordinated Universal Time | Giờ phối hợp quốc tế (giờ chuẩn thế giới) |
| WFH | Work From Home | Làm việc tại nhà (remote) |
