# Bảng thuật ngữ — Sách 02: Điện thoại công việc tiếng Nhật

> Các viết tắt chuyên ngành dùng trong sách. Tra theo bảng chữ cái.

| Viết tắt | Dạng đầy đủ | Nghĩa tiếng Việt |
|----------|-------------|------------------|
| AI | Artificial Intelligence | Trí tuệ nhân tạo |
| API | Application Programming Interface | Giao diện lập trình ứng dụng |
| ASAP | As Soon As Possible | Càng sớm càng tốt — nên tránh dùng khi nói tiếng Nhật, thay bằng「至急」 |
| BD | Business Development | Phát triển kinh doanh (chức danh) |
| BJT | Business Japanese Test | Kỳ thi tiếng Nhật thương mại (ビジネス日本語能力テスト) |
| CFO | Chief Financial Officer | Giám đốc Tài chính |
| CRM | Customer Relationship Management | Phần mềm quản lý quan hệ khách hàng |
| CTO | Chief Technology Officer | Giám đốc Kỹ thuật |
| ETA | Estimated Time of Arrival | Thời gian dự kiến hoàn thành hoặc đến nơi |
| FE | Front-End | Kỹ thuật giao diện người dùng (lập trình phía trình duyệt) |
| FYI | For Your Information | Để bạn biết — nên tránh dùng khi nói tiếng Nhật, thay bằng「ご参考までに」 |
| IT | Information Technology | Công nghệ thông tin (bộ phận hoặc lĩnh vực) |
| KPI | Key Performance Indicator | Chỉ số hiệu suất chính |
| PDF | Portable Document Format | Định dạng tài liệu cố định |
| PM | Project Manager | Quản lý dự án |
