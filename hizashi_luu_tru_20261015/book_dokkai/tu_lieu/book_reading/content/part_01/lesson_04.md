# Bài 4: Trợ từ quan hệ - と・から・まで・より

> Nhóm này thể hiện quan hệ giữa các thành phần: cùng ai, từ đâu, đến đâu, so với gì.

---

## と (to)

### Cách dùng 1: Cùng với (đồng hành)

```
友達と / 映画を / 見ました。 → Cùng bạn, phim, đã xem.
家族と / 旅行します。       → Cùng gia đình, du lịch.
```

### Cách dùng 2: Liệt kê đầy đủ (A và B - chỉ bấy nhiêu)

```
りんごと / みかんを / 買いました。 → Táo và cam, đã mua. (Chỉ 2 thứ)
犬と / 猫が / います。             → Chó và mèo, có.
```

### Cách dùng 3: Trích dẫn

```
「おはよう」と / 言いました。     → "Ohayou" rằng, đã nói.
先生は「静かに」と / 言いました。 → Thầy "im lặng" rằng, đã nói.
彼は行くと / 思います。           → Anh ấy đi rằng, nghĩ.
```

### Cách dùng 4: Điều kiện tự nhiên / Tất yếu

```
春になると / 桜が咲きます。       → Hễ đến xuân, anh đào nở.
このボタンを押すと / ドアが開きます。→ Hễ bấm nút này, cửa mở.
→ Kết quả xảy ra TẤT YẾU, không phải giả thuyết.
```

> **Cấm:** Không dùng と cho ý chí / mệnh lệnh ở vế sau.
> ⚠️ 雨が降ると、行きません -- Trong JLPT/sách giáo khoa, vế sau của と không nên chứa ý chí/mệnh lệnh. Dùng たら: ✅ 雨が降ったら、行きません. Lưu ý: trong tiếng Nhật tự nhiên, ranh giới này linh hoạt hơn.

### Cách dùng 5: Tương tác hai chiều

```
先生と / 話しました。     → Nói chuyện VỚI thầy. (2 bên cùng tham gia)
→ Khác với: 先生に話しました → Nói với thầy (một chiều, báo cáo)

友達と / 相談しました。   → Bàn bạc VỚI bạn.
```

### Cách dùng 6: Điều kiện tự nhiên / Tất yếu (hễ...thì)

```
春になると / 桜が咲きます。           → Hễ đến xuân, anh đào nở.
このボタンを押すと / ドアが開きます。 → Hễ bấm nút này, cửa mở.
ここをまっすぐ行くと / 右に銀行があります。→ Đi thẳng đây thì, bên phải có ngân hàng.
```

> **Đặc điểm:** Kết quả xảy ra TẤT YẾU, không phải giả thuyết.
> Không dùng ý chí / mệnh lệnh ở vế sau.
> Phổ biến khi chỉ đường, mô tả quy luật, hướng dẫn sử dụng.

### Mũi tên dự báo

```
[Người]と   → Sắp làm gì đó CÙNG NHAU
[N1]と[N2]  → Liệt kê đầy đủ
「」と       → Sắp có 言う/思う/聞く (nói/nghĩ/nghe)
[V]と       → Sắp có KẾT QUẢ TẤT YẾU
```

### Thử áp dụng dự đoán - と đồng hành

```
家族と / 旅行します。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 家族と | 🔒 **đóng gói:** "gia đình" → と → cùng với → dự đoán: sắp làm gì đó cùng gia đình |
| 2 | 旅行します | xác nhận: "du lịch" → câu kết thúc ✅ |
| **Dịch** | | **Du lịch cùng gia đình.** |

### Thử áp dụng dự đoán - と trích dẫn

```
先生は「静かに」と / 言いました。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 先生は | 🔒 **đóng gói:** "thầy" → は → chủ đề → dự đoán: sắp nói gì về thầy |
| 2 | 「静かに」と | 🔒 **đóng gói:** "im lặng" → 「」と → trích dẫn → dự đoán: sắp có 言う/思う (nói/nghĩ) |
| 3 | 言いました | xác nhận: "đã nói" → câu kết thúc ✅ |
| **Dịch** | | **Thầy đã nói "im lặng."** |

## から (kara)

### Cách dùng 1: Điểm bắt đầu (không gian)

```
東京から / 来ました。     → Từ Tokyo, đã đến.
ここから / 歩きます。     → Từ đây, đi bộ.
```

### Cách dùng 2: Điểm bắt đầu (thời gian)

```
9時から / 働きます。     → Từ 9 giờ, làm việc.
来週から / 始めます。     → Từ tuần sau, bắt đầu.
```

### Cách dùng 3: Nguồn / Xuất xứ

```
友達から / 聞きました。   → Từ bạn, đã nghe.
先生から / もらいました。 → Từ thầy, đã nhận.
```

### Cách dùng 4: Nguyên nhân (chủ quan)

```
雨だから / 行きません。       → Vì mưa, không đi.
疲れたから / 早く寝ます。     → Vì mệt, ngủ sớm.
暑いですから / 窓を開けます。 → Vì nóng, mở cửa sổ.
```

> **Sắc thái:** から mang tính chủ quan, nhấn mạnh phán đoán cá nhân. Lịch sự hơn dùng ので.

### Cách dùng 5: Sau khi (Vてから)

```
ご飯を食べてから / 出かけます。 → Sau khi ăn cơm, ra ngoài.
手を洗ってから / 食べます。     → Sau khi rửa tay, ăn.
```

### Mũi tên dự báo

```
[Nơi]から    → Sắp có di chuyển hoặc まで
[Thời gian]から → Sắp có hành động bắt đầu hoặc まで
[Lý do]から  → Sắp có KẾT QUẢ / HÀNH ĐỘNG
Vてから      → Sắp có hành động TIẾP THEO
```

### Thử áp dụng dự đoán - から + まで

```
9時から / 5時まで / 働きます。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 9時から | 🔒 **đóng gói:** "9 giờ" → から → điểm bắt đầu → dự đoán: sắp có まで hoặc hành động |
| 2 | 5時まで | 🔒 **đóng gói:** "từ 9 giờ đến 5 giờ" → まで → điểm kết thúc → dự đoán: sắp có hành động trong khoảng này |
| 3 | 働きます | xác nhận: "làm việc" → câu kết thúc ✅ |
| **Dịch** | | **Làm việc từ 9 giờ đến 5 giờ.** |

## まで (made)

### Cách dùng 1: Điểm kết thúc (không gian)

```
東京から / 大阪まで / 行きます。 → Từ Tokyo, đến Osaka, đi.
ここまで / 来てください。       → Đến đây, xin hãy đến.
```

### Cách dùng 2: Điểm kết thúc (thời gian)

```
5時まで / 働きます。       → Đến 5 giờ, làm việc.
来月まで / 待ちます。       → Đến tháng sau, đợi.
```

### Cách dùng 3: Mức độ / "Thậm chí"

```
子供まで / 知っています。   → Thậm chí trẻ con, cũng biết.
```

### までに = Trước hạn

```
金曜日までに / 出してください。 → Trước thứ sáu, xin hãy nộp.
→ までに ≠ まで:
  5時まで働く = Làm việc ĐẾN 5 giờ (liên tục)
  5時までに出す = Nộp TRƯỚC 5 giờ (hạn chót)
```

## より (yori) - So sánh

### Cách dùng 1: Hơn (so sánh)

```
東京より / 大阪の方が / 好きです。   → Hơn Tokyo, Osaka, thích.
夏より / 冬の方が / 寒いです。       → Hơn hè, đông, lạnh.
バスより / 電車の方が / 速いです。   → Hơn xe buýt, tàu, nhanh.
```

### Cách dùng 2: Từ (trang trọng, thay から)

```
心より / 感謝します。 → Từ tận đáy lòng, cảm ơn. (Văn viết)
```

### Mũi tên dự báo

```
...より → Sắp có SO SÁNH → đợi 方が + tính từ
```

### Thử áp dụng dự đoán - より so sánh

```
バスより / 電車の方が / 速いです。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | バスより | 🔒 **đóng gói:** "xe buýt" → より → so sánh → dự đoán: sắp có 方が + tính từ (cái gì đó hơn xe buýt) |
| 2 | 電車の方が | 🔒 **đóng gói:** "tàu điện" → の方が → bên được so sánh → dự đoán: sắp có tính từ mô tả tàu hơn xe buýt |
| 3 | 速いです | xác nhận: "nhanh" → câu kết thúc ✅ |
| **Dịch** | | **Tàu điện nhanh hơn xe buýt.** |

## Bảng tổng kết dự báo - Bài 4

| Gặp trợ từ | Dự đoán điều gì sắp đến | Ví dụ |
|------------|-------------------------|-------|
| **[Người]と** | Hành động CÙNG NHAU | 友達と... → sắp làm gì cùng bạn |
| **[N1]と[N2]** | Liệt kê đầy đủ, chỉ bấy nhiêu | りんごとみかん → chỉ có táo và cam |
| **「...」と** | 言う/思う/聞く (nói/nghĩ/nghe) | 「おはよう」と... → sắp nói |
| **[V]と** | Kết quả TẤT YẾU (quy luật) | 春になると... → chắc chắn có kết quả |
| **[V]と** (chỉ đường) | Hướng dẫn vị trí | まっすぐ行くと... → sắp mô tả vị trí |
| **[Nơi]から** | Di chuyển từ đây hoặc まで | 東京から... → từ Tokyo đi đâu |
| **[Thời gian]から** | Bắt đầu hành động hoặc まで | 9時から... → bắt đầu từ 9 giờ |
| **[Người]から** | Nhận từ ai | 先生から... → nhận gì từ thầy |
| **[Lý do]から** | Kết quả / hành động tiếp | 雨だから... → nên sẽ làm gì |
| **Vてから** | Hành động TIẾP THEO | 食べてから... → sau khi ăn thì... |
| **...まで** | Giới hạn kết thúc | 5時まで... → đến 5 giờ thì dừng |
| **...までに** | Hạn chót | 金曜日までに... → trước thứ sáu phải... |
| **...より** | So sánh → đợi 方が + tính từ | 東京より... → sắp so sánh với Tokyo |
