# Bài 1: Trợ từ đề mục - は・も

> Nhóm này KHÔNG đánh dấu vai trò ngữ pháp (chủ ngữ, tân ngữ...).
> Chúng chỉ đánh dấu **chủ đề** hoặc **nhấn mạnh**, và có thể THAY THẾ các trợ từ cách.

---

## は (wa) - Đánh dấu chủ đề

### Cách dùng 1: Đặt chủ đề

Đánh dấu "cái đang được nói đến." Không dịch thành từ cụ thể nào.

```
[N]は = "Về [N] thì..."
```

```
私は / 学生です。
→ Về phần tôi thì, là sinh viên.

東京は / 大きいです。
→ Về Tokyo thì, lớn.

この本は / 面白いです。
→ Về cuốn sách này thì, thú vị.
```

> **Cạm bẫy:** は KHÔNG có nghĩa "là." Câu 私は学生です không phải "Tôi LÀ sinh viên" mà là "Về phần tôi thì, [tôi] là sinh viên." Chữ "là" nằm ở です, không phải は.

### Cách dùng 2: Tương phản ngầm

Khi dùng は, ngầm ý so sánh với thứ khác.

```
肉は / 食べます。   (Thịt thì ăn. [Ngầm: nhưng cá thì không])
今日は / 暑いです。 (Hôm nay thì nóng. [Ngầm: hôm qua thì không])
私は / 行きます。   (Tôi thì đi. [Ngầm: còn anh thì tùy])
```

### Cách dùng 3: は thay thế trợ từ cách

は có thể thay thế が hoặc を khi biến thành chủ đề:

```
りんごが好きです。 → りんごは好きです。  (が bị は thay thế)
本を読みました。  → 本は読みました。   (を bị は thay thế)

NHƯNG: に, で, と... không bị thay thế mà は thêm vào SAU:
学校に行きます。 → 学校には行きます。  (に vẫn còn, は thêm vào)
```

### Mũi tên dự báo

```
...は → Sắp có THÔNG TIN / MÔ TẢ / BÌNH LUẬN về chủ đề này
```

### Thử áp dụng dự đoán - は đặt chủ đề

```
東京は / 大きいです。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 東京は | 🔒 **đóng gói:** "Tokyo" → は → chủ đề → dự đoán: sắp có thông tin mô tả về Tokyo |
| 2 | 大きいです | xác nhận: "lớn" → câu kết thúc ✅ |
| **Dịch** | | **Tokyo thì lớn.** |

### Thử áp dụng dự đoán - は tương phản

```
肉は / 食べます。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 肉は | 🔒 **đóng gói:** "thịt" → は → chủ đề + tương phản → dự đoán: sắp nói thịt thì sao, ngầm ý có cái khác thì khác |
| 2 | 食べます | xác nhận: "ăn" → câu kết thúc ✅ |
| **Dịch** | | **Thịt thì ăn.** *(ngầm: nhưng cá thì không)* |

## も (mo) - Cũng / Thêm

### Cách dùng 1: Cũng (thay thế は/が/を)

```
田中さんは / 学生です。 → 山田さんも / 学生です。
→ Tanaka là sinh viên. Yamada CŨNG là sinh viên.

私は / コーヒーを飲みます。 → 私は / 紅茶も / 飲みます。
→ Tôi uống cà phê. Tôi trà CŨNG uống.
```

### Cách dùng 2: も...も = Cả...lẫn... (liệt kê)

```
コーヒーも / 紅茶も / 好きです。
→ Cà phê cũng, trà cũng, thích. (Thích cả cà phê lẫn trà)

日本語も / 英語も / 話せます。
→ Tiếng Nhật cũng, tiếng Anh cũng, nói được.
```

### Cách dùng 3: も + phủ định = Không...nào / Chẳng...gì

```
誰も / 来ませんでした。         → Không ai đến.
何も / 食べませんでした。       → Chẳng ăn gì.
どこへも / 行きませんでした。   → Chẳng đi đâu.
```

### Cách dùng 4: も + trợ từ khác (にも, でも, からも)

```
誰にも / 言わないで。       → Đừng nói với ai.
ここでも / 買えます。       → Ở đây cũng mua được.
日本からも / 来ました。     → Từ Nhật cũng đến.
```

### Cách dùng 5: も nhấn mạnh số lượng (nhiều/lâu bất ngờ)

```
3時間も / 待ちました。     → Đợi những 3 tiếng. (Nhấn mạnh: lâu quá)
1万円も / かかりました。   → Tốn những 1 vạn yên. (Nhấn mạnh: đắt quá)
```

### Mũi tên dự báo

```
...も → Sắp có thông tin TƯƠNG TỰ với cái trước
...も + phủ định → KHÔNG CÓ GÌ / KHÔNG AI
```

### Thử áp dụng dự đoán - も (cũng)

```
田中さんは / 学生です。 山田さんも / 学生です。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 田中さんは | 🔒 **đóng gói:** "Tanaka" → は → chủ đề → dự đoán: sắp nói gì về Tanaka |
| 2 | 学生です。 | xác nhận: "là sinh viên" → câu 1 kết thúc ✅ |
| 3 | 山田さんも | 🔒 **đóng gói:** "Yamada" → も → cũng → dự đoán: Yamada sẽ giống Tanaka |
| 4 | 学生です。 | xác nhận: "cũng là sinh viên" → đúng như dự đoán ✅ |
| **Dịch** | | **Tanaka là sinh viên. Yamada cũng là sinh viên.** |

### Thử áp dụng dự đoán - も + phủ định

```
誰も / 来ませんでした。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 誰も | 🔒 **đóng gói:** "ai + cũng" → dự đoán: nếu vế sau phủ định → "không ai" |
| 2 | 来ませんでした | phủ định → xác nhận: "không đến" → câu kết thúc ✅ |
| **Dịch** | | **Không ai đến cả.** |

## Bảng tổng kết dự báo - Bài 1

| Gặp trợ từ | Dự đoán điều gì sắp đến | Ví dụ |
|------------|-------------------------|-------|
| **...は** | Thông tin / mô tả / bình luận về chủ đề | 私は... → sắp nói gì đó về "tôi" |
| **...は** (tương phản) | Thông tin KHÁC với cái khác | 肉は食べます → thịt thì ăn (ngầm: cá thì không) |
| **...も** | Thông tin TƯƠNG TỰ cái trước | 山田さんも... → Yamada cũng sẽ như Tanaka |
| **...も...も** | Liệt kê cả hai/nhiều | コーヒーも紅茶も... → cả hai đều... |
| **...も + phủ định** | Không gì / không ai | 誰も... → không ai cả |
| **...にも / でも / からも** | Trợ từ + cũng | ここでも... → ở đây cũng... |
| **[Số lượng] + も** | Nhấn mạnh NHIỀU / LÂU bất ngờ | 3時間も... → những 3 tiếng (lâu quá) |
