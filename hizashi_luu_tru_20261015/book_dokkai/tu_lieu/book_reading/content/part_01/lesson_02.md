# Bài 2: Trợ từ cách cơ bản - が・を・の

> Nhóm này đánh dấu vai trò ngữ pháp cốt lõi: ai làm, làm gì, thuộc về ai.

---

## が (ga) - Chủ ngữ

### Cách dùng 1: Chủ ngữ tồn tại

```
猫が / います。           → Con mèo, có. (Có con mèo)
机の上に / 本が / あります。→ Trên bàn, sách, có.
```

### Cách dùng 2: Thông tin mới / Nhấn mạnh

```
誰が / 来ましたか。     → AI đến?
田中さんが / 来ました。 → TANAKA đến. (Nhấn mạnh: chính Tanaka)
```

### Cách dùng 3: Đối tượng cảm xúc / năng lực

Với 好き, 嫌い, 欲しい, わかる, できる, 上手, 下手... đối tượng dùng が chứ không phải を.

```
音楽が / 好きです。       → Âm nhạc, thích.
日本語が / わかります。   → Tiếng Nhật, hiểu.
料理が / 上手です。       → Nấu ăn, giỏi.
水が / 欲しいです。       → Nước, muốn.
```

### Cách dùng 4: Hiện tượng tự nhiên / Sự kiện

```
雨が / 降っています。   → Mưa, đang rơi.
風が / 吹いています。   → Gió, đang thổi.
電気が / 消えました。   → Điện, đã tắt.
```

### Cách dùng 5: が nối mệnh đề (nhưng) - chi tiết ở Bài 6

```
高いですが、おいしいです。→ Đắt, nhưng ngon.
```

### Cách dùng 6: が trong mệnh đề phụ (bổ nghĩa danh từ)

Trong mệnh đề bổ nghĩa danh từ, chủ ngữ LUÔN dùng が, không dùng は.

```
[私が作った] / 料理       → Món ăn [mà tôi đã nấu]
[友達が買った] / 本       → Sách [mà bạn đã mua]
[先生が言った] / こと     → Điều [mà thầy đã nói]
[母が作った] / お弁当     → Cơm hộp [mà mẹ đã làm]
```

> Đây là case CỰC KỲ QUAN TRỌNG cho đọc hiểu. Mọi câu phức trong tiếng Nhật đều có mệnh đề phụ dùng が.

### は vs が - Phân biệt

```
は = ĐÈN CHIẾU → Chiếu vào cái ĐÃ BIẾT, sắp có bình luận
が = LỐI VÀO    → Cái MỚI xuất hiện, sắp có thông tin mới

むかしむかし、おじいさんが住んでいました。 (が: ông lão MỚI xuất hiện)
おじいさんは毎日山へ行きました。          (は: ông lão ĐÃ BIẾT, nói thêm)
```

### Mũi tên dự báo

```
...が → "Cái này (cụ thể) sắp LÀM GÌ / ĐƯỢC MÔ TẢ"
    + います/あります → tồn tại
    + 好き/嫌い/わかる → cảm xúc/năng lực
    + 降る/吹く/消える → hiện tượng
```

### Thử áp dụng dự đoán - が tồn tại

```
机の上に / 本が / あります。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 机の上に | 🔒 **đóng gói:** "trên bàn" → に → vị trí tồn tại → dự đoán: sắp có cái gì ĐÓ ở đây |
| 2 | 本が | 🔒 **đóng gói:** "sách" → が → chủ ngữ mới → dự đoán: sách sắp làm gì hoặc tồn tại |
| 3 | あります | xác nhận: "có" (tồn tại) → câu kết thúc ✅ |
| **Dịch** | | **Trên bàn có sách.** |

### Thử áp dụng dự đoán - が trong mệnh đề phụ

```
[母が作った] / お弁当
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 母が | 🔒 **đóng gói:** "mẹ" → が → chủ ngữ trong mệnh đề phụ → dự đoán: mẹ sắp làm gì đó |
| 2 | 作った | xác nhận: "đã làm" → đây là mệnh đề bổ nghĩa → dự đoán: sắp có danh từ được bổ nghĩa |
| 3 | お弁当 | 🔒 **đóng gói:** "cơm hộp mà mẹ đã làm" → gom thành 1 khối hình ảnh ✅ |
| **Dịch** | | **Cơm hộp mà mẹ đã làm.** |

## を (wo) - Tân ngữ / Đối tượng

### Cách dùng 1: Đối tượng trực tiếp của hành động

```
本を / 読みます。         → Sách, đọc.
コーヒーを / 飲みます。   → Cà phê, uống.
手紙を / 書きました。     → Thư, đã viết.
```

### Cách dùng 2: Không gian đi qua / Di chuyển qua

```
公園を / 歩きます。   → Công viên, đi bộ qua.
橋を / 渡ります。     → Cầu, băng qua.
道を / 走ります。     → Đường, chạy.
角を / 曲がります。   → Góc, rẽ.
```

### Cách dùng 3: Nơi rời khỏi

```
家を / 出ます。       → Nhà, ra khỏi.
大学を / 卒業します。 → Đại học, tốt nghiệp (rời khỏi).
電車を / 降ります。   → Tàu, xuống.
```

### Mũi tên dự báo

```
...を → Sắp có ĐỘNG TỪ tác động (ăn, đọc, mua, viết, xem...)
       hoặc động từ di chuyển/rời khỏi (đi qua, băng qua, ra khỏi)
```

### Thử áp dụng dự đoán - を tân ngữ

```
手紙を / 書きました。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 手紙を | 🔒 **đóng gói:** "thư" → を → tân ngữ → dự đoán: sắp có động từ tác động lên thư (đọc? viết? gửi?) |
| 2 | 書きました | xác nhận: "đã viết" → câu kết thúc ✅ |
| **Dịch** | | **Đã viết thư.** |

## の (no) - Sở hữu / Liên kết / Bổ nghĩa

### Cách dùng 1: Sở hữu

```
私の本         → Sách CỦA tôi
田中さんの車   → Xe CỦA Tanaka
```

### Cách dùng 2: Thuộc về / Liên kết

```
日本の料理     → Món ăn (CỦA) Nhật
東京の大学     → Đại học (Ở) Tokyo
歴史の本       → Sách (VỀ) lịch sử
```

### Cách dùng 3: Chuỗi の (thu hẹp phạm vi)

Đọc từ trái sang phải, mỗi の thu hẹp phạm vi:

```
東京の / 駅の / 近くの / レストラン
→ Tokyo → ga → gần → nhà hàng
→ Nhà hàng gần ga Tokyo

日本の / 大学の / 先生
→ Nhật → đại học → giáo viên
→ Giáo viên đại học Nhật
```

### Cách dùng 4: の thay thế danh từ (tránh lặp)

```
赤いのがほしい。   → Muốn cái màu đỏ. (の = cái/chiếc)
大きいのをください。→ Cái lớn cho tôi.
```

### Cách dùng 5: の cuối câu (giải thích / hỏi)

```
どうしたの？       → Sao thế? (hỏi nhẹ nhàng)
明日行くの。       → Ngày mai đi đấy. (giải thích)
```

### Cách dùng 6: の danh từ hóa động từ (Vの)

```
泳ぐのが / 好きです。     → Bơi, thích. (の biến "bơi" thành danh từ)
食べるのを / やめました。 → Ăn, đã dừng. (の biến "ăn" thành danh từ)
走るのが / 速い。         → Chạy, nhanh.
```

### Mũi tên dự báo

```
...の → Sắp có DANH TỪ tiếp theo (bổ nghĩa, thu hẹp)
```

### Thử áp dụng dự đoán - chuỗi の thu hẹp phạm vi

```
日本の / 大学の / 先生
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 日本の | "Nhật" → の → dự đoán: sắp có danh từ thuộc về Nhật → phạm vi bắt đầu thu hẹp |
| 2 | 大学の | "đại học" → の → dự đoán: sắp có danh từ thuộc về đại học Nhật → tiếp tục thu hẹp |
| 3 | 先生 | 🔒 **đóng gói:** "giáo viên đại học Nhật" → gom thành 1 khối hình ảnh ✅ |
| **Dịch** | | **Giáo viên đại học Nhật.** |

## Bảng tổng kết dự báo - Bài 2

| Gặp trợ từ | Dự đoán điều gì sắp đến | Ví dụ |
|------------|-------------------------|-------|
| **...が** + います/あります | Tồn tại | 猫が... → có con mèo |
| **...が** + 好き/嫌い/わかる | Cảm xúc / năng lực | 音楽が... → thích/ghét/hiểu âm nhạc |
| **...が** + 降る/吹く/消える | Hiện tượng tự nhiên | 雨が... → mưa sắp rơi |
| **...が** (trong câu hỏi) | Nhấn mạnh AI / CÁI GÌ | 誰が... → AI cụ thể? |
| **...を** | Ngoại động từ (ăn, đọc, mua, viết...) | 本を... → sắp đọc/mua/viết sách |
| **...を** + 歩く/渡る/走る | Di chuyển QUA không gian | 公園を... → đi bộ qua công viên |
| **...を** + 出る/降りる/卒業する | Rời khỏi | 家を... → ra khỏi nhà |
| **...の** | Danh từ tiếp theo (bổ nghĩa) | 日本の... → sắp có danh từ thuộc về Nhật |
| **...の...の...の** | Thu hẹp dần phạm vi | 東京の駅の近くの... → nhà hàng gần ga Tokyo |
| **[...が V た] + N** | Mệnh đề bổ nghĩa danh từ | [私が作った]料理 → món ăn mà tôi nấu |
| **V + の** | Danh từ hóa động từ → đợi trợ từ tiếp | 泳ぐのが... → bơi (danh từ) sắp được mô tả |
