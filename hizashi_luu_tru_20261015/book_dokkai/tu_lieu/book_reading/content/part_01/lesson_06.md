# Bài 6: Trợ từ nối mệnh đề - けど/が・ので・のに・し・なら

> Nhóm này nối 2 mệnh đề, thể hiện quan hệ logic giữa chúng.

---

## けど / が (kedo / ga) - Nhưng / Tương phản

```
高いですが / おいしいです。         → Đắt nhưng, ngon.
日本語は難しいですけど / 面白いです。→ Tiếng Nhật khó nhưng, thú vị.
```

> **が** trang trọng hơn けど. けど thân mật, văn nói.
> **が** còn dùng làm mào đầu (không mang nghĩa "nhưng"):
> すみませんが、... → Xin lỗi, [cho tôi hỏi]...

> Biến thể trang trọng: けど → けれど → けれども (trong sách/văn viết, gặp けれども rất nhiều).

### Thử áp dụng dự đoán

```
高いですが / おいしいです。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 高いですが | が → dự đoán: vế sau sẽ tương phản, "đắt nhưng..." → chờ điều ngược lại |
| 2 | おいしいです | xác nhận tương phản: "ngon" → ghép lại: "đắt nhưng ngon" → câu kết thúc ✅ |
| **Dịch** | | **Đắt nhưng ngon.** |

---

## ので (node) - Vì (khách quan, lịch sự)

```
病気なので / 休みます。             → Vì bệnh, nghỉ.
試験があるので / 勉強しています。   → Vì có thi, đang học.
```

> **から vs ので:** から chủ quan, ので khách quan lịch sự hơn.

### Thử áp dụng dự đoán

```
試験があるので / 勉強しています。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 試験があるので | ので → dự đoán: nguyên nhân khách quan, "vì có thi" → chờ kết quả tất yếu |
| 2 | 勉強しています | xác nhận kết quả: "đang học" → hợp lý → câu kết thúc ✅ |
| **Dịch** | | **Vì có thi nên đang học.** |

---

## のに (noni) - Vậy mà / Mặc dù (thất vọng, bất mãn)

```
勉強したのに / 落ちました。         → Đã học vậy mà, trượt.
約束したのに / 来ませんでした。     → Đã hẹn vậy mà, không đến.
```

> **のに** mang cảm xúc mạnh: thất vọng, bất mãn, ngạc nhiên.

### Thử áp dụng dự đoán

```
約束したのに / 来ませんでした。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 約束したのに | のに → dự đoán: kết quả bất ngờ, thất vọng, "đã hẹn rồi vậy mà..." |
| 2 | 来ませんでした | xác nhận: "đã không đến" → đúng là thất vọng → câu kết thúc ✅ |
| **Dịch** | | **Đã hẹn rồi vậy mà không đến.** |

### So sánh ので vs のに (dễ nhầm!)

| | ので | のに |
|---|---|---|
| Nghĩa | Vì, do | Vậy mà, mặc dù |
| Cảm xúc | Trung tính, khách quan | Thất vọng, bất mãn |
| Ví dụ | 病気なので休む (Vì bệnh nên nghỉ) | 薬を飲んだのに治らない (Uống thuốc rồi vậy mà không khỏi) |

---

## し (shi) - Liệt kê lý do (vừa...vừa..., và còn...)

```
安いし / おいしいし / この店が好きです。
→ Vừa rẻ, vừa ngon, tiệm này thích.

忙しいし / お金もないし / 行けません。
→ Vừa bận, vừa không có tiền, không đi được.
```

> **Sắc thái:** Ngầm ý "còn nhiều lý do nữa nhưng chỉ kể vậy thôi."

### Thử áp dụng dự đoán

```
安いし / おいしいし / この店が好きです。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 安いし | し → dự đoán: lý do thứ nhất "rẻ", còn lý do nữa → đọc tiếp |
| 2 | おいしいし | し lần 2 → lý do thứ hai "ngon", sắp có kết luận |
| 3 | この店が好きです | xác nhận kết luận: "thích tiệm này" → câu kết thúc ✅ |
| **Dịch** | | **Vừa rẻ, vừa ngon, nên thích tiệm này.** |

---

---

## なら (nara) - Nếu là...thì (dựa trên ngữ cảnh, lời khuyên)

```
日本へ行くなら / 京都がいいですよ。→ Nếu đi Nhật, Kyoto tốt đấy.
それなら / 大丈夫です。           → Nếu vậy, không sao.
日本語なら / わかります。         → Nếu là tiếng Nhật, hiểu.
```

### なら với thứ tự đảo ngược

```
日本へ行くなら / この本を読んでおいて。
→ Nếu định đi Nhật, hãy đọc cuốn sách này trước.
(Hành động "đọc sách" xảy ra TRƯỚC "đi Nhật" -- đảo thứ tự)
```

> **Đặc điểm:** なら tiếp nhận thông tin từ người khác rồi đưa lời khuyên/kết luận.
> Vế sau có thể xảy ra TRƯỚC vế trước về mặt thời gian.

---

> **Cấu trúc nâng cao (xem Part 2):** Các trợ từ nối cần chia động từ sẽ được giới thiệu ở phần cấu trúc câu:
> - ても (dù...cũng): 雨が降っても行きます
> - ながら (vừa...vừa): 音楽を聞きながら勉強する
> - たり (liệt kê hành động): 映画を見たり本を読んだりする
> - て form (nối trình tự, trạng thái): 起きて食べて行く

## Bảng tổng kết dự báo - Bài 6

| Gặp trợ từ | Dự đoán điều gì sắp đến | Ví dụ |
|------------|-------------------------|-------|
| **...けど / ...が** | Vế SAU sẽ TƯƠNG PHẢN | 高いですが... → đắt nhưng sắp có điểm tốt |
| **...が** (mào đầu) | Sắp có YÊU CẦU / CÂU HỎI | すみませんが... → sắp nhờ vả |
| **...ので** | Kết quả TẤT NHIÊN (khách quan) | 病気なので... → nên sẽ nghỉ/không đi |
| **...のに** | Kết quả BẤT NGỜ / THẤT VỌNG | 勉強したのに... → vậy mà kết quả xấu |
| **...し...し** | Thêm lý do, dẫn đến KẾT LUẬN | 安いし、おいしいし... → nên thích/chọn |
| **...なら** | LỜI KHUYÊN / phản hồi ngữ cảnh | 日本へ行くなら... → sắp có gợi ý |
| **[N]なら** | Giới hạn chủ đề: "nếu là cái này thì..." | 日本語なら... → sắp có nhận xét |
