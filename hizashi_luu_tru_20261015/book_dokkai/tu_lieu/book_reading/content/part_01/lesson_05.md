# Bài 5: Trợ từ phạm vi & giới hạn - だけ・しか・ばかり・ほど・くらい・など・や・とか

## Phần A: Giới hạn - だけ・しか・ばかり

---

## だけ (dake) - Chỉ / Chỉ có

```
私だけ / 知っています。   → Chỉ tôi, biết.
今日だけ / 安いです。     → Chỉ hôm nay, rẻ.
少しだけ / 食べました。   → Chỉ một chút, đã ăn.
```

### Thử áp dụng dự đoán

```
今日だけ / 安いです。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 今日だけ | だけ → dự đoán: giới hạn phạm vi, "chỉ hôm nay" thôi → chờ xem chuyện gì |
| 2 | 安いです | xác nhận: "rẻ" → câu kết thúc ✅ |
| **Dịch** | | **Chỉ hôm nay là rẻ.** |

---

## しか (shika) - Chỉ (+ phủ định, nhấn mạnh ít)

```
私しか / 知りません。       → Chỉ tôi, không biết. (Chỉ mình tôi biết)
10分しか / ありません。     → Chỉ 10 phút, không có. (Chỉ có 10 phút)
水しか / 飲みません。       → Chỉ nước, không uống. (Chỉ uống nước)
```

> **だけ vs しか:** だけ trung tính, しか nhấn mạnh "ít, không đủ."

### Thử áp dụng dự đoán

```
水しか / 飲みません。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 水しか | しか → dự đoán: sắp có phủ định, nhấn mạnh "chỉ có nước thôi, ít" |
| 2 | 飲みません | xác nhận phủ định: "không uống" → ghép lại: "chỉ uống nước" → câu kết thúc ✅ |
| **Dịch** | | **Chỉ uống mỗi nước thôi.** |

---

## ばかり (bakari) - Toàn / Chỉ toàn

```
間違いばかり / です。       → Toàn lỗi.
嘘ばかり / 言う。           → Toàn nói dối.
文句ばかり / 言わないで。   → Đừng toàn phàn nàn.
```

> **Cấu trúc nâng cao (xem Part 2):** ばかり còn kết hợp với động từ chia thể:
> - Vてばかり (toàn làm gì đó): 食べてばかりいる
> - Vたばかり (vừa mới): 来たばかり

### Thử áp dụng dự đoán

```
嘘ばかり / 言う。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 嘘ばかり | ばかり → dự đoán: "toàn là nói dối", sắc thái phàn nàn → chờ động từ |
| 2 | 言う | xác nhận: "nói" → ghép lại: "toàn nói dối" → câu kết thúc ✅ |
| **Dịch** | | **Toàn nói dối!** |

---

### So sánh だけ vs しか vs ばかり

| | だけ | しか (+phủ định) | ばかり |
|---|---|---|---|
| Sắc thái | Trung tính | Nhấn mạnh ÍT, thiếu | Phàn nàn, tiêu cực |
| Ví dụ | 水だけ飲む (Chỉ uống nước) | 水しか飲まない (Chỉ uống mỗi nước) | 水ばかり飲む (Toàn uống nước) |

### だけでなく...も = Không chỉ...mà còn

```
日本語だけでなく / 英語も / 話せます。
→ Không chỉ tiếng Nhật, tiếng Anh cũng, nói được.
```

## Phần B: Mức độ & Liệt kê - ほど・くらい・など・や・とか

---

## ほど (hodo) - Mức độ / Khoảng

```
死ぬほど / 疲れました。     → Mức chết, đã mệt. (Mệt chết)
父ほど / 背が高くない。     → Mức bố, không cao. (Không cao bằng bố)
```

> **Cấu trúc nâng cao (xem Part 2):** VばVるほど (càng...càng): 考えれば考えるほど難しい

### Thử áp dụng dự đoán

```
死ぬほど / 疲れました。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 死ぬほど | ほど → dự đoán: mức độ rất cao, "đến mức chết" → chờ xem chuyện gì |
| 2 | 疲れました | xác nhận: "đã mệt" → ghép lại: "mệt đến mức chết" → câu kết thúc ✅ |
| **Dịch** | | **Mệt chết đi được.** |

### ほど phủ định (so sánh: không bằng)

```
東京ほど / 大きくない。   → Không lớn bằng Tokyo.
兄ほど / 背が高くない。   → Không cao bằng anh.
```

---

## くらい / ぐらい (kurai/gurai) - Khoảng / Chừng

```
10分くらい / かかります。   → Khoảng 10 phút, mất.
3人ぐらい / 来ました。     → Khoảng 3 người, đã đến.
```

---

## など (nado) - Vân vân / Và những thứ tương tự

```
りんごや / みかんなどを / 買いました。 → Táo, cam vân vân, đã mua.
```

---

## や (ya) - Liệt kê đại diện (còn nhiều thứ khác)

```
りんごや / みかんを / 買いました。 → Táo, cam (và nhiều thứ khác), đã mua.
→ と = liệt kê ĐẦY ĐỦ (chỉ bấy nhiêu)
→ や = liệt kê ĐẠI DIỆN (còn nữa)
```

> や...など thường đi cùng nhau thành cụm cố định: りんごやみかんなど.

---

## とか (toka) - Liệt kê không chắc chắn / Đại loại

```
映画とか / 本とか / 好きです。 → Đại loại phim, sách, thích. (Văn nói)
```

> とか là văn NÓI, không dùng trong văn viết trang trọng.

---

## Bảng tổng kết dự báo - Bài 5

| Gặp trợ từ | Dự đoán điều gì sắp đến | Ví dụ |
|------------|-------------------------|-------|
| **...だけ** | Giới hạn (chỉ có bấy nhiêu) | 今日だけ... → chỉ hôm nay thôi |
| **...しか + phủ định** | Nhấn mạnh ÍT, không đủ | 10分しか... → chỉ có 10 phút (ít quá) |
| **[N]ばかり** | Toàn là (phàn nàn) | 間違いばかり... → toàn lỗi |
| **...ほど** | Mức độ / Không bằng (phủ định) | 死ぬほど... → mức chết; 父ほど...ない → không bằng bố |
| **[Số]くらい/ぐらい** | Khoảng chừng (ước lượng) | 10分くらい... → khoảng 10 phút |
| **...など** | Còn nhiều thứ tương tự | りんごなど... → táo và những thứ tương tự |
| **[N1]や[N2]** | Liệt kê đại diện (còn nữa) | りんごやみかん... → táo, cam và nhiều thứ khác |
| **...とか...とか** | Liệt kê mơ hồ (văn nói) | 映画とか本とか... → đại loại phim, sách |
