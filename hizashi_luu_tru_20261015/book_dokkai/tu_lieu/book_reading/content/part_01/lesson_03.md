# Bài 3: Trợ từ không gian & thời gian - に・で・へ

> Nhóm dễ nhầm nhất. Cùng liên quan "nơi chốn" nhưng chức năng hoàn toàn khác.

---

## に (ni) - Điểm / Đích / Thời điểm

### Cách dùng 1: Vị trí tồn tại (TĨNH)

Nơi mà ai/cái gì TỒN TẠI (không hành động).

```
部屋に / 猫が / います。     → Trong phòng, mèo, có.
机の上に / 本が / あります。 → Trên bàn, sách, có.
```

### Cách dùng 2: Thời điểm cụ thể

```
7時に / 起きます。       → 7 giờ, thức dậy.
月曜日に / 会議があります。→ Thứ hai, có họp.
3月に / 日本へ行きます。 → Tháng 3, đi Nhật.
```

> **Lưu ý thời gian:**
> - ❌ 今日に行きます / ✅ 今日行きます (thời gian tương đối → không dùng に)
> - ❌ 毎日に勉強します / ✅ 毎日勉強します
> - ✅ 月曜日に行きます (ngày cụ thể → dùng に)
> - ✅ 3月に日本へ行きます (tháng cụ thể → dùng に)

### Cách dùng 3: Điểm đến (đích di chuyển)

```
学校に / 行きます。   → Trường, đi.
日本に / 来ました。   → Nhật, đã đến.
家に / 帰ります。     → Nhà, về.
```

### Cách dùng 4: Người nhận / Đối tượng gián tiếp

```
友達に / プレゼントを / あげました。 → Bạn, quà, đã tặng.
先生に / 質問しました。             → Thầy, đã hỏi.
母に / 電話をかけます。             → Mẹ, gọi điện.
```

### Cách dùng 5: Mục đích (Vに行く)

```
買い物に / 行きます。   → Mua sắm, đi. (Đi để mua sắm)
映画を見に / 行きます。 → Xem phim, đi. (Đi để xem phim)
食べに / 来ました。     → Ăn, đã đến. (Đến để ăn)
```

### Cách dùng 6: Kết quả biến đổi (になる)

```
医者に / なりました。   → Bác sĩ, đã trở thành.
春に / なると...        → Xuân, khi trở thành... (Khi đến xuân...)
```

### Cách dùng 7: Người thực hiện trong câu bị động

```
先生に / 叱られました。   → Bị thầy, mắng.
雨に / 降られました。     → Bị mưa, dính.
```

### Cách dùng 8: Tần suất

```
週に / 3回 / 泳ぎます。   → Tuần, 3 lần, bơi.
1日に / 2回 / 薬を飲みます。→ Ngày, 2 lần, uống thuốc.
```

### Mũi tên dự báo

```
[Nơi]に     → います/あります (tồn tại) hoặc 行く/来る/帰る (di chuyển)
[Thời gian]に → Sắp có hành động VÀO LÚC này
[Người]に   → あげる/もらう/教える (trao đổi)
[V ます]に  → 行く/来る (mục đích)
```

### Thử áp dụng dự đoán - に điểm đến

```
3月に / 日本に / 行きます。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 3月に | 🔒 **đóng gói:** "tháng 3" → に → thời điểm → dự đoán: sắp có hành động vào tháng 3 |
| 2 | 日本に | 🔒 **đóng gói:** "Nhật" → に → điểm đến → dự đoán: sắp có động từ di chuyển (đi/đến/về) |
| 3 | 行きます | xác nhận: "đi" → câu kết thúc ✅ |
| **Dịch** | | **Tháng 3 đi Nhật.** |

### Thử áp dụng dự đoán - に người nhận

```
友達に / プレゼントを / あげました。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 友達に | 🔒 **đóng gói:** "bạn" → に → đối tượng gián tiếp → dự đoán: sắp cho/nhận/nói gì với bạn |
| 2 | プレゼントを | 🔒 **đóng gói:** "quà" → を → tân ngữ → dự đoán: sắp có động từ tác động lên quà |
| 3 | あげました | xác nhận: "đã tặng" → câu kết thúc ✅ |
| **Dịch** | | **Đã tặng quà cho bạn.** |

## で (de) - Sân khấu / Phương tiện

### Cách dùng 1: Địa điểm hành động (ĐỘNG)

Nơi mà hành động DIỄN RA.

```
図書館で / 勉強します。       → Tại thư viện, học.
レストランで / 食べます。     → Tại nhà hàng, ăn.
公園で / 子供が遊んでいます。 → Tại công viên, trẻ em đang chơi.
```

### Cách dùng 2: Phương tiện / Công cụ

```
バスで / 行きます。   → Bằng xe buýt, đi.
箸で / 食べます。     → Bằng đũa, ăn.
ペンで / 書きます。   → Bằng bút, viết.
```

### Cách dùng 3: Ngôn ngữ / Chất liệu

```
日本語で / 話します。 → Bằng tiếng Nhật, nói.
木で / 作りました。   → Bằng gỗ, đã làm.
```

### Cách dùng 4: Phạm vi / Giới hạn

```
クラスで / 一番です。 → Trong lớp, nhất.
世界で / 一番高い山   → Trên thế giới, núi cao nhất.
三人で / 行きます。   → Ba người, đi. (Đi ba người)
```

### Cách dùng 5: Nguyên nhân (sự kiện / tình huống)

```
事故で / 電車が止まりました。 → Vì tai nạn, tàu đã dừng.
病気で / 休みました。         → Vì bệnh, đã nghỉ.
```

### Mũi tên dự báo

```
[Nơi]で     → Sắp có HÀNH ĐỘNG diễn ra tại đây
[Công cụ]で → Sắp có HÀNH ĐỘNG dùng cái này
[Số]で      → Sắp có HÀNH ĐỘNG chung nhóm
```

### Thử áp dụng dự đoán - で địa điểm hành động

```
図書館で / 勉強します。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 図書館で | 🔒 **đóng gói:** "thư viện" → で → sân khấu hành động → dự đoán: sắp có hành động diễn ra tại thư viện |
| 2 | 勉強します | xác nhận: "học" → câu kết thúc ✅ |
| **Dịch** | | **Học tại thư viện.** |

## に vs で - Phân biệt

| に (TĨNH / ĐIỂM) | で (ĐỘNG / SÂN KHẤU) |
|---|---|
| 学校に**います** (Ở trường - tồn tại) | 学校で**勉強します** (Học TẠI trường - hành động) |
| 公園に**います** (Ở công viên) | 公園で**遊びます** (Chơi TẠI công viên) |
| 家に**帰ります** (Về NHÀ - đích) | 家で**食べます** (Ăn TẠI nhà - hành động) |
| 椅子に**座ります** (Ngồi lên ghế - điểm) | 椅子で**寝ます** (Ngủ trên ghế - hành động) |

```
Mẹo: に hỏi "Ở ĐÂU?" (tồn tại, đích đến)
     で hỏi "LÀM GÌ ở đâu?" (có hành động)
```

## へ (e) - Hướng di chuyển

### Cách dùng 1: Hướng (gần giống に nhưng nhấn mạnh hướng đi)

```
日本へ / 行きます。     → Về phía Nhật, đi.
南へ / 向かいます。     → Về phía nam, hướng tới.
どこへ / 行きますか。   → Về phía đâu, đi?
```

### に vs へ

```
学校に行きます → Đi ĐẾN trường (nhấn mạnh đích đến)
学校へ行きます → Đi VỀ PHÍA trường (nhấn mạnh hướng)
→ Hầu hết trường hợp thay thế được cho nhau.
→ へ không dùng cho tồn tại hay thời điểm (chỉ に mới có).
```

### Mũi tên dự báo

```
...へ → Chắc chắn sắp có ĐỘNG TỪ DI CHUYỂN (行く/来る/帰る/向かう)
```

### Thử áp dụng dự đoán - へ hướng di chuyển

```
南へ / 向かいます。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 南へ | 🔒 **đóng gói:** "phía nam" → へ → hướng → dự đoán: chắc chắn sắp có động từ di chuyển |
| 2 | 向かいます | xác nhận: "hướng tới" → câu kết thúc ✅ |
| **Dịch** | | **Hướng về phía nam.** |

## Bảng tổng kết dự báo - Bài 3

| Gặp trợ từ | Dự đoán điều gì sắp đến | Ví dụ |
|------------|-------------------------|-------|
| **[Nơi]に** | います/あります (tồn tại) | 部屋に... → có gì đó trong phòng |
| **[Thời gian]に** | Hành động vào lúc này | 7時に... → sắp làm gì lúc 7 giờ |
| **[Nơi]に** + 行く/来る/帰る | Di chuyển đến đích | 学校に... → sắp đi/đến/về trường |
| **[Người]に** | Trao đổi (cho/nhận/nói) | 友達に... → sắp cho/nhận/nói với bạn |
| **[Vます]に** + 行く/来る | Mục đích di chuyển | 買い物に... → đi để mua sắm |
| **[N]に** + なる | Biến đổi thành | 医者に... → trở thành bác sĩ |
| **[Nơi]で** | Hành động diễn ra tại đây | 図書館で... → sắp làm gì ở thư viện |
| **[Công cụ]で** | Hành động dùng cái này | バスで... → đi bằng xe buýt |
| **[Ngôn ngữ]で** | Nói/viết bằng ngôn ngữ này | 日本語で... → sắp nói bằng tiếng Nhật |
| **[Số]で** | Hành động chung nhóm | 三人で... → ba người cùng làm |
| **[Sự kiện]で** | Nguyên nhân | 事故で... → vì tai nạn nên... |
| **...へ** | Động từ di chuyển (行く/来る/帰る) | 日本へ... → sắp đi về phía Nhật |
| **[Người]に + られる** | Câu bị động | 先生に... → bị thầy làm gì |
| **[Thời gian]に + [Số]回** | Tần suất | 週に... → bao nhiêu lần mỗi tuần |
