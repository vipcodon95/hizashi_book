# Bài 30: Mệnh đề nguyên nhân — から・ので・て・ために

> Tiếng Nhật có nhiều cách diễn đạt nguyên nhân - lý do, mỗi cách mang sắc thái khác nhau.
> Khi đọc, gặp tín hiệu nguyên nhân → dự đoán: phần SAU sẽ là **kết quả**.
> Chìa khóa: nhận diện tín hiệu → biết ngay câu này giải thích "vì sao".

---

## 1. から — Vì ~ (chủ quan, trực tiếp)

**Cấu trúc:** [Mệnh đề TTT/thể lịch sự] + から + [kết quả]

```
雨が / 降っているから / 傘を / 持って行きます。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 雨が | が → chủ ngữ → 🔒 **đóng gói:** "mưa" → が cho biết chủ ngữ → đọc tiếp |
| 2 | 降っているから | Vている + **から** → 🔒 **đóng gói:** "đang mưa" → giải phóng bộ nhớ → から cho biết: sắp có kết quả/hành động → đọc tiếp |
| 3 | 傘を | を → 🔒 **đóng gói:** "ô/dù" → を cho biết đối tượng → đọc tiếp |
| 4 | 持って行きます | (chủ ngữ ẩn: tôi) → "mang theo" → câu kết thúc ✅ |
| **Dịch** | | **Vì đang mưa nên tôi mang ô theo.** |

---

```
お腹が / 空いたから / 何か / 食べたいです。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | お腹が | が → chủ ngữ → 🔒 **đóng gói:** "bụng" → が cho biết chủ ngữ → đọc tiếp |
| 2 | 空いたから | Vた + **から** → 🔒 **đóng gói:** "đã đói" → giải phóng bộ nhớ → から cho biết: sắp có kết quả → đọc tiếp |
| 3 | 何か | "cái gì đó" |
| 4 | 食べたいです | (chủ ngữ ẩn: tôi) → Vたい → "muốn ăn" → câu kết thúc ✅ |
| **Dịch** | | **Vì đói nên muốn ăn gì đó.** |

---

## 2. ので — Vì ~ (khách quan, lịch sự hơn)

**Cấu trúc:** [Mệnh đề TTT] + ので + [kết quả]

> **Lưu ý tiếp nối:** Aな dùng **な**ので, N dùng **な**ので (giống mệnh đề bổ nghĩa).
>
> **Lưu ý:** ので không tự nhiên khi vế sau là mệnh lệnh/yêu cầu thô. Dùng から thay thế:
> ✅ 危ない**から**触るな (Nguy hiểm nên đừng chạm!)
> ❌ 危ない**ので**触るな (nghe không tự nhiên — ので lịch sự nhưng 触るな thô)

```
電車が / 遅れたので / 会議に / 遅刻しました。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 電車が | が → chủ ngữ → 🔒 **đóng gói:** "tàu điện" → が cho biết chủ ngữ → đọc tiếp |
| 2 | 遅れたので | Vた + **ので** → 🔒 **đóng gói:** "tàu đã trễ" → giải phóng bộ nhớ → ので cho biết: sắp có kết quả → đọc tiếp |
| 3 | 会議に | に → 🔒 **đóng gói:** "cuộc họp" → に cho biết điểm đến → đọc tiếp |
| 4 | 遅刻しました | (chủ ngữ ẩn: tôi) → "đã đến muộn" → câu kết thúc ✅ |
| **Dịch** | | **Vì tàu điện trễ nên tôi đã đến muộn cuộc họp.** |

---

```
この辺りは / 静かなので / 住みやすいです。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | この辺りは | は → chủ đề → 🔒 **đóng gói:** "vùng này" → は cho biết chủ đề → đọc tiếp |
| 2 | 静かなので | Aな + **なので** → 🔒 **đóng gói:** "yên tĩnh" → giải phóng bộ nhớ → ので cho biết: sắp có kết quả → đọc tiếp |
| 3 | 住みやすいです | Vます + やすい → "dễ sống" → câu kết thúc ✅ |
| **Dịch** | | **Vùng này vì yên tĩnh nên dễ sống.** |

## 3. Vて — Vì ~ (nguyên nhân nhẹ, không chủ đích)

Đã học ở Bài 16. Ở đây nhắc lại trong bối cảnh so sánh.

```
道に / 迷って / 約束の時間に / 遅れてしまいました。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 道に | に → 🔒 **đóng gói:** "đường" → に cho biết địa điểm → đọc tiếp |
| 2 | 迷って | Vて → 🔒 **đóng gói:** "bị lạc đường" → giải phóng bộ nhớ → て cho biết: sắp có kết quả → đọc tiếp |
| 3 | 約束の時間に | に → 🔒 **đóng gói:** "giờ hẹn" → に cho biết thời điểm → đọc tiếp |
| 4 | 遅れてしまいました | (chủ ngữ ẩn: tôi) → Vてしまう → tiếc nuối → "đã lỡ đến muộn" → câu kết thúc ✅ |
| **Dịch** | | **Vì bị lạc đường nên đã lỡ đến muộn giờ hẹn.** |

---

```
風邪を / ひいて / 学校を / 休みました。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 風邪を | を → 🔒 **đóng gói:** "cảm" → を cho biết đối tượng → đọc tiếp |
| 2 | ひいて | Vて → 🔒 **đóng gói:** "bị cảm" → giải phóng bộ nhớ → て cho biết: sắp có kết quả → đọc tiếp |
| 3 | 学校を | を → 🔒 **đóng gói:** "trường" → を cho biết đối tượng → đọc tiếp |
| 4 | 休みました | (chủ ngữ ẩn: tôi) → "đã nghỉ" → câu kết thúc ✅ |
| **Dịch** | | **Vì bị cảm nên nghỉ học.** |

## 4. ために — Vì ~ (nguyên nhân trang trọng)

> **Cảnh báo:** ために có **2 nghĩa**: (1) nguyên nhân và (2) mục đích (Bài 31). Cách phân biệt ở cuối mục này.

```
台風のために / 電車が / 止まりました。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 台風のために | N + **のために** → 🔒 **đóng gói:** "bão" → giải phóng bộ nhớ → ために cho biết: sắp có kết quả (thường tiêu cực) → đọc tiếp |
| 2 | 電車が | が → chủ ngữ → 🔒 **đóng gói:** "tàu điện" → が cho biết chủ ngữ → đọc tiếp |
| 3 | 止まりました | "đã dừng" → câu kết thúc ✅ |
| **Dịch** | | **Vì bão nên tàu điện đã ngừng chạy.** |

---

```
事故が / あったために / 道が / 渋滞しています。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 事故が | が → chủ ngữ → 🔒 **đóng gói:** "tai nạn" → が cho biết chủ ngữ → đọc tiếp |
| 2 | あったために | Vた + **ために** → 🔒 **đóng gói:** "đã có tai nạn" → giải phóng bộ nhớ → ために cho biết: sắp có kết quả → đọc tiếp |
| 3 | 道が | が → chủ ngữ → 🔒 **đóng gói:** "đường" → が cho biết chủ ngữ → đọc tiếp |
| 4 | 渋滞しています | Vている → "đang tắc" → câu kết thúc ✅ |
| **Dịch** | | **Vì đã có tai nạn nên đường đang tắc.** |

### Phân biệt ために nguyên nhân vs ために mục đích

| | ために nguyên nhân | ために mục đích |
|---|-------------------|----------------|
| **Trước ために** | Vた (quá khứ) / N の | Vる (từ điển) / N の |
| **Kết quả** | Thường tiêu cực, ngoài ý muốn | Tích cực, có chủ đích |
| **Ví dụ** | 事故があった**ために**遅れた (vì tai nạn nên trễ) | 日本語を勉強する**ために**日本に来た (để học tiếng Nhật nên đến Nhật) |
| **Mẹo đọc** | Vた + ために → nguyên nhân | Vる + ために → mục đích |

## 5. から với thể lịch sự

から có thể gắn sau cả TTT lẫn thể lịch sự (ので phổ biến nhất với TTT, nhưng cũng đi được với thể lịch sự: ですので, ますので — sắc thái rất trang trọng).

```
暑いですから / 窓を / 開けてください。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 暑いですから | Aいです + **から** → 🔒 **đóng gói:** "nóng" → giải phóng bộ nhớ → から cho biết: sắp có kết quả/yêu cầu → đọc tiếp |
| 2 | 窓を | を → 🔒 **đóng gói:** "cửa sổ" → を cho biết đối tượng → đọc tiếp |
| 3 | 開けてください | (chủ ngữ ẩn: bạn) → Vてください → yêu cầu → "xin hãy mở" → câu kết thúc ✅ |
| **Dịch** | | **Vì nóng nên xin hãy mở cửa sổ.** |

---

```
明日は / 試験がありますから / 今日は / 早く / 寝ます。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 明日は | は → 🔒 **đóng gói:** "ngày mai" → は cho biết chủ đề → đọc tiếp |
| 2 | 試験がありますから | Vます + **から** → 🔒 **đóng gói:** "có thi" → giải phóng bộ nhớ → から cho biết: sắp có kết quả → đọc tiếp |
| 3 | 今日は | は → 🔒 **đóng gói:** "hôm nay" → は cho biết chủ đề → đọc tiếp |
| 4 | 早く寝ます | (chủ ngữ ẩn: tôi) → "ngủ sớm" → câu kết thúc ✅ |
| **Dịch** | | **Vì ngày mai có thi nên hôm nay tôi ngủ sớm.** |

> **So sánh:** TTT + から (thân mật): 暑い**から**開けて. Thể lịch sự + から: 暑い**ですから**開けてください. Cả 2 đều đúng. ので phổ biến nhất với TTT, nhưng cũng đi được với thể lịch sự (ですので, ますので).

## 6. Vて nguyên nhân vs Vて trình tự -- Nhắc lại

Bài 16 đã giới thiệu Vて có 2 nghĩa. Ở đây so sánh trong ngữ cảnh nguyên nhân:

```
Trình tự:  朝起きて、顔を洗って、学校に行く。
           → Sáng dậy, rửa mặt, rồi đi học. (theo thời gian, không có nhân quả)

Nguyên nhân: 事故があって、電車が遅れた。
             → Vì có tai nạn nên tàu trễ. (A là nguyên nhân trực tiếp của B)
```

> **Cách phân biệt khi đọc:** Nếu hành động 1 là **nguyên nhân trực tiếp** dẫn đến hành động 2 → nghĩa nguyên nhân. Nếu chỉ theo **trình tự thời gian** → nghĩa nối.

## 7. Vなくて -- Nguyên nhân phủ định

Đã học ở Bài 17. Ở đây nhắc lại trong bối cảnh so sánh.

```
時間が / なくて / 朝ご飯を / 食べられませんでした。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 時間が | が → chủ ngữ → 🔒 **đóng gói:** "thời gian" → が cho biết chủ ngữ → đọc tiếp |
| 2 | なくて | ない dạng て → 🔒 **đóng gói:** "không có thời gian" → giải phóng bộ nhớ → なくて cho biết: sắp có kết quả → đọc tiếp |
| 3 | 朝ご飯を | を → 🔒 **đóng gói:** "bữa sáng" → を cho biết đối tượng → đọc tiếp |
| 4 | 食べられませんでした | (chủ ngữ ẩn: tôi) → phủ định quá khứ khả năng → "đã không ăn được" → câu kết thúc ✅ |
| **Dịch** | | **Vì không có thời gian nên không ăn sáng được.** |

---

```
勉強しなくて / 試験に / 落ちました。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 勉強しなくて | Vなくて → 🔒 **đóng gói:** "không học" → giải phóng bộ nhớ → なくて cho biết: sắp có kết quả → đọc tiếp |
| 2 | 試験に | に → 🔒 **đóng gói:** "bài thi" → に cho biết đối tượng → đọc tiếp |
| 3 | 落ちました | (chủ ngữ ẩn: tôi) → "đã trượt" → câu kết thúc ✅ |
| **Dịch** | | **Vì không học nên trượt bài thi.** |

> **Phân biệt Vなくて vs Vないで:**
> - **Vなくて** = vì không A nên B (nhân quả). Ví dụ: 食べ**なくて**元気がない (vì không ăn nên mệt)
> - **Vないで** = không làm A mà làm B (trạng thái kèm theo). Ví dụ: 食べ**ないで**出かけた (không ăn mà đi ra ngoài)
> Khi đọc: gặp なくて → dự đoán kết quả (nhân quả). Gặp ないで → dự đoán hành động khác (trạng thái).

## 8. だから / ですから -- Liên từ đầu câu (vì vậy)

Khác với から gắn cuối mệnh đề, **だから / ですから** đứng **đầu câu SAU** để nối 2 câu riêng biệt.

```
雨が降っています。だから / 傘を / 持って行きます。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 雨が降っています。 | Câu 1 hoàn chỉnh → 🔒 **đóng gói:** "đang mưa" → giải phóng bộ nhớ → đọc tiếp |
| 2 | だから | **liên từ đầu câu** → 🔒 **đóng gói:** "vì vậy" → giải phóng bộ nhớ → だから cho biết: sắp có kết quả → đọc tiếp |
| 3 | 傘を | を → 🔒 **đóng gói:** "ô" → を cho biết đối tượng → đọc tiếp |
| 4 | 持って行きます | (chủ ngữ ẩn: tôi) → "mang theo" → câu kết thúc ✅ |
| **Dịch** | | **Đang mưa. Vì vậy tôi mang ô theo.** |

---

```
明日は試験です。ですから / 今日は / 早く / 寝てください。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 明日は試験です。 | Câu 1 → 🔒 **đóng gói:** "ngày mai có thi" → giải phóng bộ nhớ → đọc tiếp |
| 2 | ですから | **liên từ lịch sự** → 🔒 **đóng gói:** "vì vậy" → giải phóng bộ nhớ → ですから cho biết: sắp có kết quả/yêu cầu → đọc tiếp |
| 3 | 今日は | は → 🔒 **đóng gói:** "hôm nay" → は cho biết chủ đề → đọc tiếp |
| 4 | 早く寝てください | (chủ ngữ ẩn: bạn) → "xin hãy ngủ sớm" → câu kết thúc ✅ |
| **Dịch** | | **Ngày mai có thi. Vì vậy hôm nay hãy ngủ sớm.** |

> **Phân biệt:**
> - **から** (trợ từ): gắn cuối mệnh đề, nối 2 mệnh đề trong 1 câu → 雨だ**から**傘を持つ
> - **だから** (liên từ): đứng đầu câu mới, nối 2 câu riêng biệt → 雨だ。**だから**傘を持つ
> - **ですから**: dạng lịch sự của だから

## 9. そのため / そのために -- Liên từ trang trọng (do đó)

Dạng trang trọng của だから, thường gặp trong **tin tức, báo cáo, văn viết**.

```
大雨が降りました。そのため / 電車が / 止まりました。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 大雨が降りました。 | Câu 1 → 🔒 **đóng gói:** "mưa lớn" → giải phóng bộ nhớ → đọc tiếp |
| 2 | そのため | **liên từ trang trọng** → 🔒 **đóng gói:** "do đó" → giải phóng bộ nhớ → そのため cho biết: sắp có kết quả (thường tiêu cực) → đọc tiếp |
| 3 | 電車が | が → chủ ngữ → 🔒 **đóng gói:** "tàu điện" → が cho biết chủ ngữ → đọc tiếp |
| 4 | 止まりました | "đã dừng" → câu kết thúc ✅ |
| **Dịch** | | **Mưa lớn. Do đó tàu điện đã ngừng chạy.** |

---

```
人口が増加しています。そのために / 住宅問題が / 深刻になっています。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 人口が増加しています。 | Câu 1 → 🔒 **đóng gói:** "dân số đang tăng" → giải phóng bộ nhớ → đọc tiếp |
| 2 | そのために | **liên từ** → 🔒 **đóng gói:** "do đó" → giải phóng bộ nhớ → そのために cho biết: sắp có kết quả → đọc tiếp |
| 3 | 住宅問題が | が → chủ ngữ → 🔒 **đóng gói:** "vấn đề nhà ở" → が cho biết chủ ngữ → đọc tiếp |
| 4 | 深刻になっています | "đang trở nên nghiêm trọng" → câu kết thúc ✅ |
| **Dịch** | | **Dân số đang tăng. Do đó vấn đề nhà ở đang trở nên nghiêm trọng.** |

> **So sánh liên từ nguyên nhân:**
> | Liên từ | Sắc thái | Ngữ cảnh |
> |---------|----------|----------|
> | だから | Trực tiếp, văn nói | Hội thoại, blog |
> | ですから | Lịch sự | Hội thoại trang trọng |
> | そのため(に) | Trang trọng, khách quan | Tin tức, báo cáo, luận văn |

## 10. Bảng so sánh tổng hợp -- Tất cả dạng nguyên nhân

### Trợ từ/cấu trúc gắn trong câu

| Dạng | Sắc thái | Trang trọng | Ví dụ |
|------|----------|-------------|-------|
| **から** | Chủ quan, lý do cá nhân | Thấp~Trung | 疲れた**から**帰る (mệt nên về) |
| **ので** | Khách quan, lịch sự | Trung bình | 疲れた**ので**帰ります (vì mệt nên xin về) |
| **Vて** | Nguyên nhân nhẹ, tự nhiên | Thấp | 疲れ**て**寝てしまった (mệt nên ngủ mất) |
| **Vなくて** | Nguyên nhân phủ định | Thấp | 時間がなく**て**行けなかった (vì không có thời gian) |
| **ために** | Trang trọng, báo cáo | Cao | 疲労の**ために**倒れた (do kiệt sức nên ngã) |

### Liên từ đầu câu (nối 2 câu riêng biệt)

| Liên từ | Sắc thái | Ngữ cảnh | Ví dụ |
|---------|----------|----------|-------|
| **だから** | Trực tiếp | Hội thoại, blog | 雨だ。**だから**行かない。 |
| **ですから** | Lịch sự | Hội thoại trang trọng | 雨です。**ですから**行きません。 |
| **そのため(に)** | Khách quan, trang trọng | Tin tức, báo cáo, luận văn | 大雨。**そのため**電車停止。 |

> **Mẹo đọc nhanh:**
> - **から** → lý do cá nhân, thường dùng trong hội thoại
> - **ので** → lý do lịch sự, thường gặp trong văn viết lịch sự
> - **Vて / Vなくて** → nguyên nhân tự nhiên / phủ định
> - **ために** → trang trọng, thường gặp trong tin tức, báo cáo
> - **だから / ですから / そのため** → liên từ đầu câu, dễ nhận diện nhất

## Dự đoán tổng hợp: Mệnh đề nguyên nhân

| Gặp tín hiệu | Dự đoán | Xác nhận |
|--------------|---------|----------|
| [TTT/thể lịch sự] + **から** | Nguyên nhân chủ quan → sắp có kết quả | Kết quả/hành động theo sau |
| [TTT] + **ので** | Nguyên nhân khách quan → sắp có kết quả | Kết quả/hành động theo sau |
| Vて + [mệnh đề kết quả] | Nguyên nhân nhẹ (vì A nên B) | Mệnh đề sau là hậu quả |
| Vなくて + [kết quả] | Nguyên nhân phủ định (vì không A nên B) | Kết quả theo sau |
| Vた/**Nの** + **ために** | Nguyên nhân trang trọng (thường tiêu cực) | Kết quả ngoài ý muốn |
| Vる + **ために** | **Không phải nguyên nhân** → mục đích (Bài 31) | Hành động có chủ đích |
| **だから / ですから** (đầu câu) | Liên từ → câu trước là nguyên nhân, câu sau là kết quả | "Vì vậy..." |
| **そのため(に)** (đầu câu) | Liên từ trang trọng → nguyên nhân ở câu trước | "Do đó..." (tin tức, báo cáo) |

> **Nguyên tắc vàng:** Gặp tín hiệu nguyên nhân → biết ngay phần SAU là kết quả. Đọc phần nguyên nhân trước, tạm giữ trong đầu, rồi đọc tiếp kết quả → ghép lại: "vì A nên B". Liên từ đầu câu (だから, そのため) thì ngược lại: đọc câu trước (nguyên nhân), gặp liên từ → biết câu sau là kết quả.
