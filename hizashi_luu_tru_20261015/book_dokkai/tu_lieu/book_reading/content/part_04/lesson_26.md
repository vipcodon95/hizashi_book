# Bài 26: Mệnh đề bổ nghĩa danh từ

> Đây là cấu trúc **quan trọng nhất** để đọc hiểu tiếng Nhật ở mức trung cấp trở lên.
> Mọi câu phức trong tiếng Nhật đều xây dựng trên nền tảng này.
> Khác biệt cốt lõi: tiếng Việt đặt mệnh đề SAU danh từ, tiếng Nhật đặt TRƯỚC.

---

## 1. So sánh trực quan: Nhật vs Việt

```
Tiếng Việt:
   cuốn sách    [mà tôi mua hôm qua]
      N          ← mệnh đề SAU

Tiếng Nhật:
   [昨日買った]     本
   mệnh đề TRƯỚC →  N
```

Cùng 1 câu phức:

```
Tiếng Việt:
   Tôi đã xem   bộ phim   [mà bạn giới thiệu].
   → Đọc "bộ phim" trước → biết ngay đang nói về phim → rồi mới đọc mệnh đề bổ nghĩa.

Tiếng Nhật:
   [友達が薦めた]    映画を    見ました。
   → Đọc mệnh đề dài trước → chưa biết nó bổ nghĩa cho gì → đến 映画 mới biết.
```

> **Vấn đề của người Việt:** Đọc mệnh đề dài mà chưa biết nó bổ nghĩa cho danh từ nào → não bị "treo". Giải pháp: nhận ra **tín hiệu mệnh đề bổ nghĩa** để dự đoán.

---

## 2. Tín hiệu nhận diện: Khi nào đang ở trong mệnh đề bổ nghĩa?

Khi đọc từ trái sang phải, nếu thấy:
- TTT (Vた, Vる, Vない, Vている) **mà không có** です/ます/か ở cuối
- **Và** ngay sau đó là danh từ

→ Đó là mệnh đề bổ nghĩa.

```
昨日 / 買った / 本          → 買った + 本 → mệnh đề bổ nghĩa ✅
昨日 / 買いました。         → 買いました。→ câu hoàn chỉnh, không bổ nghĩa ✗
```

> **Quy tắc:** TTT + Danh từ = mệnh đề bổ nghĩa. Thể lịch sự + 。= câu hoàn chỉnh.

## 3. Dạng cơ bản: Động từ bổ nghĩa danh từ

### Hiện tại / Thói quen

```
毎朝 / 飲む / コーヒー
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 毎朝 | thời gian → "mỗi sáng" |
| 2 | 飲む | Vる (TTT hiện tại) → "uống" → không có です → dự đoán: mệnh đề bổ nghĩa |
| 3 | コーヒー | danh từ chính → "cà phê (mà uống mỗi sáng)" |
| **Dịch** | | **cà phê uống mỗi sáng** |

### Quá khứ

```
昨日 / 買った / 本は / 面白いです。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 昨日 | thời gian → "hôm qua" |
| 2 | 買った | Vた (TTT quá khứ) → "đã mua" → không có です → dự đoán: mệnh đề bổ nghĩa |
| 3 | 本は | danh từ chính + は → 🔒 **đóng gói:** "sách mua hôm qua" → は cho biết đây là chủ đề → sắp có vị ngữ kết câu |
| 4 | 面白いです | vị ngữ chính → "thú vị" → người đánh giá: **tôi** (ẩn) → câu kết thúc ✅ |
| **Dịch** | | **Cuốn sách mua hôm qua thú vị.** |

### Phủ định

```
砂糖を / 入れない / コーヒーが / 好きです。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 砂糖を | を → đối tượng → "đường" |
| 2 | 入れない | Vない (TTT phủ định) → "không cho" → dự đoán: mệnh đề bổ nghĩa |
| 3 | コーヒーが | danh từ chính + が → 🔒 **đóng gói:** "cà phê không đường" → が cho biết là đối tượng cảm xúc → sắp có 好き/嫌い |
| 4 | 好きです | vị ngữ → "thích" → người thích: **tôi** (ẩn) → câu kết thúc ✅ |
| **Dịch** | | **Tôi thích cà phê không đường.** |

### Đang (ている)

```
今 / 走っている / 人は / 田中さんです。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 今 | "bây giờ" |
| 2 | 走っている | Vている (TTT tiếp diễn) → "đang chạy" → chưa kết câu → dự đoán: mệnh đề bổ nghĩa |
| 3 | 人は | danh từ chính + は → 🔒 **đóng gói:** "người đang chạy" → は cho biết chủ đề → sắp có vị ngữ |
| 4 | 田中さんです | "là Tanaka" → câu kết thúc ✅ |
| **Dịch** | | **Người đang chạy kia là Tanaka.** |

## 4. Quy tắc が thay は trong mệnh đề phụ

Chủ ngữ bên trong mệnh đề bổ nghĩa **luôn dùng が**, không dùng は.

```
Câu đơn:    母は    料理を    作ります。     (は = chủ đề)
Mệnh đề:   母が    作った    料理            (が = chủ ngữ mệnh đề phụ)
```

```
母が / 作った / 料理は / おいしいです。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 母が | **が** → chủ ngữ mệnh đề phụ (không phải chủ ngữ chính!) → "mẹ" |
| 2 | 作った | Vた → "đã nấu" → dự đoán: bổ nghĩa danh từ tiếp |
| 3 | 料理は | danh từ chính + **は** → 🔒 **đóng gói:** "món ăn mẹ nấu" → は → chủ đề chính → sắp có vị ngữ |
| 4 | おいしいです | vị ngữ → "ngon" → người đánh giá: **tôi** (ẩn, 母が là chủ ngữ mệnh đề phụ "nấu") → câu kết thúc ✅ |
| **Dịch** | | **Món ăn mà mẹ nấu rất ngon.** |

---

```
先生が / 書いた / 本を / 読みました。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 先生が | **が** → chủ ngữ mệnh đề phụ → "thầy/cô" |
| 2 | 書いた | Vた → "đã viết" → bổ nghĩa |
| 3 | 本を | danh từ chính + を → 🔒 **đóng gói:** "sách thầy viết" → を → đối tượng → sắp có hành động |
| 4 | 読みました | vị ngữ chính → "đã đọc" → chủ ngữ ẩn: **tôi** đọc (先生が là chủ ngữ mệnh đề phụ "viết") → câu kết thúc ✅ |
| **Dịch** | | **Tôi đã đọc cuốn sách mà thầy/cô viết.** |

> **Mẹo đọc:** Gặp が giữa câu mà SAU nó là TTT (không phải です/ます) → đây là chủ ngữ mệnh đề phụ. Chủ ngữ/chủ đề CHÍNH sẽ có は hoặc が ở vị trí sau.

## 5. Tính từ & Danh từ bổ nghĩa -- Quy tắc đặc biệt

Khi tính từ な hoặc danh từ bổ nghĩa danh từ ở **thì hiện tại khẳng định**, có quy tắc riêng:

| Loại | Câu đơn (vị ngữ) | Bổ nghĩa danh từ |
|------|-------------------|-------------------|
| Tính từ い | 高い**です** | 高い + N (giữ nguyên) |
| Tính từ な | 静か**です** / 静か**だ** | 静か**な** + N (だ → な) |
| Danh từ | 学生**です** / 学生**だ** | 学生**の** + N (だ → の) |

```
有名な / レストランで / 食べました。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 有名な | Aな + **な** → dự đoán: sắp có danh từ được bổ nghĩa |
| 2 | レストランで | danh từ chính + で → 🔒 **đóng gói:** "nhà hàng nổi tiếng" → で → địa điểm hành động → sắp có hành động |
| 3 | 食べました | "đã ăn" → chủ ngữ ẩn: **tôi** ăn → câu kết thúc ✅ |
| **Dịch** | | **Tôi đã ăn ở nhà hàng nổi tiếng.** |

---

```
日本語が / 上手な / 学生が / 発表しました。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 日本語が | が → "tiếng Nhật" (chủ ngữ mệnh đề phụ -- đối tượng năng lực) |
| 2 | 上手な | Aな + な → bổ nghĩa → "giỏi" |
| 3 | 学生が | danh từ chính + が → 🔒 **đóng gói:** "sinh viên giỏi tiếng Nhật" → が → chủ ngữ chính → sắp có vị ngữ |
| 4 | 発表しました | "đã thuyết trình" → câu kết thúc ✅ |
| **Dịch** | | **Sinh viên giỏi tiếng Nhật đã thuyết trình.** |

---

```
20歳以上の / 人は / お酒を / 買えます。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 20歳以上の | N + **の** → bổ nghĩa → "từ 20 tuổi trở lên" |
| 2 | 人は | danh từ chính + は → 🔒 **đóng gói:** "người từ 20 tuổi trở lên" → は → chủ đề → sắp có vị ngữ kết câu |
| 3 | お酒を | を → đối tượng → "rượu" |
| 4 | 買えます | "có thể mua" → câu kết thúc ✅ |
| **Dịch** | | **Người từ 20 tuổi trở lên có thể mua rượu.** |

> **Cảnh báo:** Một số từ kết thúc bằng い nhưng thực ra là **tính từ な**, phải dùng **な** (không dùng の) trước danh từ:
> - きれい**な**花 ✅ → "hoa đẹp"
> - ~~きれいの花~~ ❌ → きれい là tính từ な, dù nhìn giống Aい
> - 有名**な**人 ✅ → "người nổi tiếng"
>
> Khi đọc, gặp **な** trước danh từ → đây là tính từ な bổ nghĩa.

## 6. Mệnh đề bổ nghĩa KHÔNG có chủ ngữ

Rất phổ biến. Khi chủ ngữ mệnh đề phụ trùng với chủ ngữ chính, hoặc rõ từ ngữ cảnh, nó bị lược bỏ.

```
昨日 / 食べた / ラーメンは / おいしかったです。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 昨日 | "hôm qua" |
| 2 | 食べた | Vた → "đã ăn" → ai ăn? → không có が → ngầm hiểu: **tôi** ăn |
| 3 | ラーメンは | danh từ chính + は → 🔒 **đóng gói:** "mì ramen tôi ăn hôm qua" → は → chủ đề → sắp có vị ngữ kết câu |
| 4 | おいしかったです | "ngon" → câu kết thúc ✅ |
| **Dịch** | | **Mì ramen tôi ăn hôm qua ngon lắm.** |

---

```
駅の近くに / ある / レストランで / 食べましょう。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 駅の近くに | に → vị trí → "ở gần ga" |
| 2 | ある | Vる → "có/tồn tại" → không có chủ ngữ → bổ nghĩa danh từ tiếp |
| 3 | レストランで | danh từ chính + で → 🔒 **đóng gói:** "nhà hàng gần ga" → で → địa điểm hành động → sắp có hành động |
| 4 | 食べましょう | "ăn nhé" → chủ ngữ ẩn: **chúng ta** → câu kết thúc ✅ |
| **Dịch** | | **Ăn ở nhà hàng gần ga đi.** |

## 7. Mệnh đề bổ nghĩa dạng nội dung

Ở các mục trước, danh từ được bổ nghĩa luôn đóng **vai trò ngữ pháp** trong mệnh đề (là chủ ngữ, tân ngữ...):
- 買った**本** → 本 là tân ngữ của 買う ("sách mà đã mua")
- 走っている**人** → 人 là chủ ngữ của 走る ("người đang chạy")

Nhưng còn một dạng rất phổ biến: mệnh đề diễn tả **nội dung** của danh từ, và danh từ **không** đóng vai trò ngữ pháp trong mệnh đề:

```
日本に行く予定
```
→ "dự định đi Nhật" (予定 không phải chủ ngữ hay tân ngữ của 行く -- mệnh đề mô tả **nội dung** của dự định)

Các danh từ thường gặp trong dạng này: **予定** (dự định), **ニュース** (tin tức), **話** (chuyện), **噂** (tin đồn), **理由** (lý do), **経験** (kinh nghiệm), **約束** (lời hứa), **計画** (kế hoạch)...

### Ví dụ 1

```
日本に / 行く / 予定が / あります。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 日本に | に → điểm đến → "đến Nhật" |
| 2 | 行く | Vる (TTT) → "đi" → không kết câu → dự đoán: mệnh đề bổ nghĩa |
| 3 | 予定が | danh từ chính + が → 🔒 **đóng gói:** "dự định đi Nhật" → が → chủ ngữ → sắp có vị ngữ |
| 4 | あります | "có" → câu kết thúc ✅ |
| **Dịch** | | **Tôi có dự định đi Nhật.** |

### Ví dụ 2

```
地震が / あった / ニュースを / 見ました。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 地震が | が → chủ ngữ mệnh đề phụ → "động đất" |
| 2 | あった | Vた → "đã có/xảy ra" → dự đoán: bổ nghĩa danh từ tiếp |
| 3 | ニュースを | danh từ chính + を → 🔒 **đóng gói:** "tin về động đất" → を → đối tượng → sắp có hành động |
| 4 | 見ました | "đã xem" → chủ ngữ ẩn: **tôi** xem (地震が là chủ ngữ mệnh đề phụ "xảy ra") → câu kết thúc ✅ |
| **Dịch** | | **Tôi đã xem tin về động đất.** |

> **Mẹo đọc:** Dạng nội dung trông giống hệt dạng quan hệ (đều là TTT + Danh từ). Cách đọc vẫn giống nhau: TTT + Danh từ → mệnh đề bổ nghĩa. Khác biệt chỉ ở nghĩa: "N **mà** ~" (quan hệ) vs "N **rằng/về việc** ~" (nội dung). Bạn không cần phân biệt khi đọc -- quy trình xử lý hoàn toàn giống nhau.

## 8. Mệnh đề dài -- Nhiều thành phần

```
友達が / 去年の夏 / 一人で / 旅行した / 国は / タイです。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 友達が | が → chủ ngữ mệnh đề phụ → "bạn" |
| 2 | 去年の夏 | thời gian → "mùa hè năm ngoái" |
| 3 | 一人で | で → phương thức → "một mình" |
| 4 | 旅行した | Vた → "đã du lịch" → bổ nghĩa |
| 5 | 国は | danh từ chính + は → 🔒 **đóng gói:** "đất nước bạn đã du lịch một mình" → は → chủ đề → sắp có vị ngữ kết câu |
| 6 | タイです | "là Thái Lan" → câu kết thúc ✅ |
| **Dịch** | | **Đất nước mà bạn tôi đã một mình du lịch mùa hè năm ngoái là Thái Lan.** |

```
母が / 毎朝 / 早く起きて / 家族のために / 作ってくれる / 朝ご飯が / 大好きです。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 母が | が → chủ ngữ mệnh đề phụ → "mẹ" |
| 2 | 毎朝 | "mỗi sáng" |
| 3 | 早く起きて | Vて → nối hành động → "dậy sớm, rồi..." |

| 5 | 作ってくれる | Vてくれる (TTT) → "nấu cho (tôi)" → bổ nghĩa |
| 6 | 朝ご飯が | danh từ chính + が → 🔒 **đóng gói:** "bữa sáng mẹ dậy sớm nấu cho cả nhà" → が → đối tượng cảm xúc → sắp có 好き/嫌い |
| 7 | 大好きです | "rất thích" → người thích: **tôi** (ẩn, 母が là chủ ngữ mệnh đề phụ "nấu") → câu kết thúc ✅ |
| **Dịch** | | **Tôi rất thích bữa sáng mà mẹ dậy sớm mỗi sáng nấu cho cả nhà.** |

## 9. Mệnh đề lồng 2 lớp

Một mệnh đề bổ nghĩa có thể chứa mệnh đề bổ nghĩa khác bên trong.

```
[先生が 授業で 使っている] 教科書を / 書いた / 人に / 会いました。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 先生が | が → chủ ngữ mệnh đề phụ (lớp trong) → "thầy" |
| 2 | 授業で | で → "trong lớp" |
| 3 | 使っている | Vている (TTT) → "đang dùng" → bổ nghĩa |
| 4 | 教科書を | danh từ (lớp trong) + を → 🔒 **đóng gói:** "giáo trình mà thầy đang dùng" → trong đầu giờ chỉ còn **"giáo trình đó"** |
| 5 | 書いた | Vた → "đã viết" → bổ nghĩa lớp ngoài |
| 6 | 人に | danh từ chính (lớp ngoài) + に → 🔒 **đóng gói:** "người viết giáo trình đó" → trong đầu giờ chỉ còn **"người đó"** |
| 7 | 会いました | vị ngữ chính → "đã gặp" → chủ ngữ ẩn: **tôi** gặp (先生が là chủ ngữ mệnh đề phụ "dùng") → câu kết thúc ✅ |
| **Dịch** | | **Tôi đã gặp người viết cuốn giáo trình mà thầy đang dùng trong lớp.** |

> **Chiến lược đọc 2 lớp:**
> 1. Đọc từ trái sang phải, gặp danh từ + trợ từ lần 1 (教科書を) → lớp trong kết thúc
> 2. Tiếp tục đọc, gặp danh từ + trợ từ lần 2 (人に) → lớp ngoài kết thúc
> 3. Cuối cùng gặp vị ngữ chính (会いました)

---

```
[昨日 私が 駅で 偶然 会った] 友達が / [先月 出版した] 本は / ベストセラーになりました。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 昨日 | "hôm qua" |
| 2 | 私が | が → chủ ngữ mệnh đề phụ lớp 1 → "tôi" |
| 3 | 駅で | で → "ở ga" |
| 4 | 偶然 | "tình cờ" |
| 5 | 会った | Vた → "đã gặp" → bổ nghĩa |
| 6 | 友達が | danh từ lớp 1 + が → 🔒 **đóng gói:** "người bạn gặp ở ga hôm qua" → trong đầu giờ chỉ còn **"bạn đó"** → chủ ngữ lớp 2 |
| 7 | 先月 | "tháng trước" |
| 8 | 出版した | Vた → "đã xuất bản" → bổ nghĩa |
| 9 | 本は | danh từ lớp 2 + は → 🔒 **đóng gói:** "sách mà bạn đó xuất bản tháng trước" → trong đầu giờ chỉ còn **"cuốn sách đó"** → chủ đề chính |
| 10 | ベストセラーになりました | "đã trở thành bestseller" → câu kết thúc ✅ |
| **Dịch** | | **Cuốn sách mà người bạn (tôi tình cờ gặp ở ga hôm qua) xuất bản tháng trước đã trở thành bestseller.** |

## 10. Thử thách: Mệnh đề lồng 3 lớp

```
去年の夏に / 私が / 北海道で / 偶然 / 出会った / 画家が / 最近 / 東京の有名なギャラリーで / 開いた / 展覧会で / 友達が / 買った / 絵は / とても / 美しかったです。
```

### Tách 3 lớp

```
Lớp 1 (trong cùng):
  去年の夏に 私が 北海道で 偶然 出会った → [画家]
  "mùa hè năm ngoái tôi tình cờ gặp ở Hokkaido" → bổ nghĩa cho 画家 (họa sĩ)

Lớp 2 (giữa):
  画家が 最近 東京の有名なギャラリーで 開いた → [展覧会]
  "họa sĩ (đó) gần đây mở ở gallery nổi tiếng Tokyo" → bổ nghĩa cho 展覧会 (triển lãm)

Lớp 3 (ngoài):
  展覧会で 友達が 買った → [絵]
  "bạn mua ở triển lãm (đó)" → bổ nghĩa cho 絵 (bức tranh)

Mệnh đề chính:
  絵は とても 美しかったです。
  "bức tranh (đó) rất đẹp."
```

### Phân tích từng bước

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 去年の夏に | に → thời điểm → "mùa hè năm ngoái" |
| 2 | 私が | **が** → chủ ngữ lớp 1 → "tôi" |
| 3 | 北海道で | で → địa điểm → "ở Hokkaido" |
| 4 | 偶然 | trạng từ → "tình cờ" |
| 5 | 出会った | Vた → "đã gặp" → chưa kết câu (câu Nhật phải kết bằng vị ngữ, đây chưa phải) → bổ nghĩa |
| 6 | 画家が | danh từ lớp 1 + **が** → 🔒 **đóng gói lớp 1:** "họa sĩ mà tôi tình cờ gặp ở Hokkaido" → trong đầu giờ chỉ còn **"họa sĩ đó"** → が cho biết họa sĩ đó là chủ ngữ tiếp → đọc tiếp |
| 7 | 最近 | thời gian → "gần đây" |
| 8 | 東京の有名なギャラリーで | の + な + で → "ở gallery nổi tiếng Tokyo" |
| 9 | 開いた | Vた → "đã mở" → vẫn chưa kết câu → bổ nghĩa |
| 10 | 展覧会で | danh từ lớp 2 + **で** → 🔒 **đóng gói lớp 2:** "triển lãm mà họa sĩ đó mở" → trong đầu giờ chỉ còn **"triển lãm đó"** → で cho biết là địa điểm → đọc tiếp |
| 11 | 友達が | **が** → chủ ngữ lớp 3 → "bạn" |
| 12 | 買った | Vた → "đã mua" → bổ nghĩa |
| 13 | 絵は | danh từ chính + **は** → 🔒 **đóng gói lớp 3:** "bức tranh mà bạn mua ở triển lãm đó" → trong đầu giờ chỉ còn **"bức tranh đó"** → は cho biết đây là chủ đề chính → sắp có vị ngữ kết câu |
| 14 | とても | "rất" |
| 15 | 美しかったです | vị ngữ chính → "đẹp" → câu kết thúc ✅ |
| **Dịch** | | **Bức tranh mà bạn tôi mua ở triển lãm mà họa sĩ (tôi tình cờ gặp ở Hokkaido mùa hè năm ngoái) gần đây mở tại gallery nổi tiếng Tokyo rất đẹp.** |

> **Nhận diện 3 chủ ngữ khác nhau:** Mỗi lớp có 1 chủ ngữ riêng đều đánh dấu bằng が:
> - 私**が** → chủ ngữ lớp 1 (tôi gặp)
> - 画家**が** → chủ ngữ lớp 2 (họa sĩ mở)
> - 友達**が** → chủ ngữ lớp 3 (bạn mua)
> - 絵**は** → chủ đề chính (bức tranh)
>
> **Chiến lược:** Mỗi lần gặp が → biết đang có chủ ngữ mới. Mỗi lần gặp Vた + danh từ → biết 1 lớp mệnh đề vừa kết thúc. Đếm số lần gặp が = đếm số lớp.

## 11. Phân biệt: Mệnh đề bổ nghĩa vs Câu hoàn chỉnh

| Dấu hiệu | Là gì | Ví dụ |
|-----------|-------|-------|
| TTT + **Danh từ** | Mệnh đề bổ nghĩa | 買った**本** (sách mà đã mua) |
| TTT + **と** | Mệnh đề trích dẫn (bài 27) | 買った**と**言った (nói rằng đã mua) |
| TTT + **から/ので** | Mệnh đề nguyên nhân (bài 28) | 買った**から** (vì đã mua) |
| TTT + **。** | Câu hoàn chỉnh (văn nói/văn viết) | 買った**。** (Đã mua.) |
| ます/です + **。** | Câu hoàn chỉnh (lịch sự) | 買いました**。** |

> **Mẹo:** Khi đọc gặp TTT giữa câu → nhìn ngay phần SAU nó: danh từ? と? から? → xác định loại mệnh đề.

## Chiến lược đọc tổng hợp -- 5 bước

> **Tại sao cần chiến lược?** Câu phức tiếng Nhật có thể có **nhiều chủ ngữ khác nhau** ở mỗi mệnh đề. Chủ ngữ mệnh đề phụ (が) thường **khác** chủ ngữ câu chính. Nếu không phân biệt → hiểu sai "ai làm gì". Chiến lược này giúp: (1) nhận diện chủ ngữ từng mệnh đề, (2) đóng gói đúng "ai làm gì", (3) giải phóng bộ nhớ để đọc tiếp.

### Bước 1: Nhận diện chủ ngữ

Đọc từ trái sang phải. Việc đầu tiên là xác định **"ai"** đang được nói đến:

| Gặp | Ý nghĩa | Thuộc về |
|-----|---------|----------|
| **は** | Chủ đề chính của **toàn câu** | Câu chính |
| **が** + TTT (chưa kết câu) | Chủ ngữ **mệnh đề phụ** | Mệnh đề phụ -- KHÔNG phải chủ ngữ chính! |
| **が** + vị ngữ kết câu | Chủ ngữ chính | Câu chính |
| Không có は/が | Chủ ngữ bị ẩn | Suy từ ngữ cảnh (thường là "tôi" hoặc chủ ngữ câu trước) |

> **Cạm bẫy lớn nhất:** 母**が**作った料理は おいしいです
> - 母**が** → chủ ngữ mệnh đề phụ → **MẸ** nấu
> - 料理**は** → chủ đề chính → **tôi** đánh giá (ẩn)
> → Hai hành động, hai chủ ngữ khác nhau! Mẹ nấu, nhưng tôi là người nói ngon.

### Bước 2: Nhận diện mệnh đề bổ nghĩa

Gặp TTT (Vた, Vる, Vない, Vている) mà chưa thấy vị ngữ kết câu → **đang trong mệnh đề bổ nghĩa**. Tiếp tục đọc cho đến gặp **danh từ + trợ từ** → mệnh đề kết thúc tại đó.

### Bước 3: Xác định "Ai làm gì"

Trước khi đóng gói, hỏi: **"Ai thực hiện hành động trong mệnh đề vừa đọc?"**

```
母が / 作った / 料理    → Ai nấu? → 母 (mẹ) -- có が rõ ràng
昨日 / 買った / 本      → Ai mua? → không có が → chủ ngữ ẩn → "tôi" mua
友達が / 薦めた / 映画   → Ai giới thiệu? → 友達 (bạn)
```

> **Lưu ý:** Chủ ngữ mệnh đề phụ có thể **khác hoàn toàn** chủ ngữ câu chính:
> - 母**が**作った料理は おいしいです → **Mẹ** nấu, **tôi** nói ngon
> - 友達**が**薦めた映画を 見ました → **Bạn** giới thiệu, **tôi** xem
> - 先生**が**書いた本を 読みました → **Thầy** viết, **tôi** đọc

### Bước 4: Đóng gói 🔒

Gom mệnh đề + danh từ thành **1 khối duy nhất**. **Phải gắn đúng chủ ngữ vào hình ảnh:**

```
母が作った料理    → 🔒 "món ăn MẸ nấu" (không phải "món ăn nấu")
昨日買った本      → 🔒 "sách TÔI mua hôm qua" (chủ ngữ ẩn = tôi)
友達が薦めた映画  → 🔒 "phim BẠN giới thiệu"
```

Sau khi đóng gói → trong đầu chỉ còn **"món ăn đó / sách đó / phim đó"** + biết **ai** liên quan → giải phóng bộ nhớ → sẵn sàng đọc tiếp.

### Bước 5: Đọc tiếp + Dự đoán

Trợ từ sau danh từ cho biết vai trò của khối vừa đóng gói → dự đoán phần tiếp:
- **は** → chủ đề chính → sắp có nhận xét/mô tả → **câu sắp kết thúc**
- **が** → chủ ngữ mới → sắp có hành động → **có thể là mệnh đề phụ tiếp hoặc câu chính**
- **を** → đối tượng → sắp có hành động tác động
- **に/で** → địa điểm/phương tiện → sắp có hành động

Nếu gặp thêm mệnh đề + danh từ → **lặp lại từ bước 1** (nhận diện chủ ngữ mới).

### Ví dụ áp dụng 5 bước -- Câu 1 lớp

```
私が / 大学で / 一緒に / 勉強した / 友達が / 来年 / 日本に / 来ます。
```

- Bước 1: 私**が** + TTT (chưa kết câu) → **tôi** là chủ ngữ mệnh đề phụ
- Bước 2: ...勉強した → TTT chưa kết câu → mệnh đề bổ nghĩa
- Bước 3: Ai học? → **tôi** học (私が)
- Bước 4: 🔒 友達 → đóng gói: **"bạn mà TÔI đã cùng học ở đại học"** → chỉ còn **"bạn đó"**
- Bước 5: 友達**が** → chủ ngữ chính → đọc tiếp → 来年日本に来ます
- **Kết quả:** "Bạn đó sẽ đến Nhật năm sau." (bạn đến, không phải tôi đến)

### Ví dụ áp dụng 5 bước -- Câu 3 lớp

```
去年の夏に私が北海道で偶然出会った画家が最近東京の有名なギャラリーで開いた展覧会で友達が買った絵はとても美しかったです。
```

**Lớp 1:**
- Bước 1: 私**が** → chủ ngữ mệnh đề phụ lớp 1 → **tôi**
- Bước 3: Ai gặp? → **tôi** gặp
- Bước 4: 🔒 画家 → **"họa sĩ TÔI tình cờ gặp ở Hokkaido"** → chỉ còn **"họa sĩ đó"**
- Bước 5: 画家**が** → chủ ngữ mới → đọc tiếp (lặp lại bước 1)

**Lớp 2:**
- Bước 1: 画家**が** → chủ ngữ mệnh đề phụ lớp 2 → **họa sĩ đó**
- Bước 3: Ai mở triển lãm? → **họa sĩ đó** mở (không phải tôi!)
- Bước 4: 🔒 展覧会 → **"triển lãm HỌA SĨ ĐÓ mở"** → chỉ còn **"triển lãm đó"**
- Bước 5: 展覧会**で** → địa điểm → đọc tiếp

**Lớp 3:**
- Bước 1: 友達**が** → chủ ngữ mệnh đề phụ lớp 3 → **bạn**
- Bước 3: Ai mua? → **bạn** mua (không phải tôi, không phải họa sĩ!)
- Bước 4: 🔒 絵 → **"bức tranh BẠN mua"** → chỉ còn **"bức tranh đó"**
- Bước 5: 絵**は** → chủ đề chính → sắp kết câu

**Câu chính:** とても美しかったです → "rất đẹp" → câu kết thúc ✅
- **Kết quả:** "Bức tranh đó rất đẹp."

> **3 chủ ngữ khác nhau, 3 hành động khác nhau:**
> - **Tôi** gặp họa sĩ
> - **Họa sĩ** mở triển lãm
> - **Bạn** mua tranh
> → Nếu gán cùng 1 chủ ngữ → hiểu sai hoàn toàn!

> **Đây chính là kỹ thuật Hình Ảnh Hóa (Semantic Encoding) từ Part 0 áp dụng vào câu phức:** Đọc đến đâu, xác định "ai làm gì" đến đó, đóng gói thành 1 hình ảnh, rồi đọc tiếp. Không cần nhớ toàn bộ chi tiết -- chỉ cần nhớ **"cái gì đó do ai đó làm"** rồi đọc tiếp.

## Dự đoán tổng hợp: Mệnh đề bổ nghĩa danh từ

| Gặp tín hiệu | Dự đoán | Ví dụ |
|--------------|---------|-------|
| Vた / Vる / Vない / Vている + **N** | Mệnh đề bổ nghĩa → "N mà..." | 買った本 |
| **が** giữa câu (chưa kết câu) | Chủ ngữ mệnh đề phụ | 母**が**作った料理 |
| **Aな** + N | Tính từ な bổ nghĩa (な thay cho だ) | 有名**な**レストラン |
| **Nの** + N | Danh từ bổ nghĩa (の thay cho だ) | 20歳以上**の**人 |
| TTT + **danh từ trừu tượng** (予定, ニュース, 理由...) | Mệnh đề nội dung → "N rằng/về việc ~" | 行く**予定**, あった**ニュース** |
| Chuỗi dài + TTT mà chưa kết câu | Đang trong mệnh đề → đọc tiếp tìm danh từ chính | ...勉強した + 友達 |
| Danh từ + **は/が/を/に/で** sau mệnh đề | Danh từ chính → mệnh đề phía trước bổ nghĩa cho nó | 友達**が** (chủ ngữ chính) |
| 2 lần gặp danh từ + trợ từ | 2 lớp mệnh đề lồng nhau | 教科書**を**書いた人**に** |
