# Bài 28: Mệnh đề trích dẫn — と

> Khi đọc tiếng Nhật, gặp と sau một mệnh đề (TTT) → đây thường là **trích dẫn**: ai đó nghĩ/nói/nghe rằng...
> と là "dấu ngoặc kép" của tiếng Nhật: nội dung bên trong 「...」と được trích dẫn lại.
> Chìa khóa: **đọc nội dung trước と**, rồi xem động từ sau と để biết đó là "nghĩ", "nói" hay "nghe".

---

## 1. と思う — Tôi nghĩ rằng ~

**Cấu trúc:** [Mệnh đề TTT] + と思う

```
明日は / 雨が降ると / 思います。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 明日は | 🔒 **đóng gói:** "ngày mai" → は cho biết đây là chủ đề → đọc tiếp |
| 2 | 雨が降ると | 🔒 **đóng gói:** "mưa" → が cho biết chủ ngữ → Vる + **と** → tín hiệu trích dẫn → dự đoán: sắp có 思う/言う → đọc tiếp |
| 3 | 思います | と → 🔒 **đóng gói nội dung trích dẫn:** "ngày mai mưa sẽ rơi" → giải phóng bộ nhớ → 思います cho biết: đây là ý kiến → (tôi) nghĩ → câu kết thúc ✅ |
| **Dịch** | | **Tôi nghĩ ngày mai sẽ mưa.** |

---

```
日本語は / 難しいけど / おもしろいと / 思います。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 日本語は | 🔒 **đóng gói:** "tiếng Nhật" → は cho biết đây là chủ đề → đọc tiếp |
| 2 | 難しいけど | Aい + けど → "khó nhưng..." → đọc tiếp |
| 3 | おもしろいと | Aい + **と** → trích dẫn → "thú vị" → dự đoán: sắp có 思う/言う → đọc tiếp |
| 4 | 思います | と → 🔒 **đóng gói nội dung trích dẫn:** "tiếng Nhật khó nhưng thú vị" → giải phóng bộ nhớ → 思います cho biết: đây là ý kiến → (tôi) nghĩ → câu kết thúc ✅ |
| **Dịch** | | **Tôi nghĩ tiếng Nhật khó nhưng thú vị.** |

> **Lưu ý:** と思う dùng **TTT** trước と. Không nói ~~です/ますと思います~~.

> **Cảnh báo -- Lỗi cực kỳ phổ biến:** Trước と (trích dẫn gián tiếp) phải dùng TTT, **không dùng です/ます**:
>
> | ❌ Sai | ✅ Đúng | Giải thích |
> |--------|---------|------------|
> | おもしろい**です**と思います | おもしろい**と**思います | Aい: bỏ です |
> | 行き**ます**と言いました | 行く**と**言いました | V: chuyển về TTT |
> | 静か**です**と思います | 静か**だと**思います | **Aな: です → だ** (hay quên nhất!) |
>
> Đặc biệt lưu ý tính từ な: です phải chuyển thành **だ** (không phải bỏ hẳn).

## 2. と言う — Nói rằng ~

```
先生は / 「明日テストがある」と / 言いました。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 先生は | 🔒 **đóng gói:** "thầy/cô" → は cho biết đây là chủ đề → đọc tiếp |
| 2 | 「明日テストがある」と | nội dung trong 「」+ **と** → trích dẫn trực tiếp → "ngày mai có kiểm tra" → dự đoán: sắp có 言う/思う → đọc tiếp |
| 3 | 言いました | と → 🔒 **đóng gói nội dung trích dẫn:** "ngày mai có kiểm tra" → giải phóng bộ nhớ → 言いました cho biết: đây là lời nói → (thầy/cô) đã nói → câu kết thúc ✅ |
| **Dịch** | | **Thầy/cô đã nói "ngày mai có kiểm tra".** |

---

```
田中さんは / パーティーに / 行かないと / 言っていました。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 田中さんは | 🔒 **đóng gói:** "anh Tanaka" → は cho biết đây là chủ đề → đọc tiếp |
| 2 | パーティーに | 🔒 **đóng gói:** "tiệc" → に cho biết điểm đến → đọc tiếp |
| 3 | 行かないと | Vない + **と** → trích dẫn → "không đi" → dự đoán: sắp có 言う/思う → đọc tiếp |
| 4 | 言っていました | と → 🔒 **đóng gói nội dung trích dẫn:** "không đi tiệc" → giải phóng bộ nhớ → 言っていました cho biết: đây là lời nói → (anh Tanaka) đã nói → câu kết thúc ✅ |
| **Dịch** | | **Anh Tanaka nói là không đi tiệc.** |

> **Phân biệt trích dẫn trực tiếp và gián tiếp:**
> - **Trực tiếp** (có 「」): Giữ nguyên lời nói gốc, **có thể chứa です/ます** bên trong 「」.
>   → 先生は「明日テストが**あります**」と言いました。
> - **Gián tiếp** (không có 「」): Bắt buộc chuyển sang **TTT** trước と.
>   → 先生は明日テストが**ある**と言いました。
>
> Khi đọc: thấy 「」→ trích dẫn trực tiếp, đọc nguyên văn. Không có 「」→ trích dẫn gián tiếp, nội dung ở dạng TTT.

## 3. と聞く — Nghe nói rằng ~

```
来月 / 会社が / 引っ越すと / 聞きました。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 来月 | thời gian → "tháng sau" → đọc tiếp |
| 2 | 会社が | 🔒 **đóng gói:** "công ty" → が cho biết chủ ngữ → đọc tiếp |
| 3 | 引っ越すと | Vる + **と** → trích dẫn → "sẽ chuyển" → dự đoán: sắp có 思う/言う/聞く → đọc tiếp |
| 4 | 聞きました | と → 🔒 **đóng gói nội dung trích dẫn:** "tháng sau công ty sẽ chuyển" → giải phóng bộ nhớ → 聞きました cho biết: đây là tin nghe được → (tôi) đã nghe → câu kết thúc ✅ |
| **Dịch** | | **Tôi nghe nói tháng sau công ty sẽ chuyển.** |

---

```
あの店は / おいしいと / 聞いたので / 行ってみました。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | あの店は | 🔒 **đóng gói:** "quán đó" → は cho biết đây là chủ đề → đọc tiếp |
| 2 | おいしいと | Aい + **と** → trích dẫn → "ngon" → dự đoán: sắp có 思う/言う/聞く → đọc tiếp |
| 3 | 聞いたので | と → 🔒 **đóng gói nội dung trích dẫn:** "quán đó ngon" → giải phóng bộ nhớ → 聞いた cho biết: đây là tin nghe được → "vì đã nghe nói" + ので → lý do → đọc tiếp |
| 4 | 行ってみました | Vてみる → (tôi) đã thử đi → câu kết thúc ✅ |
| **Dịch** | | **Vì nghe nói quán đó ngon nên tôi đã thử đi.** |

## 4. という — Gọi là ~, rằng ~

**という** là cấu trúc cực kỳ phổ biến trong văn viết, dùng để giải thích hoặc đặt tên.

### という + Danh từ: "~ gọi là..."

```
「寿司」という / 食べ物を / 知っていますか。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 「寿司」という | 🔒 **đóng gói nội dung trích dẫn:** "sushi" → giải phóng bộ nhớ → という cho biết: đặt tên → "gọi là sushi" → bổ nghĩa danh từ tiếp → đọc tiếp |
| 2 | 食べ物を | 🔒 **đóng gói:** "món ăn gọi là sushi" → を cho biết đối tượng → đọc tiếp |
| 3 | 知っていますか | Vている + か → (bạn) có biết không? → câu kết thúc ✅ |
| **Dịch** | | **Bạn có biết món ăn gọi là "sushi" không?** |

---

### ということ: "việc rằng ~"

```
彼が / 来ないということは / 知りませんでした。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 彼が | 🔒 **đóng gói:** "anh ấy" → が cho biết chủ ngữ (mệnh đề phụ) → đọc tiếp |
| 2 | 来ないということは | Vない + **ということ** → 🔒 **đóng gói nội dung trích dẫn:** "anh ấy không đến" → giải phóng bộ nhớ → ということ cho biết: danh từ hóa → "việc rằng ~" + は → chủ đề chính → đọc tiếp |
| 3 | 知りませんでした | (tôi) đã không biết → câu kết thúc ✅ |
| **Dịch** | | **Tôi đã không biết việc anh ấy không đến.** |

---

### という + Danh từ trừu tượng: "rằng ~"

Khi という đứng trước **danh từ trừu tượng** (ニュース, 話, 事実, 噂, 意見...), nghĩa không phải "gọi là" mà là **"rằng ~"** -- cụ thể hóa nội dung của danh từ đó.

```
地震が / あったという / ニュースを / 聞きました。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 地震が | 🔒 **đóng gói:** "động đất" → が cho biết chủ ngữ (mệnh đề phụ) → đọc tiếp |
| 2 | あったという | Vた + **という** → 🔒 **đóng gói nội dung trích dẫn:** "đã xảy ra động đất" → giải phóng bộ nhớ → という cho biết: nội dung "rằng ~" → bổ nghĩa danh từ tiếp → đọc tiếp |
| 3 | ニュースを | 🔒 **đóng gói:** "tin tức rằng có động đất" → を cho biết đối tượng → đọc tiếp |
| 4 | 聞きました | (tôi) đã nghe → câu kết thúc ✅ |
| **Dịch** | | **Tôi đã nghe tin rằng có động đất.** |

> **Phân biệt nhanh:**
> - という + **danh từ cụ thể** (食べ物, 人, 映画...) → **"gọi là ~"**: 「寿司」という食べ物
> - という + **danh từ trừu tượng** (ニュース, 話, 事実...) → **"rằng ~"**: 地震があったというニュース

## 5. って — Dạng văn nói của と

Trong manga, hội thoại, tin nhắn, って thay thế と:

```
田中さん、/ 明日 / 来ないって。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 田中さん、 | 🔒 **đóng gói:** "anh Tanaka" → dấu phẩy cho biết đây là chủ đề → đọc tiếp |
| 2 | 明日 | thời gian → "ngày mai" → đọc tiếp |
| 3 | 来ないって | Vない + **って** → 🔒 **đóng gói nội dung trích dẫn:** "ngày mai không đến" → giải phóng bộ nhớ → って = と(言っていた) cho biết: đây là lời nói → (anh Tanaka) nói là không đến → câu kết thúc ✅ |
| **Dịch** | | **Anh Tanaka nói là ngày mai không đến.** |

---

```
この映画、/ おもしろかったって / 聞いたよ。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | この映画、 | 🔒 **đóng gói:** "phim này" → dấu phẩy cho biết đây là chủ đề → đọc tiếp |
| 2 | おもしろかったって | Aい quá khứ + **って** → trích dẫn văn nói → "nghe nói hay" → dự đoán: sắp có 聞く → đọc tiếp |
| 3 | 聞いたよ | って → 🔒 **đóng gói nội dung trích dẫn:** "phim này hay" → giải phóng bộ nhớ → 聞いた cho biết: đây là tin nghe được → (tôi) đã nghe đấy → câu kết thúc ✅ |
| **Dịch** | | **Tôi nghe nói phim này hay lắm.** |

> **Mẹo đọc:** って = と(言う/思う/聞く). Động từ phía sau thường bị lược bỏ trong văn nói.

### って = というのは — Hỏi nghĩa / định nghĩa

って còn dùng để **hỏi nghĩa** hoặc **định nghĩa** một từ, tương đương というのは:

```
「JLPT」って何？
```
→ "JLPT là gì?" (って = というのは)

Dạng này rất phổ biến trong manga và hội thoại. Khi đọc gặp **[từ] + って + 何/どういう意味**, đây là câu hỏi nghĩa, không phải trích dẫn.

## 6. Phân biệt 3 nghĩa của と

と có nhiều nghĩa — cách phân biệt khi đọc:

| と | Tín hiệu nhận biết | Ví dụ |
|---|---------------------|-------|
| **Trích dẫn** | [Mệnh đề TTT] + と + 思う/言う/聞く | おいしい**と**思う |
| **Điều kiện** | [Mệnh đề TTT] + と + [kết quả tự nhiên] | 春になる**と**花が咲く |
| **Liệt kê "và"** | N1**と**N2 | コーヒー**と**紅茶 |

### Cách phân biệt khi đọc:

```
このボタンを / 押すと / ドアが / 開きます。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | このボタンを | 🔒 **đóng gói:** "nút này" → を cho biết đối tượng → đọc tiếp |
| 2 | 押すと | Vる + **と** → phía sau không phải 思う/言う → **điều kiện** → "nếu nhấn thì..." → đọc tiếp |
| 3 | ドアが | 🔒 **đóng gói:** "cửa" → が cho biết chủ ngữ → đọc tiếp |
| 4 | 開きます | (cửa) mở → câu kết thúc ✅ |
| **Dịch** | | **Nếu nhấn nút này thì cửa sẽ mở.** |

> **Mẹo phân biệt nhanh:**
> - Sau と có **思う/言う/聞く** → trích dẫn
> - Sau と có **kết quả/hiện tượng tự nhiên** → điều kiện
> - と nằm **giữa 2 danh từ** → liệt kê "và"

## Dự đoán tổng hợp: Mệnh đề trích dẫn

| Gặp tín hiệu | Dự đoán | Xác nhận |
|--------------|---------|----------|
| [TTT] + **と** + 思う | Ý kiến cá nhân: "tôi nghĩ rằng ~" | 思います/思っている |
| [TTT] + **と** + 言う | Trích dẫn lời nói: "nói rằng ~" | 言いました/言っていた |
| [TTT] + **と** + 聞く | Nghe nói: "nghe nói rằng ~" | 聞きました/聞いた |
| **という** + N cụ thể | Đặt tên: "gọi là ~" | Danh từ cụ thể theo sau |
| **という** + N trừu tượng | Nội dung: "rằng ~" | ニュース, 話, 事実... |
| **ということ** | Danh từ hóa: "việc rằng ~" | + は/が/を/も |
| **って** | Văn nói = と(言う/思う) | Động từ thường bị lược |
| **[từ] + って + 何** | Hỏi nghĩa = というのは | 「JLPT」って何？ |
| [TTT] + **と** (không có 思う/言う) | Có thể là điều kiện, không phải trích dẫn | Kết quả tự nhiên theo sau |

> **Nguyên tắc vàng:** Gặp と sau mệnh đề TTT → **nhìn động từ phía SAU と** để xác định nghĩa. Có 思う/言う/聞く → trích dẫn. Không có → nhiều khả năng là điều kiện.
