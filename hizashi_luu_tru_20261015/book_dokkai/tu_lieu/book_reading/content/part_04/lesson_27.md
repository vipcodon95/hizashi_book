# Bài 27: Danh từ hóa mệnh đề -- こと・の・もの

> Trong tiếng Nhật, để biến một mệnh đề thành "danh từ" (làm chủ ngữ, tân ngữ...), dùng **こと** hoặc **の** sau mệnh đề.
> Giống như tiếng Việt thêm "việc" trước mệnh đề: "việc anh ấy đến" = 彼が来ること.
> Chìa khóa: gặp こと/の/もの sau mệnh đề TTT → biết mệnh đề đã được "đóng gói" thành danh từ.

---

## 1. こと -- Danh từ hóa trừu tượng (việc, điều)

**Cấu trúc:** [Mệnh đề TTT] + こと + trợ từ

> **Tư duy:** こと biến hành động/sự kiện thành **khái niệm trừu tượng** -- "việc ~", "điều ~". Khi gặp こと sau mệnh đề TTT → đóng gói toàn bộ mệnh đề phía trước thành 1 khối danh từ.

### 1.1 Vることは...です -- Danh từ hóa làm chủ đề

```
外国語を / 勉強することは / 大切です。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 外国語を | を → đối tượng → "ngoại ngữ" |
| 2 | 勉強することは | Vる + **こと** → danh từ hóa + は → 🔒 **đóng gói loại 2:** "việc học ngoại ngữ" → は cho biết chủ đề → sắp có vị ngữ kết câu |
| 3 | 大切です | Aな → "quan trọng" → câu kết thúc ✅ |
| **Dịch** | | **Việc học ngoại ngữ rất quan trọng.** |

```
一人で / 旅行することは / 楽しいです。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 一人で | で → phương thức → "một mình" |
| 2 | 旅行することは | Vる + **こと** → danh từ hóa + は → 🔒 **đóng gói loại 2:** "việc đi du lịch một mình" → は → chủ đề → sắp có vị ngữ |
| 3 | 楽しいです | Aい → "vui" → câu kết thúc ✅ |
| **Dịch** | | **Đi du lịch một mình thì vui.** |

### 1.2 Vたことがある -- Kinh nghiệm (đã từng ~)

```
富士山に / 登ったことが / ありますか。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 富士山に | に → điểm đến → "núi Phú Sĩ" |
| 2 | 登ったことが | Vた + **こと** + が → 🔒 **đóng gói loại 2:** "kinh nghiệm leo (núi Phú Sĩ)" → が → chủ ngữ → sắp có vị ngữ |
| 3 | ありますか | **ことがある** → "đã từng ~?" → câu kết thúc ✅ |
| **Dịch** | | **Bạn đã từng leo núi Phú Sĩ chưa?** |

```
日本料理を / 食べたことが / ありません。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 日本料理を | を → đối tượng → "món Nhật" |
| 2 | 食べたことが | Vた + **こと** + が → 🔒 **đóng gói loại 2:** "kinh nghiệm ăn (món Nhật)" → が → chủ ngữ |
| 3 | ありません | **ことがない** → "chưa từng ~" → câu kết thúc ✅ |
| **Dịch** | | **Tôi chưa từng ăn món Nhật.** |

### 1.3 Vることができる -- Khả năng (có thể ~)

```
田中さんは / 英語を / 話すことが / できます。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 田中さんは | は → chủ đề → "anh Tanaka" |
| 2 | 英語を | を → đối tượng → "tiếng Anh" |
| 3 | 話すことが | Vる + **こと** + が → 🔒 **đóng gói loại 2:** "việc nói tiếng Anh" → が → chủ ngữ |
| 4 | できます | **ことができる** → "có thể ~" → câu kết thúc ✅ |
| **Dịch** | | **Anh Tanaka có thể nói tiếng Anh.** |

```
この漢字を / 読むことが / できますか。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | この漢字を | を → đối tượng → "Hán tự này" |
| 2 | 読むことが | Vる + **こと** + が → 🔒 **đóng gói loại 2:** "việc đọc (Hán tự này)" → が → chủ ngữ |
| 3 | できますか | **ことができる** → "có thể ~?" → câu kết thúc ✅ |
| **Dịch** | | **Bạn có thể đọc được Hán tự này không?** |

### 1.4 Vることにする -- Quyết định (tự mình quyết)

```
来月から / 毎日 / 運動することに / しました。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 来月から | から → điểm bắt đầu → "từ tháng sau" |
| 2 | 毎日 | thời gian → "mỗi ngày" |
| 3 | 運動することに | Vる + **ことに** → 🔒 **đóng gói loại 2:** "việc tập thể dục mỗi ngày" → に hướng tới quyết định |
| 4 | しました | **ことにする** → "đã quyết định ~" → chủ ngữ ẩn: **tôi** → câu kết thúc ✅ |
| **Dịch** | | **Tôi đã quyết định từ tháng sau sẽ tập thể dục mỗi ngày.** |

```
今年は / タバコを / やめることに / しました。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 今年は | は → chủ đề thời gian → "năm nay" |
| 2 | タバコを | を → đối tượng → "thuốc lá" |
| 3 | やめることに | Vる + **ことに** → 🔒 **đóng gói loại 2:** "việc bỏ thuốc lá" → に hướng tới quyết định |
| 4 | しました | **ことにする** → "đã quyết định ~" → chủ ngữ ẩn: **tôi** → câu kết thúc ✅ |
| **Dịch** | | **Năm nay tôi đã quyết định bỏ thuốc lá.** |

### 1.5 Vることになる -- Được quyết định (không phải mình quyết)

```
来年 / 日本に / 留学することに / なりました。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 来年 | thời gian → "năm sau" |
| 2 | 日本に | に → điểm đến → "đến Nhật" |
| 3 | 留学することに | Vる + **ことに** → 🔒 **đóng gói loại 2:** "việc du học Nhật" → に hướng tới kết quả |
| 4 | なりました | **ことになる** → "đã được quyết định ~" → câu kết thúc ✅ |
| **Dịch** | | **Năm sau tôi sẽ đi du học Nhật (đã được quyết định).** |

```
来月から / 大阪に / 転勤することに / なりました。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 来月から | から → điểm bắt đầu → "từ tháng sau" |
| 2 | 大阪に | に → điểm đến → "đến Osaka" |
| 3 | 転勤することに | Vる + **ことに** → 🔒 **đóng gói loại 2:** "việc chuyển công tác đến Osaka" → に hướng tới kết quả |
| 4 | なりました | **ことになる** → "đã được quyết định ~" → câu kết thúc ✅ |
| **Dịch** | | **Từ tháng sau tôi sẽ chuyển công tác đến Osaka (công ty quyết định).** |

> **So sánh ことにする vs ことになる:**
> - ことに**する** → **TỰ MÌNH** quyết định (ý chí cá nhân)
> - ことに**なる** → **ĐƯỢC** quyết định (công ty, trường, hoàn cảnh...)
> - する = "làm" (chủ động) / なる = "trở thành" (bị động)

## 2. の -- Danh từ hóa cụ thể / cảm nhận trực tiếp

**Cấu trúc:** [Mệnh đề TTT] + の + trợ từ

> **Tư duy:** の biến hành động thành **cảnh cụ thể, cảm nhận được** -- "cảnh ~", "việc ~ (tôi thấy/cảm nhận được)". Dùng nhiều với động từ cảm nhận (見る、聞く), cảm xúc (好き、嫌い), quên/nhớ (忘れる、覚える).

### 2.1 Vるのが好き / 上手 -- Thích / Giỏi

```
料理を / 作るのが / 好きです。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 料理を | を → đối tượng → "món ăn" |
| 2 | 作るのが | Vる + **の** + が → 🔒 **đóng gói loại 2:** "việc nấu ăn" → が → đối tượng cảm xúc → sắp có 好き/嫌い |
| 3 | 好きです | Aな → "thích" → người thích: **tôi** (ẩn) → câu kết thúc ✅ |
| **Dịch** | | **Tôi thích nấu ăn.** |

```
妹は / 絵を / 描くのが / 上手です。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 妹は | は → chủ đề → "em gái" |
| 2 | 絵を | を → đối tượng → "tranh" |
| 3 | 描くのが | Vる + **の** + が → 🔒 **đóng gói loại 2:** "việc vẽ tranh" → が → đối tượng đánh giá năng lực → sắp có 上手/下手 |
| 4 | 上手です | Aな → "giỏi" → câu kết thúc ✅ |
| **Dịch** | | **Em gái tôi giỏi vẽ tranh.** |

### 2.2 Vるのを見る / 聞く / 忘れる / 待つ -- Cảm nhận / Hành động

```
子どもたちが / 遊んでいるのが / 見えます。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 子どもたちが | が → chủ ngữ mệnh đề phụ → "bọn trẻ" |
| 2 | 遊んでいるのが | Vている + **の** + が → 🔒 **đóng gói loại 2:** "cảnh bọn trẻ đang chơi" → が → chủ ngữ (cái được nhìn thấy) → sắp có 見える/聞こえる |
| 3 | 見えます | "nhìn thấy" → chủ ngữ ẩn: **tôi** nhìn thấy → câu kết thúc ✅ |
| **Dịch** | | **Tôi nhìn thấy bọn trẻ đang chơi.** |

```
傘を / 持ってくるのを / 忘れました。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 傘を | を → đối tượng → "ô/dù" |
| 2 | 持ってくるのを | Vる + **の** + を → 🔒 **đóng gói loại 2:** "việc mang ô" → を → đối tượng → sắp có hành động |
| 3 | 忘れました | "đã quên" → chủ ngữ ẩn: **tôi** → câu kết thúc ✅ |
| **Dịch** | | **Tôi đã quên mang ô.** |

### 2.3 Vるのは...です -- Danh từ hóa làm chủ đề

```
一人で / 住むのは / さびしいです。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 一人で | で → phương thức → "một mình" |
| 2 | 住むのは | Vる + **の** + は → 🔒 **đóng gói loại 2:** "việc sống một mình" → は → chủ đề → sắp có vị ngữ kết câu |
| 3 | さびしいです | Aい → "cô đơn" → câu kết thúc ✅ |
| **Dịch** | | **Sống một mình thì cô đơn.** |

```
朝 / 早く / 起きるのは / 大変です。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 朝 | thời gian → "buổi sáng" |
| 2 | 早く | trạng từ → "sớm" |
| 3 | 起きるのは | Vる + **の** + は → 🔒 **đóng gói loại 2:** "việc dậy sớm buổi sáng" → は → chủ đề → sắp có vị ngữ |
| 4 | 大変です | Aな → "vất vả" → câu kết thúc ✅ |
| **Dịch** | | **Dậy sớm buổi sáng thì vất vả.** |

## 3. こと vs の -- Phân biệt

### 3.1 Bảng so sánh tổng quát

| Tình huống | Dùng | Ví dụ |
|------------|------|-------|
| **Cảm nhận trực tiếp** (見える、聞こえる、見る、聞く) | **の** (bắt buộc) | 歌っている**のが**聞こえる |
| **Cấu trúc cố định** với こと | **こと** (bắt buộc) | 行った**ことが**ある |
| **Trừu tượng, khái niệm chung** | **こと** (ưu tiên) | 勉強する**ことは**大切だ |
| **Hành động cụ thể, đời thường** | **の** (ưu tiên) | 泳ぐ**のが**好き |
| **Cả hai đều được** | こと / の | 読む**こと/のが**好き |

### 3.2 Chỉ dùng こと (không thể thay bằng の)

| Cấu trúc | Ví dụ |
|----------|-------|
| Vた**ことがある** (kinh nghiệm) | 日本に行った**ことがある** |
| Vる**ことができる** (khả năng) | 漢字を読む**ことができる** |
| Vる**ことにする** (quyết định) | 留学する**ことにした** |
| Vる**ことになる** (được quyết định) | 転勤する**ことになった** |

> **Mẹo:** Các cấu trúc cố định với こと đều là **thành ngữ đã hóa thạch** -- không thể thay đổi thành phần.

### 3.3 Chỉ dùng の (không thể thay bằng こと)

| Cấu trúc | Ví dụ |
|----------|-------|
| V**のが**見える / 聞こえる (cảm nhận tự nhiên) | 鳥が飛んでいる**のが**見える |
| V**のを**見る / 聞く (cảm nhận chủ động) | 彼が走っている**のを**見た |
| V**のを**やめる (ngừng hành động) | タバコを吸う**のを**やめた |
| V**のを**待つ (chờ hành động) | 電車が来る**のを**待つ |

> **Mẹo:** Khi hành động **cụ thể, diễn ra trước mắt** (nhìn thấy, nghe thấy, chờ, ngừng) → dùng の.

### 3.4 Ví dụ so sánh trực tiếp

```
Ví dụ 1 -- Cả hai đều được:
  本を読む【こと/の】が好きです。 → Tôi thích đọc sách.

Ví dụ 2 -- Chỉ dùng こと:
  日本に行った【ことが】あります。 → Tôi đã từng đi Nhật.
  日本に行った【×のが】あります。 → ❌ Sai

Ví dụ 3 -- Chỉ dùng の:
  彼が走っている【のを】見ました。 → Tôi nhìn thấy anh ấy đang chạy.
  彼が走っている【×ことを】見ました。 → ❌ Sai (cảm nhận trực tiếp phải dùng の)
```

> **Mẹo đọc:** Trong thực tế đọc, gặp こと hay の sau mệnh đề TTT → đều hiểu là "danh từ hóa". Không cần phân biệt quá kỹ khi đọc hiểu -- cả hai đều biến mệnh đề thành "một khối danh từ". Chỉ cần nhận diện → đóng gói → đọc tiếp.

## 4. もの -- Vật / Thứ / Điều (danh từ hóa cụ thể)

**Cấu trúc:** [Mệnh đề TTT / Tính từ] + もの

> **Tư duy:** もの chỉ **vật cụ thể hoặc trừu tượng nhưng "có hình"** -- "thứ ~", "đồ ~", "cái ~". Khác với こと (việc/sự kiện) và の (cảnh/cảm nhận).

### 4.1 Tính từ / Mệnh đề + もの -- Mô tả vật

```
甘いものが / 食べたいです。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 甘いものが | Aい + **もの** + が → 🔒 **đóng gói loại 1:** "đồ ngọt" → が → chủ ngữ (đối tượng mong muốn) → sắp có Vたい |
| 2 | 食べたいです | Vたい → "muốn ăn" → chủ ngữ ẩn: **tôi** → câu kết thúc ✅ |
| **Dịch** | | **Tôi muốn ăn đồ ngọt.** |

```
何か / 冷たいものが / 飲みたいです。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 何か | "cái gì đó" |
| 2 | 冷たいものが | Aい + **もの** + が → 🔒 **đóng gói loại 1:** "đồ uống mát gì đó" → が → chủ ngữ |
| 3 | 飲みたいです | Vたい → "muốn uống" → câu kết thúc ✅ |
| **Dịch** | | **Tôi muốn uống cái gì đó mát mát.** |

### 4.2 Mệnh đề bổ nghĩa + もの -- Xác định vật

```
これは / 母が / 作ったものです。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | これは | は → chủ đề → "cái này" |
| 2 | 母が | が → chủ ngữ mệnh đề phụ → "mẹ" |
| 3 | 作ったものです | Vた + **もの** → 🔒 **đóng gói loại 2:** "thứ mà mẹ đã làm" → câu kết thúc ✅ |
| **Dịch** | | **Đây là thứ mà mẹ tôi làm.** |

```
旅行に / 必要なものを / 買いました。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 旅行に | に → mục đích → "cho chuyến đi" |
| 2 | 必要なものを | Aな + **もの** + を → 🔒 **đóng gói loại 1:** "những thứ cần thiết cho chuyến đi" → を → đối tượng → sắp có hành động |
| 3 | 買いました | "đã mua" → chủ ngữ ẩn: **tôi** → câu kết thúc ✅ |
| **Dịch** | | **Tôi đã mua những thứ cần thiết cho chuyến đi.** |

### 4.3 ものだ -- Hoài niệm (ngày xưa thì ~)

```
子どものころは / よく / この川で / 泳いだものです。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 子どものころは | は → chủ đề thời gian → "hồi còn nhỏ" |
| 2 | よく | trạng từ → "thường" |
| 3 | この川で | で → địa điểm hành động → "ở con sông này" |
| 4 | 泳いだものです | Vた + **ものだ** → "ngày xưa thường ~" (hoài niệm) → câu kết thúc ✅ |
| **Dịch** | | **Hồi còn nhỏ tôi thường bơi ở con sông này.** |

```
学生のころは / 毎晩 / 遅くまで / 勉強したものです。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 学生のころは | は → chủ đề thời gian → "hồi còn là sinh viên" |
| 2 | 毎晩 | thời gian → "mỗi tối" |
| 3 | 遅くまで | まで → giới hạn → "đến khuya" |
| 4 | 勉強したものです | Vた + **ものだ** → "ngày xưa thường ~" (hoài niệm) → câu kết thúc ✅ |
| **Dịch** | | **Hồi sinh viên mỗi tối tôi thường học đến khuya.** |

> **Nhận biết ものだ hoài niệm:**
> - Thường đi với **~のころ** (hồi ~), **昔** (ngày xưa), **よく** (thường)
> - Thể quá khứ: Vた + ものだ
> - Sắc thái: nhớ về ngày xưa với cảm xúc (vui, nuối tiếc...)

### こと vs もの -- Khi nào dùng cái nào?

**Quy tắc cốt lõi:**
- **こと** = **sự việc, hành động, khái niệm** (trừu tượng, không sờ được)
- **もの** = **vật, thứ, đồ** (cụ thể, "có hình", sờ/nhìn/cầm được)

| Tình huống | Dùng こと | Dùng もの |
|-----------|----------|----------|
| **Nói về hành động/sự việc** | ✅ 旅行する**こと**が好き (thích việc du lịch) | ❌ |
| **Nói về vật cụ thể** | ❌ | ✅ 食べたい**もの**がない (không có thứ muốn ăn) |
| **Nói về "điều" trừu tượng** | ✅ 大切な**こと** (điều quan trọng) | ⚠ 大切な**もの** (thứ quan trọng -- hơi khác nghĩa) |
| **Kinh nghiệm** | ✅ Vた**こと**がある | ❌ |
| **Khả năng** | ✅ Vる**こと**ができる | ❌ |
| **Quyết định** | ✅ Vる**こと**にする | ❌ |
| **Quà/đồ mua** | ❌ | ✅ お土産に何か**もの**を買う |
| **Hoài niệm** | ❌ | ✅ よく遊んだ**ものだ** |
| **Lời khuyên/quy tắc** | ❌ | ✅ 人の話は聞く**ものだ** (phải nghe người khác nói chứ) |

### Ví dụ so sánh trực tiếp

```
大切なことを忘れた。    → Quên một ĐIỀU quan trọng. (sự việc: cuộc hẹn, lời hứa...)
大切なものを忘れた。    → Quên một THỨ quan trọng. (đồ vật: ví, chìa khóa, hộ chiếu...)
```

```
面白いことがあった。    → Có CHUYỆN thú vị xảy ra. (sự kiện)
面白いものを見つけた。  → Tìm thấy THỨ thú vị. (đồ vật, sản phẩm)
```

```
知らないことが多い。    → Nhiều ĐIỀU không biết. (kiến thức, thông tin)
知らないものが多い。    → Nhiều THỨ không biết. (đồ vật, món ăn lạ)
```

> **Mẹo đọc:** Gặp こと → nghĩ đến **sự việc/hành động** (trừu tượng). Gặp もの → nghĩ đến **vật/thứ** (cụ thể, có thể hình dung được). Nếu thay こと thành もの mà nghĩa thay đổi → 2 cái khác nhau. Nếu không thay đổi nhiều → vùng xám, cả 2 đều được.

## 5. ことにしている / ことになっている -- Thói quen và Quy định

> **Đây là cấu trúc mở rộng của ことにする/ことになる ở mục 1.** Khi thêm **ている** (trạng thái đang duy trì), nghĩa chuyển từ "quyết định (1 lần)" sang "duy trì thường xuyên".

### 5.1 ことにしている -- Thói quen do tự mình quyết định

**Cấu trúc:** Vる/Vない + ことにしている

> **Tư duy:** "Tự mình quyết định" (ことにする) + "đang duy trì" (ている) = **thói quen tự giác**

```
毎朝 / 6時に / 起きることに / しています。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 毎朝 | thời gian → "mỗi sáng" |
| 2 | 6時に | に → thời điểm → "lúc 6 giờ" |
| 3 | 起きることに | Vる + **ことに** → 🔒 **đóng gói loại 2:** "việc dậy lúc 6 giờ" → に hướng tới quyết định |
| 4 | しています | **ことにしている** → "đang duy trì quyết định ~" = thói quen tự giác → câu kết thúc ✅ |
| **Dịch** | | **Mỗi sáng tôi tự duy trì thói quen dậy lúc 6 giờ.** |

```
寝る前に / 甘いものを / 食べないことに / しています。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 寝る前に | Vる + **前に** → 🔒 **đóng gói loại 2:** "trước khi ngủ" → sắp có hành động |
| 2 | 甘いものを | を → đối tượng → "đồ ngọt" |
| 3 | 食べないことに | Vない + **ことに** → 🔒 **đóng gói loại 2:** "việc không ăn đồ ngọt" → に hướng tới quyết định |
| 4 | しています | **ことにしている** → "đang duy trì quyết định ~" = thói quen tự giác → câu kết thúc ✅ |
| **Dịch** | | **Tôi tự quy định cho mình là trước khi ngủ không ăn đồ ngọt.** |

### 5.2 ことになっている -- Quy định / Quy tắc (được quy định)

**Cấu trúc:** Vる/Vない + ことになっている

> **Tư duy:** "Được quyết định" (ことになる) + "đang duy trì" (ている) = **quy định đang có hiệu lực**

```
この会社では / 毎朝 / 朝礼をすることに / なっています。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | この会社では | では → phạm vi → "ở công ty này" |
| 2 | 毎朝 | thời gian → "mỗi sáng" |
| 3 | 朝礼をすることに | Vる + **ことに** → 🔒 **đóng gói loại 2:** "việc họp sáng" → に hướng tới quy định |
| 4 | なっています | **ことになっている** → "có quy định rằng ~" → câu kết thúc ✅ |
| **Dịch** | | **Ở công ty này có quy định mỗi sáng phải họp.** |

```
図書館では / 食べ物を / 持ち込まないことに / なっています。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 図書館では | では → phạm vi → "ở thư viện" |
| 2 | 食べ物を | を → đối tượng → "đồ ăn" |
| 3 | 持ち込まないことに | Vない + **ことに** → 🔒 **đóng gói loại 2:** "việc không mang đồ ăn vào" → に hướng tới quy định |
| 4 | なっています | **ことになっている** → "có quy định rằng ~" → câu kết thúc ✅ |
| **Dịch** | | **Ở thư viện có quy định không được mang đồ ăn vào.** |

> **So sánh ことにしている vs ことになっている:**
>
> | | ことにしている | ことになっている |
> |---|---|---|
> | **Ai quyết định?** | **Tự mình** quyết định | **Tổ chức / quy tắc** quyết định |
> | **Sắc thái** | Thói quen tự giác, có thể thay đổi | Quy định bắt buộc, không thể tự ý thay |
> | **Ví dụ** | 毎日走ることにしている (tôi tự quyết định chạy mỗi ngày) | 8時に出社することになっている (quy định 8h phải đến công ty) |

## 6. Bảng dự đoán tổng hợp: Danh từ hóa mệnh đề

| Gặp tín hiệu | Dự đoán | Xác nhận |
|--------------|---------|----------|
| [TTT] + **こと** + は/が/を | Danh từ hóa trừu tượng → "việc ~" | Vị ngữ chính theo sau |
| Vた + **ことがある** | Kinh nghiệm: "đã từng ~" | ある/ない theo sau |
| Vる + **ことができる** | Khả năng: "có thể ~" | できる/できない |
| Vる + **ことにする** | Quyết định (tự mình): "quyết định ~" | する/した |
| Vる + **ことになる** | Được quyết định: "sẽ ~" | なる/なった |
| Vる + **ことにしている** | Thói quen tự giác: "tự duy trì ~" | している |
| Vる + **ことになっている** | Quy định: "có quy định ~" | なっている |
| [TTT] + **の** + が/を | Danh từ hóa cụ thể → "việc/cảnh ~" | 見える/聞こえる/好き/忘れる |
| [TTT] + **もの** | Vật/thứ cụ thể | Mô tả về vật thể |
| Vた + **ものだ** | Hoài niệm: "ngày xưa thường ~" | ものだ/ものです |

> **Nguyên tắc vàng:** Gặp こと/の/もの sau mệnh đề TTT → **mệnh đề đã được đóng gói thành 1 khối danh từ**. Đọc toàn bộ cụm trước こと/の/もの như một "từ dài", rồi xem trợ từ sau nó (は/が/を) để biết vai trò trong câu.
