## 1. Triết lý: Đọc theo dòng chảy, không dịch ngược

### Vấn đề của người Việt học tiếng Nhật

Tiếng Việt: **Chủ ngữ → Hành động → Bổ ngữ** (SVO)
```
Tôi    ăn    cơm.
(ai)  (làm gì) (cái gì)
→ Đọc "ăn" là biết ngay hành động.
```

Tiếng Nhật: **Chủ ngữ → Bổ ngữ → Hành động** (SOV)
```
私は    ご飯を    食べます。
(ai)    (cái gì)   (làm gì)
→ Phải đọc đến cuối mới biết hành động!
```

Khi câu ngắn 3 phần → não xử lý được. Nhưng câu 6-7 phần → não phải giữ mọi thứ "treo" → quá tải bộ nhớ ngắn hạn (giới hạn 5-9 đơn vị theo Miller, 1956).

**Cách đọc sai (dịch ngược):** Đọc hết câu → dịch từng từ → sắp xếp lại theo tiếng Việt → ghép → hiểu (nếu chưa quên).

**Cách đọc đúng (đọc theo dòng chảy):** Đọc từ trái sang phải, mỗi khối đọc đến đâu → dự đoán đến đó → đóng gói → giải phóng bộ nhớ → đọc tiếp.

## 2. Bốn kỹ thuật cốt lõi

### Kỹ thuật 1: Chia khối (Bunsetsu / 文節)

Mỗi khối = **[Từ nội dung] + [Trợ từ]** hoặc **[Cụm động từ]**.

```
KHÔNG chia (13 đơn vị → QUÁ TẢI):
昨日友達と東京のレストランで日本の料理を食べました

CÓ chia (5 khối → NÃO XỬ LÝ ĐƯỢC):
昨日 / 友達と / 東京のレストランで / 日本の料理を / 食べました
```

**Trong sách:** Câu mẫu luyện tập dùng dấu `/` chia sẵn.

### Kỹ thuật 2: Dự đoán (Prediction)

Trợ từ = **biển báo** giúp dự đoán phần tiếp theo TRƯỚC KHI đọc đến cuối câu.

| Gặp trợ từ | Dự đoán |
|------------|---------|
| [N]を | Sắp có **hành động** tác động lên N |
| [Nơi]に | Sắp có **di chuyển** đến đây |
| [Nơi]で | Sắp có **hành động** diễn ra tại đây |
| [Người]と | Sắp làm gì đó **cùng nhau** |
| [N]は | Sắp có **thông tin** về N |
| [N]が | Sắp có **cảm xúc/tồn tại/năng lực** |
| [Lý do]から/ので | Sắp có **kết quả** |
| [V]と | Sắp có **kết quả tất yếu** |

**Cơ sở:** Nghiên cứu eye-tracking (Kamide et al., 2003) chứng minh người Nhật dự đoán nhờ trợ từ trước khi đọc đến động từ.

### Kỹ thuật 3: Đóng gói 🔒 (Packaging)

Sau khi chia khối + dự đoán → **gom lại thành 1 hình ảnh** → giải phóng bộ nhớ.

**Hai loại tín hiệu đóng gói:**
1. **Loại 1: Danh từ + Trợ từ** (は/が/を/に/で) → đóng gói ngay
2. **Loại 2: Cấu trúc ngữ pháp kết thúc mệnh đề** (後で, 前に, とき, てから, から, ので, けど, のに, ても...) → đóng gói cả mệnh đề

```
📖 Đọc: 「昨日 / 友達と / 公園で / サッカーを / しました」

Bước 1: 昨日 → 🔒 "hôm qua" (giải phóng)
Bước 2: 友達と → 🔒 "cùng bạn" (giải phóng)
Bước 3: 公園で → 🔒 "ở công viên" (giải phóng)
Bước 4: サッカーを → 🔒 "bóng đá" (giải phóng)
Bước 5: しました → "đã chơi" → xác nhận mọi dự đoán ✅

→ Não chỉ cần ghép 5 hình ảnh đã nén, không cần nhớ chữ Hán.
```

### Kỹ thuật 4: Nhận diện chủ ngữ

Mỗi mệnh đề có thể có chủ ngữ KHÁC NHAU. Phải xác định **AI làm GÌ** ở mỗi đoạn.

```
母が作った料理はおいしいです。
→ Chủ ngữ "nấu" = 母 (mẹ - từ が)
→ Chủ ngữ "ngon" = 私 (tôi - ẩn, người đánh giá)
```

## 3. Quy trình đọc 5 bước

Áp dụng cho mọi câu tiếng Nhật:

```
1. Xác định chủ ngữ → AI đang hành động?
2. Xác định mệnh đề → ĐÂU là ranh giới mệnh đề?
3. Xác định "ai làm gì" → Mỗi mệnh đề: AI + LÀM GÌ
4. Đóng gói 🔒 → Gom thành hình ảnh, giải phóng bộ nhớ
5. Đọc tiếp + Dự đoán → Trợ từ cho biết phần tiếp theo là gì
```

### Nguyên tắc viết câu hỏi

1. **Giúp hiểu phương pháp**, không đố mẹo
2. Mỗi câu hỏi liên kết với kỹ thuật: chia khối / dự đoán / đóng gói

4. Đáp án sai phải hợp lý (người chưa hiểu có thể chọn)
5. question_text **KHÔNG** chứa gợi ý lộ đáp án
6. Difficulty: 1 = cơ bản, 2 = cần suy luận, 3 = nâng cao

## 6. Hệ thống luyện tập đọc-dịch (Practice)

### 2 loại luyện tập

#### A. Câu mẫu luyện dịch (Sentence Practice)

Người dùng nhận câu tiếng Nhật **đã chia khối** → tự dịch → xem đáp án + giải thích kỹ thuật.

```json
{
  "id": "L01_SP_01",
  "difficulty": 1,
  "sentence": "田中さんは / 先生です。",
  "translation": "Tanaka là giáo viên.",
  "note": "は → chủ đề 'Tanaka' → です khẳng định. Câu 2 khối cơ bản."
}
```

- `sentence`: câu JP **đã chia khối bằng `/`**
- `translation`: bản dịch tự nhiên
- `note`: giải thích ngắn gọn quá trình đọc (trợ từ → dự đoán → xác nhận)

#### B. Bài đọc luyện dịch (Reading Passage)

Người dùng nhận **đoạn văn liền** (không chia khối) → tự đọc-dịch toàn đoạn → xem dịch tham khảo + hướng dẫn đọc.

```json
{
  "id": "L01_RP_01",
  "title": "Tự giới thiệu bản thân",
  "text": "私はグエンです。ベトナム人です。今は東京に住んでいます。",
  "translation": "Tôi là Nguyen. Là người Việt Nam. Hiện tại sống ở Tokyo.",
  "process": "Câu 1: は → chủ đề → です kết câu. Câu 2: lược bỏ は. Câu 3: 今は tương phản → に tồn tại → 住んでいます kết câu."
}
```

- `text`: đoạn văn **KHÔNG chia khối** (để người dùng tự luyện)
- `translation`: dịch toàn đoạn
- `process`: hướng dẫn quá trình đọc từng câu, viết như **thầy giáo dạy đọc hiểu**

### Phong cách hướng dẫn đọc (process)

**Part 1-2:** Ngắn gọn, tập trung trợ từ → dự đoán.

**Part 3-5:** Chi tiết, viết như thầy giáo hướng dẫn từng bước:

```
📖 Câu 1: 「たくさん勉強したのに、テストに落ちました。」
→ Chia khối: たくさん / 勉強したのに / テストに / 落ちました
→ Gặp のに → ⚠️ Bẫy: のに = "vậy mà" (thất vọng), KHÔNG phải ので "vì"!
→ 🔒 Đóng gói: "đã học nhiều rồi vậy mà..." → giải phóng bộ nhớ
→ 💡 Chú ý: のに báo hiệu kết quả NGƯỢC với kỳ vọng
→ Dịch: Đã học nhiều vậy mà trượt.
```

Ký hiệu:
- 📖 Mỗi câu trong đoạn
- ⚠️ Bẫy / điểm dễ nhầm
- 💡 Insight / kiến thức quan trọng
- 🔒 Điểm đóng gói

## 7. Quy trình tạo nội dung (Content Pipeline)

### Bước 1: Viết draft (Markdown)
```
## fill_particle | 1
猫がいます。
Có con mèo.
猫（　）います。
> が | は | を | に
= が
? Chủ ngữ tồn tại → が
! が đánh dấu chủ ngữ tồn tại
# が tồn_tại
```

### Bước 2: Convert → JSON
```bash
python exercises_common/convert_draft_to_json.py input.md output.json
```

### Bước 3: Validate format
```bash
python exercises_common/validate_exercises.py output.json
```
Kiểm tra: required fields, answer mode, difficulty, correct answer marked, dấu tiếng Việt, duplicate answers, answer position bias.

### Bước 4: Review 3 bước
1. **Chuyên gia tiếng Nhật**: Câu tự nhiên? Ngữ pháp đúng?
2. **Chuyên gia tiếng Việt**: Dịch đúng? Có dấu? Tự nhiên?
3. **Kiểm tra kỹ thuật**: Giải thích đúng phương pháp? Đóng gói đúng?

### Bước 5: Fix → Validate lại → Hoàn tất

## 8. Quy tắc bắt buộc

1. **Tiếng Việt PHẢI có dấu** -- Không bao giờ viết không dấu
2. **Question text không lộ đáp án** -- Không thêm [gợi ý] trong câu hỏi
3. **TTT = Thể Thông Thường** (普通形) -- Không dùng "plain form"
4. **Câu mẫu khác câu trong bài học** -- Không copy
5. **Process tập trung kỹ thuật đọc** -- Không giải thích ngữ pháp lý thuyết

## 11. Cơ sở khoa học

| Kỹ thuật | Cơ sở | Tham khảo |
|----------|-------|-----------|
| Chia khối (Chunking) | Giảm tải bộ nhớ ngắn hạn | Miller (1956) "The Magical Number Seven" |
| Dự đoán (Prediction) | Não dự đoán liên tục khi đọc | Kamide et al. (2003) eye-tracking trong tiếng Nhật |
| Đóng gói (Packaging) | Nén thông tin thành đơn vị lớn hơn | Ericsson & Kintsch (1995) Long-term working memory |
| Surprisal | Dự đoán sai → ghi nhớ mạnh hơn | Hale (2001), Levy (2008) Surprisal Theory |
