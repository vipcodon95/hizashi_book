# Bài 21: Thể khả năng (potential form)

> Thể khả năng diễn tả "có thể làm ~". Khi đọc, nhận diện bằng đuôi **-える / -られる**.
> Bạn đã biết cách chia thể khả năng. Bài này tập trung vào: **nhận diện khi đọc**, **sự thay đổi trợ từ**, và các **tình huống dễ nhầm**.

---

## Lưu ý quan trọng: Trợ từ thay đổi!

Với thể khả năng, tân ngữ thường dùng **が** thay vì を.

```
Thể ます:    日本語を 話します。     (Nói tiếng Nhật.)
Thể khả năng: 日本語が 話せます。     (Nói được tiếng Nhật.)
```

> Khi đọc, gặp が + động từ đuôi -える/-られる → đó là thể khả năng. が ở đây đánh dấu **đối tượng có khả năng**, không phải chủ ngữ.

---

## 1. Vられます / Vえます -- Có thể làm ~

### Nhóm 2: đuôi -られる

```
私は / 刺身が / 食べられます。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 私は | 🔒 **đóng gói:** "tôi" → は cho biết chủ đề → đọc tiếp |
| 2 | 刺身が | 🔒 **đóng gói:** "sashimi" → が cho biết đối tượng khả năng → dự đoán: sắp có thể khả năng |
| 3 | 食べられます | -られます → khả năng → "ăn được" → câu kết thúc ✅ |
| **Dịch** | | **Tôi ăn được sashimi.** |

---

### Nhóm 3 (bất quy tắc)

| Động từ | Thể khả năng | Ghi chú |
|---------|-------------|---------|
| する | **できる** | Thay hoàn toàn, không phải される |
| 来る（くる） | **来られる（こられる）** | Đuôi -られる giống nhóm 2 |

> **Lưu ý:** する **không** chia thành される ở thể khả năng. Phải dùng できる. Ví dụ: 運動する → 運動**できる** (có thể tập thể dục).

---

### Nhóm 1: đuôi -える

```
田中さんは / 漢字が / 読めます。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 田中さんは | 🔒 **đóng gói:** "Tanaka" → は cho biết chủ đề → đọc tiếp |
| 2 | 漢字が | 🔒 **đóng gói:** "chữ Hán" → が cho biết đối tượng khả năng → dự đoán: sắp có thể khả năng |
| 3 | 読めます | -えます → khả năng → "đọc được" → câu kết thúc ✅ |
| **Dịch** | | **Tanaka đọc được chữ Hán.** |

---

```
日本語が / 話せます。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 日本語が | 🔒 **đóng gói:** "tiếng Nhật" → が cho biết đối tượng khả năng → dự đoán: sắp có thể khả năng |
| 2 | 話せます | -えます → khả năng → "nói được" → (chủ ngữ ẩn: tôi) → câu kết thúc ✅ |
| **Dịch** | | **Nói được tiếng Nhật.** |

---

### Phủ định: không thể làm ~

```
私は / 泳げません。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 私は | 🔒 **đóng gói:** "tôi" → は cho biết chủ đề → đọc tiếp |
| 2 | 泳げません | -えません → khả năng phủ định → "không bơi được" → câu kết thúc ✅ |
| **Dịch** | | **Tôi không biết bơi.** |

---

```
辛い物が / 食べられません。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 辛い物が | 🔒 **đóng gói:** "đồ cay" → が cho biết đối tượng khả năng → dự đoán: sắp có thể khả năng |
| 2 | 食べられません | -られません → khả năng phủ định → "không ăn được" → (chủ ngữ ẩn: tôi) → câu kết thúc ✅ |
| **Dịch** | | **Không ăn được đồ cay.** |

> **Tín hiệu nhận diện:** Gặp が + V(-える/-られる) → thể khả năng. Gặp が + V(-えません/-られません) → "không thể".

## 2. 見えます / 聞こえます -- Nhìn thấy / Nghe thấy (tự nhiên)

Hai động từ đặc biệt diễn tả khả năng **tự nhiên, không cố ý**. Trợ từ đi kèm: が.

```
ここから / 富士山が / 見えます。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | ここから | 🔒 **đóng gói:** "từ đây" → から cho biết điểm xuất phát → đọc tiếp |
| 2 | 富士山が | 🔒 **đóng gói:** "núi Phú Sĩ" → が cho biết đối tượng nhìn thấy → đọc tiếp |
| 3 | 見えます | 見える → "(tự) nhìn thấy" → câu kết thúc ✅ |
| **Dịch** | | **Từ đây nhìn thấy núi Phú Sĩ.** |

---

```
隣の部屋から / 音楽が / 聞こえます。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 隣の部屋から | 🔒 **đóng gói:** "từ phòng bên cạnh" → から cho biết điểm xuất phát → đọc tiếp |
| 2 | 音楽が | 🔒 **đóng gói:** "nhạc" → が cho biết đối tượng nghe thấy → đọc tiếp |
| 3 | 聞こえます | 聞こえる → "(tự) nghe thấy" → câu kết thúc ✅ |
| **Dịch** | | **Nghe thấy nhạc từ phòng bên cạnh.** |

---

```
声が / 小さくて / 聞こえません。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 声が | 🔒 **đóng gói:** "giọng nói / tiếng" → が cho biết đối tượng → đọc tiếp |
| 2 | 小さくて | 🔒 **đóng gói:** "tiếng nhỏ" → giải phóng bộ nhớ → て cho biết nguyên nhân → dự đoán: sắp có hệ quả |
| 3 | 聞こえません | 聞こえない → "không nghe thấy" → câu kết thúc ✅ |
| **Dịch** | | **Tiếng nhỏ quá nên không nghe thấy.** |

> **So sánh quan trọng:**
> - 見えます = tự nhiên nhìn thấy (vô ý). Ví dụ: 山が見える (núi hiện ra trước mắt).
> - 見られます = có thể nhìn / có cơ hội xem (chủ ý). Ví dụ: この映画が見られる (có thể xem bộ phim này).
> - 聞こえます = tự nhiên nghe thấy (vô ý). Ví dụ: 音が聞こえる (nghe thấy tiếng).
> - 聞けます = có thể nghe (chủ ý). Ví dụ: ラジオが聞ける (có thể nghe radio).

## 3. Vことができる vs Vられる

Hai cách diễn tả "có thể làm ~" với cùng nghĩa nhưng khác cách dùng.

```
日本語を / 話すことが / できます。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 日本語を | 🔒 **đóng gói:** "tiếng Nhật" → を cho biết đối tượng (chú ý: を, không phải が) → đọc tiếp |
| 2 | 話すことが | 🔒 **đóng gói:** "việc nói tiếng Nhật" → が cho biết chủ ngữ → dự đoán: sắp có できる |
| 3 | できます | できる → "có thể" → (chủ ngữ ẩn: tôi) → câu kết thúc ✅ |
| **Dịch** | | **Có thể nói tiếng Nhật.** |

---

```
ここで / 写真を / 撮ることが / できますか。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | ここで | 🔒 **đóng gói:** "ở đây" → で cho biết địa điểm → đọc tiếp |
| 2 | 写真を | 🔒 **đóng gói:** "ảnh" → を cho biết đối tượng → đọc tiếp |
| 3 | 撮ることが | 🔒 **đóng gói:** "việc chụp ảnh ở đây" → が cho biết chủ ngữ → dự đoán: sắp có できる |
| 4 | できますか | できます + か → "có thể không?" → câu kết thúc ✅ |
| **Dịch** | | **Ở đây có thể chụp ảnh không?** |

> **So sánh khi đọc:**
>
> | | Vことができる | Vられる / Vえる |
> |---|---|---|
> | Trợ từ tân ngữ | を (giữ nguyên) | が (thay đổi) |
> | Văn phong | Trang trọng, văn viết | Tự nhiên, văn nói |
> | Tín hiệu nhận diện | ...ことができる | đuôi -える / -られる |
>
> Khi đọc gặp cả hai, hiểu nghĩa giống nhau: "có thể làm ~".

## 4. ら抜き -- Bỏ ら trong tiếng Nhật hiện đại

Trong tiếng Nhật hiện đại (đặc biệt văn nói, manga, blog), người Nhật thường **bỏ ら** ở nhóm 2.

```
Chuẩn:       食べられる → ăn được
ら抜き:      食べれる   → ăn được (cùng nghĩa)

Chuẩn:       見られる   → có thể xem
ら抜き:      見れる     → có thể xem (cùng nghĩa)
```

```
この店で / おいしいすしが / 食べれますよ。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | この店で | 🔒 **đóng gói:** "ở quán này" → で cho biết địa điểm → đọc tiếp |
| 2 | おいしいすしが | 🔒 **đóng gói:** "sushi ngon" → が cho biết đối tượng khả năng → dự đoán: sắp có thể khả năng |
| 3 | 食べれますよ | 食べれる (ら抜き) → khả năng → "ăn được" + よ → nhấn mạnh → câu kết thúc ✅ |
| **Dịch** | | **Ở quán này ăn được sushi ngon đấy!** |

---

```
明日 / 来れる？
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 明日 | thời gian → "ngày mai" |
| 2 | 来れる？ | 来れる (ら抜き của 来られる) → khả năng → "đến được không?" → (chủ ngữ ẩn: bạn) → câu kết thúc ✅ |
| **Dịch** | | **Ngày mai đến được không?** |

> **Lưu ý khi đọc:** Gặp 食べれる、見れる、来れる → đó là dạng ら抜き, nghĩa giống 食べられる、見られる、来られる. Dạng này **rất phổ biến** trong manga, tin nhắn, blog, hội thoại. Sách giáo khoa có thể dùng dạng chuẩn, nhưng văn bản thực tế thường dùng ら抜き.

## 5. Vるようになる -- Trở nên có thể làm ~

Mẫu này diễn tả **sự thay đổi khả năng** -- từ không thể → có thể (hoặc ngược lại).

```
日本語が / 少し / 話せるように / なりました。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 日本語が | 🔒 **đóng gói:** "tiếng Nhật" → が cho biết đối tượng khả năng → đọc tiếp |
| 2 | 少し | trạng từ → "một chút" |
| 3 | 話せるように | 🔒 **đóng gói:** "nói được tiếng Nhật một chút" → giải phóng bộ nhớ → ようになる cho biết sự thay đổi khả năng → dự đoán: sắp có なる |
| 4 | なりました | → "đã trở nên" → (chủ ngữ ẩn: tôi) → câu kết thúc ✅ |
| **Dịch** | | **Tôi đã nói được tiếng Nhật một chút rồi.** |

---

```
漢字が / 読めるように / なりたいです。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 漢字が | 🔒 **đóng gói:** "chữ Hán" → が cho biết đối tượng khả năng → đọc tiếp |
| 2 | 読めるように | 🔒 **đóng gói:** "đọc được chữ Hán" → giải phóng bộ nhớ → ようになる cho biết sự thay đổi khả năng → dự đoán: sắp có なる |
| 3 | なりたいです | たい → mong muốn → "muốn trở nên" → (chủ ngữ ẩn: tôi) → câu kết thúc ✅ |
| **Dịch** | | **Tôi muốn đọc được chữ Hán.** |

> **Phân biệt:**
> - Vられる/Vえる = **hiện tại** có thể làm hay không
> - Vられるようになる = **quá trình thay đổi** từ không thể → có thể
> Khi đọc thấy ようになる, biết ngay đây là sự thay đổi trạng thái.

## Câu phức hợp: Thể khả năng trong câu dài

```
私は / 日本語は / 少し / 話せますが / 漢字が / あまり / 読めません。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 私は | 🔒 **đóng gói:** "tôi" → は cho biết chủ đề → đọc tiếp |
| 2 | 日本語は | 🔒 **đóng gói:** "tiếng Nhật" → は cho biết đề tài (tương phản) → đọc tiếp |
| 3 | 少し | trạng từ → "một chút" |
| 4 | 話せますが | 🔒 **đóng gói:** "tiếng Nhật nói được một chút" → giải phóng bộ nhớ → が cho biết tương phản → dự đoán: sắp có thông tin trái ngược |
| 5 | 漢字が | 🔒 **đóng gói:** "chữ Hán" → が cho biết đối tượng khả năng → đọc tiếp |
| 6 | あまり | biển báo → dự đoán: phủ định |
| 7 | 読めません | -えません → khả năng phủ định → "không đọc được" → câu kết thúc ✅ |
| **Dịch** | | **Tiếng Nhật thì tôi nói được một chút, nhưng chữ Hán thì không đọc được mấy.** |

---

```
この図書館で / 日本の映画が / 見られる / と聞きました。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | この図書館で | 🔒 **đóng gói:** "ở thư viện này" → で cho biết địa điểm → đọc tiếp |
| 2 | 日本の映画が | 🔒 **đóng gói:** "phim Nhật" → が cho biết đối tượng khả năng → dự đoán: sắp có thể khả năng |
| 3 | 見られる | -られる → khả năng → "xem được" |
| 4 | と聞きました | 🔒 **đóng gói:** "ở thư viện này xem được phim Nhật" → giải phóng bộ nhớ → と聞きました cho biết trích dẫn lời nghe → (chủ ngữ ẩn: tôi) → câu kết thúc ✅ |
| **Dịch** | | **Tôi nghe nói ở thư viện này xem được phim Nhật.** |

## Bảng dự đoán tổng hợp

| Gặp | Dự đoán | Ví dụ |
|-----|---------|-------|
| が + V(-える/-られる) | Thể khả năng → "có thể làm ~" | 漢字が読めます |
| が + V(-えません/-られません) | Khả năng phủ định → "không thể làm ~" | 泳げません |
| が + 見えます | Tự nhiên nhìn thấy (không cố ý) | 山が見えます |
| が + 聞こえます | Tự nhiên nghe thấy (không cố ý) | 音が聞こえます |
| Vことが + できる | Có thể làm ~ (trang trọng, を giữ nguyên) | 話すことができます |
| V(-れる) không có ら | ら抜き → khả năng (văn nói hiện đại) | 食べれる = 食べられる |
| Vられるようになる | Trở nên có thể → sự thay đổi khả năng | 話せるようになった |
| から + が + 見える/聞こえる | Từ [nơi] + nhìn thấy/nghe thấy [gì] | ここから富士山が見える |
| が (thay vì を) | Tín hiệu thể khả năng → đuôi sẽ là -える/-られる | 日本語**が**話せる |
