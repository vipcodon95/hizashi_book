# Bài 19: Thể た (ta-form)

> Bài 13 đã giới thiệu ました -- dạng quá khứ lịch sự. Bài này giới thiệu thể た -- dạng quá khứ thông thường
> Bạn đã biết cách chia thể た. Bài này tập trung vào: **nhận diện た khi đọc** và các **mẫu câu chỉ có ở thể た**.
> Thể た không chỉ diễn tả quá khứ mà còn là nguyên liệu để tạo nhiều mẫu câu quan trọng trong đọc hiểu.

---

## 1. Vたことがあります -- Đã từng làm ~

Mẫu câu diễn tả **kinh nghiệm** đã từng trải qua. Trợ từ đi kèm: を hoặc に trước động từ.

```
日本に / 行ったことが / あります。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 日本に | 🔒 **đóng gói:** "Nhật Bản" → に cho biết điểm đến → đọc tiếp |
| 2 | 行ったことが | 🔒 **đóng gói:** "việc đã đi Nhật" → ことが cho biết kinh nghiệm → dự đoán: sắp có ある/ない |
| 3 | あります | "có" → "đã từng đi" → câu kết thúc ✅ |
| **Dịch** | | **Tôi đã từng đi Nhật Bản.** (chủ ngữ ẩn: tôi) |

---

```
すしを / 食べたことが / あります。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | すしを | 🔒 **đóng gói:** "sushi" → を cho biết đối tượng → đọc tiếp |
| 2 | 食べたことが | 🔒 **đóng gói:** "việc đã ăn sushi" → ことが cho biết kinh nghiệm → dự đoán: sắp có ある/ない |
| 3 | あります | "có" → "đã từng ăn" → câu kết thúc ✅ |
| **Dịch** | | **Tôi đã từng ăn sushi.** (chủ ngữ ẩn: tôi) |

---

```
富士山に / 登ったことが / ありません。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 富士山に | 🔒 **đóng gói:** "núi Phú Sĩ" → に cho biết điểm đến → đọc tiếp |
| 2 | 登ったことが | 🔒 **đóng gói:** "việc đã leo núi Phú Sĩ" → ことが cho biết kinh nghiệm → dự đoán: ある hay ない? |
| 3 | ありません | "không có" → "chưa từng leo" → câu kết thúc ✅ |
| **Dịch** | | **Tôi chưa từng leo núi Phú Sĩ.** (chủ ngữ ẩn: tôi) |

> **Tín hiệu nhận diện:** Gặp Vた + ことが → luôn dự đoán あります hoặc ありません phía sau. Nghĩa là "đã từng" hoặc "chưa từng".

---

## 2. Vたり Vたり します -- Liệt kê hành động đại diện

Mẫu câu liệt kê **một số hành động tiêu biểu**, ngụ ý "và nhiều thứ khác nữa". Cuối câu luôn có します.

```
日曜日は / 本を読んだり / 音楽を聴いたり / します。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 日曜日は | 🔒 **đóng gói:** "chủ nhật" → は cho biết chủ đề (thời gian) → đọc tiếp |
| 2 | 本を読んだり | 🔒 **đóng gói:** "đọc sách" → たり cho biết liệt kê → dự đoán: sắp có thêm たり |
| 3 | 音楽を聴いたり | 🔒 **đóng gói:** "nghe nhạc" → たり cho biết liệt kê tiếp → dự đoán: します sắp đến |
| 4 | します | kết thúc liệt kê → câu kết thúc ✅ |
| **Dịch** | | **Chủ nhật thì đọc sách, nghe nhạc (và nhiều thứ khác).** (chủ ngữ ẩn: tôi) |

---

```
休みの日は / 買い物をしたり / 映画を見たり / します。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 休みの日は | 🔒 **đóng gói:** "ngày nghỉ" → は cho biết chủ đề → đọc tiếp |
| 2 | 買い物をしたり | 🔒 **đóng gói:** "mua sắm" → たり cho biết liệt kê → dự đoán: sắp có thêm たり |
| 3 | 映画を見たり | 🔒 **đóng gói:** "xem phim" → たり cho biết liệt kê tiếp → dự đoán: します sắp đến |
| 4 | します | kết thúc liệt kê → câu kết thúc ✅ |
| **Dịch** | | **Ngày nghỉ thì đi mua sắm, xem phim (và nhiều thứ khác).** (chủ ngữ ẩn: tôi) |

> **Tín hiệu nhận diện:** Gặp Vたり → luôn dự đoán sẽ có thêm Vたり nữa, và kết thúc bằng します.

## 3. Vたあとで -- Sau khi làm ~

Trợ từ đi kèm: を hoặc に trước động từ chính.

```
ご飯を / 食べたあとで / コーヒーを / 飲みます。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | ご飯を | 🔒 **đóng gói:** "cơm" → を cho biết đối tượng → đọc tiếp |
| 2 | 食べたあとで | 🔒 **đóng gói:** "sau khi ăn cơm" → giải phóng bộ nhớ → あとで cho biết sắp có hành động tiếp theo |
| 3 | コーヒーを | 🔒 **đóng gói:** "cà phê" → を cho biết đối tượng → đọc tiếp |
| 4 | 飲みます | "uống" → câu kết thúc ✅ |
| **Dịch** | | **Sau khi ăn cơm thì uống cà phê.** (chủ ngữ ẩn: tôi) |

---

```
仕事が / 終わったあとで / 友達に / 会います。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 仕事が | 🔒 **đóng gói:** "công việc" → が cho biết chủ ngữ → đọc tiếp |
| 2 | 終わったあとで | 🔒 **đóng gói:** "sau khi công việc kết thúc" → giải phóng bộ nhớ → あとで cho biết sắp có hành động tiếp theo |
| 3 | 友達に | 🔒 **đóng gói:** "bạn bè" → に cho biết đối tượng gặp gỡ → đọc tiếp |
| 4 | 会います | "gặp" → câu kết thúc ✅ |
| **Dịch** | | **Sau khi công việc kết thúc thì gặp bạn.** (chủ ngữ ẩn: tôi) |

> **Tín hiệu nhận diện:** Gặp Vた + あとで → nghĩa là "sau khi ~", luôn dự đoán hành động tiếp theo phía sau.
>
> **Lưu ý thực tế:** Trong thực tế đọc, thường gặp Vたあと (không có で) -- nghĩa tương đương. Ví dụ: 食べたあと出かけます = 食べたあとで出かけます.

**So sánh ngắn -- たあとで vs てから (Bài 16):**

- **たあとで**: nhấn mạnh "SAU KHI xong hẳn" → khoảng cách thời gian có thể dài.
- **てから**: nhấn mạnh "thứ tự, A xong rồi mới B" → hai việc nối tiếp nhau.
- Khi đọc, hai mẫu này **thường thay thế được cho nhau** -- điều quan trọng là nhận diện cả hai đều mang nghĩa "sau khi."

## 4. Vたほうがいいです -- Nên làm ~ (lời khuyên)

```
薬を / 飲んだほうが / いいです。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 薬を | 🔒 **đóng gói:** "thuốc" → を cho biết đối tượng → đọc tiếp |
| 2 | 飲んだほうが | 🔒 **đóng gói:** "nên uống thuốc" → ほうが cho biết lời khuyên → dự đoán: sắp có いいです |
| 3 | いいです | "tốt" → "nên uống" → câu kết thúc ✅ |
| **Dịch** | | **Nên uống thuốc.** |

---

```
早く / 寝たほうが / いいですよ。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 早く | trạng từ → "sớm" → dự đoán: sắp có hành động → đọc tiếp |
| 2 | 寝たほうが | 🔒 **đóng gói:** "nên ngủ sớm" → ほうが cho biết lời khuyên → dự đoán: sắp có いいです |
| 3 | いいですよ | "tốt" + よ nhấn mạnh → "nên ngủ sớm nhé" → câu kết thúc ✅ |
| **Dịch** | | **Nên ngủ sớm nhé.** |

> **Tín hiệu nhận diện:** Gặp Vた + ほうが → luôn dự đoán いいです phía sau. Nghĩa là "nên làm ~".
> **So sánh:** Vないほうがいい = "không nên làm ~" (đã học ở Bài 17).
> **Người thực hiện:** Lời khuyên hướng đến **người nghe** — bạn nên làm ~. Cặp đối nghĩa với Vないほうがいい (Bài 17).

## 5. Vたら -- Nếu / Khi / Sau khi ~ (điều kiện)

Mẫu câu đa nghĩa: tùy ngữ cảnh, Vたら có thể là "nếu", "khi", hoặc "sau khi".

```
雨が / 降ったら / 家に / いましょう。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 雨が | 🔒 **đóng gói:** "mưa" → が cho biết chủ ngữ → đọc tiếp |
| 2 | 降ったら | 🔒 **đóng gói:** "nếu mưa rơi" → giải phóng bộ nhớ → たら cho biết điều kiện → sắp có kết quả |
| 3 | 家に | 🔒 **đóng gói:** "nhà" → に cho biết điểm đến → đọc tiếp |
| 4 | いましょう | "hãy ở nhà" → câu kết thúc ✅ |
| **Dịch** | | **Nếu trời mưa thì ở nhà nhé.** |

---

```
駅に / 着いたら / 電話して / ください。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 駅に | 🔒 **đóng gói:** "ga" → に cho biết điểm đến → đọc tiếp |
| 2 | 着いたら | 🔒 **đóng gói:** "khi đến ga" → giải phóng bộ nhớ → たら cho biết điều kiện → sắp có yêu cầu |
| 3 | 電話して | "gọi điện" → đọc tiếp |
| 4 | ください | yêu cầu → "hãy gọi điện" → câu kết thúc ✅ |
| **Dịch** | | **Khi đến ga thì hãy gọi điện nhé.** |

---

```
安かったら / 買います。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 安かったら | 🔒 **đóng gói:** "nếu rẻ" → giải phóng bộ nhớ → たら cho biết điều kiện → sắp có kết quả |
| 2 | 買います | "mua" → câu kết thúc ✅ |
| **Dịch** | | **Nếu rẻ thì mua.** (chủ ngữ ẩn: tôi) |

> **Tín hiệu nhận diện:** Gặp Vた + ら hoặc Aかった + ら → luôn dự đoán phía sau là kết quả / hành động tiếp theo. たら là tín hiệu "điều kiện" rất rõ ràng.

**Phát hiện bất ngờ -- Vたら...た (cả 2 vế quá khứ):**

```
窓を開けたら / 雪が降っていました。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 窓を開けたら | 🔒 **đóng gói:** "mở cửa sổ ra thì..." → giải phóng bộ nhớ → たら cho biết điều kiện → sắp có phát hiện |
| 2 | 雪が降っていました | 🔒 **đóng gói:** "tuyết đang rơi" → が cho biết chủ ngữ → phát hiện bất ngờ → câu kết thúc ✅ |
| **Dịch** | | **Mở cửa sổ ra thì thấy tuyết đang rơi.** (chủ ngữ ẩn: tôi mở) |

**Bảng phân biệt 3 nghĩa của たら:**

| Nghĩa | Dấu hiệu | Ví dụ |
|-------|-----------|-------|
| Nếu (giả thuyết) | Vế sau là tương lai/ý chí | 雨が降ったら行きません |
| Khi/Sau khi (trình tự) | Vế sau tiếp diễn tự nhiên | 家に帰ったら電話します |
| Phát hiện bất ngờ | Cả 2 vế quá khứ (た...た) | 開けたら雪が降っていた |

## 6. Vたばかり -- Vừa mới làm ~

```
今 / 来たばかりです。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 今 | thời gian → "bây giờ" → đọc tiếp |
| 2 | 来たばかりです | 🔒 **đóng gói:** "vừa mới đến" → giải phóng bộ nhớ → ばかり cho biết vừa mới xảy ra → câu kết thúc ✅ |
| **Dịch** | | **Vừa mới đến.** (chủ ngữ ẩn: tôi) |

---

```
日本に / 来たばかりで / まだ / よくわかりません。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 日本に | 🔒 **đóng gói:** "Nhật Bản" → に cho biết điểm đến → đọc tiếp |
| 2 | 来たばかりで | 🔒 **đóng gói:** "vừa mới đến Nhật" → giải phóng bộ nhớ → ばかりで cho biết vừa mới xảy ra + lý do → sắp có hệ quả |
| 3 | まだ | biển báo → dự đoán: phủ định (chưa...) → đọc tiếp |
| 4 | よくわかりません | "chưa hiểu rõ" → câu kết thúc ✅ |
| **Dịch** | | **Vừa mới đến Nhật nên chưa hiểu rõ lắm.** (chủ ngữ ẩn: tôi) |

> **Tín hiệu nhận diện:** Gặp Vた + ばかり → nghĩa là "vừa mới làm ~", nhấn mạnh thời gian rất gần.

## 7. Vたとおりに -- Làm đúng theo ~

Trợ từ đi kèm: に sau とおり, を trước động từ chính.

```
先生が / 言ったとおりに / やって / ください。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 先生が | 🔒 **đóng gói:** "thầy/cô giáo" → が cho biết chủ ngữ → đọc tiếp |
| 2 | 言ったとおりに | 🔒 **đóng gói:** "đúng theo cách thầy/cô đã nói" → giải phóng bộ nhớ → とおりに cho biết sắp có hành động chính |
| 3 | やって | "làm" → đọc tiếp |
| 4 | ください | yêu cầu → "hãy làm" → câu kết thúc ✅ |
| **Dịch** | | **Hãy làm đúng theo lời thầy/cô nói.** |

---

```
レシピに / 書いてあったとおりに / 料理を / 作りました。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | レシピに | 🔒 **đóng gói:** "trong công thức" → に cho biết vị trí thông tin → đọc tiếp |
| 2 | 書いてあったとおりに | 🔒 **đóng gói:** "đúng theo cách đã viết trong công thức" → giải phóng bộ nhớ → とおりに cho biết sắp có hành động chính |
| 3 | 料理を | 🔒 **đóng gói:** "món ăn" → を cho biết đối tượng → đọc tiếp |
| 4 | 作りました | "đã nấu" → câu kết thúc ✅ |
| **Dịch** | | **Đã nấu món ăn đúng theo công thức.** (chủ ngữ ẩn: tôi) |

> **Tín hiệu nhận diện:** Gặp Vた + とおりに → nghĩa là "đúng theo cách đã ~", luôn dự đoán hành động chính phía sau.

## 8. Vたまま — Để nguyên trạng thái (làm A rồi giữ nguyên)

```
電気を / つけたまま / 寝てしまいました。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 電気を | 🔒 **đóng gói:** "đèn" → を cho biết đối tượng → đọc tiếp |
| 2 | つけたまま | 🔒 **đóng gói:** "bật đèn để nguyên" → giải phóng bộ nhớ → まま cho biết giữ nguyên trạng thái → sắp có hành động tiếp |
| 3 | 寝てしまいました | "đã lỡ ngủ" (てしまう → tiếc nuối) → câu kết thúc ✅ |
| **Dịch** | | **Bật đèn để nguyên rồi ngủ mất.** (chủ ngữ ẩn: tôi) |

---

```
靴を / 履いたまま / 家に / 入らないでください。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 靴を | 🔒 **đóng gói:** "giày" → を cho biết đối tượng → đọc tiếp |
| 2 | 履いたまま | 🔒 **đóng gói:** "đi giày nguyên (không cởi)" → giải phóng bộ nhớ → まま cho biết giữ nguyên trạng thái → sắp có hành động tiếp |
| 3 | 家に | 🔒 **đóng gói:** "nhà" → に cho biết điểm đến → đọc tiếp |
| 4 | 入らないでください | "xin đừng vào" (Vない + でください → yêu cầu đừng) → câu kết thúc ✅ |
| **Dịch** | | **Xin đừng đi giày vào nhà.** |

> **Tín hiệu nhận diện:** Gặp Vた + まま → hành động đã làm và **giữ nguyên trạng thái đó** khi thực hiện hành động tiếp theo. Tùy ngữ cảnh có thể mang sắc thái tiêu cực (quên, bất cẩn) hoặc hoàn toàn trung tính (mô tả đơn thuần).

**Ví dụ trung tính:**

```
立ったまま / 食べました。
```

→ **Ăn đứng (ăn trong tư thế đứng).** -- Đơn thuần mô tả trạng thái, không có sắc thái tiêu cực.

## Bảng dự đoán tổng hợp

| Gặp | Dự đoán | Ví dụ |
|-----|---------|-------|
| Vた + ことが | Sắp có あります/ありません → "đã từng / chưa từng" | 食べたことがあります |
| Vたり | Sắp có thêm Vたり + します → liệt kê hành động | 読んだり聴いたりします |
| Vた + あとで | Sắp có hành động tiếp theo → "sau khi ~" | 食べたあとで飲みます |
| Vた + ほうが | Sắp có いいです → "nên làm ~" | 寝たほうがいいです |
| Vた + ら | Sắp có kết quả/hành động → "nếu / khi ~" | 降ったら家にいます |
| Vたら...た | Cả 2 vế quá khứ → "phát hiện bất ngờ" | 開けたら雪が降っていた |
| Vた + ばかり | Nhấn mạnh "vừa mới ~" | 来たばかりです |
| Vた + とおりに | Sắp có hành động chính → "đúng theo cách đã ~" | 言ったとおりにやる |
| Vた + まま | Giữ nguyên trạng thái → "để nguyên ~ rồi..." | つけたまま寝た |
