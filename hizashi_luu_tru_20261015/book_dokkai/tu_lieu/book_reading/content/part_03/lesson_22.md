# Bài 22: Thể ý chí, mệnh lệnh, cấm chỉ

> Ba dạng này đều liên quan đến **ý muốn, yêu cầu, hoặc cấm đoán**.
> Khi đọc manga, biển báo, hướng dẫn sử dụng -- bạn sẽ gặp chúng liên tục.
> Bài này tập trung vào **nhận diện** từng dạng khi đọc và hiểu đúng mức độ mạnh/nhẹ.

---

## 1. Vよう -- Làm ~ thôi / Định làm ~

Đuôi よう (hoặc おう với nhóm I) đánh dấu **ý chí** -- người nói tự quyết định hoặc rủ người khác.

```
一緒に / 日本語を / 勉強しよう。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 一緒に | 🔒 **đóng gói:** "cùng nhau" → に cho biết trạng thái → đọc tiếp |
| 2 | 日本語を | 🔒 **đóng gói:** "tiếng Nhật" → を cho biết đối tượng → đọc tiếp |
| 3 | 勉強しよう | 🔒 **đóng gói:** "học thôi" → giải phóng bộ nhớ → よう cho biết ý chí / rủ rê → câu kết thúc ✅ |
| **Dịch** | | **Cùng học tiếng Nhật thôi.** |

---

```
もう / 帰ろう。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | もう | trạng từ → "đã / rồi" → dự đoán: sắp có hành động kết thúc |
| 2 | 帰ろう | 🔒 **đóng gói:** "về thôi" → giải phóng bộ nhớ → ろう cho biết ý chí → câu kết thúc ✅ |
| **Dịch** | | **Về thôi.** |

> **Nhận diện khi đọc:** Đuôi よう / ろう / おう ở cuối câu = ý chí hoặc rủ rê. Không có trợ từ đặc biệt đi kèm, nhưng thường thấy 一緒に khi rủ người khác.

---

## 2. Vようと思う -- Định làm ~ / Đang định làm ~

Hai dạng: **Vようと思います** (quyết định tại chỗ) và **Vようと思っています** (dự định đã có từ trước, vẫn đang giữ).

### Vようと思います -- Vừa quyết định

```
今日から / 毎日 / 運動しようと / 思います。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 今日から | から → điểm bắt đầu → "từ hôm nay" |
| 2 | 毎日 | trạng từ → "mỗi ngày" |
| 3 | 運動しようと | 🔒 **đóng gói:** "sẽ tập thể dục" → giải phóng bộ nhớ → ようと cho biết sắp có 思う |
| 4 | 思います | → "tôi quyết định" → câu kết thúc ✅ (chủ ngữ ẩn: tôi) |
| **Dịch** | | **Từ hôm nay tôi quyết định mỗi ngày sẽ tập thể dục.** |

> **思います vs 思っています:**
> - Vようと**思います** = quyết định **vừa mới** đưa ra (tại thời điểm nói)
> - Vようと**思っています** = dự định **đã hình thành từ trước** và vẫn đang giữ

---

### Vようと思っています -- Dự định kéo dài

Mẫu này diễn tả **dự định đã hình thành và vẫn đang giữ**. Khác với 思います, mẫu này nhấn mạnh trạng thái "đang nghĩ từ lâu".

```
来年 / 日本に / 留学しようと / 思っています。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 来年 | thời gian → "năm sau" |
| 2 | 日本に | 🔒 **đóng gói:** "Nhật" → に cho biết điểm đến → đọc tiếp |
| 3 | 留学しようと | 🔒 **đóng gói:** "du học ở Nhật" → giải phóng bộ nhớ → ようと cho biết sắp có 思う |
| 4 | 思っています | → "đang định" → trạng thái kéo dài → câu kết thúc ✅ (chủ ngữ ẩn: tôi) |
| **Dịch** | | **Tôi đang định năm sau đi du học Nhật.** |

---

```
転職しようと / 思っています。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 転職しようと | 🔒 **đóng gói:** "đổi việc" → giải phóng bộ nhớ → ようと cho biết sắp có 思う |
| 2 | 思っています | → "đang định" → câu kết thúc ✅ (chủ ngữ ẩn: tôi) |
| **Dịch** | | **Tôi đang định đổi việc.** |

> **Trợ từ quan trọng:** と trong ようと là trợ từ trích dẫn -- đánh dấu nội dung suy nghĩ. Khi đọc thấy ようと, ngay lập tức dự đoán phía sau sẽ có 思う hoặc 考える.

---

## Vようとする -- Cố gắng làm ~ / Sắp sửa làm ~

Mẫu này diễn tả **nỗ lực** hoặc **khoảnh khắc ngay trước hành động**. Rất phổ biến trong truyện, tiểu thuyết.

```
ドアを / 開けようとしたが / 開かなかった。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | ドアを | 🔒 **đóng gói:** "cửa" → を cho biết đối tượng → đọc tiếp |
| 2 | 開けようとしたが | 🔒 **đóng gói:** "cố mở cửa nhưng..." → giải phóng bộ nhớ → ようとした cho biết cố gắng (quá khứ) → が cho biết tương phản → dự đoán: sắp có kết quả trái ngược |
| 3 | 開かなかった | → "không mở được" → câu kết thúc ✅ |
| **Dịch** | | **Cố mở cửa nhưng không mở được.** |

---

```
猫が / 魚を / 食べようとしている。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 猫が | 🔒 **đóng gói:** "con mèo" → が cho biết chủ ngữ → đọc tiếp |
| 2 | 魚を | 🔒 **đóng gói:** "cá" → を cho biết đối tượng → đọc tiếp |
| 3 | 食べようとしている | 🔒 **đóng gói:** "đang sắp ăn" → giải phóng bộ nhớ → ようとしている cho biết khoảnh khắc ngay trước hành động → câu kết thúc ✅ |
| **Dịch** | | **Con mèo đang sắp ăn cá.** |

> **Phân biệt:**
> - Vようとする = **cố gắng** làm (có thể thất bại) hoặc **sắp sửa** làm (khoảnh khắc ngay trước)
> - Vようと思う = **dự định / quyết định** trong đầu
> Khi đọc truyện, gặp ようとした thường là cảnh nhân vật cố gắng làm gì đó → kết quả có thể thành công hoặc thất bại.

## 3. Mệnh lệnh: Vろ / Vえ / Vなさい

Hai dạng mệnh lệnh, khác nhau về mức độ:

- **Vろ (nhóm II):** Mệnh lệnh mạnh, thô. Ví dụ: 食べろ、起きろ. Thường gặp trong manga, phim, quân đội.
- **Vえ (nhóm I: 行け、読め、書け):** Mệnh lệnh mạnh, thô. Chuyển đuôi sang hàng え.
- **する → しろ, 来る → 来い (nhóm III, bất quy tắc):** する và 来る không thuộc nhóm I hay II, chia riêng.
- **Vなさい:** Mệnh lệnh nhẹ hơn. Thường gặp trong lời bố mẹ nói với con, giáo viên nói với học sinh, đề thi.

```
早く / 起きろ！
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 早く | trạng từ → "nhanh lên" → dự đoán: sắp có mệnh lệnh/yêu cầu |
| 2 | 起きろ！ | 🔒 **đóng gói:** "dậy đi!" → giải phóng bộ nhớ → ろ cho biết mệnh lệnh mạnh → câu kết thúc ✅ |
| **Dịch** | | **Dậy mau!** |

---

```
静かに / しろ！
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 静かに | に → trạng thái → "yên lặng" → dự đoán: sắp có yêu cầu |
| 2 | しろ！ | 🔒 **đóng gói:** "im đi!" → giải phóng bộ nhớ → ろ cho biết mệnh lệnh mạnh → câu kết thúc ✅ |
| **Dịch** | | **Im đi!** |

---

```
早く / 行け！
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 早く | trạng từ → "nhanh" → dự đoán: sắp có mệnh lệnh |
| 2 | 行け！ | 🔒 **đóng gói:** "đi đi!" → giải phóng bộ nhớ → え cho biết mệnh lệnh mạnh → câu kết thúc ✅ |
| **Dịch** | | **Đi nhanh!** |

---

```
早く / 寝なさい。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 早く | trạng từ → "sớm / nhanh" |
| 2 | 寝なさい | 🔒 **đóng gói:** "đi ngủ đi" → giải phóng bộ nhớ → なさい cho biết mệnh lệnh nhẹ → câu kết thúc ✅ |
| **Dịch** | | **Đi ngủ sớm đi con.** |

---

```
この問題に / 答えなさい。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | この問題に | 🔒 **đóng gói:** "câu hỏi này" → に cho biết đối tượng → đọc tiếp |
| 2 | 答えなさい | 🔒 **đóng gói:** "hãy trả lời" → giải phóng bộ nhớ → なさい cho biết mệnh lệnh nhẹ → câu kết thúc ✅ |
| **Dịch** | | **Hãy trả lời câu hỏi này.** |

> **Nhận diện khi đọc:** Vろ thường kết thúc bằng dấu ！ trong manga. Vなさい thường gặp trong đề thi (答えなさい、書きなさい、選びなさい).

---

## 4. Vるな -- Cấm! Đừng!

Thể cấm chỉ: **Vる (thể từ điển) + な**. Rất mạnh, thường gặp trên biển báo và trong manga.

```
ここで / 写真を / 撮るな！
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | ここで | 🔒 **đóng gói:** "ở đây" → で cho biết địa điểm → đọc tiếp |
| 2 | 写真を | 🔒 **đóng gói:** "ảnh" → を cho biết đối tượng → đọc tiếp |
| 3 | 撮るな！ | 🔒 **đóng gói:** "đừng chụp!" → giải phóng bộ nhớ → るな cho biết cấm chỉ → câu kết thúc ✅ |
| **Dịch** | | **Cấm chụp ảnh ở đây!** |

---

```
触るな！
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 触るな！ | 🔒 **đóng gói:** "đừng chạm!" → giải phóng bộ nhớ → るな cho biết cấm chỉ → câu kết thúc ✅ |
| **Dịch** | | **Cấm sờ! / Đừng chạm vào!** |

---

```
入るな。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 入るな | 🔒 **đóng gói:** "đừng vào" → giải phóng bộ nhớ → るな cho biết cấm chỉ → câu kết thúc ✅ |
| **Dịch** | | **Cấm vào.** |

> **Biển báo thường gặp:**
> - 入るな = Cấm vào
> - 触るな = Cấm sờ / Đừng chạm
> - 撮るな = Cấm chụp ảnh
> - 捨てるな = Cấm vứt rác

---

## 5. So sánh: Vてください vs Vなさい vs Vろ

Ba dạng yêu cầu/mệnh lệnh, từ lịch sự đến thô:

```
座ってください。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 座ってください | → yêu cầu lịch sự → "xin hãy ngồi" → câu kết thúc ✅ |
| **Dịch** | | **Xin mời ngồi.** |

---

```
座りなさい。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 座りなさい | 🔒 **đóng gói:** "ngồi xuống đi" → giải phóng bộ nhớ → なさい cho biết mệnh lệnh nhẹ → câu kết thúc ✅ |
| **Dịch** | | **Ngồi xuống đi.** |

---

```
座れ！
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 座れ！ | 🔒 **đóng gói:** "ngồi xuống!" → giải phóng bộ nhớ → れ cho biết mệnh lệnh mạnh → câu kết thúc ✅ |
| **Dịch** | | **Ngồi xuống!** |

---

### Bảng so sánh mức độ

| Dạng | Mức độ | Ngữ cảnh thường gặp |
|------|--------|---------------------|
| Vてください | Lịch sự | Giao tiếp hằng ngày, dịch vụ |
| Vなさい | Ra lệnh nhẹ | Bố mẹ → con, thầy → trò, đề thi |
| Vろ (nhóm II) / Vえ (nhóm I) / しろ, 来い (nhóm III) | Ra lệnh mạnh | Manga, quân đội, cãi nhau |
| Vるな | Cấm | Biển báo, manga, la mắng |

---

## Bảng dự đoán tổng hợp

| Gặp | Dự đoán |
|-----|---------|
| よう / ろう / おう (cuối câu) | Ý chí hoặc rủ rê → "làm ~ thôi" |
| 一緒に ... よう | Rủ cùng làm → "cùng ~ thôi" |
| ようと思います | Quyết định vừa mới → "tôi quyết định ~" |
| ようと思っています | Dự định kéo dài → "đang định ~" |
| ようとする | Cố gắng / sắp sửa làm → khoảnh khắc trước hành động |
| ようとしたが | Cố gắng nhưng... → sắp có kết quả trái ngược |
| ろ (nhóm II) / え (nhóm I) (cuối câu + ！) | Mệnh lệnh mạnh → ngữ cảnh manga, quân đội |
| なさい (cuối câu) | Mệnh lệnh nhẹ → bố mẹ, thầy cô, đề thi |
| Vるな | Cấm chỉ → biển báo, manga |
| てください | Yêu cầu lịch sự |
| 早く + mệnh lệnh | Giục giã → "nhanh lên!" |
