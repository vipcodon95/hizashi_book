# Bài 23: Thể điều kiện ば

> Bài 4 (Part 1) đã giới thiệu と -- điều kiện tự nhiên/máy móc.
> Bài 14 (Part 2) đã giới thiệu なら -- điều kiện dựa trên giả định của người nghe.
> Bài này bổ sung **ば** -- dạng điều kiện **logic**: "nếu A thì tất yếu B".
> Cuối bài sẽ so sánh đầy đủ cả 4 dạng điều kiện.

---

## 1. Vば -- Nếu ~ thì ~

Đuôi ば đánh dấu **điều kiện logic**. Nếu vế trước xảy ra, vế sau là kết quả tự nhiên/hợp lý.

```
ボタンを / 押せば / ドアが / 開きます。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | ボタンを | 🔒 **đóng gói:** "nút" → を cho biết đối tượng → đọc tiếp |
| 2 | 押せば | 🔒 **đóng gói:** "nếu nhấn nút" → giải phóng bộ nhớ → ば cho biết sắp có kết quả |
| 3 | ドアが | 🔒 **đóng gói:** "cửa" → が cho biết chủ ngữ → đọc tiếp |
| 4 | 開きます | → kết quả → "mở" → câu kết thúc ✅ |
| **Dịch** | | **Nếu nhấn nút thì cửa mở.** |

---

```
薬を / 飲めば / 治ります。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 薬を | 🔒 **đóng gói:** "thuốc" → を cho biết đối tượng → đọc tiếp |
| 2 | 飲めば | 🔒 **đóng gói:** "nếu uống thuốc" → giải phóng bộ nhớ → ば cho biết sắp có kết quả |
| 3 | 治ります | → kết quả → "sẽ khỏi" → câu kết thúc ✅ |
| **Dịch** | | **Uống thuốc thì sẽ khỏi.** |

---

```
時間が / あれば / 行きます。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 時間が | 🔒 **đóng gói:** "thời gian" → が cho biết chủ ngữ → đọc tiếp |
| 2 | あれば | 🔒 **đóng gói:** "nếu có thời gian" → giải phóng bộ nhớ → ば cho biết sắp có kết quả |
| 3 | 行きます | → kết quả → "sẽ đi" → câu kết thúc ✅ (chủ ngữ ẩn: tôi) |
| **Dịch** | | **Nếu có thời gian thì tôi sẽ đi.** |

> **Trợ từ thường đi kèm:** Vế trước ば thường có を (đối tượng hành động) hoặc が (chủ ngữ điều kiện). Vế sau thường kết thúc bằng ます/る.

## 2. Aければ -- Nếu [tính chất] thì ~

Tính từ い cũng chia được sang ば: bỏ い → thêm ければ.

```
安ければ / 買います。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 安ければ | 🔒 **đóng gói:** "nếu rẻ" → giải phóng bộ nhớ → ければ cho biết sắp có kết quả |
| 2 | 買います | → kết quả → "sẽ mua" → câu kết thúc ✅ |
| **Dịch** | | **Nếu rẻ thì mua.** |

---

```
天気が / よければ / 散歩に / 行きましょう。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 天気が | 🔒 **đóng gói:** "thời tiết" → が cho biết chủ ngữ → đọc tiếp |
| 2 | よければ | 🔒 **đóng gói:** "nếu thời tiết tốt" → giải phóng bộ nhớ → ければ cho biết sắp có kết quả |
| 3 | 散歩に | 🔒 **đóng gói:** "đi dạo" → に cho biết mục đích → đọc tiếp |
| 4 | 行きましょう | → rủ rê → "đi thôi" → câu kết thúc ✅ |
| **Dịch** | | **Nếu thời tiết đẹp thì đi dạo thôi.** |

---

```
おいしくなければ / 食べません。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | おいしくなければ | 🔒 **đóng gói:** "nếu không ngon" → giải phóng bộ nhớ → くなければ cho biết sắp có kết quả |
| 2 | 食べません | → phủ định → "không ăn" → câu kết thúc ✅ |
| **Dịch** | | **Nếu không ngon thì không ăn.** |

> **Nhận diện:** Thấy ければ ở giữa câu → điều kiện tính từ い. Thấy くなければ → điều kiện phủ định. Ngoại lệ: いい → よければ (không phải いければ).

---

## Tính từ な / Danh từ + であれば / なら（ば）

Tính từ な và danh từ dùng **であれば** hoặc **なら（ば）** để tạo điều kiện.

```
静かであれば / どこでも / いいです。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 静かであれば | 🔒 **đóng gói:** "nếu yên tĩnh" → giải phóng bộ nhớ → であれば cho biết sắp có kết quả |
| 2 | どこでも | でも → "đâu cũng" |
| 3 | いいです | → "được" → câu kết thúc ✅ |
| **Dịch** | | **Nếu yên tĩnh thì ở đâu cũng được.** |

---

```
学生であれば / 割引が / あります。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 学生であれば | 🔒 **đóng gói:** "nếu là sinh viên" → giải phóng bộ nhớ → であれば cho biết sắp có kết quả |
| 2 | 割引が | 🔒 **đóng gói:** "giảm giá" → が cho biết chủ ngữ → đọc tiếp |
| 3 | あります | → "có" → câu kết thúc ✅ |
| **Dịch** | | **Nếu là sinh viên thì có giảm giá.** |

> **Nhận diện:** Thấy であれば → điều kiện cho tính từ な hoặc danh từ. Trong văn nói, có thể dùng なら thay thế: 静かなら、学生なら.

## 3. VばVるほど -- Càng ~ càng ~

Mẫu đặc biệt: lặp lại động từ ở hai thể (ば + る) rồi thêm ほど.

```
読めば / 読むほど / 面白くなります。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 読めば | ば → điều kiện → "nếu đọc" → dự đoán: sắp có kết quả |
| 2 | 読むほど | 🔒 **đóng gói:** "càng đọc" → giải phóng bộ nhớ → ば...ほど cho biết mức độ tăng dần |
| 3 | 面白くなります | → trở nên → "càng thú vị" → câu kết thúc ✅ |
| **Dịch** | | **Càng đọc càng thú vị.** |

---

```
考えれば / 考えるほど / わからなくなる。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 考えれば | ば → điều kiện → "nếu nghĩ" → dự đoán: sắp có kết quả |
| 2 | 考えるほど | 🔒 **đóng gói:** "càng nghĩ" → giải phóng bộ nhớ → ば...ほど cho biết mức độ tăng dần |
| 3 | わからなくなる | → trở nên không ~ → "càng không hiểu" → câu kết thúc ✅ |
| **Dịch** | | **Càng nghĩ càng không hiểu.** |

---

```
練習すれば / するほど / 上手になります。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 練習すれば | ば → điều kiện → "nếu luyện tập" → dự đoán: sắp có kết quả |
| 2 | するほど | 🔒 **đóng gói:** "càng luyện tập" → giải phóng bộ nhớ → ば...ほど cho biết mức độ tăng dần |
| 3 | 上手になります | → trở nên → "càng giỏi" → câu kết thúc ✅ |
| **Dịch** | | **Càng luyện tập càng giỏi.** |

> **Dấu hiệu nhận diện:** Khi thấy cùng một động từ xuất hiện 2 lần liên tiếp (thể ば + thể る), ngay lập tức nhận ra mẫu "càng ~ càng ~". Từ ほど xác nhận.

## 4. Vばよかった -- Giá mà đã làm ~

Mẫu diễn tả **hối tiếc** -- ước gì đã làm điều gì đó.

```
もっと / 勉強すれば / よかった。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | もっと | trạng từ → "hơn nữa" → dự đoán: sắp có so sánh hoặc mong muốn |
| 2 | 勉強すれば | 🔒 **đóng gói:** "nếu học" → giải phóng bộ nhớ → ば cho biết sắp có kết quả |
| 3 | よかった | → mẫu ばよかった → hối tiếc → "giá mà đã ~" → câu kết thúc ✅ (chủ ngữ ẩn: tôi) |
| **Dịch** | | **Giá mà đã học nhiều hơn.** |

---

```
あの時 / 言えば / よかった。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | あの時 | thời gian → "lúc đó" → dự đoán: sắp nói về quá khứ |
| 2 | 言えば | 🔒 **đóng gói:** "nếu nói" → giải phóng bộ nhớ → ば cho biết sắp có kết quả |
| 3 | よかった | → mẫu ばよかった → hối tiếc → "giá mà đã ~" → câu kết thúc ✅ (chủ ngữ ẩn: tôi) |
| **Dịch** | | **Giá mà lúc đó đã nói.** |

---

```
傘を / 持ってくれば / よかった。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 傘を | 🔒 **đóng gói:** "ô / dù" → を cho biết đối tượng → đọc tiếp |
| 2 | 持ってくれば | 🔒 **đóng gói:** "nếu mang theo ô" → giải phóng bộ nhớ → ば cho biết sắp có kết quả |
| 3 | よかった | → mẫu ばよかった → hối tiếc → "giá mà đã ~" → câu kết thúc ✅ (chủ ngữ ẩn: tôi) |
| **Dịch** | | **Giá mà đã mang theo ô.** |

> **Nhận diện:** ばよかった luôn nằm cuối câu. Thường đi kèm もっと (hơn nữa), あの時 (lúc đó).

### Phủ định: Vなければよかった -- Giá mà đã không làm ~

```
あんなことを / 言わなければ / よかった。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | あんなことを | 🔒 **đóng gói:** "chuyện đó" → を cho biết đối tượng → đọc tiếp |
| 2 | 言わなければ | 🔒 **đóng gói:** "nếu đã không nói" → giải phóng bộ nhớ → なければ cho biết điều kiện phủ định |
| 3 | よかった | → mẫu なければよかった → hối tiếc → "giá mà đã không ~" → câu kết thúc ✅ (chủ ngữ ẩn: tôi) |
| **Dịch** | | **Giá mà đã không nói chuyện đó.** |

---

```
食べすぎなければ / よかった。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 食べすぎなければ | 🔒 **đóng gói:** "nếu đã không ăn quá nhiều" → giải phóng bộ nhớ → なければ cho biết điều kiện phủ định |
| 2 | よかった | → mẫu なければよかった → hối tiếc → "giá mà đã không ~" → câu kết thúc ✅ (chủ ngữ ẩn: tôi) |
| **Dịch** | | **Giá mà đã không ăn quá nhiều.** |

> **So sánh:**
> - Vば**よかった** = "giá mà **đã làm** ~" (hối tiếc vì đã không làm)
> - Vなければ**よかった** = "giá mà **đã không làm** ~" (hối tiếc vì đã làm)

## 5. So sánh tổng hợp 4 điều kiện: たら vs ば vs と vs なら

| | たら | ば | と | なら |
|---|------|-----|-----|------|
| **Nghĩa** | Nếu ~ (sau khi ~) | Nếu ~ thì ~ | Khi ~ thì luôn ~ | Nếu (theo lời bạn) thì ~ |
| **Đặc điểm** | Linh hoạt nhất, dùng được hầu hết trường hợp (*) | Điều kiện logic, tổng quát | Tự nhiên, máy móc, thói quen | Dựa trên thông tin của người khác |
| **Dùng cho quá khứ** | Được | Không | Không | Không |
| **Ý chí vế sau** | Được | Hạn chế (**) | Không | Được |
| **Ví dụ** | 雨が降ったら、行かない | 雨が降れば、中止する | 春になると、桜が咲く | 日本に行くなら、京都がいい |
| **Dịch** | Nếu trời mưa thì không đi | Nếu trời mưa thì hủy | Cứ đến xuân là hoa anh đào nở | Nếu đi Nhật thì Kyoto hay đấy |

> (*) **たら và chân lý/quy luật tự nhiên:** たら linh hoạt nhất nhưng **không phù hợp** cho chân lý, quy luật tự nhiên -- lúc đó dùng と. Ví dụ: ○ 春になると桜が咲く (chân lý) nhưng △ 春になったら桜が咲く (nghe không tự nhiên).
>
> (**) **ば và ý chí vế sau:** ば thường dùng cho kết quả **tự nhiên/logic**, không dùng khi vế sau là yêu cầu/mời mọc trực tiếp. Ví dụ: ○ 安ければ買います (logic) nhưng × 安ければ買ってください (yêu cầu). Ngoại lệ: vế trước là trạng thái (あれば、よければ) thì vế sau có thể có ý chí. Ngoại lệ khác: khi vế trước là **phủ định なければ**, vế sau cũng có thể có ý chí. Ví dụ: ○ 急がなければ間に合いませんよ (nếu không nhanh thì không kịp đâu).

### Mẹo nhận diện khi đọc

```
雨が / 降れば / 試合は / 中止です。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 雨が | 🔒 **đóng gói:** "mưa" → が cho biết chủ ngữ → đọc tiếp |
| 2 | 降れば | 🔒 **đóng gói:** "nếu trời mưa" → giải phóng bộ nhớ → ば cho biết sắp có kết quả |
| 3 | 試合は | 🔒 **đóng gói:** "trận đấu" → は cho biết chủ đề → đọc tiếp |
| 4 | 中止です | → kết quả → "hủy" → câu kết thúc ✅ |
| **Dịch** | | **Nếu trời mưa thì trận đấu hủy.** |

---

```
日本に / 行くなら / 新幹線が / 便利ですよ。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 日本に | 🔒 **đóng gói:** "Nhật" → に cho biết điểm đến → đọc tiếp |
| 2 | 行くなら | 🔒 **đóng gói:** "nếu đi Nhật" → giải phóng bộ nhớ → なら cho biết sắp có lời khuyên |
| 3 | 新幹線が | 🔒 **đóng gói:** "Shinkansen" → が cho biết chủ ngữ → đọc tiếp |
| 4 | 便利ですよ | → nhận xét + よ (nhấn mạnh) → "tiện lắm" → câu kết thúc ✅ |
| **Dịch** | | **Nếu đi Nhật thì tàu Shinkansen tiện lắm đấy.** |

## Bảng dự đoán tổng hợp

| Gặp | Dự đoán |
|-----|---------|
| Vば / Vれば | Điều kiện logic → sắp có kết quả ở vế sau |
| Aければ | Điều kiện tính từ い → sắp có kết quả |
| くなければ | Điều kiện phủ định tính từ い → "nếu không ~" |
| であれば | Điều kiện tính từ な / danh từ → "nếu là ~" |
| VばVるほど | Càng ~ càng ~ → sắp có mức độ tăng dần |
| ばよかった | Hối tiếc → "giá mà đã làm ~" |
| なければよかった | Hối tiếc → "giá mà đã không làm ~" |
| もっと ... ば | Hối tiếc hoặc mong muốn thêm |
| と (điều kiện) | Tự nhiên, máy móc → kết quả luôn xảy ra |
| たら | Linh hoạt → "nếu / sau khi ~" |
| なら | Dựa trên thông tin → thường đi kèm lời khuyên |
| が (vế sau ば) | Chủ ngữ mới → kết quả của điều kiện |
