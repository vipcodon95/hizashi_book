# Bài 24: Thể bị động (Passive form)

> Thể bị động rất phổ biến trong tiếng Nhật, đặc biệt trong **văn viết, báo chí, và kể chuyện**.
> Nhận diện bằng đuôi **-れる / -られる**.
> Điểm then chốt khi đọc: **trợ từ に đánh dấu người thực hiện hành động** (người/vật gây ra).
> Tiếng Nhật có 2 loại bị động: trực tiếp (giống tiếng Việt) và gián tiếp (bị ảnh hưởng -- đặc trưng tiếng Nhật).

---

## 1. [Người]に + Vられます -- Bị động trực tiếp

Chủ ngữ là người **chịu** hành động. に đánh dấu người **thực hiện** hành động.

```
私は / 先生に / 褒められました。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 私は | 🔒 **đóng gói:** "tôi" → は cho biết chủ đề → đọc tiếp |
| 2 | 先生に | 🔒 **đóng gói:** "bởi thầy" → に cho biết người thực hiện → dự đoán: sắp có bị động |
| 3 | 褒められました | られました → bị động + quá khứ → "được khen" → câu kết thúc ✅ |
| **Dịch** | | **Tôi được thầy khen.** |

---

```
弟は / 母に / 叱られました。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 弟は | 🔒 **đóng gói:** "em trai" → は cho biết chủ đề → đọc tiếp |
| 2 | 母に | 🔒 **đóng gói:** "bởi mẹ" → に cho biết người thực hiện → dự đoán: bị động |
| 3 | 叱られました | られました → bị động → "bị mắng" → câu kết thúc ✅ |
| **Dịch** | | **Em trai bị mẹ mắng.** |

---

```
犯人は / 警察に / 逮捕されました。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 犯人は | 🔒 **đóng gói:** "tên tội phạm" → は cho biết chủ đề → đọc tiếp |
| 2 | 警察に | 🔒 **đóng gói:** "bởi cảnh sát" → に cho biết người thực hiện → dự đoán: bị động |
| 3 | 逮捕されました | されました → bị động (する→される) → "bị bắt giữ" → câu kết thúc ✅ |
| **Dịch** | | **Tên tội phạm bị cảnh sát bắt giữ.** |

> **Trợ từ quan trọng nhất:** に trước động từ bị động = "bởi ~". Khi đọc thấy [người]に, ngay lập tức dự đoán: sắp có động từ bị động phía sau.

---

## 2. [Người]に + Vられます -- Bị động gián tiếp (bị ảnh hưởng / phiền hà)

Đây là loại bị động **đặc trưng tiếng Nhật**, không có trong tiếng Việt. Chủ ngữ **bị ảnh hưởng** bởi hành động của người khác, dù hành động đó không trực tiếp nhắm vào mình.

```
雨に / 降られて / 困りました。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 雨に | 🔒 **đóng gói:** "mưa" → に cho biết nguồn gây ảnh hưởng → dự đoán: bị động |
| 2 | 降られて | 🔒 **đóng gói:** "bị dính mưa" → giải phóng bộ nhớ → て cho biết sắp có kết quả/hệ quả |
| 3 | 困りました | → kết quả → "khổ sở / phiền" → câu kết thúc ✅ (chủ ngữ ẩn: tôi) |
| **Dịch** | | **Bị mưa (nên) khổ quá.** |

---

```
電車で / 隣の人に / 足を / 踏まれました。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 電車で | 🔒 **đóng gói:** "trên tàu" → で cho biết địa điểm → đọc tiếp |
| 2 | 隣の人に | 🔒 **đóng gói:** "người bên cạnh" → に cho biết người gây ảnh hưởng → dự đoán: bị động |
| 3 | 足を | 🔒 **đóng gói:** "chân" → を cho biết đối tượng → đọc tiếp |
| 4 | 踏まれました | れました → bị động → "bị giẫm" → câu kết thúc ✅ (chủ ngữ ẩn: tôi) |
| **Dịch** | | **Bị người bên cạnh giẫm lên chân trên tàu.** |

---

```
子供に / 夜中に / 泣かれて / 寝られませんでした。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 子供に | 🔒 **đóng gói:** "con" → に cho biết nguồn gây phiền → dự đoán: bị động phiền hà |
| 2 | 夜中に | 🔒 **đóng gói:** "giữa đêm" → に cho biết thời gian → đọc tiếp |
| 3 | 泣かれて | 🔒 **đóng gói:** "bị con khóc" → giải phóng bộ nhớ → て cho biết sắp có kết quả/hệ quả |
| 4 | 寝られませんでした | られません → khả năng phủ định + でした → "không ngủ được" → câu kết thúc ✅ (chủ ngữ ẩn: tôi) |
| **Dịch** | | **Con khóc giữa đêm nên không ngủ được.** |

> **Phân biệt trực tiếp vs gián tiếp:** Bị động gián tiếp thường mang sắc thái **phiền hà, bất tiện**. Chủ ngữ không phải đối tượng trực tiếp của hành động, mà chỉ bị ảnh hưởng.
>
> **⚠ Cảnh báo cho người Việt:** Tiếng Việt **không có** bị động gián tiếp. Nếu dịch theo cấu trúc sẽ rất lạ: "Tôi bị con khóc", "Tôi bị mưa rơi". **PHẢI** dịch thoát ý:
> - 子供に泣かれた → "Con khóc nên tôi khổ" (KHÔNG dịch: "Tôi bị con khóc")
> - 雨に降られた → "Bị dính mưa" / "Bị trời mưa" (KHÔNG dịch: "Tôi bị mưa rơi")
> - 友達に先に帰られた → "Bạn về trước mất rồi" (KHÔNG dịch: "Tôi bị bạn về trước")

## 3. NはNに/からVられました -- Bị động trong văn viết

Trong văn viết, báo chí, khoa học -- bị động rất phổ biến. Có thể dùng に hoặc から (từ ~) hoặc によって (bởi ~).

```
この小説は / 夏目漱石に / 書かれました。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | この小説は | 🔒 **đóng gói:** "tiểu thuyết này" → は cho biết chủ đề → đọc tiếp |
| 2 | 夏目漱石に | 🔒 **đóng gói:** "bởi Natsume Soseki" → に cho biết tác giả/người thực hiện → dự đoán: bị động |
| 3 | 書かれました | れました → bị động → "được viết" → câu kết thúc ✅ |
| **Dịch** | | **Tiểu thuyết này được viết bởi Natsume Soseki.** |

---

```
この建物は / 1920年に / 建てられました。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | この建物は | 🔒 **đóng gói:** "tòa nhà này" → は cho biết chủ đề → đọc tiếp |
| 2 | 1920年に | 🔒 **đóng gói:** "năm 1920" → に cho biết thời gian → đọc tiếp |
| 3 | 建てられました | られました → bị động → "được xây" → câu kết thúc ✅ |
| **Dịch** | | **Tòa nhà này được xây năm 1920.** |

---

```
新しい政策が / 政府から / 発表されました。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 新しい政策が | 🔒 **đóng gói:** "chính sách mới" → が cho biết chủ ngữ → đọc tiếp |
| 2 | 政府から | 🔒 **đóng gói:** "từ chính phủ" → から cho biết nguồn → dự đoán: bị động |
| 3 | 発表されました | されました → bị động (する→される) → "được công bố" → câu kết thúc ✅ |
| **Dịch** | | **Chính sách mới được chính phủ công bố.** |

---

### によって -- Bởi ~ (trang trọng, học thuật)

Trong văn phong khoa học, lịch sử, báo chí, によって thường thay に để nhấn mạnh tác nhân.

```
アメリカ大陸は / コロンブスによって / 発見されました。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | アメリカ大陸は | 🔒 **đóng gói:** "châu Mỹ" → は cho biết chủ đề → đọc tiếp |
| 2 | コロンブスによって | 🔒 **đóng gói:** "bởi Columbus" → giải phóng bộ nhớ → によって cho biết tác nhân (trang trọng) → dự đoán: bị động |
| 3 | 発見されました | されました → bị động → "được phát hiện" → câu kết thúc ✅ |
| **Dịch** | | **Châu Mỹ được Columbus phát hiện.** |

---

```
この研究は / 東京大学によって / 行われました。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | この研究は | 🔒 **đóng gói:** "nghiên cứu này" → は cho biết chủ đề → đọc tiếp |
| 2 | 東京大学によって | 🔒 **đóng gói:** "bởi Đại học Tokyo" → giải phóng bộ nhớ → によって cho biết tổ chức thực hiện → dự đoán: bị động |
| 3 | 行われました | われました → bị động (行う→行われる) → "được tiến hành" → câu kết thúc ✅ |
| **Dịch** | | **Nghiên cứu này được Đại học Tokyo tiến hành.** |

---

### Bị động trong báo chí / khoa học -- không có tác nhân

Trong tin tức và văn bản khoa học, câu bị động thường **bỏ tác nhân** (không có に/によって) vì người thực hiện không quan trọng hoặc không rõ.

```
新しいワクチンが / 開発されました。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 新しいワクチンが | 🔒 **đóng gói:** "vắc-xin mới" → が cho biết chủ ngữ → đọc tiếp |
| 2 | 開発されました | されました → bị động (する→される) → "đã được phát triển" → câu kết thúc ✅ |
| **Dịch** | | **Vắc-xin mới đã được phát triển.** |

---

```
会議は / 来週に / 延期されました。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 会議は | 🔒 **đóng gói:** "cuộc họp" → は cho biết chủ đề → đọc tiếp |
| 2 | 来週に | 🔒 **đóng gói:** "sang tuần sau" → に cho biết thời gian → đọc tiếp |
| 3 | 延期されました | されました → bị động → "đã bị hoãn" → câu kết thúc ✅ |
| **Dịch** | | **Cuộc họp đã bị hoãn sang tuần sau.** |

> **Trợ từ trong văn viết:**
> - に: người/tổ chức thực hiện (phổ biến nhất)
> - から: nguồn, nơi phát ra
> - によって: bởi ~ (trang trọng, học thuật) -- thường gặp trong lịch sử, khoa học
> - Không có tác nhân: phổ biến trong tin tức, văn bản khoa học -- tập trung vào sự việc, không quan trọng ai làm
>
> **⚠ Lưu ý:** によって **chỉ dùng cho sự kiện lịch sử, khoa học, phát minh** -- không dùng trong đời thường. Ví dụ:
> - ○ アメリカ大陸はコロンブスによって発見された (lịch sử)
> - ○ この理論はアインシュタインによって発表された (khoa học)
> - × 私は友達によって褒められた → phải dùng **に**: 友達に褒められた

## 4. Phân biệt bị động trực tiếp vs gián tiếp

| | Trực tiếp | Gián tiếp (phiền hà) |
|---|-----------|----------------------|
| **Chủ ngữ** | Là đối tượng trực tiếp của hành động | Bị ảnh hưởng gián tiếp |
| **Sắc thái** | Trung tính (bị/được) | Phiền hà, bất tiện |
| **Tiếng Việt** | Dịch được bằng "bị/được" | Thường phải dịch thoát ý |
| **Ví dụ** | 先生に褒められた (được thầy khen) | 雨に降られた (bị dính mưa -- phiền) |

```
友達に / 秘密を / 言われた。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 友達に | 🔒 **đóng gói:** "bạn bè" → に cho biết người thực hiện → dự đoán: bị động |
| 2 | 秘密を | 🔒 **đóng gói:** "bí mật" → を cho biết đối tượng → đọc tiếp |
| 3 | 言われた | れた → bị động quá khứ → "bị nói" → に...を...れた → bị động gián tiếp (phiền hà) → câu kết thúc ✅ (chủ ngữ ẩn: tôi) |
| **Dịch** | | **Bị bạn nói mất bí mật. (Bạn đi nói bí mật của tôi.)** |

> **Mẹo:** Khi chủ ngữ (は) **không phải** đối tượng trực tiếp của hành động mà chỉ bị ảnh hưởng → đó là bị động gián tiếp. Sắc thái luôn là phiền hà.

## 5. Lưu ý: 食べられる = bị ăn HOẶC có thể ăn

Với động từ nhóm II, thể bị động và thể khả năng **trùng hình thức**:

| Hình thức | Nghĩa 1 (bị động) | Nghĩa 2 (khả năng) |
|-----------|-------------------|---------------------|
| 食べられる | bị ăn | có thể ăn |
| 見られる | bị nhìn / bị xem | có thể nhìn / có thể xem |
| 起きられる | bị (ai) dậy | có thể dậy |

```
この魚は / 生で / 食べられます。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | この魚は | 🔒 **đóng gói:** "cá này" → は cho biết chủ đề → đọc tiếp |
| 2 | 生で | 🔒 **đóng gói:** "sống / sashimi" → で cho biết cách thức → đọc tiếp |
| 3 | 食べられます | られます → bị động hay khả năng? → ngữ cảnh: nói về cá ăn sống → **khả năng** → "ăn được" → câu kết thúc ✅ |
| **Dịch** | | **Cá này ăn sống được.** |

---

```
猫に / 魚を / 食べられた。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 猫に | 🔒 **đóng gói:** "mèo" → に cho biết người thực hiện → dự đoán: bị động |
| 2 | 魚を | 🔒 **đóng gói:** "cá" → を cho biết đối tượng → đọc tiếp |
| 3 | 食べられた | られた → có に phía trước → **bị động** → "bị ăn" → câu kết thúc ✅ (chủ ngữ ẩn: tôi) |
| **Dịch** | | **Bị mèo ăn mất cá. (Mèo ăn mất cá rồi.)** |

> **Mẹo phân biệt khi đọc:**
> - Có **に (người/vật)** phía trước → **bị động**: "bị ~ làm"
> - Không có に, nói về **khả năng/năng lực** → **khả năng**: "có thể ~"
> - Trong tiếng Nhật nói hiện đại, thể khả năng nhóm II thường rút gọn: 食べれる (bỏ ら). Dạng này chắc chắn là khả năng, không phải bị động.

## 6. Vれる/Vられる dùng cho kính ngữ -- Trùng hình thức với bị động!

Ngoài bị động và khả năng, đuôi れる/られる còn dùng để diễn tả **kính ngữ** (tôn kính người trên). Khi đọc văn trang trọng, gặp れる/られる mà **không có に** và **không phải nói về khả năng** → rất có thể là kính ngữ.

```
先生は / もう / 帰られました。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 先生は | 🔒 **đóng gói:** "thầy giáo" → は cho biết chủ đề → đọc tiếp |
| 2 | もう | trạng từ → "đã rồi" |
| 3 | 帰られました | られました → không có に trước → không phải bị động → chủ ngữ là 先生 (bề trên) → **kính ngữ** → "đã về" → câu kết thúc ✅ |
| **Dịch** | | **Thầy đã về rồi ạ.** |

---

```
社長は / 何時に / 来られますか。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 社長は | 🔒 **đóng gói:** "giám đốc" → は cho biết chủ đề → đọc tiếp |
| 2 | 何時に | 🔒 **đóng gói:** "mấy giờ" → に cho biết thời gian → đọc tiếp |
| 3 | 来られますか | られます → chủ ngữ là 社長 (bề trên) → **kính ngữ** → "đến" + か → câu hỏi → câu kết thúc ✅ |
| **Dịch** | | **Giám đốc mấy giờ đến ạ?** |

> **⚠ Cảnh báo:** れる/られる có **3 nghĩa** -- khi đọc phải xem ngữ cảnh:
>
> | Nghĩa | Tín hiệu nhận diện | Ví dụ |
> |-------|---------------------|-------|
> | **Bị động** | Có [người]に phía trước | 先生**に**褒め**られた** (được thầy khen) |
> | **Khả năng** | Nói về năng lực, có が | 日本語**が**話**せる** (nói được tiếng Nhật) |
> | **Kính ngữ** | Chủ ngữ là bề trên, không có に | **先生は**帰**られた** (thầy đã về) |
>
> Trong văn viết trang trọng (email công ty, báo chí, bài phát biểu), dạng kính ngữ này rất phổ biến. Thiếu nhận diện sẽ nhầm thành bị động.

## 7. Bị động với で -- Chất liệu / phương tiện

Trong văn viết, bị động thường đi với **で** để chỉ chất liệu hoặc phương tiện tạo ra.

```
この家は / 木で / 作られています。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | この家は | 🔒 **đóng gói:** "ngôi nhà này" → は cho biết chủ đề → đọc tiếp |
| 2 | 木で | 🔒 **đóng gói:** "bằng gỗ" → で cho biết chất liệu → đọc tiếp |
| 3 | 作られています | られています → bị động + đang (trạng thái) → "được làm" → câu kết thúc ✅ |
| **Dịch** | | **Ngôi nhà này được làm bằng gỗ.** |

```
この本は / 日本語で / 書かれています。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | この本は | 🔒 **đóng gói:** "quyển sách này" → は cho biết chủ đề → đọc tiếp |
| 2 | 日本語で | 🔒 **đóng gói:** "bằng tiếng Nhật" → で cho biết phương tiện → đọc tiếp |
| 3 | 書かれています | かれています → bị động + đang (trạng thái) → "được viết" → câu kết thúc ✅ |
| **Dịch** | | **Quyển sách này được viết bằng tiếng Nhật.** |

> **Nhận diện:** Khi gặp [chất liệu/ngôn ngữ]で + Vられている → bị động mô tả trạng thái. Mẫu này rất phổ biến trong văn bản giới thiệu, mô tả sản phẩm.

## Bảng dự đoán tổng hợp

| Gặp | Dự đoán |
|-----|---------|
| [Người/vật]に + ...れる/られる | Bị động → "bị/được [người] làm ~" |
| に trước động từ đuôi れる | Người thực hiện hành động → bị động |
| から + ...される | Nguồn / nơi phát ra → bị động văn viết |
| によって + ...される | Bởi ~ → bị động trang trọng, học thuật |
| は + ...に + ...を + Vれる | Bị động gián tiếp → sắc thái phiền hà |
| は + ...で + Vられる (không có に) | Khả năng → "có thể ~" |
| られる (nhóm II, không có に) | Có thể là khả năng hoặc kính ngữ → xem ngữ cảnh |
| [Bề trên]は + ...られる (không có に) | Kính ngữ → tôn kính người trên |
| [Chất liệu]で + Vられている | Bị động trạng thái → "được làm bằng ~" |
| によって (lịch sử, khoa học) | Bởi ~ (trang trọng) → không dùng đời thường |
| Vれて + câu tiếp | Bị động + nối → sắp có kết quả/hệ quả |
| されました (văn viết) | Bị động する → thường gặp trong tin tức, báo cáo |
