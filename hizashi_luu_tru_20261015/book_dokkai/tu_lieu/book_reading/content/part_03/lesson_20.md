# Bài 20: Thể thông thường tổng hợp

> Thể thông thường (普通形 - ふつうけい) là hệ thống tổng hợp tất cả các dạng khác với thể lịch sự (ます) khi trình bày tôi sẽ viết là TTT.
> Trong đọc hiểu, TTT xuất hiện **cực kỳ nhiều** trong mệnh đề phụ, trích dẫn, và văn viết.
> Bạn đã biết chia TTT. Bài này tập trung vào: **nhận diện TTT khi đọc** và các **mẫu câu quan trọng** dùng TTT.

---

## Bảng tổng hợp TTT

| Loại | Khẳng định | Phủ định | Quá khứ KĐ | Quá khứ PĐ |
|------|-----------|---------|-----------|-----------|
| V (nhóm II) | 食べる | 食べない | 食べた | 食べなかった |
| V (nhóm I) | 書く | 書かない | 書いた | 書かなかった |
| V (nhóm III) | する | しない | した | しなかった |
| V (nhóm III) | 来る | 来ない | 来た | 来なかった |
| Aい | 高い | 高くない | 高かった | 高くなかった |
| Aな | 静かだ | 静かじゃない | 静かだった | 静かじゃなかった |
| N | 学生だ | 学生じゃない | 学生だった | 学生じゃなかった |

> Khi đọc, gặp đuôi る/ない/た/なかった (động từ), い/くない/かった/くなかった (tính từ い), だ/じゃない/だった/じゃなかった (danh từ, tính từ な) → đó là TTT. Phía sau thường có mẫu câu cần nhận diện.

---

## 1. TTT + と思います -- Tôi nghĩ rằng ~

Trợ từ と đánh dấu **nội dung suy nghĩ**. Gặp と → dự đoán sắp có 思います/言います/... phía sau.

```
明日は / 雨だ / と思います。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 明日は | 🔒 **đóng gói:** "ngày mai" → は cho biết chủ đề → đọc tiếp |
| 2 | 雨だ | TTT (N + だ) → "là mưa" → đọc tiếp |
| 3 | と思います | 🔒 **đóng gói:** "ngày mai mưa" → giải phóng bộ nhớ → と思います cho biết ý kiến cá nhân → câu kết thúc ✅ |
| **Dịch** | | **Tôi nghĩ ngày mai trời mưa.** |

---

```
この映画は / おもしろい / と思います。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | この映画は | 🔒 **đóng gói:** "bộ phim này" → は cho biết chủ đề → đọc tiếp |
| 2 | おもしろい | TTT (Aい) → "thú vị" → đọc tiếp |
| 3 | と思います | 🔒 **đóng gói:** "phim này thú vị" → giải phóng bộ nhớ → と思います cho biết ý kiến cá nhân → câu kết thúc ✅ |
| **Dịch** | | **Tôi nghĩ bộ phim này thú vị.** |

---

```
彼は / 来ない / と思います。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 彼は | 🔒 **đóng gói:** "anh ấy" → は cho biết chủ đề → đọc tiếp |
| 2 | 来ない | TTT phủ định → "không đến" → đọc tiếp |
| 3 | と思います | 🔒 **đóng gói:** "anh ấy không đến" → giải phóng bộ nhớ → と思います cho biết ý kiến cá nhân → câu kết thúc ✅ |
| **Dịch** | | **Tôi nghĩ anh ấy không đến.** |

> **Tín hiệu nhận diện:** Gặp TTT + と → luôn dự đoán phía sau là 思います, 言います, hoặc động từ suy nghĩ/phát ngôn.

> **⚠ Cảnh báo cho người Việt -- だ trước các mẫu phỏng đoán:**
>
> | Mẫu | Danh từ / Aな trước đó | Ví dụ |
> |-----|------------------------|-------|
> | と思います | **Cần** だ | 雨**だ**と思います ✅ |
> | でしょう | **Không** dùng だ | 雨でしょう ✅ ~~雨だでしょう~~ ❌ |
> | かもしれません | **Không** dùng だ | 雨かもしれません ✅ ~~雨だかもしれません~~ ❌ |
>
> Lý do: と là trợ từ trích dẫn, cần câu hoàn chỉnh (có だ) trước nó. Còn でしょう và かもしれません nối trực tiếp, không qua trợ từ.

```
先生は / 「明日 / テストがある」 / と言いました。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 先生は | 🔒 **đóng gói:** "thầy/cô" → は cho biết chủ đề → đọc tiếp |

| 3 | テストがある | 🔒 **đóng gói:** "bài kiểm tra" → が cho biết chủ ngữ (trong trích dẫn) → "có bài kiểm tra" → đọc tiếp |
| 4 | と言いました | 🔒 **đóng gói:** "ngày mai có bài kiểm tra" → giải phóng bộ nhớ → と言いました cho biết trích dẫn lời nói → câu kết thúc ✅ |
| **Dịch** | | **Thầy/cô nói rằng ngày mai có bài kiểm tra.** |

```

```

|------|-----|-------|

| 4 | と言いました | 🔒 **đóng gói:** "không đi dự tiệc" → giải phóng bộ nhớ → と言いました cho biết trích dẫn lời nói → câu kết thúc ✅ |
| **Dịch** | | **Tanaka nói rằng không đi dự tiệc.** |

## 3. TTT + N -- Mệnh đề bổ nghĩa danh từ

Đây là mẫu câu **quan trọng nhất cho đọc hiểu**. TTT đứng trước danh từ để bổ nghĩa, giống như mệnh đề quan hệ trong tiếng Việt.

> **⚠ Thứ tự ngược so với tiếng Việt:** Tiếng Việt đặt mệnh đề bổ nghĩa **SAU** danh từ, tiếng Nhật đặt **TRƯỚC**.
> - Tiếng Việt: sách **[mà hôm qua đã mua]** → danh từ trước, mệnh đề sau
> - Tiếng Nhật: **[昨日買った]** 本 → mệnh đề trước, danh từ sau
>
> Khi đọc, gặp TTT mà chưa thấy dấu kết thúc câu → **kiên nhẫn đọc tiếp**, danh từ được bổ nghĩa sẽ xuất hiện ngay sau đó.

> **Ghi chú quan trọng:** Khi Aな và N bổ nghĩa danh từ:
> - Aな + N → dùng **な** (KHÔNG dùng だ): ✅ 静か**な**町 (thị trấn yên tĩnh) ❌ 静か~~だ~~町
> - N + N → dùng **の**: ✅ 学生**の**田中さん (Tanaka là học sinh)

```
昨日 / 買った / 本は / おもしろいです。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 昨日 | thời gian → "hôm qua" |
| 2 | 買った | TTT quá khứ → "đã mua" → chưa kết thúc câu, dự đoán: bổ nghĩa danh từ |
| 3 | 本は | 🔒 **đóng gói:** "cuốn sách mua hôm qua" → は cho biết chủ đề → đọc tiếp |
| 4 | おもしろいです | tính từ → "thú vị" → câu kết thúc ✅ |
| **Dịch** | | **Cuốn sách mua hôm qua thú vị.** |

---

```
母が / 作った / 料理を / 食べました。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 母が | 🔒 **đóng gói:** "mẹ" → が cho biết chủ ngữ (trong mệnh đề phụ) → đọc tiếp |
| 2 | 作った | TTT quá khứ → "đã nấu" → dự đoán: bổ nghĩa danh từ tiếp theo |
| 3 | 料理を | 🔒 **đóng gói:** "món ăn mẹ nấu" → を cho biết đối tượng → đọc tiếp |
| 4 | 食べました | động từ quá khứ → "đã ăn" → (chủ ngữ ẩn: tôi) → câu kết thúc ✅ |
| **Dịch** | | **Tôi đã ăn món ăn mẹ nấu.** |

---

```
日本語を / 教えている / 先生は / 山田さんです。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 日本語を | 🔒 **đóng gói:** "tiếng Nhật" → を cho biết đối tượng → đọc tiếp |
| 2 | 教えている | TTT (đang dạy) → dự đoán: bổ nghĩa danh từ tiếp theo |
| 3 | 先生は | 🔒 **đóng gói:** "thầy/cô đang dạy tiếng Nhật" → は cho biết chủ đề → đọc tiếp |
| 4 | 山田さんです | です → "là Yamada" → câu kết thúc ✅ |
| **Dịch** | | **Thầy/cô đang dạy tiếng Nhật là Yamada.** |

> **Tín hiệu nhận diện:** Gặp TTT + danh từ → đó là mệnh đề bổ nghĩa. TTT mô tả danh từ đứng ngay sau nó. Trong mệnh đề phụ, chủ ngữ dùng が (không dùng は).

## 4. TTT + んです / のです -- Giải thích lý do / Nhấn mạnh

```
頭が / 痛いんです。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 頭が | 🔒 **đóng gói:** "đầu" → が cho biết chủ ngữ → đọc tiếp |
| 2 | 痛いんです | 🔒 **đóng gói:** "đau đầu" → giải phóng bộ nhớ → んです cho biết giải thích lý do → câu kết thúc ✅ |
| **Dịch** | | **(Là vì) đau đầu.** |

---

```
昨日 / 寝なかったんです。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 昨日 | thời gian → "hôm qua" |
| 2 | 寝なかったんです | 🔒 **đóng gói:** "hôm qua không ngủ" → giải phóng bộ nhớ → んです cho biết giải thích lý do → (chủ ngữ ẩn: tôi) → câu kết thúc ✅ |
| **Dịch** | | **(Là vì) hôm qua không ngủ.** |

---

```
電車が / 遅れたんです。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 電車が | 🔒 **đóng gói:** "tàu điện" → が cho biết chủ ngữ → đọc tiếp |
| 2 | 遅れたんです | 🔒 **đóng gói:** "tàu điện bị trễ" → giải phóng bộ nhớ → んです cho biết giải thích lý do → câu kết thúc ✅ |
| **Dịch** | | **(Là vì) tàu điện bị trễ.** |

> **Tín hiệu nhận diện:** Gặp TTT + んです/のです → người nói đang giải thích lý do hoặc nhấn mạnh. のです là dạng trang trọng hơn của んです.
> **Lưu ý:** Với danh từ và tính từ な: N + **な**んです, Aな + **な**んです. Ví dụ: 病気**な**んです (là vì bị bệnh).

**Hỏi lý do / tình huống:**

```
どうしたんですか。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | どうしたんですか | どうした + んです + か → hỏi lý do → "có chuyện gì vậy?" → câu kết thúc ✅ |
| **Dịch** | | **Có chuyện gì vậy?** |

> んです không chỉ giải thích mà còn dùng để **hỏi lý do/tình huống**: どうしたんですか (chuyện gì vậy?), なぜ来たんですか (sao lại đến?).

## 5. TTT + でしょう -- Chắc là ~ / ~ nhỉ?

```
明日は / いい天気 / でしょう。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 明日は | 🔒 **đóng gói:** "ngày mai" → は cho biết chủ đề → đọc tiếp |
| 2 | いい天気 | danh từ → "thời tiết đẹp" → đọc tiếp |
| 3 | でしょう | 🔒 **đóng gói:** "ngày mai thời tiết đẹp" → giải phóng bộ nhớ → でしょう cho biết phỏng đoán → câu kết thúc ✅ |
| **Dịch** | | **Ngày mai chắc trời đẹp nhỉ.** |

---

```
彼は / もう / 帰った / でしょう。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 彼は | 🔒 **đóng gói:** "anh ấy" → は cho biết chủ đề → đọc tiếp |
| 2 | もう | trạng từ → "rồi / đã" |
| 3 | 帰った | TTT quá khứ → "đã về" → đọc tiếp |
| 4 | でしょう | 🔒 **đóng gói:** "anh ấy đã về rồi" → giải phóng bộ nhớ → でしょう cho biết phỏng đoán → câu kết thúc ✅ |
| **Dịch** | | **Anh ấy chắc đã về rồi nhỉ.** |

> **Tín hiệu nhận diện:** Gặp TTT + でしょう → người nói phỏng đoán, không chắc chắn 100%.
> **Lưu ý:** Với danh từ và tính từ な, **KHÔNG** thêm だ trước でしょう. Nói ✅ 雨**でしょう**, KHÔNG nói ❌ 雨~~だ~~でしょう.

**でしょう？ với ngữ điệu lên -- Nghĩa xác nhận:**

Khi đọc hội thoại, でしょう？ (có dấu hỏi, ngữ điệu lên) mang nghĩa **xác nhận** -- "đúng không? / phải không?":

```
この映画、おもしろかったでしょう？
```

→ **Phim này hay, đúng không?** (người nói muốn đối phương đồng ý)

> **Phân biệt khi đọc:**
> - でしょう。(dấu chấm) → phỏng đoán: "chắc là ~"
> - でしょう？(dấu hỏi) → xác nhận: "~ đúng không? / ~ phải không?"

## 6. TTT + かもしれません -- Có lẽ ~

```
明日は / 雨が / 降るかもしれません。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 明日は | 🔒 **đóng gói:** "ngày mai" → は cho biết chủ đề → đọc tiếp |
| 2 | 雨が | 🔒 **đóng gói:** "mưa" → が cho biết chủ ngữ → đọc tiếp |
| 3 | 降るかもしれません | 🔒 **đóng gói:** "ngày mai có lẽ mưa" → giải phóng bộ nhớ → かもしれません cho biết phỏng đoán mức thấp → câu kết thúc ✅ |
| **Dịch** | | **Ngày mai có lẽ trời mưa.** |

---

```
あの人は / 日本人 / かもしれません。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | あの人は | 🔒 **đóng gói:** "người kia" → は cho biết chủ đề → đọc tiếp |
| 2 | 日本人 | danh từ → "người Nhật" → đọc tiếp |
| 3 | かもしれません | 🔒 **đóng gói:** "người kia là người Nhật" → giải phóng bộ nhớ → かもしれません cho biết phỏng đoán mức thấp → câu kết thúc ✅ |
| **Dịch** | | **Người kia có lẽ là người Nhật.** |

> **Tín hiệu nhận diện:** Gặp TTT + かもしれません → mức độ chắc chắn thấp hơn でしょう, "có lẽ / biết đâu".
> **Lưu ý:** Với danh từ và tính từ な, **không** thêm だ trước かもしれません. Nói 学生かもしれません, KHÔNG nói 学生だかもしれません.

### So sánh mức độ chắc chắn

| Mức độ | Mẫu | Nghĩa |
|--------|-----|-------|
| Chắc chắn (ý kiến cá nhân) | と思います | Tôi nghĩ rằng ~ |
| Khá chắc (~70-80%) | でしょう | Chắc là ~ |
| Có thể (~30-50%) | かもしれません | Có lẽ / biết đâu ~ |

## 7. TTT + かどうか -- Có ~ hay không

```
明日 / 来るかどうか / わかりません。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 明日 | thời gian → "ngày mai" |

| 3 | わかりません | phủ định → "không biết" → (chủ ngữ ẩn: tôi) → câu kết thúc ✅ |
| **Dịch** | | **Không biết ngày mai có đến hay không.** |

---


| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | この答えが | 🔒 **đóng gói:** "câu trả lời này" → が cho biết chủ ngữ → đọc tiếp |

> **Tín hiệu nhận diện:** Gặp TTT + かどうか → nghĩa là "có ~ hay không", luôn dự đoán phía sau là わかる/知る/聞く/確認する/...

## 8. TTT + そうです -- Nghe nói rằng ~

Truyền đạt thông tin nghe được từ người khác. **Khác hoàn toàn** với Vそう (có vẻ ~, dựa vào quan sát).

```
天気予報によると / 明日は / 雨だ / そうです。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 天気予報によると | 🔒 **đóng gói:** "theo dự báo thời tiết" → によると cho biết nguồn tin → đọc tiếp |
| 2 | 明日は | 🔒 **đóng gói:** "ngày mai" → は cho biết chủ đề → đọc tiếp |
| 3 | 雨だ | TTT → "mưa" → đọc tiếp |
| 4 | そうです | 🔒 **đóng gói:** "nghe nói ngày mai mưa" → giải phóng bộ nhớ → そうです cho biết thông tin nghe được → câu kết thúc ✅ |
| **Dịch** | | **Nghe nói (theo dự báo thời tiết) ngày mai trời mưa.** |

---

```
田中さんは / 来月 / 結婚する / そうです。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 田中さんは | 🔒 **đóng gói:** "Tanaka" → は cho biết chủ đề → đọc tiếp |
| 2 | 来月 | thời gian → "tháng sau" |
| 3 | 結婚する | TTT → "kết hôn" → đọc tiếp |
| 4 | そうです | 🔒 **đóng gói:** "Tanaka tháng sau kết hôn" → giải phóng bộ nhớ → そうです cho biết thông tin nghe được → câu kết thúc ✅ |
| **Dịch** | | **Nghe nói Tanaka tháng sau kết hôn.** |

> **⚠ Phân biệt hai loại そう khi đọc:**
>
> | | TTT + そうです | Vます(bỏ ます) + そうです |
> |--|---------------|------------------------|
> | Nghĩa | Nghe nói ~ (tin đồn/truyền đạt) | Có vẻ ~ (quan sát/phỏng đoán) |
> | Trước そう | Câu hoàn chỉnh ở TTT | Gốc động từ/tính từ (không có đuôi) |
> | Ví dụ | 雨だそうです (nghe nói mưa) | 雨が降りそうです (có vẻ sắp mưa) |
> | Dấu hiệu | Thường có によると (theo ~) | Thường mô tả tình huống trước mắt |

## 9. TTT + はずです -- Lẽ ra phải ~ / Chắc hẳn ~

Diễn tả suy luận dựa trên lý do hợp lý -- "theo lý mà nói thì phải thế".

```
もう届いた / はずです。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | もう届いた | "đã gửi đến rồi" → đọc tiếp |
| 2 | はずです | 🔒 **đóng gói:** "chắc hẳn đã gửi đến rồi" → giải phóng bộ nhớ → はず cho biết suy luận có căn cứ → câu kết thúc ✅ |
| **Dịch** | | **Chắc hẳn đã gửi đến rồi (lẽ ra phải đến rồi).** |

---

```
田中さんは / 知っている / はずです。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 田中さんは | 🔒 **đóng gói:** "Tanaka" → は cho biết chủ đề → đọc tiếp |
| 2 | 知っている | TTT → "biết" → đọc tiếp |
| 3 | はずです | 🔒 **đóng gói:** "Tanaka chắc hẳn biết" → giải phóng bộ nhớ → はず cho biết suy luận có căn cứ → câu kết thúc ✅ |
| **Dịch** | | **Tanaka chắc hẳn biết (lẽ ra phải biết).** |

> **So sánh mức độ phỏng đoán (bổ sung):**
>
> | Mức độ | Mẫu | Nghĩa | Căn cứ |
> |--------|-----|-------|--------|
> | Chắc chắn (ý kiến) | と思います | Tôi nghĩ ~ | Ý kiến cá nhân |
> | Suy luận có lý (~90%) | はずです | Chắc hẳn ~ / Lẽ ra ~ | Có lý do cụ thể |
> | Khá chắc (~70-80%) | でしょう | Chắc là ~ | Kinh nghiệm/cảm giác |
> | Có thể (~30-50%) | かもしれません | Có lẽ ~ | Khả năng, không chắc |

## 10. TTT + ようです / みたいです -- Có vẻ như ~

Diễn tả **phán đoán dựa trên quan sát gián tiếp** -- không nhìn thấy trực tiếp nhưng suy ra từ dấu hiệu.

```
この店は / 人気がある / ようです。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | この店は | 🔒 **đóng gói:** "cửa hàng này" → は cho biết chủ đề → đọc tiếp |
| 2 | 人気がある | TTT → "nổi tiếng" → đọc tiếp |
| 3 | ようです | 🔒 **đóng gói:** "cửa hàng này có vẻ nổi tiếng" → giải phóng bộ nhớ → ようです cho biết phán đoán từ quan sát → câu kết thúc ✅ |
| **Dịch** | | **Cửa hàng này có vẻ nổi tiếng.** |

---

```
彼は / 忙しい / みたいです。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 彼は | 🔒 **đóng gói:** "anh ấy" → は cho biết chủ đề → đọc tiếp |
| 2 | 忙しい | TTT (Aい) → "bận" → đọc tiếp |
| 3 | みたいです | 🔒 **đóng gói:** "anh ấy có vẻ bận" → giải phóng bộ nhớ → みたいです cho biết phán đoán (văn nói) → câu kết thúc ✅ |
| **Dịch** | | **Anh ấy có vẻ bận.** |

> **ようです vs みたいです:** Nghĩa giống nhau ("có vẻ như ~"). ようです trang trọng hơn (văn viết), みたいです thân mật hơn (văn nói). Khi đọc gặp cả hai đều xử lý giống nhau.

## Bảng dự đoán tổng hợp

| Gặp | Dự đoán | Ví dụ |
|-----|---------|-------|
| TTT + と | Sắp có 思います/言います → "nghĩ rằng / nói rằng" | おもしろいと思います |
| TTT + N | Mệnh đề bổ nghĩa danh từ → "N mà ~" | 買った本 (sách mà đã mua) |
| TTT + んです | Giải thích lý do / nhấn mạnh → "là vì ~" | 痛いんです |
| TTT + でしょう | Phỏng đoán → "chắc là ~" | 帰ったでしょう |
| TTT + かもしれません | Phỏng đoán thấp → "có lẽ ~" | 降るかもしれません |
| TTT + かどうか | Câu hỏi gián tiếp → "có ~ hay không" | 来るかどうかわかりません |
| TTT + そうです | Truyền đạt → "nghe nói ~" | 結婚するそうです |
| TTT + はずです | Suy luận có căn cứ → "chắc hẳn ~ / lẽ ra ~" | 届いたはずです |
| TTT + ようです | Phán đoán từ quan sát → "có vẻ ~" (trang trọng) | 人気があるようです |
| TTT + みたいです | Phán đoán từ quan sát → "có vẻ ~" (thân mật) | 忙しいみたいです |
| が (trong mệnh đề phụ) | Chủ ngữ của mệnh đề phụ (không dùng は) | 母**が**作った料理 |
| と | Trích dẫn / nội dung suy nghĩ → sắp có động từ phát ngôn/suy nghĩ | ...と思う / ...と言う |
