# Bài 17: Thể ない (nai-form)

> Bài 12 đã giới thiệu ません — dạng phủ định lịch sự. Bài này giới thiệu ない — dạng phủ định thông thường (informal).
> Bài này **không dạy cách chia** thể ない — bạn đã biết rồi.
> Điểm quan trọng: có nhiều mẫu câu **chỉ dùng được với thể ない**, không dùng được với ません.
> Khi đọc gặp Vない, hãy nhìn phần **SAU** nó để xác định mẫu câu.

---

## 1. Vないでください — Xin đừng làm ~

**Trợ từ thường gặp:** を + Vないでください

```
ここで / 写真を / 撮らないでください。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | ここで | 🔒 **đóng gói:** "ở đây" → で cho biết địa điểm hành động → đọc tiếp |
| 2 | 写真を | 🔒 **đóng gói:** "hình ảnh bức ảnh" → を cho biết đối tượng → đọc tiếp |
| 3 | 撮らないでください | 🔒 **đóng gói:** "xin đừng chụp" → Vないでください → yêu cầu đừng làm → câu kết thúc ✅ |
| **Dịch** | | **Xin đừng chụp ảnh ở đây.** |

---

```
窓を / 開けないでください。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 窓を | 🔒 **đóng gói:** "hình ảnh cửa sổ" → を cho biết đối tượng → đọc tiếp |
| 2 | 開けないでください | 🔒 **đóng gói:** "xin đừng mở" → Vないでください → yêu cầu đừng làm → câu kết thúc ✅ |
| **Dịch** | | **Xin đừng mở cửa sổ.** |

> **So sánh với Bài 16:** Vてください = "xin hãy làm ~" ↔ Vないでください = "xin đừng làm ~". Cặp đối nghĩa.

> **Người thực hiện:** Yêu cầu hướng đến **người nghe/người đọc** — "bạn đừng làm ~". Giống てください (bài 16), cả hai đều yêu cầu **đối phương** hành động (hoặc không hành động).

---

## 2. Vなければなりません — Phải làm ~ (bắt buộc)

**Trợ từ thường gặp:** を + Vなければなりません

```
毎日 / 薬を / 飲まなければなりません。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 毎日 | thời gian → "mỗi ngày" |
| 2 | 薬を | 🔒 **đóng gói:** "hình ảnh viên thuốc" → を cho biết đối tượng → đọc tiếp |
| 3 | 飲まなければなりません | 🔒 **đóng gói:** "phải uống" → Vなければなりません → bắt buộc → (chủ ngữ ẩn: 私) → câu kết thúc ✅ |
| **Dịch** | | **Mỗi ngày phải uống thuốc.** |

---

```
明日 / レポートを / 出さなければなりません。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 明日 | thời gian → "ngày mai" |
| 2 | レポートを | 🔒 **đóng gói:** "hình ảnh bài báo cáo" → を cho biết đối tượng → đọc tiếp |
| 3 | 出さなければなりません | 🔒 **đóng gói:** "phải nộp" → Vなければなりません → bắt buộc → (chủ ngữ ẩn: 私) → câu kết thúc ✅ |
| **Dịch** | | **Ngày mai phải nộp báo cáo.** |

> **Mẹo đọc:** なければなりません rất dài nhưng chỉ cần nhận ra なければ → biết ngay là "phải làm". Dạng ngắn gọn hơn: なきゃ (口語 — văn nói), なくてはいけません (nghĩa tương đương). Khi đọc gặp bất kỳ dạng nào, đều hiểu là **bắt buộc**.

> **Ai phải làm?** Nhìn chủ ngữ (は/が) phía trước để xác định. Nếu không có chủ ngữ → suy từ ngữ cảnh:
> - Tự nói: 薬を飲まなければなりません → **Tôi** phải uống thuốc
> - Nói với đối phương: レポートを出さなければなりませんよ → **Bạn** phải nộp báo cáo đấy
> - Quy tắc chung: ここでは静かにしなければなりません → **Ai cũng** phải giữ yên lặng ở đây

## 3. Biến thể văn nói: なきゃ / なくちゃ

Trong manga, hội thoại, blog, thường gặp dạng rút gọn của mục 2:

```
なければなりません → なければ → なきゃ
なくてはいけません → なくては → なくちゃ
```

```
もう / 行かなきゃ。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | もう | "rồi / đã" |
| 2 | 行かなきゃ | 🔒 **đóng gói:** "phải đi" → なきゃ = なければ → bắt buộc → (chủ ngữ ẩn: 私) → câu kết thúc ✅ |
| **Dịch** | | **Phải đi rồi.** |

---

```
宿題 / やらなくちゃ。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 宿題 | 🔒 **đóng gói:** "hình ảnh bài tập" → đọc tiếp |
| 2 | やらなくちゃ | 🔒 **đóng gói:** "phải làm" → なくちゃ = なくてはいけない → bắt buộc → (chủ ngữ ẩn: 私) → câu kết thúc ✅ |
| **Dịch** | | **Phải làm bài tập.** |

> **Mẹo đọc:** Gặp なきゃ hoặc なくちゃ → hiểu là "phải làm" (= なければなりません). Đây là dạng thân mật nhất.

---

## 4. Vなくてもいいです — Không làm ~ cũng được

**Trợ từ thường gặp:** を + Vなくてもいいです

```
明日は / 来なくてもいいです。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 明日は | 🔒 **đóng gói:** "ngày mai" → は cho biết chủ đề (thời gian) → đọc tiếp |
| 2 | 来なくてもいいです | 🔒 **đóng gói:** "không đến cũng được" → Vなくてもいいです → không bắt buộc → câu kết thúc ✅ |
| **Dịch** | | **Ngày mai không đến cũng được.** |

---

```
全部 / 食べなくてもいいです。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 全部 | trạng từ → "tất cả" |
| 2 | 食べなくてもいいです | 🔒 **đóng gói:** "không ăn hết cũng được" → Vなくてもいいです → không bắt buộc → câu kết thúc ✅ |
| **Dịch** | | **Không cần ăn hết cũng được.** |

> **So sánh cặp đối lập:**
> - Vなければなりません → **phải** làm (bắt buộc)
> - Vなくてもいいです → **không cần** làm (không bắt buộc)

> **Ai được miễn?** Tương tự mục 2, nhìn ngữ cảnh:
> - Cho phép đối phương: 明日は来なくてもいいです → **Bạn** không đến cũng được
> - Tự nhẹ nhõm: 全部覚えなくてもいいんだ → **Mình** không cần nhớ hết cũng được
> - Quy tắc chung: この試験では辞書を使わなくてもいいです → **Ai cũng** không cần dùng từ điển

## 5. Vないほうがいいです — Không nên làm ~

```
夜 / コーヒーを / 飲まないほうがいいです。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 夜 | thời gian → "buổi tối" |
| 2 | コーヒーを | 🔒 **đóng gói:** "hình ảnh ly cà phê" → を cho biết đối tượng → đọc tiếp |
| 3 | 飲まないほうがいいです | 🔒 **đóng gói:** "không nên uống" → Vないほうがいい → lời khuyên phủ định → câu kết thúc ✅ |
| **Dịch** | | **Buổi tối không nên uống cà phê.** |

---

```
あまり / 無理を / しないほうがいいですよ。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | あまり | biển báo → dự đoán: sắp có phủ định (không...lắm) |
| 2 | 無理を | 🔒 **đóng gói:** "hình ảnh sự gắng sức" → を cho biết đối tượng → đọc tiếp |
| 3 | しないほうがいいですよ | 🔒 **đóng gói:** "không nên làm" → Vないほうがいい → lời khuyên phủ định → câu kết thúc ✅ |
| **Dịch** | | **Không nên cố quá sức đấy.** |

> **Mẹo đọc:** Gặp ほうがいい → đây là lời khuyên. Nếu trước đó là Vない → khuyên **không nên** làm. Nếu trước đó là Vた → khuyên **nên** làm (sẽ học ở bài thể た).

> **Người thực hiện:** Lời khuyên hướng đến **người nghe** — "bạn không nên làm ~". Người nói đóng vai trò khuyên nhủ.

---

## 6. Vないで — Không làm ~ mà... (trạng thái)

```
朝ご飯を / 食べないで / 学校に / 行きました。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 朝ご飯を | 🔒 **đóng gói:** "hình ảnh bữa sáng" → を cho biết đối tượng → đọc tiếp |
| 2 | 食べないで | 🔒 **đóng gói:** "không ăn mà..." → giải phóng bộ nhớ → Vないで cho biết sắp có hành động chính → đọc tiếp |
| 3 | 学校に | 🔒 **đóng gói:** "hình ảnh trường học" → に cho biết điểm đến → đọc tiếp |
| 4 | 行きました | "đã đi" → (chủ ngữ ẩn: 私) → câu kết thúc ✅ |
| **Dịch** | | **Không ăn sáng mà đi học luôn.** |

---

```
傘を / 持たないで / 出かけました。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 傘を | 🔒 **đóng gói:** "hình ảnh cây ô" → を cho biết đối tượng → đọc tiếp |
| 2 | 持たないで | 🔒 **đóng gói:** "không mang mà..." → giải phóng bộ nhớ → Vないで cho biết sắp có hành động chính → đọc tiếp |
| 3 | 出かけました | "đã ra ngoài" → (chủ ngữ ẩn: 私) → câu kết thúc ✅ |
| **Dịch** | | **Không mang ô mà đi ra ngoài.** |

> **Phân biệt Vないで:**
> - Vないでください → yêu cầu đừng làm (có ください ở cuối)
> - Vないで + V2 → không làm A mà làm B (mô tả trạng thái khi thực hiện hành động)
> - Vないで。(đứng một mình cuối câu) → van nài, thân mật hơn ください. Phổ biến trong manga.
>   - 行かないで。→ Đừng đi mà.
>   - 一人にしないで。→ Đừng để một mình mà.

## 7. Vなくて — Vì không... nên... (nguyên nhân phủ định)

Dạng て của ない. Dùng khi lý do là **không làm gì đó / không có gì đó**.

```
時間が / なくて / 行けませんでした。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 時間が | 🔒 **đóng gói:** "hình ảnh thời gian" → が cho biết chủ ngữ → đọc tiếp |
| 2 | なくて | 🔒 **đóng gói:** "vì không có" → giải phóng bộ nhớ → なくて cho biết sắp có kết quả → đọc tiếp |
| 3 | 行けませんでした | "đã không đi được" → (chủ ngữ ẩn: 私) → câu kết thúc ✅ |
| **Dịch** | | **Vì không có thời gian nên không đi được.** |

---

```
お金が / なくて / 買えません。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | お金が | 🔒 **đóng gói:** "hình ảnh tiền" → が cho biết chủ ngữ → đọc tiếp |
| 2 | なくて | 🔒 **đóng gói:** "vì không có" → giải phóng bộ nhớ → なくて cho biết sắp có kết quả → đọc tiếp |
| 3 | 買えません | "không mua được" → (chủ ngữ ẩn: 私) → câu kết thúc ✅ |
| **Dịch** | | **Vì không có tiền nên không mua được.** |

> **So sánh:** Vないで + V2 = không làm A **mà** làm B (trạng thái). Vなくて + kết quả = **vì** không làm/không có **nên** kết quả.

Ví dụ với động từ hành động:

```
勉強しなくて / テストに / 落ちました。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 勉強しなくて | 🔒 **đóng gói:** "vì không học" → giải phóng bộ nhớ → Vなくて cho biết sắp có kết quả → đọc tiếp |
| 2 | テストに | 🔒 **đóng gói:** "hình ảnh bài kiểm tra" → に cho biết đối tượng → đọc tiếp |
| 3 | 落ちました | "đã trượt" → (chủ ngữ ẩn: 私) → câu kết thúc ✅ |
| **Dịch** | | **Vì không học nên trượt bài kiểm tra.** |

---

## 8. Vないと — Nếu không... thì... (điều kiện phủ định)

Rất phổ biến trong văn nói. Nghĩa: "nếu không làm ~ thì (sẽ xấu)."

```
早く / 行かないと / 遅れますよ。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 早く | trạng từ → "sớm" |
| 2 | 行かないと | 🔒 **đóng gói:** "nếu không đi" → giải phóng bộ nhớ → Vないと cho biết sắp có kết quả xấu → đọc tiếp |
| 3 | 遅れますよ | "sẽ trễ đấy" → câu kết thúc ✅ |
| **Dịch** | | **Không đi sớm thì trễ đấy.** |

---

```
薬を / 飲まないと / 治りませんよ。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 薬を | 🔒 **đóng gói:** "hình ảnh viên thuốc" → を cho biết đối tượng → đọc tiếp |
| 2 | 飲まないと | 🔒 **đóng gói:** "nếu không uống" → giải phóng bộ nhớ → Vないと cho biết sắp có kết quả xấu → đọc tiếp |
| 3 | 治りませんよ | "không khỏi đấy" → câu kết thúc ✅ |
| **Dịch** | | **Không uống thuốc thì không khỏi đấy.** |

> **Trong văn nói:** Vないと thường bỏ lửng vế sau (ngầm hiểu là "sẽ xấu"):
> 早く行かないと。 → Không đi sớm thì... (ngầm: sẽ trễ)
> もう寝ないと。 → Phải đi ngủ thôi. (ngầm: nếu không thì mệt)

## 9. So sánh ません vs ない

```
食べません。(lịch sự)
食べない。  (thông thường)
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 食べません | ません → phủ định lịch sự → "không ăn" → câu kết thúc ✅ |
| 1' | 食べない | ない → phủ định thông thường → "không ăn" → câu kết thúc ✅ |
| **Dịch** | | **Nghĩa giống nhau, chỉ khác mức độ lịch sự.** |

---

```
私は / 肉を / 食べません。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 私は | 🔒 **đóng gói:** "hình ảnh tôi" → は cho biết chủ đề → đọc tiếp |
| 2 | 肉を | 🔒 **đóng gói:** "hình ảnh thịt" → を cho biết đối tượng → đọc tiếp |
| 3 | 食べません | "không ăn" → phủ định lịch sự → câu kết thúc ✅ |
| **Dịch** | | **Tôi không ăn thịt.** (lịch sự) |

---

```
私は / 肉を / 食べない。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 私は | 🔒 **đóng gói:** "hình ảnh tôi" → は cho biết chủ đề → đọc tiếp |
| 2 | 肉を | 🔒 **đóng gói:** "hình ảnh thịt" → を cho biết đối tượng → đọc tiếp |
| 3 | 食べない | "không ăn" → phủ định thông thường → câu kết thúc ✅ |
| **Dịch** | | **Tôi không ăn thịt.** (thân mật) |

> **Khi nào gặp ない trong bài đọc?**
> - Hội thoại giữa bạn bè, gia đình
> - Suy nghĩ nội tâm của nhân vật
> - Văn phong nhẹ nhàng, blog, mạng xã hội
> - **Trong các mẫu câu đặc biệt** (ないでください, なければ, なくても...) → chỉ dùng ない, không dùng ません

## Dự đoán tổng hợp: Thể ない

| Gặp Vない + ... | Dự đoán | Trợ từ thường đi kèm |
|----------------|---------|----------------------|
| でください | Yêu cầu đừng làm: "xin đừng ~" | を + Vないでください |
| なければなりません | Bắt buộc: "phải ~" | を + Vなければなりません |
| なくてもいいです | Không bắt buộc: "không ~ cũng được" | を + Vなくてもいいです |
| ほうがいいです | Lời khuyên: "không nên ~" | を + Vないほうがいいです |
| で + V2 | Trạng thái: "không ~ mà..." | を + Vないで + V2 |
| なくて + kết quả | Nguyên nhân: "vì không ~ nên..." | が + Vなくて |
| と (+ kết quả xấu) | Điều kiện: "nếu không ~ thì..." | Vないと + kết quả |
| なきゃ / なくちゃ | Bắt buộc (văn nói): "phải ~" | = なければなりません |
| 。(kết thúc câu) | Phủ định thông thường (= ません) | Giống ません |

> **Nguyên tắc vàng:** Giống thể て, thể ない cũng cần nhìn phần **SAU** nó. Gặp ない → đọc tiếp xem có でください, なければ, なくても, ほうがいい hay không. Phần sau quyết định nghĩa của cả cụm.
