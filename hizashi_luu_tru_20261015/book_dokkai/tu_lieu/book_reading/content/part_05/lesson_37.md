# Bài 37: Kính ngữ nhận diện

> Sách này không dạy **TẠO** kính ngữ, chỉ dạy **NHẬN DIỆN** khi đọc.
> Kính ngữ biến đổi hoàn toàn hình dạng động từ → nếu không biết, đọc không hiểu.
> Quan trọng hơn: kính ngữ là **manh mối xác định chủ ngữ ẩn**.
> Gặp 尊敬語 → chủ ngữ là **người trên**. Gặp 謙譲語 → chủ ngữ là **tôi/phe tôi**. Chỉ cần nhớ quy tắc này.

---

## 1. Ba loại kính ngữ -- Nhận diện nhanh

```
                          Chủ ngữ là AI?
                               │
        ┌──────────────────────┼──────────────────────┐
        │                      │                      │
   尊敬語 (そんけいご)      丁寧語 (ていねいご)     謙譲語 (けんじょうご)
   Tôn kính ngữ            Lịch sự ngữ            Khiêm nhường ngữ
        │                      │                      │
   NGƯỜI TRÊN              không xác định          TÔI / PHE TÔI
   (khách, sếp,            (です/ます --           (người nói hạ
    thầy cô)                ai cũng dùng)           mình xuống)
```

> **Quy tắc vàng khi đọc:**
> - Gặp 尊敬語 (tôn kính) → chủ ngữ ẩn = **NGƯỜI TRÊN** (sếp, khách hàng, thầy cô)
> - Gặp 謙譲語 (khiêm nhường) → chủ ngữ ẩn = **TÔI** hoặc **phe tôi** (đồng nghiệp cùng công ty)
> - Gặp 丁寧語 (lịch sự) → です/ます → không giúp xác định chủ ngữ

## 2. Bảng 15 động từ kính ngữ đặc biệt

Đây là những động từ **thay đổi hoàn toàn hình dạng**. Nếu không nhận ra, bạn sẽ gặp từ lạ hoàn toàn khi đọc.

| Động từ gốc | 尊敬語 (người trên) | 謙譲語 (tôi) | Nghĩa |
|-------------|-------------------|-------------|-------|
| 行く (đi) | いらっしゃる | 参る（まいる） | đi |
| 来る (đến) | いらっしゃる | 参る（まいる） | đến |
| いる (ở) | いらっしゃる | おる | ở / có mặt |
| 言う (nói) | おっしゃる | 申す（もうす） | nói |
| 食べる (ăn) | 召し上がる（めしあがる） | いただく | ăn |
| 飲む (uống) | 召し上がる（めしあがる） | いただく | uống |
| 見る (xem) | ご覧になる（ごらんになる） | 拝見する（はいけんする） | xem |
| 知る (biết) | ご存じだ（ごぞんじだ） | 存じる（ぞんじる） | biết |
| する (làm) | なさる | いたす | làm |
| くれる (cho tôi) | くださる | -- | cho (tôi) |
| もらう (nhận) | -- | いただく | nhận |
| あげる (cho) | -- | 差し上げる（さしあげる） | cho (người trên) |
| 聞く (hỏi/nghe) | -- | 伺う（うかがう） | hỏi/nghe |
| 行く (đi thăm) | -- | 伺う（うかがう） | đi thăm |
| 会う (gặp) | -- | お目にかかる | gặp |

> **Mẹo đọc:** Không cần nhớ hết. Khi đọc gặp từ lạ, kiểm tra bảng này. Dần dần sẽ quen.
> Quan trọng nhất: **いらっしゃる** (3 nghĩa: đi/đến/ở -- người trên) và **参る/申す/いただく** (tôi).

## 3. Mẫu nhận diện kính ngữ

### Mẫu 尊敬語: お/ご + V + になる → "người trên ~"

#### Ví dụ 1

```
先生は / もう / お帰りになりました。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 先生は | 🔒 **đóng gói:** "thầy/cô" → は → chủ đề |
| 2 | もう | biển báo → dự đoán: hoàn thành |
| 3 | お帰りになりました | **お + 帰り + になる** → 尊敬語 → "đã về" → xác nhận chủ ngữ: **thầy/cô** (người trên) → câu kết thúc ✅ |
| **Dịch** | | **Thầy/cô đã về rồi.** |

#### Ví dụ 2

```
社長は / この資料を / お読みになりましたか。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 社長は | 🔒 **đóng gói:** "giám đốc" → は → chủ đề |
| 2 | この資料を | 🔒 **đóng gói:** "tài liệu này" → を → đối tượng → sắp có hành động |
| 3 | お読みになりましたか | **お + 読み + になる** → 尊敬語 → "đã đọc chưa?" → xác nhận chủ ngữ: **giám đốc** → câu kết thúc ✅ |
| **Dịch** | | **Giám đốc đã đọc tài liệu này chưa ạ?** |

---

### Mẫu 謙譲語: お/ご + V + する/いたす → "tôi ~ (cho người trên)"

#### Ví dụ 1

```
私が / ご案内いたします。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 私が | が → chủ ngữ → "tôi" |
| 2 | ご案内いたします | **ご + 案内 + いたす** → 謙譲語 → "xin hướng dẫn" → xác nhận chủ ngữ: **tôi** (hạ mình) → câu kết thúc ✅ |
| **Dịch** | | **Tôi xin hướng dẫn ạ.** |

#### Ví dụ 2

```
明日 / お電話いたします。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 明日 | "ngày mai" |
| 2 | お電話いたします | **お + 電話 + いたす** → 謙譲語 → "xin gọi điện" → chủ ngữ ẩn: **tôi** → câu kết thúc ✅ |
| **Dịch** | | **Ngày mai tôi xin gọi điện ạ.** |

---

### Mẫu 尊敬語: お/ご + V + ください → "xin (người trên) hãy ~"

#### Ví dụ 1

```
こちらに / お座りください。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | こちらに | 🔒 **đóng gói:** "ở đây" → に → địa điểm |
| 2 | お座りください | **お + 座り + ください** → 尊敬語 → "xin mời ngồi" → chủ ngữ ẩn: **người trên** → câu kết thúc ✅ |
| **Dịch** | | **Xin mời ngồi ở đây ạ.** |

#### Ví dụ 2

```
少々 / お待ちください。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 少々 | "một chút" |
| 2 | お待ちください | **お + 待ち + ください** → 尊敬語 → "xin hãy đợi" → chủ ngữ ẩn: **người trên** → câu kết thúc ✅ |
| **Dịch** | | **Xin vui lòng đợi một chút ạ.** |

---

### Mẫu 尊敬語: れる/られる (thể bị động dùng như tôn kính ngữ)

Đây là mẫu tôn kính ngữ **phổ biến nhất** trong văn viết, nhưng rất dễ nhầm với thể bị động thật sự.

> **Quy tắc phân biệt:** Nhìn chủ ngữ!
> - Chủ ngữ là **người trên** (先生, 社長...) + れる/られる → **尊敬語** (tôn kính)
> - Chủ ngữ là **vật/người dưới** + れる/られる → **bị動** (bị động thật sự)

#### Ví dụ 1

```
先生が / 来られました。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 先生が | が → chủ ngữ → "thầy/cô" |
| 2 | 来られました | **来る + られる** → chủ ngữ là **先生** (người trên) → 尊敬語 → "đã đến" (tôn kính) → câu kết thúc ✅ |
| **Dịch** | | **Thầy/cô đã đến.** |

#### Ví dụ 2

```
社長が / この計画について / 話されました。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 社長が | が → chủ ngữ → "giám đốc" |
| 2 | この計画について | 🔒 **đóng gói:** "về kế hoạch này" |
| 3 | 話されました | **話す + される** → chủ ngữ là **社長** (người trên) → 尊敬語 → "đã nói" (tôn kính) → câu kết thúc ✅ |
| **Dịch** | | **Giám đốc đã nói về kế hoạch này.** |

> **Mẹo đọc:** Khi gặp れる/られる → kiểm tra chủ ngữ:
> - 先生が**来られた** → thầy đến (尊敬語) ≠ thầy bị đến
> - 先生**に**叱**られた** → bị thầy mắng (bị動) -- có に chỉ tác nhân
> Dấu hiệu bị動 thật: thường có **に** chỉ tác nhân phía trước.

## 4. Kính ngữ = manh mối chủ ngữ ẩn

Đây là ứng dụng **quan trọng nhất** của kính ngữ khi đọc. Trong văn bản tiếng Nhật, chủ ngữ rất hay bị ẩn. Kính ngữ giúp bạn xác định **ai** đang hành động.

### Ví dụ 1: Ai nói?

```
部長が / そう / おっしゃいました。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 部長が | 🔒 **đóng gói:** "trưởng phòng" → が → chủ ngữ |
| 2 | そう | "như vậy" |
| 3 | おっしゃいました | **おっしゃる** → 尊敬語 của 言う → "đã nói" → xác nhận: **trưởng phòng** nói (người trên) → câu kết thúc ✅ |
| **Dịch** | | **Trưởng phòng đã nói như vậy.** |

### Ví dụ 2: Ai đi? Ai ở?

```
社長は / もう / お帰りになりましたが、/ 田中部長は / まだ / いらっしゃいます。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 社長は | 🔒 **đóng gói:** "giám đốc" → は → chủ đề |
| 2 | もう | biển báo → hoàn thành |
| 3 | お帰りになりましたが | **お帰りになる** → 尊敬語 → "đã về" → chủ ngữ: **giám đốc** (người trên) → 🔒 **đóng gói loại 2:** "giám đốc đã về rồi, nhưng..." → が → sắp có thông tin ngược |
| 4 | 田中部長は | 🔒 **đóng gói:** "trưởng phòng Tanaka" → は → chủ đề mới |
| 5 | まだ | biển báo → "vẫn còn" |
| 6 | いらっしゃいます | **いらっしゃる** → 尊敬語 của いる → "vẫn còn ở" → xác nhận: **trưởng phòng** ở (người trên) → câu kết thúc ✅ |
| **Dịch** | | **Giám đốc đã về rồi, nhưng trưởng phòng Tanaka vẫn còn ở.** |

### Ví dụ 3: Chủ ngữ hoàn toàn ẩn

```
先日 / 申し上げた / 件について / ご報告いたします。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 先日 | "hôm trước" |
| 2 | 申し上げた | **申し上げる** → 謙譲語 của 言う → "đã thưa" → chủ ngữ ẩn: **tôi** (khiêm nhường) → TTT + chưa kết câu → bổ nghĩa |
| 3 | 件について | 🔒 **đóng gói:** "về vấn đề (mà tôi đã thưa hôm trước)" → について → sắp có thông tin |
| 4 | ご報告いたします | **ご + 報告 + いたす** → 謙譲語 → "xin báo cáo" → chủ ngữ ẩn: **tôi** → câu kết thúc ✅ |
| **Dịch** | | **Tôi xin báo cáo về vấn đề mà tôi đã thưa hôm trước.** |

> **Lưu ý:** Cả câu không có は hay が nào, nhưng nhờ 謙譲語 (申し上げる, いたす) → biết ngay chủ ngữ là **tôi**. Nếu thay bằng おっしゃった và ご報告なさいます → chủ ngữ trở thành **người trên**.

## 5. Bảng đối chiếu: Động từ kính ngữ đặc biệt trong ngữ cảnh

Khi đọc văn bản, bạn sẽ gặp các cặp đối lập. Nhận diện đúng sẽ giúp hiểu **ai làm gì**:

| Ngữ cảnh | 尊敬語 (người trên làm) | 謙譲語 (tôi làm) |
|-----------|----------------------|-----------------|
| Nói | おっしゃる | 申す / 申し上げる |
| Đi/Đến | いらっしゃる | 参る / 伺う |
| Ăn/Uống | 召し上がる | いただく |
| Xem | ご覧になる | 拝見する |
| Biết | ご存じだ | 存じる / 存じ上げる |
| Cho | くださる | 差し上げる |
| Làm | なさる | いたす |

### Ví dụ đối chiếu

```
Câu 1: 先生がおっしゃったことを、私は社長に申し上げました。
Câu 2: 社長がご覧になった資料を、私も拝見しました。
```

**Câu 1:**

```
先生が / おっしゃったことを、/ 私は / 社長に / 申し上げました。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 先生が | が → chủ ngữ mệnh đề phụ → "thầy/cô" |
| 2 | おっしゃったことを | **おっしゃる** → 尊敬語 → "đã nói" → chủ ngữ: **thầy/cô** (người trên) → 🔒 **đóng gói:** "điều thầy/cô đã nói" → を → đối tượng |
| 3 | 私は | 🔒 **đóng gói:** "tôi" → は → chủ đề chính |
| 4 | 社長に | 🔒 **đóng gói:** "với giám đốc" → に → đối tượng |
| 5 | 申し上げました | **申し上げる** → 謙譲語 → "đã thưa" → chủ ngữ: **tôi** (khiêm nhường) → câu kết thúc ✅ |
| **Dịch** | | **Tôi đã thưa lại với giám đốc điều mà thầy/cô đã nói.** |

**Câu 2:**

```
社長が / ご覧になった / 資料を、/ 私も / 拝見しました。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 社長が | が → chủ ngữ mệnh đề phụ → "giám đốc" |
| 2 | ご覧になった | **ご覧になる** → 尊敬語 → "đã xem" → chủ ngữ: **giám đốc** (người trên) → bổ nghĩa |
| 3 | 資料を | 🔒 **đóng gói:** "tài liệu mà giám đốc đã xem" → を → đối tượng |
| 4 | 私も | 🔒 **đóng gói:** "tôi cũng" → も → chủ đề |
| 5 | 拝見しました | **拝見する** → 謙譲語 → "đã xem" → chủ ngữ: **tôi** (khiêm nhường) → câu kết thúc ✅ |
| **Dịch** | | **Tôi cũng đã xem tài liệu mà giám đốc đã xem.** |

> **2 người cùng "xem" nhưng dùng từ khác nhau:**
> - Giám đốc xem → **ご覧になる** (尊敬語 -- nâng người trên lên)
> - Tôi xem → **拝見する** (謙譲語 -- hạ mình xuống)
> → Cùng nghĩa "xem" nhưng kính ngữ cho biết **ai** đang hành động.

## 6. Kính ngữ trong email -- Nhận diện khi đọc

Email công việc tiếng Nhật đầy kính ngữ. Dưới đây là những mẫu bạn sẽ gặp thường xuyên:

### させていただきます -- "xin phép được ~"

```
明日 / 会議の資料を / 送らせていただきます。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 明日 | "ngày mai" |
| 2 | 会議の資料を | 🔒 **đóng gói:** "tài liệu họp" → を → đối tượng |
| 3 | 送らせていただきます | **させていただく** → 謙譲語 → "xin phép được gửi" → chủ ngữ ẩn: **tôi** → câu kết thúc ✅ |
| **Dịch** | | **Ngày mai tôi xin phép được gửi tài liệu họp.** |

### いただけますでしょうか -- "liệu có thể ~ được không ạ?"

```
この書類を / ご確認いただけますでしょうか。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | この書類を | 🔒 **đóng gói:** "tài liệu này" → を → đối tượng |
| 2 | ご確認いただけますでしょうか | **ご + 確認 + いただく** → 謙譲語 → "có thể xác nhận giùm không?" → chủ ngữ ngữ pháp (ẩn): **tôi** (người xin/nhờ -- いただく = "tôi được nhận"), người thực hiện hành động 確認: **người trên** → câu kết thúc ✅ |
| **Dịch** | | **Ngài có thể xác nhận tài liệu này giùm được không ạ?** |

### 申し上げます -- "xin thưa"

```
心より / お礼を / 申し上げます。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 心より | "từ đáy lòng" |
| 2 | お礼を | 🔒 **đóng gói:** "lời cảm ơn" → を → đối tượng |
| 3 | 申し上げます | **申し上げる** → 謙譲語 → "xin thưa/xin gửi" → chủ ngữ ẩn: **tôi** → câu kết thúc ✅ |
| **Dịch** | | **Xin gửi lời cảm ơn từ đáy lòng.** |

## 7. Ứng dụng: Đọc email hoàn chỉnh

```
田中様

先日は / お忙しい中 / お時間をいただき、/ ありがとうございました。

先日 / ご依頼いただいた / 資料を / 添付させていただきます。
ご不明な点が / ございましたら、/ お気軽に / お問い合わせください。

今後とも / よろしくお願い申し上げます。

山本
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 田中様 | "Ngài Tanaka" → người nhận (người trên) |
| 2 | 先日は / お忙しい中 | "hôm trước, trong lúc bận" |
| 3 | お時間をいただき | **いただく** → 謙譲語 → "được nhận thời gian" → chủ ngữ: **tôi** nhận (thời gian của **người trên**) |
| 4 | ありがとうございました | "xin cảm ơn" |
| 5 | 先日 / ご依頼いただいた | **いただく** → 謙譲語 → "được nhờ" → **người trên** nhờ, **tôi** nhận → bổ nghĩa |
| 6 | 資料を | 🔒 **đóng gói:** "tài liệu (mà ngài đã nhờ)" → を → đối tượng |
| 7 | 添付させていただきます | **させていただく** → 謙譲語 → "xin phép đính kèm" → chủ ngữ: **tôi** |

## Bảng dự đoán tổng hợp: Kính ngữ → Nhận diện chủ ngữ

| Gặp... | Dự đoán chủ ngữ | Loại | Ví dụ |
|--------|-----------------|------|-------|
| **いらっしゃる** | NGƯỜI TRÊN (đi/đến/ở) | 尊敬語 | 先生がいらっしゃる → "thầy đang ở" |
| **おっしゃる** | NGƯỜI TRÊN (nói) | 尊敬語 | 社長がおっしゃる → "giám đốc nói" |
| **ご覧になる** | NGƯỜI TRÊN (xem) | 尊敬語 | 部長がご覧になる → "trưởng phòng xem" |
| **召し上がる** | NGƯỜI TRÊN (ăn/uống) | 尊敬語 | お客様が召し上がる → "khách ăn" |
| **くださる** | NGƯỜI TRÊN (cho tôi) | 尊敬語 | 先生がくださる → "thầy cho" |
| **なさる** | NGƯỜI TRÊN (làm) | 尊敬語 | 社長がなさる → "giám đốc làm" |
| **お/ご~になる** | NGƯỜI TRÊN | 尊敬語 | お読みになる → "người trên đọc" |
| **Vれる/られる** | NGƯỜI TRÊN (nếu chủ ngữ là người trên) | 尊敬語 | 先生が来られた → "thầy đến" |
| **参る** | TÔI (đi/đến) | 謙譲語 | 私が参る → "tôi đi" |
| **申す/申し上げる** | TÔI (nói) | 謙譲語 | 私が申す → "tôi thưa" |
| **いただく** | TÔI (nhận/ăn) | 謙譲語 | 私がいただく → "tôi nhận" |
| **拝見する** | TÔI (xem) | 謙譲語 | 私が拝見する → "tôi xem" |
| **伺う** | TÔI (hỏi/đi thăm) | 謙譲語 | 私が伺う → "tôi hỏi/đi thăm" |
| **いたす** | TÔI (làm) | 謙譲語 | 私がいたす → "tôi làm" |
| **お/ご~する/いたす** | TÔI | 謙譲語 | ご案内いたす → "tôi hướng dẫn" |
| **させていただく** | TÔI (xin phép) | 謙譲語 | 送らせていただく → "tôi xin gửi" |

> **Chiến thuật đọc kính ngữ:**
> 1. Gặp động từ lạ → kiểm tra: có phải kính ngữ đặc biệt?
> 2. Nếu là 尊敬語 → chủ ngữ = **người trên** (dù không viết ra)
> 3. Nếu là 謙譲語 → chủ ngữ = **tôi/phe tôi** (dù không viết ra)
> 4. Xác định chủ ngữ xong → đóng gói → đọc tiếp
>
> Kính ngữ không phải để "nói lịch sự" -- khi đọc, nó là **la bàn chỉ chủ ngữ**!
