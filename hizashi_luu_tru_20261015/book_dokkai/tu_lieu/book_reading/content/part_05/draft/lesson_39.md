# Bài 39: Liên từ & Cấu trúc đoạn văn -- Dự đoán cấp đoạn văn

> Từ Part 1-4, ta đọc từng **CÂU**. Bài này nâng lên đọc **ĐOẠN VĂN**.
> Liên từ đứng đầu câu cho biết mối quan hệ với câu trước -- đây là **"Dự đoán cấp đoạn văn"** (nâng từ dự đoán cấp câu lên cấp đoạn).
> Ở cấp câu: trợ từ là biển báo. Ở cấp đoạn văn: **liên từ là biển báo**.

---

## 1. Nhóm bổ sung / liệt kê: "Thêm thông tin cùng hướng"

Khi gặp các liên từ này đầu câu → dự đoán: câu tiếp sẽ **bổ sung thông tin cùng hướng** với câu trước.

| Liên từ | Nghĩa | Sắc thái |
|---------|-------|----------|
| また | ngoài ra | trung tính, thêm ý mới |
| そして | và rồi | nối tiếp tự nhiên |
| さらに | hơn nữa | nhấn mạnh mức độ tăng |
| それに | thêm nữa | bổ sung ý (văn nói) |
| しかも | lại còn | bất ngờ + bổ sung |

### Ví dụ 1

```
この店は / 安い。/ また、/ 料理の / 種類も / 多い。
```

**Câu 1:**

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | この店は | は → chủ đề → 🔒 **đóng gói:** "cửa hàng này" |
| 2 | 安い | "rẻ" → câu kết thúc ✅ |
| **Dịch** | | **Cửa hàng này rẻ.** |

**Câu 2:**

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | また | liên từ bổ sung → dự đoán: "thêm thông tin cùng hướng" (ưu điểm tiếp) |
| 2 | 料理の | の → bổ nghĩa → "của món ăn" |
| 3 | 種類も | danh từ + も → 🔒 **đóng gói:** "chủng loại món ăn" → も → "cũng" → nhấn mạnh thêm ưu điểm |
| 4 | 多い | "nhiều" → câu kết thúc ✅ |
| **Dịch** | | **Ngoài ra, chủng loại món ăn cũng nhiều.** |

### Ví dụ 2

```
日本語は / 文法が / 難しい。/ さらに、/ 漢字も / 覚えなければならない。
```

**Câu 1:**

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 日本語は | は → chủ đề → "tiếng Nhật" |
| 2 | 文法が | が → chủ ngữ phụ → "ngữ pháp" |
| 3 | 難しい | "khó" → câu kết thúc ✅ |
| **Dịch** | | **Tiếng Nhật thì ngữ pháp khó.** |

**Câu 2:**

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | さらに | liên từ bổ sung mạnh → dự đoán: "hơn nữa, thêm khó khăn" |
| 2 | 漢字も | danh từ + も → 🔒 **đóng gói:** "chữ Hán" → も → "cũng" |
| 3 | 覚えなければならない | "phải nhớ" → câu kết thúc ✅ |
| **Dịch** | | **Hơn nữa, chữ Hán cũng phải nhớ.** |

## 2. Nhóm tương phản: "Đảo chiều"

Khi gặp các liên từ này đầu câu → dự đoán: câu tiếp sẽ **đảo chiều**, nói điều ngược lại hoặc khác với câu trước.

| Liên từ | Nghĩa | Sắc thái |
|---------|-------|----------|
| しかし | tuy nhiên | trang trọng, văn viết |
| でも | nhưng mà | văn nói, trung tính |
| ところが | ai ngờ | bất ngờ, ngoài dự đoán |
| ただし | tuy nhiên, ngoại lệ | bổ sung điều kiện/hạn chế |
| 一方 | mặt khác | so sánh hai mặt |

### Ví dụ 1

```
この薬は / よく / 効く。/ しかし、/ 副作用が / ある。
```

**Câu 1:**

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | この薬は | は → chủ đề → 🔒 **đóng gói:** "thuốc này" |
| 2 | よく | "rất, tốt" |
| 3 | 効く | "có tác dụng" → câu kết thúc ✅ |
| **Dịch** | | **Thuốc này rất có tác dụng.** |

**Câu 2:**

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | しかし | liên từ tương phản → dự đoán: "đảo chiều -- sắp nói nhược điểm" |
| 2 | 副作用が | が → chủ ngữ → "tác dụng phụ" |
| 3 | ある | "có" → câu kết thúc ✅ |
| **Dịch** | | **Tuy nhiên, có tác dụng phụ.** |

### Ví dụ 2

```
天気予報では / 晴れる / はずだった。/ ところが、/ 急に / 大雨が / 降り出した。
```

**Câu 1:**

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 天気予報では | で → nguồn thông tin + は → chủ đề → 🔒 **đóng gói:** "theo dự báo thời tiết" |
| 2 | 晴れる | "trời nắng" |
| 3 | はずだった | "đáng lẽ phải ~" (quá khứ, thực tế khác) → câu kết thúc ✅ |
| **Dịch** | | **Theo dự báo thời tiết, đáng lẽ phải nắng.** |

**Câu 2:**

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | ところが | liên từ tương phản bất ngờ → dự đoán: "ai ngờ, chuyện ngược lại đã xảy ra!" |
| 2 | 急に | "đột nhiên" |
| 3 | 大雨が | が → chủ ngữ → "mưa lớn" |
| 4 | 降り出した | "bắt đầu rơi" → câu kết thúc ✅ |
| **Dịch** | | **Ai ngờ, đột nhiên mưa lớn ập đến.** |

## 3. Nhóm nguyên nhân - kết quả: "Kết quả sắp đến"

Khi gặp các liên từ này đầu câu → dự đoán: câu tiếp là **kết quả/hệ quả** của câu trước.

| Liên từ | Nghĩa | Sắc thái |
|---------|-------|----------|
| だから | vì vậy | văn nói, trung tính |
| そのため | do đó | văn viết, trang trọng |
| したがって | theo đó | rất trang trọng (luận văn) |
| それで | thế rồi | văn nói, kể chuyện |
| その結果 | kết quả là | văn viết, trình bày kết quả |

### Ví dụ 1

```
昨日 / 遅くまで / 勉強した。/ だから、/ 今日は / 眠い。
```

**Câu 1:**

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 昨日 | "hôm qua" |
| 2 | 遅くまで | まで → "đến tận khuya" |
| 3 | 勉強した | "đã học" → chủ ngữ ẩn: **tôi** → câu kết thúc ✅ |
| **Dịch** | | **Hôm qua tôi đã học đến tận khuya.** |

**Câu 2:**

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | だから | liên từ nguyên nhân-kết quả → dự đoán: "kết quả/hệ quả sắp đến" |
| 2 | 今日は | は → chủ đề → "hôm nay" |
| 3 | 眠い | "buồn ngủ" → chủ ngữ ẩn: **tôi** (thừa kế từ câu trước) → câu kết thúc ✅ |
| **Dịch** | | **Vì vậy, hôm nay tôi buồn ngủ.** |

### Ví dụ 2

```
人口が / 減少している。/ そのため、/ 労働力の / 不足が / 深刻な / 問題と / なっている。
```

**Câu 1:**

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 人口が | が → chủ ngữ → "dân số" |
| 2 | 減少している | "đang giảm" → câu kết thúc ✅ |
| **Dịch** | | **Dân số đang giảm.** |

**Câu 2:**

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | そのため | liên từ nguyên nhân-kết quả (trang trọng) → dự đoán: "hệ quả trang trọng sắp được trình bày" |
| 2 | 労働力の | の → bổ nghĩa → "của lực lượng lao động" |
| 3 | 不足が | danh từ + が → 🔒 **đóng gói:** "sự thiếu hụt lao động" → が → chủ ngữ |
| 4 | 深刻な | Aな + な → bổ nghĩa → "nghiêm trọng" |
| 5 | 問題と | danh từ + と → 🔒 **đóng gói:** "vấn đề nghiêm trọng" → と → "trở thành" |
| 6 | なっている | "đang trở thành" → câu kết thúc ✅ |
| **Dịch** | | **Do đó, sự thiếu hụt lao động đang trở thành vấn đề nghiêm trọng.** |

## 4. Nhóm chuyển đổi chủ đề: "Chủ đề mới"

Khi gặp các liên từ này → dự đoán: người viết/nói sắp **chuyển sang chủ đề khác**.

| Liên từ | Nghĩa | Sắc thái |
|---------|-------|----------|
| ところで | nhân tiện | chuyển đề đột ngột |
| さて | nào | chuyển đề tự nhiên |
| では | vậy thì | chuyển sang bước tiếp |

### Ví dụ 1

```
試験の / 結果は / よかったです。/ ところで、/ 来週の / 旅行の / 準備は / できましたか？
```

**Câu 1:**

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 試験の | の → bổ nghĩa → "của kỳ thi" |
| 2 | 結果は | danh từ + は → 🔒 **đóng gói:** "kết quả kỳ thi" → は → chủ đề |
| 3 | よかったです | "tốt" → câu kết thúc ✅ |
| **Dịch** | | **Kết quả kỳ thi tốt.** |

**Câu 2:**

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | ところで | liên từ chuyển đề → dự đoán: "chủ đề mới, không liên quan câu trước" |
| 2 | 来週の | の → bổ nghĩa → "tuần sau" |
| 3 | 旅行の | の → bổ nghĩa → "chuyến đi" |
| 4 | 準備は | danh từ + は → 🔒 **đóng gói:** "việc chuẩn bị chuyến đi tuần sau" → は → chủ đề mới |
| 5 | できましたか | "xong chưa?" → câu kết thúc ✅ |
| **Dịch** | | **Nhân tiện, chuẩn bị cho chuyến đi tuần sau xong chưa?** |

### Ví dụ 2

```
以上が / 今月の / 報告です。/ では、/ 質問が / ある方は / どうぞ。
```

**Câu 1:**

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 以上が | が → chủ ngữ → "trên đây" |
| 2 | 今月の | の → bổ nghĩa → "tháng này" |
| 3 | 報告です | "là báo cáo" → câu kết thúc ✅ |
| **Dịch** | | **Trên đây là báo cáo tháng này.** |

**Câu 2:**

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | では | liên từ chuyển bước → dự đoán: "chuyển sang phần tiếp theo" |
| 2 | 質問が | が → chủ ngữ → "câu hỏi" |
| 3 | ある方は | ある + 方 + は → 🔒 **đóng gói:** "người có câu hỏi" → は → chủ đề |
| 4 | どうぞ | "xin mời" → câu kết thúc ✅ |
| **Dịch** | | **Vậy thì, ai có câu hỏi xin mời.** |

## 5. Nhóm giải thích / ví dụ: "Diễn giải lại"

Khi gặp các liên từ này → dự đoán: câu tiếp sẽ **giải thích, tóm tắt, hoặc cho ví dụ** về câu trước.

| Liên từ | Nghĩa | Sắc thái |
|---------|-------|----------|
| つまり | tức là | tóm gọn ý chính |
| 例えば | ví dụ | đưa ví dụ minh họa |
| 要するに | tóm lại | đúc kết ý |
| 言い換えれば | nói cách khác | diễn đạt lại |

### Ví dụ 1

```
彼は / 毎日 / 8時間 / 練習している。/ つまり、/ 非常に / 努力家である。
```

**Câu 1:**

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 彼は | は → chủ đề → "anh ấy" |
| 2 | 毎日 | "mỗi ngày" |
| 3 | 8時間 | "8 tiếng" |
| 4 | 練習している | "đang luyện tập" → câu kết thúc ✅ |
| **Dịch** | | **Anh ấy mỗi ngày luyện tập 8 tiếng.** |

**Câu 2:**

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | つまり | liên từ giải thích → dự đoán: "đúc kết, tóm gọn ý vừa nói" |
| 2 | 非常に | "cực kỳ" |
| 3 | 努力家である | danh từ + である → "là người nỗ lực" → câu kết thúc ✅ |
| **Dịch** | | **Tức là, anh ấy là người cực kỳ nỗ lực.** |

### Ví dụ 2

```
日本には / 多くの / 伝統文化がある。/ 例えば、/ 茶道や / 華道、/ 書道などである。
```

**Câu 1:**

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 日本には | に → địa điểm + は → chủ đề → "ở Nhật Bản" |
| 2 | 多くの | の → bổ nghĩa → "nhiều" |
| 3 | 伝統文化がある | "có văn hóa truyền thống" → câu kết thúc ✅ |
| **Dịch** | | **Ở Nhật Bản có nhiều văn hóa truyền thống.** |

**Câu 2:**

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 例えば | liên từ ví dụ → dự đoán: "ví dụ minh họa sắp được liệt kê" |
| 2 | 茶道や | や → liệt kê → "trà đạo," |
| 3 | 華道 | "hoa đạo" |
| 4 | 書道などである | など → "v.v." + である → "là ~" → câu kết thúc ✅ |
| **Dịch** | | **Ví dụ như trà đạo, hoa đạo, thư đạo, v.v.** |

## 6. Từ chỉ thị (こそあ) -- Liên kết câu trước-sau

Từ chỉ thị là "con trỏ" -- chúng **trỏ ngược lại** thông tin đã nói ở câu trước, giúp liên kết đoạn văn.

### Bảng tổng hợp

| Loại | こ (gần người nói) | そ (vừa nhắc) | あ (xa/ký ức) |
|------|-------------------|---------------|--------------|
| Trước danh từ | **この** N | **その** N | **あの** N |
| Thay danh từ | **これ** | **それ** | **あれ** |
| Cách thức | **こう** | **そう** | **ああ** |
| Nơi chốn | **ここ** | **そこ** | **あそこ** |

> **Khi đọc đoạn văn:** その/それ xuất hiện nhiều nhất. Chúng luôn **trỏ về thông tin ở câu trước**. Khi gặp → tìm ngược lại câu trước để biết nó chỉ cái gì.

### Ví dụ

```
日本の人口は減少している。/ この問題は / 「少子高齢化」と / 呼ばれている。/ それに対して、/ 政府は / さまざまな / 対策を / 行っている。
```

**Câu 1:**

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 日本の人口は | は → chủ đề → 🔒 **đóng gói:** "dân số Nhật Bản" |
| 2 | 減少している | "đang giảm" → câu kết thúc ✅ |
| **Dịch** | | **Dân số Nhật Bản đang giảm.** |

**Câu 2:**

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | この問題は | **この** → trỏ về câu trước (= "dân số giảm") → 🔒 **đóng gói:** "vấn đề này (dân số giảm)" → は → chủ đề |
| 2 | 「少子高齢化」と | と → trích dẫn → "ít con + già hóa" |
| 3 | 呼ばれている | "được gọi là" → câu kết thúc ✅ |
| **Dịch** | | **Vấn đề này được gọi là "giảm sinh và già hóa".** |

**Câu 3:**

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | それに対して | **それ** → trỏ về "giảm sinh và già hóa" → に対して → "đối với việc đó" → 🔒 **đóng gói loại 2:** "đối với vấn đề đó" |
| 2 | 政府は | は → chủ đề mới → "chính phủ" |
| 3 | さまざまな | Aな → "đa dạng" |
| 4 | 対策を | danh từ + を → 🔒 **đóng gói:** "các biện pháp đa dạng" → を → đối tượng |
| 5 | 行っている | "đang thực hiện" → câu kết thúc ✅ |
| **Dịch** | | **Đối với vấn đề đó, chính phủ đang thực hiện nhiều biện pháp.** |

## 7. Cấu trúc đoạn văn: Mở đầu → Triển khai → Kết luận

Đoạn văn tiếng Nhật thường có cấu trúc rõ ràng. Nhận diện cấu trúc = biết mình đang đọc phần nào.

### Từ khóa nhận diện

| Vị trí | Từ khóa | Nghĩa | Dự đoán |
|--------|---------|-------|---------|
| Mở đầu (導入) | まず | đầu tiên | Ý đầu tiên sắp được trình bày |
| Triển khai (展開) | 次に | tiếp theo | Ý thứ hai |
| Triển khai | また | ngoài ra | Thêm ý bổ sung |
| Triển khai | さらに | hơn nữa | Thêm ý mạnh hơn |
| Kết luận (結論) | 最後に | cuối cùng | Ý cuối cùng |
| Kết luận | 以上のように | như trên | Đang tóm tắt |
| Kết luận | したがって | theo đó | Rút ra kết luận |

## 8. Ví dụ đọc đoạn: Phân tích liên từ + từ chỉ thị + cấu trúc

```
①日本語の学習には、多くの時間が必要である。②まず、ひらがなとカタカナを覚えなければならない。③次に、基本的な漢字を学ぶ必要がある。④さらに、文法や語彙も重要である。⑤しかし、毎日少しずつ勉強すれば、必ず上達する。⑥つまり、大切なのは継続することである。
```

### Phân tích từng câu

**Câu ①** (Mở đầu -- giới thiệu chủ đề)

```
日本語の / 学習には、/ 多くの / 時間が / 必要である。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 日本語の | の → bổ nghĩa → "tiếng Nhật" |
| 2 | 学習には | danh từ + に + は → 🔒 **đóng gói:** "việc học tiếng Nhật" → には → chủ đề + mục đích |
| 3 | 多くの | の → bổ nghĩa → "nhiều" |
| 4 | 時間が | danh từ + が → 🔒 **đóng gói:** "nhiều thời gian" → が → chủ ngữ |
| 5 | 必要である | である → "là cần thiết" → câu kết thúc ✅ |
| **Dịch** | | **Việc học tiếng Nhật cần nhiều thời gian.** |

> Vai trò: **Câu mở đầu** -- đặt chủ đề cho toàn đoạn.

**Câu ②** (Triển khai 1)

```
まず、/ ひらがなと / カタカナを / 覚えなければならない。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | まず | từ khóa triển khai → dự đoán: "ý đầu tiên sắp được nêu" |
| 2 | ひらがなと | と → liệt kê → "hiragana và" |
| 3 | カタカナを | danh từ + を → 🔒 **đóng gói:** "hiragana và katakana" → を → đối tượng |
| 4 | 覚えなければならない | "phải nhớ" → chủ ngữ ẩn: **người học** → câu kết thúc ✅ |
| **Dịch** | | **Đầu tiên, phải nhớ hiragana và katakana.** |

**Câu ③** (Triển khai 2)

```
次に、/ 基本的な / 漢字を / 学ぶ / 必要がある。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 次に | từ khóa triển khai → dự đoán: "ý thứ hai" |
| 2 | 基本的な | Aな + な → bổ nghĩa → "cơ bản" |
| 3 | 漢字を | danh từ + を → 🔒 **đóng gói:** "chữ Hán cơ bản" → を → đối tượng |
| 4 | 学ぶ | Vる → "học" → bổ nghĩa danh từ tiếp (mệnh đề bổ nghĩa nội dung) |
| 5 | 必要がある | "cần thiết / có sự cần thiết" → câu kết thúc ✅ |
| **Dịch** | | **Tiếp theo, cần học chữ Hán cơ bản.** |

**Câu ④** (Triển khai 3)

```
さらに、/ 文法や / 語彙も / 重要である。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | さらに | liên từ bổ sung mạnh → dự đoán: "thêm điều quan trọng" |
| 2 | 文法や | や → liệt kê không đầy đủ → "ngữ pháp và" |
| 3 | 語彙も | danh từ + も → 🔒 **đóng gói:** "từ vựng" → も → "cũng" |
| 4 | 重要である | である → "quan trọng" → câu kết thúc ✅ |
| **Dịch** | | **Hơn nữa, ngữ pháp và từ vựng cũng quan trọng.** |

**Câu ⑤** (Tương phản -- chuyển hướng)

```
しかし、/ 毎日 / 少しずつ / 勉強すれば、/ 必ず / 上達する。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | しかし | liên từ tương phản → dự đoán: "đảo chiều -- tin tốt sắp đến" |
| 2 | 毎日 | "mỗi ngày" |
| 3 | 少しずつ | "từng chút một" |
| 4 | 勉強すれば | Vば → 🔒 **đóng gói loại 2:** "nếu học từng chút mỗi ngày" → ば → điều kiện → sắp có kết quả |
| 5 | 必ず | "chắc chắn" |
| 6 | 上達する | "tiến bộ" → chủ ngữ ẩn: **người học** (thừa kế từ đoạn trước) → câu kết thúc ✅ |
| **Dịch** | | **Tuy nhiên, nếu mỗi ngày học từng chút một thì chắc chắn sẽ tiến bộ.** |

**Câu ⑥** (Kết luận)

```
つまり、/ 大切なのは / 継続することである。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | つまり | liên từ giải thích → dự đoán: "tóm lại, đúc kết" |
| 2 | 大切なのは | Aな + の (danh từ hóa) + は → 🔒 **đóng gói:** "điều quan trọng" → は → chủ đề chính |
| 3 | 継続することである | する + こと (danh từ hóa) + である → "là việc tiếp tục" → câu kết thúc ✅ |
| **Dịch** | | **Tức là, điều quan trọng là kiên trì.** |

### Sơ đồ cấu trúc đoạn văn

```
① [Mở đầu]  → Giới thiệu chủ đề: "học tiếng Nhật cần nhiều thời gian"
     ↓
② [まず]     → Ý 1: hiragana + katakana
③ [次に]     → Ý 2: chữ Hán cơ bản
④ [さらに]   → Ý 3: ngữ pháp + từ vựng
     ↓
⑤ [しかし]   → Đảo chiều: nhưng nếu kiên trì thì tiến bộ
     ↓
⑥ [つまり]   → Kết luận: điều quan trọng là kiên trì
```

> **Kỹ năng đọc đoạn:** Chỉ cần nhìn liên từ đầu mỗi câu, bạn đã biết **cấu trúc logic** của toàn đoạn trước khi đọc kỹ từng câu. Đây là Dự đoán cấp đoạn văn.

## Dự đoán tổng hợp: Liên từ & Cấu trúc đoạn văn

| Gặp tín hiệu | Nhóm | Dự đoán hướng đi |
|-------------|------|-----------------|
| また, そして, さらに, それに, しかも | Bổ sung | Thêm thông tin **cùng hướng** với câu trước |
| しかし, でも, ところが, ただし, 一方 | Tương phản | **Đảo chiều** -- câu tiếp nói điều ngược lại |
| だから, そのため, したがって, それで, その結果 | Nguyên nhân-kết quả | **Kết quả/hệ quả** của câu trước |
| ところで, さて, では | Chuyển đề | **Chủ đề mới** -- không liên quan trực tiếp câu trước |
| つまり, 例えば, 要するに, 言い換えれば | Giải thích | **Diễn giải lại** hoặc đưa ví dụ về câu trước |
| この/その/あの + N | Từ chỉ thị | **Trỏ về** thông tin câu trước → liên kết đoạn văn |
| それ/これ/あれ | Từ chỉ thị (thay danh từ) | **Thay thế** danh từ đã nhắc ở câu trước |
| まず | Cấu trúc đoạn | Ý **đầu tiên** → sắp có 次に, さらに |
| 次に | Cấu trúc đoạn | Ý **thứ hai** → có thể còn ý tiếp |
| 最後に, 以上のように | Cấu trúc đoạn | **Kết luận** → đoạn sắp kết thúc |
| つまり, 要するに, したがって | Cấu trúc đoạn | Câu **tóm tắt/đúc kết** → ý chính của toàn đoạn |
