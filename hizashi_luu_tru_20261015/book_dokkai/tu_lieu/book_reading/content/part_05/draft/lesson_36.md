# Bài 36: Phó từ tín hiệu -- Dự đoán đuôi câu qua phó từ

> Phó từ (副詞) thường đứng **giữa câu**, trước động từ/tính từ. Nhưng vai trò lớn nhất của chúng khi đọc là: **báo trước đuôi câu sẽ kết thúc như thế nào**.
> Gặp きっと → dự đoán đuôi câu sẽ là でしょう. Gặp ぜんぜん → dự đoán đuôi câu sẽ là phủ định.
> Phó từ = **biển báo trên đường đọc**, giúp bạn dự đoán trước khi đến cuối câu.

---

## 1. Phó từ thời gian: Báo trạng thái thời gian

Khi gặp các phó từ này → dự đoán: đuôi câu sẽ thể hiện **trạng thái hoàn thành, đang tiếp diễn, hoặc chưa xảy ra**.

| Phó từ | Nghĩa | Dự đoán đuôi câu |
|--------|-------|------------------|
| もう | đã, rồi | → đuôi hoàn thành (Vました / Vた) |
| まだ | vẫn, chưa | → đuôi tiếp diễn (Vている) hoặc phủ định (Vていない) |
| すでに | đã (trang trọng) | → đuôi hoàn thành (Vた / Vている) |
| ちょうど | vừa đúng, đúng lúc | → đuôi hoàn thành hoặc đang diễn ra |

### Ví dụ 1

```
電車は / もう / 出発しました。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 電車は | は → chủ đề → 🔒 **đóng gói:** "tàu điện" |
| 2 | もう | biển báo → dự đoán: đuôi câu sẽ là hoàn thành |
| 3 | 出発しました | "đã khởi hành" → đúng như dự đoán (hoàn thành) → câu kết thúc ✅ |
| **Dịch** | | **Tàu điện đã khởi hành rồi.** |

### Ví dụ 2

```
宿題は / まだ / 終わっていません。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 宿題は | は → chủ đề → 🔒 **đóng gói:** "bài tập" |
| 2 | まだ | biển báo → dự đoán: đuôi câu sẽ là phủ định hoặc tiếp diễn |
| 3 | 終わっていません | "chưa xong" → đúng như dự đoán (phủ định) → câu kết thúc ✅ |
| **Dịch** | | **Bài tập vẫn chưa xong.** |

## 2. Phó từ tần suất: Báo mức độ thường xuyên

Khi gặp các phó từ này → dự đoán: đuôi câu sẽ là **khẳng định** (tần suất cao) hoặc **phủ định** (tần suất thấp).

| Phó từ | Nghĩa | Dự đoán đuôi câu |
|--------|-------|------------------|
| いつも | luôn luôn | → khẳng định |
| たいてい | thường | → khẳng định |
| よく | hay, thường | → khẳng định |
| ときどき | thỉnh thoảng | → khẳng định |
| あまり | không mấy | → **phủ định** (ません / ない) |
| ぜんぜん | hoàn toàn không | → **phủ định** (ません / ない) |
| めったに | hiếm khi | → **phủ định** (ません / ない) |

> **Quy tắc vàng:** あまり / ぜんぜん / めったに → đuôi câu **BẮT BUỘC phủ định**. Đây là tín hiệu mạnh nhất.
>
> **Cảnh báo cho người Việt:** あまり dễ gây nhầm lẫn! Tiếng Việt nói "không... mấy" đặt phủ định ở ĐẦU, nhưng tiếng Nhật đặt phủ định ở CUỐI.
> - あまり食べ**ません** ✅ (không ăn mấy) -- phủ định ở cuối
> - あまり食べ**ます** ❌ (sai! あまり BẮT BUỘC đi với phủ định)
> Khi gặp あまり → não phải "đợi" phủ định ở cuối câu, đừng kết thúc sớm bằng khẳng định.

### Ví dụ 1

```
田中さんは / いつも / 朝早く / 起きます。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 田中さんは | は → chủ đề → 🔒 **đóng gói:** "anh Tanaka" |
| 2 | いつも | biển báo → dự đoán: đuôi câu khẳng định (thói quen) |
| 3 | 朝早く | "sáng sớm" |
| 4 | 起きます | "dậy" → đúng như dự đoán (khẳng định) → câu kết thúc ✅ |
| **Dịch** | | **Anh Tanaka luôn dậy sớm.** |

### Ví dụ 2

```
彼は / ぜんぜん / 料理を / しません。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 彼は | は → chủ đề → 🔒 **đóng gói:** "anh ấy" |
| 2 | ぜんぜん | biển báo → dự đoán: đuôi câu **chắc chắn phủ định** |
| 3 | 料理を | を → đối tượng → 🔒 **đóng gói:** "nấu ăn" |
| 4 | しません | "không làm" → đúng như dự đoán (phủ định) → câu kết thúc ✅ |
| **Dịch** | | **Anh ấy hoàn toàn không nấu ăn.** |

## 3. Phó từ mức độ: Báo cường độ

Khi gặp các phó từ này → dự đoán: tính từ hoặc động từ theo sau sẽ được **nhấn mạnh hoặc giảm nhẹ**.

| Phó từ | Nghĩa | Sắc thái |
|--------|-------|----------|
| とても / すごく | rất | nhấn mạnh cao |
| かなり | khá, tương đối | nhấn mạnh vừa |
| ちょっと / 少し | hơi, một chút | giảm nhẹ |
| ほとんど | hầu như | → thường đi với phủ định (ほとんど～ない = hầu như không) |

> **Lưu ý:** ほとんど có 2 cách dùng:
> - ほとんど + khẳng định = "hầu hết" (ほとんどの人 = hầu hết mọi người)
> - ほとんど + **phủ định** = "hầu như không" (ほとんど食べない = hầu như không ăn)

### Ví dụ 1

```
この映画は / とても / 面白かったです。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | この映画は | は → chủ đề → 🔒 **đóng gói:** "bộ phim này" |
| 2 | とても | biển báo → dự đoán: tính từ mạnh sắp đến |
| 3 | 面白かったです | "rất thú vị" → đúng như dự đoán → câu kết thúc ✅ |
| **Dịch** | | **Bộ phim này rất thú vị.** |

### Ví dụ 2

```
昨日は / ほとんど / 寝ていません。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 昨日は | は → chủ đề → 🔒 **đóng gói:** "hôm qua" |
| 2 | ほとんど | biển báo → dự đoán: đuôi câu sẽ là phủ định ("hầu như không") |
| 3 | 寝ていません | "không ngủ" → đúng như dự đoán (phủ định) → chủ ngữ ẩn: **tôi** → câu kết thúc ✅ |
| **Dịch** | | **Hôm qua tôi hầu như không ngủ.** |

## 4. Phó từ phỏng đoán: Báo đuôi câu suy đoán

Khi gặp các phó từ này → dự đoán: đuôi câu sẽ là **でしょう, だろう, hoặc かもしれない** (không phải khẳng định chắc chắn).

| Phó từ | Nghĩa | Dự đoán đuôi câu |
|--------|-------|------------------|
| きっと | chắc chắn | → でしょう / だろう / hoặc **khẳng định thường** (tin chắc ~90%) |
| たぶん | có lẽ | → でしょう / かもしれない (khoảng ~60-70%) |
| もしかしたら | biết đâu | → かもしれない (khoảng ~30-40%) |

> **Quy tắc:** きっと → chắc chắn nhất. たぶん → khá chắc. もしかしたら → ít chắc nhất.
> - **たぶん / もしかしたら** → đuôi câu sẽ KHÔNG phải khẳng định thường mà là suy đoán (でしょう / かもしれない).
> - **きっと** → thường đi với でしょう/だろう, nhưng cũng **hoàn toàn tự nhiên với khẳng định thường**:
>   きっとうまくいく。(Chắc chắn sẽ suôn sẻ.) / きっと来るよ。(Chắc chắn sẽ đến.)
>   → きっと diễn tả **niềm tin chủ quan mạnh**, không bắt buộc phải dùng でしょう.

### Ví dụ 1

```
明日は / きっと / 晴れるでしょう。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 明日は | は → chủ đề → 🔒 **đóng gói:** "ngày mai" |
| 2 | きっと | biển báo → dự đoán: đuôi câu sẽ là でしょう / だろう |
| 3 | 晴れるでしょう | "trời sẽ nắng (chắc vậy)" → đúng như dự đoán (でしょう) → chủ ngữ ẩn: **trời** → câu kết thúc ✅ |
| **Dịch** | | **Ngày mai chắc chắn trời sẽ nắng.** |

### Ví dụ 2

```
もしかしたら / 彼は / 来ないかもしれない。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | もしかしたら | biển báo → dự đoán: đuôi câu sẽ là かもしれない (khả năng thấp) |
| 2 | 彼は | は → chủ đề → 🔒 **đóng gói:** "anh ấy" |
| 3 | 来ないかもしれない | "có thể không đến" → đúng như dự đoán (かもしれない) → câu kết thúc ✅ |
| **Dịch** | | **Biết đâu anh ấy sẽ không đến.** |

## 5. Phó từ ý chí: Báo đuôi câu yêu cầu / mong muốn

Khi gặp các phó từ này → dự đoán: đuôi câu sẽ là **てください, たい, ましょう** hoặc thể hiện ý muốn/yêu cầu.

| Phó từ | Nghĩa | Dự đoán đuôi câu |
|--------|-------|------------------|
| ぜひ | nhất định, xin hãy | → てください / たいです / ましょう |
| なるべく | cố gắng, càng ~ càng tốt | → てください / ようにする |
| もっと | hơn nữa | → てください / たい / 比較 |

### Ví dụ 1

```
ぜひ / 日本に / 来てください。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | ぜひ | biển báo → dự đoán: đuôi câu sẽ là てください hoặc たい |
| 2 | 日本に | に → địa điểm → 🔒 **đóng gói:** "đến Nhật Bản" |
| 3 | 来てください | "xin hãy đến" → đúng như dự đoán (てください) → câu kết thúc ✅ |
| **Dịch** | | **Nhất định hãy đến Nhật Bản nhé!** |

### Ví dụ 2

```
もっと / 野菜を / 食べたほうがいいですよ。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | もっと | biển báo → dự đoán: đuôi câu sẽ là yêu cầu hoặc so sánh |
| 2 | 野菜を | を → đối tượng → 🔒 **đóng gói:** "rau" |
| 3 | 食べたほうがいいですよ | "nên ăn" → đúng như dự đoán (lời khuyên) → câu kết thúc ✅ |
| **Dịch** | | **Bạn nên ăn rau nhiều hơn đấy.** |

## 6. Bảng dự đoán tổng hợp: Phó từ → Đuôi câu

| Gặp phó từ | Nhóm | Dự đoán đuôi câu |
|-----------|------|------------------|
| **もう** | Thời gian | → hoàn thành (Vました / Vた) |
| **まだ** | Thời gian | → tiếp diễn (Vている) hoặc phủ định (Vていない) |
| **すでに** | Thời gian | → hoàn thành (Vた / Vている) |
| **ちょうど** | Thời gian | → hoàn thành hoặc đang diễn ra |
| **いつも / たいてい / よく** | Tần suất cao | → khẳng định (thói quen) |
| **ときどき** | Tần suất vừa | → khẳng định |
| **あまり** | Tần suất thấp | → **phủ định** (ません / ない) |
| **ぜんぜん** | Tần suất 0 | → **phủ định** (ません / ない) |
| **めったに** | Tần suất rất thấp | → **phủ định** (ません / ない) |
| **とても / すごく** | Mức độ cao | → tính từ/động từ mạnh |
| **かなり** | Mức độ khá | → nhấn mạnh vừa |
| **ちょっと / 少し** | Mức độ thấp | → giảm nhẹ |
| **ほとんど** | Mức độ cực | → phủ định ("hầu như không") hoặc khẳng định ("hầu hết") |
| **きっと** | Phỏng đoán chắc | → **でしょう / だろう / khẳng định thường** |
| **たぶん** | Phỏng đoán vừa | → **でしょう / かもしれない** |
| **もしかしたら** | Phỏng đoán yếu | → **かもしれない** |
| **ぜひ** | Ý chí | → **てください / たい / ましょう** |
| **なるべく** | Ý chí | → **てください / ようにする** |
| **もっと** | Ý chí | → **てください / たい / so sánh** |

> **Chiến thuật đọc phó từ:**
> 1. Gặp phó từ giữa câu → nhận diện nhóm (thời gian / tần suất / mức độ / phỏng đoán / ý chí)
> 2. Dự đoán đuôi câu sẽ kết thúc ra sao
> 3. Đọc đến cuối câu → kiểm tra có đúng dự đoán không
> 4. Dự đoán đúng → đọc nhanh hơn, hiểu sâu hơn
>
> Phó từ không chỉ bổ nghĩa -- khi đọc, nó là **biển báo cho biết đuôi câu sắp đến**!
