# Bài 38: Văn phong & Rút gọn -- Nhận diện "hình dạng" của câu

> Cùng 1 câu tiếng Nhật có thể mang nhiều "hình dạng" khác nhau tùy văn phong.
> Sách giáo khoa dùng です/ます (lịch sự), nhưng văn bản thực dùng である体 (sách/báo) hoặc rút gọn (manga/văn nói).
> Bài này dạy **NHẬN DIỆN** -- không dạy tạo. Bạn chỉ cần đọc hiểu, không cần tự viết.

---

## 1. Ba văn phong chính của tiếng Nhật

```
       です/ます体            である体              口語
      (lịch sự)          (trang trọng/sách báo)   (văn nói thân mật)

  Dùng khi:            Dùng khi:               Dùng khi:
  - Nói chuyện lịch sự  - Báo chí, luận văn     - Nói chuyện bạn bè
  - Sách giáo khoa      - Sách chuyên ngành     - Manga, anime
  - Email công việc     - Văn học (một số loại)  - Tin nhắn, SNS
```

> **Tại sao cần biết?** Khi đọc, gặp である thì biết đang đọc văn viết trang trọng. Gặp てる/ちゃう thì biết đang đọc văn nói/manga. Nhận diện văn phong = hiểu đúng ngữ cảnh.

---

## 2. である体 -- Văn viết trang trọng

### Quy tắc chuyển đổi

| です/ます体 (lịch sự) | である体 (trang trọng) | Ý nghĩa |
|----------------------|---------------------|---------|
| ～です | ～**である** | "là ~" |
| ～ではありません / じゃないです | ～**ではない** | "không phải ~" |
| ～でした | ～**であった** | "đã là ~" |
| ～ではありませんでした | ～**ではなかった** | "đã không phải ~" |
| ～ます | ～**る** (thể từ điển) | động từ |
| ～ません | ～**ない** | phủ định động từ |

> **Điều cần nhớ:** である chỉ thay thế cho です (danh từ/tính từ な). Động từ thì dùng thể từ điển (Vる) thay cho ます.

### Ví dụ 1

```
これは / 重要な / 問題である。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | これは | は → chủ đề → "đây" |
| 2 | 重要な | Aな + な → bổ nghĩa danh từ tiếp → "quan trọng" |
| 3 | 問題である | danh từ + である → 🔒 **đóng gói:** "vấn đề quan trọng" → である = です (văn viết trang trọng) → câu kết thúc ✅ |
| **Dịch** | | **Đây là vấn đề quan trọng.** |

### Ví dụ 2

```
彼は / 学生ではない。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 彼は | は → chủ đề → "anh ấy" |
| 2 | 学生ではない | ではない = ではありません (phủ định) → "không phải là sinh viên" → câu kết thúc ✅ |
| **Dịch** | | **Anh ấy không phải là sinh viên.** |

### Ví dụ 3

```
日本の / 経済は / 世界第3位の / 規模を / 持つ。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 日本の | の → bổ nghĩa → "của Nhật Bản" |
| 2 | 経済は | danh từ + は → 🔒 **đóng gói:** "nền kinh tế Nhật Bản" → は → chủ đề → sắp có vị ngữ |
| 3 | 世界第3位の | の → bổ nghĩa → "thứ 3 thế giới" |
| 4 | 規模を | danh từ + を → 🔒 **đóng gói:** "quy mô thứ 3 thế giới" → を → đối tượng → sắp có hành động |
| 5 | 持つ | Vる (thể từ điển, thay cho 持ちます) → "có/nắm giữ" → câu kết thúc ✅ |
| **Dịch** | | **Nền kinh tế Nhật Bản có quy mô thứ 3 thế giới.** |

## 3. Bảng đối chiếu: Cùng 1 câu ở 3 văn phong

### Câu 1

| Văn phong | Câu | Ghi chú |
|-----------|-----|---------|
| です/ます体 | この問題は**重要です**。 | Sách giáo khoa |
| である体 | この問題は**重要である**。 | Báo chí, luận văn |
| 口語 | この問題、**重要だよ**。 | Nói chuyện bạn bè |

### Câu 2

| Văn phong | Câu | Ghi chú |
|-----------|-----|---------|
| です/ます体 | 明日は雨が**降ります**。 | Lịch sự, dự báo thời tiết |
| である体 | 明日は雨が**降る**。 | Bài báo |
| 口語 | 明日、雨**降るよ**。 | Tin nhắn |

### Câu 3

| Văn phong | Câu | Ghi chú |
|-----------|-----|---------|
| です/ます体 | 彼は学生**ではありません**。 | Lịch sự |
| である体 | 彼は学生**ではない**。 | Văn viết trang trọng |
| 口語 | 彼、学生**じゃないよ**。 | Văn nói |

> **Mẹo đọc:** Để ý phần cuối câu (vị ngữ) là đủ để nhận diện văn phong:
> - です/ます → lịch sự
> - である / Vる (không có ます) → văn viết trang trọng
> - だよ / Vるよ / じゃない → văn nói

## 4. Rút gọn văn nói phổ biến

Đây là phần quan trọng nhất để đọc manga, xem anime, hoặc đọc tin nhắn tiếng Nhật.

### Bảng rút gọn toàn tập

| Đầy đủ | Rút gọn | Ví dụ đầy đủ | Ví dụ rút gọn | Nghĩa |
|--------|---------|-------------|--------------|-------|
| ている | **てる** | 食べ**ている** | 食べ**てる** | đang ăn |
| ておく | **とく** | 買っ**ておく** | 買っ**とく** | mua sẵn |
| てしまう | **ちゃう** | 食べ**てしまう** | 食べ**ちゃう** | ăn mất/hết rồi |
| でしまう | **じゃう** | 飲ん**でしまう** | 飲ん**じゃう** | uống mất/hết rồi |
| ではない | **じゃない** | それ**ではない** | それ**じゃない** | không phải cái đó |
| のだ/のです | **んだ/んです** | 行く**のだ** | 行く**んだ** | (là vì) đi |
| なければ | **なきゃ** | 行か**なければ** | 行か**なきゃ** | phải đi |
| なくては | **なくちゃ** | 食べ**なくては** | 食べ**なくちゃ** | phải ăn |
| という | **って** | 田中**という**人 | 田中**って**人 | người tên Tanaka |
| と言っていた | **って** | 来る**と言っていた** | 来る**って** | nghe nói là sẽ đến |

> **Phân biệt って 2 nghĩa (quan trọng cho người Việt):**
> って có 2 nghĩa hoàn toàn khác nhau. Cách phân biệt:
> - って + **danh từ** → = という → "gọi là ~, tên là ~". Ví dụ: 田中**って**人 = người tên Tanaka
> - って **cuối câu** (hoặc trước dấu phẩy) → = と言っていた → "nghe nói ~". Ví dụ: 来る**って** = nghe nói sẽ đến
> Mẹo: nhìn **phía sau って** -- có danh từ theo sau → "gọi là"; không có gì / kết câu → "nghe nói".

### Ví dụ 1: ている → てる

```
今 / 何 / してる？
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 今 | "bây giờ" |
| 2 | 何 | "gì" |
| 3 | してる | してる = している → "đang làm" → câu kết thúc ✅ |
| **Dịch** | | **Bây giờ đang làm gì?** |

So sánh: Đầy đủ = 今、何を**していますか**？(lịch sự)

### Ví dụ 2: てしまう → ちゃう

```
ケーキ / 全部 / 食べちゃった。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | ケーキ | "bánh kem" (trợ từ を bị lược trong văn nói) |
| 2 | 全部 | "tất cả, hết" |
| 3 | 食べちゃった | 食べちゃった = 食べてしまった → "đã ăn mất/hết rồi" (hoàn thành + tiếc nuối/bất ngờ) → câu kết thúc ✅ |
| **Dịch** | | **Ăn hết bánh kem mất rồi!** |

So sánh: Đầy đủ = ケーキを全部**食べてしまいました**。(lịch sự)

### Ví dụ 3: なければ → なきゃ

```
もう / 行かなきゃ。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | もう | "đã/rồi" |
| 2 | 行かなきゃ | 行かなきゃ = 行かなければならない → "phải đi" → câu kết thúc ✅ |
| **Dịch** | | **Phải đi rồi!** |

So sánh: Đầy đủ = もう**行かなければなりません**。(lịch sự)

### Ví dụ 4: という → って

```
田中って / 人、/ 知ってる？
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 田中って | って = という → "tên là / gọi là Tanaka" |
| 2 | 人 | danh từ → 🔒 **đóng gói:** "người tên Tanaka" |
| 3 | 知ってる | 知ってる = 知っている → "biết không?" → câu kết thúc ✅ |
| **Dịch** | | **Biết người tên Tanaka không?** |

So sánh: Đầy đủ = 田中**という**人を**知っていますか**？(lịch sự)

## 5. Nhận diện văn phong khi đọc

### Tín hiệu nhận diện

| Gặp dấu hiệu | Văn phong | Ngữ cảnh |
|-------------|-----------|----------|
| ～である, ～ではない | である体 | Sách, báo, luận văn |
| ～ます, ～です | です/ます体 | Sách giáo khoa, email |
| ～てる, ～ちゃう, ～じゃん | 口語 | Manga, anime, chat |
| ～よ, ～ね, ～さ, ～ぜ | 口語 (trợ từ cuối câu) | Văn nói |
| ～のだ, ～のである | である体 (giải thích) | Sách, báo |
| ～んだ, ～んだよ | 口語 (giải thích) | Văn nói |

> **Quy tắc:** Nhìn vị ngữ (phần cuối câu) là cách nhanh nhất để nhận diện văn phong.

## 6. Ví dụ đọc: Đoạn văn viết (sách/báo)

```
日本の人口は / 約1億2千万人である。/ しかし、/ 少子高齢化が / 進んでおり、/ 将来的に / 人口が / 大幅に / 減少すると / 予測されている。
```

### Phân tích câu 1

```
日本の / 人口は / 約1億2千万人である。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 日本の | の → bổ nghĩa → "của Nhật Bản" |
| 2 | 人口は | danh từ + は → 🔒 **đóng gói:** "dân số Nhật Bản" → は → chủ đề → sắp có vị ngữ |
| 3 | 約1億2千万人である | である = です → "khoảng 120 triệu người" → câu kết thúc ✅ |
| **Dịch** | | **Dân số Nhật Bản khoảng 120 triệu người.** |

### Phân tích câu 2

```
しかし、/ 少子高齢化が / 進んでおり、/ 将来的に / 人口が / 大幅に / 減少すると / 予測されている。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | しかし | liên từ tương phản → "tuy nhiên" → dự đoán: thông tin đảo chiều |
| 2 | 少子高齢化が | が → chủ ngữ → "tình trạng giảm sinh và già hóa" |
| 3 | 進んでおり | Vておる (= ている ở văn viết) + り (nối mệnh đề) → "đang tiến triển, và..." → 🔒 **đóng gói loại 2:** "già hóa đang tiến triển" |
| 4 | 将来的に | "trong tương lai" |
| 5 | 人口が | が → chủ ngữ → "dân số" |
| 6 | 大幅に | "đáng kể" |
| 7 | 減少すると | Vる + と → 🔒 **đóng gói loại 2:** "dân số sẽ giảm đáng kể" → と → trích dẫn nội dung dự đoán |
| 8 | 予測されている | "được dự đoán" (bị động + đang) → câu kết thúc ✅ |
| **Dịch** | | **Tuy nhiên, tình trạng giảm sinh và già hóa đang tiến triển, và được dự đoán rằng dân số sẽ giảm đáng kể trong tương lai.** |

> **Dấu hiệu である体:** である, ておる (= ている), câu dài và chính xác, không có です/ます.

## 7. Ví dụ đọc: Đoạn hội thoại (manga style)

```
A: ねえ、明日のパーティー、行く？
B: うーん、行きたいんだけど、レポート終わってなくて...
A: まだ終わってないの？早くやっちゃいなよ！
B: そうだよね。今日中に終わらせなきゃ。
```

### Phân tích từng câu

**Câu A1:**
```
ねえ、/ 明日のパーティー、/ 行く？
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | ねえ | từ gọi → "này, ê" |
| 2 | 明日のパーティー | の → bổ nghĩa → 🔒 **đóng gói:** "bữa tiệc ngày mai" → trợ từ を bị lược (văn nói) |
| 3 | 行く？ | Vる + ？ → hỏi → "đi không?" (= 行きますか？) → câu kết thúc ✅ |
| **Dịch** | | **Này, bữa tiệc ngày mai, đi không?** |

**Câu B1:**
```
うーん、/ 行きたいんだけど、/ レポート / 終わってなくて...
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | うーん | từ cảm thán → "uhm..." |
| 2 | 行きたいんだけど | 行きたい + んだ (= のだ, giải thích) + けど (nhưng) → 🔒 **đóng gói loại 2:** "muốn đi nhưng..." → dự đoán: lý do sắp đến |
| 3 | レポート | "báo cáo" (trợ từ が bị lược) |
| 4 | 終わってなくて | 終わってなくて = 終わっていなくて → "chưa xong, và..." → câu bỏ lửng (văn nói) ✅ |
| **Dịch** | | **Uhm, muốn đi lắm, nhưng báo cáo chưa xong...** |

> Rút gọn: ていない → てない, のだ → んだ

**Câu A2:**
```
まだ / 終わってないの？/ 早く / やっちゃいなよ！
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | まだ | "vẫn còn, chưa" |
| 2 | 終わってないの？ | 終わってない = 終わっていない → "chưa xong" + の → hỏi (ngạc nhiên) → câu kết thúc ✅ |
| 3 | 早く | "nhanh lên" |
| 4 | やっちゃいなよ！ | やっちゃいな = やってしまいなさい → "hãy làm xong đi!" + よ (nhấn mạnh) → câu kết thúc ✅ |
| **Dịch** | | **Vẫn chưa xong á? Làm xong nhanh đi!** |

> Rút gọn: ていない → てない, てしまいなさい → ちゃいな

**Câu B2:**
```
そうだよね。/ 今日中に / 終わらせなきゃ。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | そうだよね | "đúng rồi nhỉ" (đồng tình) |
| 2 | 今日中に | に → thời điểm → "trong ngày hôm nay" |
| 3 | 終わらせなきゃ | 終わらせなきゃ = 終わらせなければならない → "phải làm xong" → câu kết thúc ✅ |
| **Dịch** | | **Đúng rồi nhỉ. Phải làm xong trong ngày hôm nay mới được.** |

> Rút gọn: なければならない → なきゃ

## Dự đoán tổng hợp: Văn phong & Rút gọn

| Gặp tín hiệu | Nhận diện | Dự đoán / Xử lý |
|-------------|-----------|----------------|
| ～である | である体 (văn viết trang trọng) | Đang đọc sách/báo/luận văn → câu dài, chính xác |
| ～ではない | である体 phủ định | "không phải ~" (= ではありません) |
| ～であった | である体 quá khứ | "đã là ~" (= でした) |
| ～ておる / ～ており | である体 tiếp diễn | "đang ~" (= ている) |
| ～てる | 口語 rút gọn ている | "đang ~" (văn nói) |
| ～ちゃう / ～じゃう | 口語 rút gọn てしまう/でしまう | "~ mất rồi" (hoàn thành/tiếc nuối) |
| ～とく | 口語 rút gọn ておく | "làm sẵn ~" |
| ～なきゃ / ～なくちゃ | 口語 rút gọn なければ/なくては | "phải ~" |
| ～んだ / ～んです | 口語/lịch sự rút gọn のだ/のです | Giải thích lý do |
| ～って | 口語 rút gọn という/と言っていた | "gọi là ~" hoặc "nghe nói ~" |
| ～じゃない | 口語 rút gọn ではない | "không phải ~" |
| Vる (cuối câu, không có ます) | である体 hoặc 口語 | Xem ngữ cảnh: sách → である体, nói chuyện → 口語 |
| よ, ね, さ, ぜ (cuối câu) | 口語 | Đang đọc văn nói / manga |
