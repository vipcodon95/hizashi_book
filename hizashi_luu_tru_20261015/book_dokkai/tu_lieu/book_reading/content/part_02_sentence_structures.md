# Phần 2: Cấu Trúc Câu - Ghép Khối Thành Câu

> Phần 1 dạy nhận diện từng trợ từ riêng lẻ.
> Phần 2 áp dụng tất cả trợ từ vào đọc hiểu câu hoàn chỉnh -- từ đơn giản đến phức tạp.

---

## Bài 18: Câu đơn - 2~3 khối

### Cấu trúc cơ bản

```
Mẫu 1: N は N です。         (A là B)
Mẫu 2: N は Aい/Aな です。   (A thì [tính chất])
```

### Quy trình đọc dịch

```
Bước 1: Nhận diện khối → tìm trợ từ
Bước 2: Dịch từng khối theo dòng chảy
Bước 3: Ghép nghĩa tự nhiên
```

### Ví dụ phân tích

```
これは / ペンです。
──────   ────────
[は: chủ đề] / [です: khẳng định]

Dịch theo khối: "Cái này thì / là bút."
Dịch tự nhiên:  "Cái này là bút."
```

```
この花は / きれいです。
────────   ──────────
[は: chủ đề] / [Aな + です]

Dịch theo khối: "Hoa này thì / đẹp."
Dịch tự nhiên:  "Hoa này đẹp."
```

```
今日は / 暑いです。
──────   ────────
[は: chủ đề] / [Aい + です]

Dịch theo khối: "Hôm nay thì / nóng."
Dịch tự nhiên:  "Hôm nay nóng."
```

### Bài tập đọc dịch

Chia khối → Dịch theo khối → Dịch tự nhiên:

1. `私は田中です。`
2. `この部屋は広いです。`
3. `日本語は難しいです。`
4. `あの人は親切です。`
5. `今日は日曜日です。`

## Bài 19: Câu hành động - 3~4 khối

### Cấu trúc

```
Mẫu: N は (N に/で/へ) N を V ます。
```

Đây là câu có **hành động** -- bắt đầu xuất hiện nhiều trợ từ phối hợp.

### Quy trình đọc

```
1. Tìm は → Xác định chủ đề
2. Tìm を → Xác định đối tượng → dự đoán hành động
3. Tìm に/で/へ → Xác định nơi/thời gian/hướng
4. Đọc V ở cuối → Xác nhận hành động
```

### Ví dụ phân tích

```
私は / 本を / 読みます。
────   ────   ──────────
[は: chủ đề] [を: tân ngữ] [V]

Dịch theo khối: "Tôi thì / sách / đọc."
Dịch tự nhiên:  "Tôi đọc sách."
```

```
田中さんは / 毎朝 / コーヒーを / 飲みます。
──────────   ────   ──────────   ──────────
[は: chủ đề] [thời gian] [を: tân ngữ] [V]

Dịch theo khối: "Tanaka thì / mỗi sáng / cà phê / uống."
Dịch tự nhiên:  "Tanaka uống cà phê mỗi sáng."
```

```
私は / 図書館で / 日本語を / 勉強します。
────   ────────   ────────   ──────────
[は] [で: địa điểm] [を: tân ngữ] [V]

Dịch theo khối: "Tôi thì / tại thư viện / tiếng Nhật / học."
Dịch tự nhiên:  "Tôi học tiếng Nhật ở thư viện."
```

### Bài tập đọc dịch

1. `母は夕ご飯を作ります。`
2. `私は毎日学校へ行きます。`
3. `友達はレストランでご飯を食べます。`
4. `田中さんは電車で会社に行きます。`
5. `私は毎晩テレビを見ます。`

## Bài 20: Câu mô tả - Tính từ い / な

### Cấu trúc

```
Tính từ い:  N は Aい です。        (khẳng định)
             N は Aく ないです。    (phủ định)

Tính từ な:  N は Aな です。        (khẳng định)
             N は Aな じゃないです。 (phủ định)
```

### Tính từ い bổ nghĩa danh từ

```
おいしい / りんごを / 食べました。
────────   ────────   ──────────
[Aい + N] [を] [V]

Dịch theo khối: "Ngon / táo / đã ăn."
→ Lưu ý: Aい gắn trực tiếp vào N, thuộc cùng 1 khối.
```

### Tính từ な bổ nghĩa danh từ

```
静かな / 部屋で / 勉強します。
──────   ──────   ──────────
[Aな + N] [で] [V]

Dịch theo khối: "Yên tĩnh / phòng tại / học."
```

### Ví dụ phân tích

```
この映画は / 面白いです。
──────────   ──────────
[は: chủ đề] [Aい: tính chất]

Dịch theo khối: "Phim này thì / thú vị."
```

```
大きい公園で / 子供が / 遊んでいます。
────────────   ──────   ────────────
[Aい+N+で: địa điểm] [が: chủ ngữ] [V đang làm]

Dịch theo khối: "Công viên lớn tại / trẻ em / đang chơi."
Dịch tự nhiên:  "Trẻ em đang chơi ở công viên lớn."
```

### Bài tập đọc dịch

1. `この本は高いです。`
2. `新しいかばんを買いました。`
3. `このレストランは有名です。`
4. `きれいな花が咲いています。`
5. `古い建物は大きくないです。`

## Bài 21: Câu phủ định & Câu hỏi

### Phủ định

```
V ます  → V ません        (không làm)
V ました → V ませんでした  (đã không làm)
Aい    → Aくない          (không [tính chất])
Aな    → Aな じゃない      (không [tính chất])
N です  → N じゃないです   (không phải)
```

### Câu hỏi

```
[Câu khẳng định] + か = Câu hỏi
Từ hỏi: 何 (gì), 誰 (ai), どこ (đâu), いつ (khi nào), どう (thế nào)
```

### Ví dụ phân tích

```
田中さんは / 来ませんでした。
──────────   ──────────────
[は: chủ đề] [V phủ định quá khứ]

Dịch theo khối: "Tanaka thì / đã không đến."
```

```
昨日 / 何を / 食べましたか。
────   ────   ────────────
[thời gian] [何+を: hỏi tân ngữ] [V quá khứ + か]

Dịch theo khối: "Hôm qua / gì / đã ăn?"
Dịch tự nhiên:  "Hôm qua đã ăn gì?"
```

```
この料理は / おいしくないです。
──────────   ──────────────
[は: chủ đề] [Aい phủ định]

Dịch theo khối: "Món này thì / không ngon."
```

### Bài tập đọc dịch

1. `私は肉を食べません。`
2. `昨日はどこへ行きましたか。`
3. `この部屋は静かじゃないです。`
4. `誰が来ますか。`
5. `先週は忙しくなかったです。`

## Bài 22: Câu 4~5 khối - Thời gian + Địa điểm + Hành động

### Thứ tự thông tin trong câu Nhật

```
[Thời gian] [Chủ đề は] [Cùng ai と] [Ở đâu で/に] [Cái gì を] [Hành động V]
```

> Lưu ý: Thứ tự các khối TRƯỚC vị ngữ có thể linh hoạt nhờ trợ từ.
> Nhưng V (vị ngữ) LUÔN ở cuối.

### Ví dụ phân tích

```
昨日 / 友達と / 公園で / サッカーを / しました。
────   ──────   ──────   ──────────   ────────
[thời gian] [と: cùng] [で: tại] [を: tân ngữ] [V]

Dịch theo khối: "Hôm qua / cùng bạn / tại công viên / bóng đá / đã chơi."
Dịch tự nhiên:  "Hôm qua tôi đã chơi bóng đá với bạn ở công viên."
```

```
毎週 / 土曜日に / 友達と / レストランで / 晩ご飯を / 食べます。
────   ────────   ──────   ──────────   ────────   ──────────
[thời gian] [に: thời điểm] [と: cùng] [で: tại] [を: tân ngữ] [V]

Dịch theo khối: "Mỗi tuần / thứ bảy / cùng bạn / tại nhà hàng / cơm tối / ăn."
```

```
来月 / 家族と / 飛行機で / 北海道へ / 行きます。
────   ──────   ────────   ────────   ──────────
[thời gian] [と: cùng] [で: phương tiện] [へ: hướng] [V]

Dịch theo khối: "Tháng tới / cùng gia đình / bằng máy bay / về phía Hokkaido / đi."
```

### Bài tập đọc dịch

1. `毎朝7時に起きます。`
2. `昨日デパートで服を買いました。`
3. `日曜日に友達と映画を見ました。`
4. `来年の夏、家族と日本へ旅行に行きます。`
5. `毎日バスで学校に行きます。`

## Bài 23: Thể て nối hành động

### Cấu trúc

```
V1て + V2て + ... + V (cuối)
→ Làm V1, rồi V2, rồi ... V cuối.
```

Thể て nối các hành động **theo trình tự**.

### Ví dụ phân tích

```
朝 / 起きて / ご飯を食べて / 学校へ行きます。
──   ──────   ────────────   ──────────────
[thời gian] [Vて: thức dậy rồi] [Vて: ăn cơm rồi] [V: đi học]

Dịch theo khối: "Sáng / thức dậy rồi / ăn cơm rồi / đi trường."
Dịch tự nhiên:  "Sáng thức dậy, ăn cơm, rồi đi học."
```

```
スーパーへ行って / 野菜を買って / 家で料理を作りました。
──────────────   ────────────   ──────────────────
[Vて: đi siêu thị rồi] [Vて: mua rau rồi] [V: nấu ăn ở nhà]

Dịch theo khối: "Đi siêu thị rồi / mua rau rồi / tại nhà nấu ăn đã làm."
```

### Thể て + います = Đang làm

```
今 / 本を / 読んでいます。
──   ────   ────────────
[thời gian] [を] [Vて+います: đang đọc]

Dịch theo khối: "Bây giờ / sách / đang đọc."
```

### Thể て + ください = Xin hãy

```
ここに / 名前を / 書いてください。
──────   ──────   ──────────────
[に: vị trí] [を: tân ngữ] [Vて+ください: xin hãy viết]

Dịch theo khối: "Ở đây / tên / xin hãy viết."
```

### Bài tập đọc dịch

1. `手を洗って、ご飯を食べます。`
2. `図書館へ行って、本を借りました。`
3. `今テレビを見ています。`
4. `ちょっと待ってください。`
5. `シャワーを浴びて、服を着て、出かけました。`

## Bài 24: Câu ghép - から、けど、が

### から = Vì (nguyên nhân → kết quả)

```
[Nguyên nhân] + から + [Kết quả]
```

```
雨が降っていますから / 傘を持っていきます。
────────────────────   ──────────────────
[から: vì trời mưa] [mang ô đi]

Dịch theo khối: "Vì trời đang mưa / ô mang đi."
```

### けど / が = Nhưng (tương phản)

```
[Vế 1] + けど/が + [Vế 2]
```

```
この店は / 高いですが / おいしいです。
────────   ──────────   ──────────
[は: chủ đề] [が: nhưng, đắt] [ngon]

Dịch theo khối: "Tiệm này thì / đắt nhưng / ngon."
```

```
日本語は / 難しいですけど / 面白いです。
────────   ──────────────   ──────────
[は] [けど: nhưng, khó] [thú vị]

Dịch theo khối: "Tiếng Nhật thì / khó nhưng / thú vị."
```

### ので = Vì (khách quan, lịch sự hơn から)

```
病気なので / 今日は / 休みます。
──────────   ──────   ────────
[ので: vì bị bệnh] [は: hôm nay] [nghỉ]

Dịch theo khối: "Vì bị bệnh / hôm nay thì / nghỉ."
```

### Bài tập đọc dịch

1. `疲れたから、早く寝ます。`
2. `日本に行きたいですが、お金がありません。`
3. `この映画は長いですけど、面白いです。`
4. `試験があるので、毎日勉強しています。`
5. `天気がいいですから、散歩に行きましょう。`

## Bài 25: Câu điều kiện - たら、と、ば、なら

### たら = Nếu / Sau khi (phổ biến nhất)

```
[Điều kiện]たら + [Kết quả]
```

```
雨が降ったら / 家にいます。
────────────   ──────────
[たら: nếu mưa] [ở nhà]

Dịch theo khối: "Nếu mưa rơi / nhà ở."
```

### と = Hễ... thì (quy luật, tự nhiên)

```
春になると / 桜が / 咲きます。
──────────   ────   ────────
[と: hễ đến xuân] [が] [nở]

Dịch theo khối: "Hễ đến xuân / hoa anh đào / nở."
```

### ば = Nếu (điều kiện logic)

```
安ければ / 買います。
────────   ────────
[ば: nếu rẻ] [mua]

Dịch theo khối: "Nếu rẻ / mua."
```

### なら = Nếu là... thì (dựa trên ngữ cảnh)

```
日本へ行くなら / 京都がいいですよ。
──────────────   ──────────────
[なら: nếu đi Nhật] [Kyoto tốt đấy]

Dịch theo khối: "Nếu đi Nhật / Kyoto tốt đấy."
```

### So sánh nhanh

| Điều kiện | Sắc thái | Ví dụ |
|-----------|----------|-------|
| **たら** | Cụ thể, cá nhân | 雨が降ったら、行きません |
| **と** | Quy luật, tất yếu | このボタンを押すと、ドアが開きます |
| **ば** | Logic, giả thuyết | 安ければ、買います |
| **なら** | Tiếp nhận thông tin, lời khuyên | 日本へ行くなら、春がいいです |

### Bài tập đọc dịch

1. `お金があったら、旅行に行きたいです。`
2. `右に曲がると、駅があります。`
3. `天気がよければ、公園で遊びましょう。`
4. `パソコンを買うなら、この店が安いですよ。`
5. `暗くなったら、電気をつけてください。`

## Bài 26: Mệnh đề bổ nghĩa trước danh từ

### Cấu trúc

Tiếng Nhật: Mệnh đề bổ nghĩa đặt **TRƯỚC** danh từ (ngược với tiếng Việt).

```
Tiếng Việt: "Cuốn sách [mà tôi mua hôm qua]"
                N      ← mệnh đề bổ nghĩa (SAU)

Tiếng Nhật: "[昨日買った] 本"
             mệnh đề bổ nghĩa (TRƯỚC) → N
```

### Cách đọc

```
Gặp chuỗi dài trước danh từ → Đó là mệnh đề bổ nghĩa.
Đọc mệnh đề trước, rồi gắn vào danh từ.
```

### Ví dụ phân tích

```
[昨日買った] / 本を / 読んでいます。
──────────   ────   ────────────
[mệnh đề: hôm qua mua] / sách / đang đọc

Dịch theo khối: "[Hôm qua đã mua] / sách / đang đọc."
Dịch tự nhiên:  "Đang đọc cuốn sách mua hôm qua."
```

```
[母が作った] / 料理は / おいしいです。
──────────   ──────   ──────────
[mệnh đề: mẹ nấu] / món ăn thì / ngon

Dịch theo khối: "[Mẹ đã nấu] / món ăn thì / ngon."
Dịch tự nhiên:  "Món ăn mẹ nấu ngon."
```

```
[日本で撮った] / 写真を / 友達に / 見せました。
────────────   ──────   ──────   ──────────
[mệnh đề: chụp ở Nhật] / ảnh / bạn / đã cho xem

Dịch theo khối: "[Chụp ở Nhật] / ảnh / bạn / đã cho xem."
Dịch tự nhiên:  "Đã cho bạn xem ảnh chụp ở Nhật."
```

### Bài tập đọc dịch

1. `友達がくれた本を読みました。`
2. `昨日見た映画は面白かったです。`
3. `私が住んでいる町は静かです。`
4. `駅の近くにあるレストランで食べました。`
5. `先生が書いた本を買いたいです。`

## Bài 27: Câu phức 5~7 khối - Tổng hợp

### Mục tiêu

Áp dụng **tất cả** trợ từ và cấu trúc đã học vào câu phức. Đây là bài kiểm tra tổng hợp.

### Quy trình đọc câu phức

```
1. Quét nhanh → Tìm vị ngữ (V cuối cùng)
2. Quét lại → Tìm tất cả trợ từ, xác định ranh giới khối
3. Đọc từng khối → Dịch theo dòng chảy
4. Ghép nghĩa tự nhiên
```

### Ví dụ phân tích

**Câu 5 khối:**

```
昨日の夜 / 友達と / 駅の近くのレストランで / 日本料理を / 食べました。
────────   ──────   ──────────────────────   ──────────   ──────────
[thời gian] [と: cùng] [の+で: tại nhà hàng gần ga] [を: tân ngữ] [V]

Dịch theo khối: "Tối hôm qua / cùng bạn / tại nhà hàng gần ga / món Nhật / đã ăn."
Dịch tự nhiên:  "Tối hôm qua tôi đã ăn món Nhật với bạn ở nhà hàng gần ga."
```

**Câu 6 khối với mệnh đề:**

```
[先週日本から来た] / 友達と / 東京の有名なレストランで / 寿司を / 食べに / 行きました。
──────────────────   ──────   ──────────────────────   ──────   ──────   ──────────
[mệnh đề bổ nghĩa] [と: cùng] [の+で: tại] [を: tân ngữ] [Vに: mục đích] [V]

Dịch theo khối: "[Tuần trước từ Nhật đến] / bạn cùng / nhà hàng nổi tiếng Tokyo tại / sushi / ăn / đã đi."
Dịch tự nhiên:  "Đã đi ăn sushi ở nhà hàng nổi tiếng Tokyo cùng người bạn tuần trước từ Nhật đến."
```

**Câu 7 khối với điều kiện:**

```
もし / 明日 / 天気がよかったら / 友達と / 大きい公園で / サッカーを / したいです。
────   ────   ──────────────   ──────   ────────────   ──────────   ──────────
[nếu] [thời gian] [たら: điều kiện] [と: cùng] [Aい+N+で: tại] [を] [V muốn]

Dịch theo khối: "Nếu / ngày mai / thời tiết tốt thì / cùng bạn / công viên lớn tại / bóng đá / muốn chơi."
Dịch tự nhiên:  "Nếu ngày mai thời tiết tốt, tôi muốn chơi bóng đá với bạn ở công viên lớn."
```

### Bài tập đọc dịch tổng hợp

1. `毎朝6時に起きて、シャワーを浴びて、朝ご飯を食べます。`

2. `来月友達と飛行機で北海道へスキーに行きます。`

3. `昨日買った本はとても面白かったですが、少し高かったです。`

4. `日本語は難しいですけど、毎日勉強しているから、少しわかるようになりました。`

## Tổng hợp: Bản đồ cấu trúc câu

### Thứ tự thông tin trong câu Nhật

```
[Thời gian] → [Chủ đề は] → [Cùng ai と] → [Từ đâu から] → [Bằng gì で]
→ [Đến đâu に/へ] → [Tại đâu で] → [Cái gì を] → [HÀNH ĐỘNG V]。
```

> V luôn ở cuối. Mọi thứ khác phía trước có thể linh hoạt nhờ trợ từ.

### Bảng tổng hợp mẫu câu

| Bài | Mẫu câu | Độ phức tạp |
|-----|---------|-------------|
| 18 | N は N/Adj です | ★ |
| 19 | N は N を V ます | ★★ |
| 20 | Aい/Aな + N, N は Adj | ★★ |
| 21 | Phủ định, câu hỏi | ★★ |
| 22 | Thời gian + Địa điểm + V (4-5 khối) | ★★★ |
