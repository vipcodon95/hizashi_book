# Bài 17: Câu điều kiện - たら、と、ば、なら

### たら = Nếu / Sau khi (phổ biến nhất)

```
[Điều kiện]たら + [Kết quả]
```

```
雨が降ったら / 家にいます。
────────────   ──────────
[たら: nếu mưa] [ở nhà]

Dịch theo khối: "Nếu mưa rơi / nhà ở."
```

### と = Hễ... thì (quy luật, tự nhiên)

```
春になると / 桜が / 咲きます。
──────────   ────   ────────
[と: hễ đến xuân] [が] [nở]

Dịch theo khối: "Hễ đến xuân / hoa anh đào / nở."
```

### ば = Nếu (điều kiện logic)

```
安ければ / 買います。
────────   ────────
[ば: nếu rẻ] [mua]

Dịch theo khối: "Nếu rẻ / mua."
```

### なら = Nếu là... thì (dựa trên ngữ cảnh)

```
日本へ行くなら / 京都がいいですよ。
──────────────   ──────────────
[なら: nếu đi Nhật] [Kyoto tốt đấy]

Dịch theo khối: "Nếu đi Nhật / Kyoto tốt đấy."
```

### So sánh nhanh

| Điều kiện | Sắc thái | Ví dụ |
|-----------|----------|-------|
| **たら** | Cụ thể, cá nhân | 雨が降ったら、行きません |
| **と** | Quy luật, tất yếu | このボタンを押すと、ドアが開きます |
| **ば** | Logic, giả thuyết | 安ければ、買います |
| **なら** | Tiếp nhận thông tin, lời khuyên | 日本へ行くなら、春がいいです |

### Bài tập đọc dịch

1. `お金があったら、旅行に行きたいです。`
2. `右に曲がると、駅があります。`
3. `天気がよければ、公園で遊びましょう。`
4. `パソコンを買うなら、この店が安いですよ。`
5. `暗くなったら、電気をつけてください。`
