# Bài 15: Thể て nối hành động

### Cấu trúc

```
V1て + V2て + ... + V (cuối)
→ Làm V1, rồi V2, rồi ... V cuối.
```

Thể て nối các hành động **theo trình tự**.

### Ví dụ phân tích

```
朝 / 起きて / ご飯を食べて / 学校へ行きます。
──   ──────   ────────────   ──────────────
[thời gian] [Vて: thức dậy rồi] [Vて: ăn cơm rồi] [V: đi học]

Dịch theo khối: "Sáng / thức dậy rồi / ăn cơm rồi / đi trường."
Dịch tự nhiên:  "Sáng thức dậy, ăn cơm, rồi đi học."
```

```
スーパーへ行って / 野菜を買って / 家で料理を作りました。
──────────────   ────────────   ──────────────────
[Vて: đi siêu thị rồi] [Vて: mua rau rồi] [V: nấu ăn ở nhà]

Dịch theo khối: "Đi siêu thị rồi / mua rau rồi / tại nhà nấu ăn đã làm."
```

### Thể て + います = Đang làm

```
今 / 本を / 読んでいます。
──   ────   ────────────
[thời gian] [を] [Vて+います: đang đọc]

Dịch theo khối: "Bây giờ / sách / đang đọc."
```

### Thể て + ください = Xin hãy

```
ここに / 名前を / 書いてください。
──────   ──────   ──────────────
[に: vị trí] [を: tân ngữ] [Vて+ください: xin hãy viết]

Dịch theo khối: "Ở đây / tên / xin hãy viết."
```

### Bài tập đọc dịch

1. `手を洗って、ご飯を食べます。`
2. `図書館へ行って、本を借りました。`
3. `今テレビを見ています。`
4. `ちょっと待ってください。`
5. `シャワーを浴びて、服を着て、出かけました。`
