# Bài 16: Câu ghép - から、けど、が

### から = Vì (nguyên nhân → kết quả)

```
[Nguyên nhân] + から + [Kết quả]
```

```
雨が降っていますから / 傘を持っていきます。
────────────────────   ──────────────────
[から: vì trời mưa] [mang ô đi]

Dịch theo khối: "Vì trời đang mưa / ô mang đi."
```

### けど / が = Nhưng (tương phản)

```
[Vế 1] + けど/が + [Vế 2]
```

```
この店は / 高いですが / おいしいです。
────────   ──────────   ──────────
[は: chủ đề] [が: nhưng, đắt] [ngon]

Dịch theo khối: "Tiệm này thì / đắt nhưng / ngon."
```

```
日本語は / 難しいですけど / 面白いです。
────────   ──────────────   ──────────
[は] [けど: nhưng, khó] [thú vị]

Dịch theo khối: "Tiếng Nhật thì / khó nhưng / thú vị."
```

### ので = Vì (khách quan, lịch sự hơn から)

```
病気なので / 今日は / 休みます。
──────────   ──────   ────────
[ので: vì bị bệnh] [は: hôm nay] [nghỉ]

Dịch theo khối: "Vì bị bệnh / hôm nay thì / nghỉ."
```

### Bài tập đọc dịch

1. `疲れたから、早く寝ます。`
2. `日本に行きたいですが、お金がありません。`
3. `この映画は長いですけど、面白いです。`
4. `試験があるので、毎日勉強しています。`
5. `天気がいいですから、散歩に行きましょう。`
