# Bài 18: Mệnh đề bổ nghĩa trước danh từ

### Cấu trúc

Tiếng Nhật: Mệnh đề bổ nghĩa đặt **TRƯỚC** danh từ (ngược với tiếng Việt).

```
Tiếng Việt: "Cuốn sách [mà tôi mua hôm qua]"
                N      ← mệnh đề bổ nghĩa (SAU)

Tiếng Nhật: "[昨日買った] 本"
             mệnh đề bổ nghĩa (TRƯỚC) → N
```

### Cách đọc

```
Gặp chuỗi dài trước danh từ → Đó là mệnh đề bổ nghĩa.
Đọc mệnh đề trước, rồi gắn vào danh từ.
```

### Ví dụ phân tích

```
[昨日買った] / 本を / 読んでいます。
──────────   ────   ────────────
[mệnh đề: hôm qua mua] / sách / đang đọc

Dịch theo khối: "[Hôm qua đã mua] / sách / đang đọc."
Dịch tự nhiên:  "Đang đọc cuốn sách mua hôm qua."
```

```
[母が作った] / 料理は / おいしいです。
──────────   ──────   ──────────
[mệnh đề: mẹ nấu] / món ăn thì / ngon

Dịch theo khối: "[Mẹ đã nấu] / món ăn thì / ngon."
Dịch tự nhiên:  "Món ăn mẹ nấu ngon."
```

```
[日本で撮った] / 写真を / 友達に / 見せました。
────────────   ──────   ──────   ──────────
[mệnh đề: chụp ở Nhật] / ảnh / bạn / đã cho xem

Dịch theo khối: "[Chụp ở Nhật] / ảnh / bạn / đã cho xem."
Dịch tự nhiên:  "Đã cho bạn xem ảnh chụp ở Nhật."
```

### Bài tập đọc dịch

1. `友達がくれた本を読みました。`
2. `昨日見た映画は面白かったです。`
3. `私が住んでいる町は静かです。`
4. `駅の近くにあるレストランで食べました。`
5. `先生が書いた本を買いたいです。`
