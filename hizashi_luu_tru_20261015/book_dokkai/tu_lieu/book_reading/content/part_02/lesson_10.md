# Bài 10: Câu hành động - 3~4 khối

> Bài 9 là câu mô tả (です/tính từ). Bài này giới thiệu câu có **hành động** -- lần đầu gặp động từ ở cuối câu.
> Đây là điểm khác biệt lớn nhất giữa tiếng Nhật và tiếng Việt.

---

## Sự khác biệt cốt lõi: Hành động ở cuối câu

Tiếng Việt đặt hành động **ở giữa** câu:

```
Tiếng Việt:  Tôi    đọc    sách.
              S       V       O
            (ai)  (làm gì) (cái gì)
→ Nghe "đọc" là biết ngay hành động.
```

Tiếng Nhật đặt hành động **ở cuối** câu:

```
Tiếng Nhật:  私は    本を    読みます。
              S       O       V
            (ai)  (cái gì) (làm gì)
→ Phải đọc đến cuối mới biết hành động.
```

> **Đây là lý do não người Việt hay bị "treo":** Thông tin đến trước, hành động đến cuối.
> Giải pháp: Dùng **trợ từ để dự đoán** hành động trước khi đọc đến cuối câu.

---

## Câu 2 khối: Chủ đề + Hành động

```
私は / 食べます。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 私は | は → chủ đề → sắp có thông tin về "tôi" |
| 2 | 食べます | động từ + ます → "ăn" |
| **Dịch** | | **Tôi ăn.** |

---

## Câu 3 khối: Chủ đề + Đối tượng + Hành động

Khi có を, não biết **sắp có hành động tác động** lên đối tượng đó.

```
私は / 本を / 読みます。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 私は | は → chủ đề |
| 2 | 本を | を → đối tượng → dự đoán: sắp có hành động với "sách" (đọc? mua? viết?) |
| 3 | 読みます | động từ → "đọc" → xác nhận dự đoán |
| **Dịch** | | **Tôi đọc sách.** |

---

```
母は / ひるご飯を / 作ります。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 母は | は → chủ đề → "mẹ" |
| 2 | ひるご飯を | を → đối tượng → dự đoán: sắp có hành động với "cơm trưa" (nấu? ăn?) |
| 3 | 作ります | động từ → "làm/nấu" → xác nhận |
| **Dịch** | | **Mẹ nấu cơm trưa.** |

---

## Câu 3 khối: Với に (điểm đến) hoặc へ (hướng)

Khi có に hoặc へ, não biết **sắp có di chuyển**.

```
私は / 学校に / 行きます。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 私は | は → chủ đề |
| 2 | 学校に | に → điểm đến → dự đoán: sắp có di chuyển đến "trường" (đi? đến? về?) |
| 3 | 行きます | động từ → "đi" → xác nhận |
| **Dịch** | | **Tôi đi đến trường.** |

---

```
友達は / 国へ / 帰りました。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 友達は | は → chủ đề → "bạn" |
| 2 | 国へ | へ → hướng → dự đoán: sắp có di chuyển về phía "nước (quê)" |
| 3 | 帰りました | động từ + ました → "đã về" |
| **Dịch** | | **Bạn đã về nước.** |

---

## Câu 3 khối: Với で (địa điểm hành động / phương tiện)

Khi có で, não biết **sắp có hành động diễn ra tại đây** hoặc **bằng cái này**.

```
友達は / レストランで / 食べます。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 友達は | は → chủ đề → "bạn" |
| 2 | レストランで | で → địa điểm hành động → dự đoán: sắp có hành động tại "nhà hàng" |
| 3 | 食べます | động từ → "ăn" → xác nhận |
| **Dịch** | | **Bạn ăn ở nhà hàng.** |

---

```
田中さんは / バスで / 行きます。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 田中さんは | は → chủ đề → "Tanaka" |
| 2 | バスで | で → phương tiện → dự đoán: sắp có di chuyển bằng "xe buýt" |
| 3 | 行きます | động từ → "đi" → xác nhận |
| **Dịch** | | **Tanaka đi bằng xe buýt.** |

---

## Câu 4 khối: Nhiều trợ từ phối hợp

Khi câu dài hơn, nhiều trợ từ xuất hiện. Mỗi trợ từ là một "biển báo" giúp dự đoán.

```
私は / 図書館で / 日本語を / 勉強します。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 私は | は → chủ đề |
| 2 | 図書館で | で → địa điểm → "ở thư viện" → sắp có hành động tại đây |
| 🔒 | **đóng gói:** | "hình ảnh thư viện" → で cho biết **địa điểm hành động** → đọc tiếp |
| 3 | 日本語を | を → đối tượng → "tiếng Nhật" → sắp có hành động với nó |
| 🔒 | **đóng gói:** | "tiếng Nhật" → を cho biết **đối tượng bị tác động** → đọc tiếp |
| 4 | 勉強します | động từ → "học" → xác nhận cả で và を ✅ |
| **Dịch** | | **Tôi học tiếng Nhật ở thư viện.** (chủ ngữ 私 từ は) |

---

```
田中さんは / 電車で / 会社に / 行きます。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 田中さんは | は → chủ đề → "Tanaka" |
| 2 | 電車で | で → phương tiện → "bằng tàu điện" |
| 🔒 | **đóng gói:** | "bằng tàu điện" → で cho biết **phương tiện** → dự đoán di chuyển → đọc tiếp |
| 3 | 会社に | に → điểm đến → "đến công ty" → dự đoán: đi/đến |
| 🔒 | **đóng gói:** | "đến công ty" → に cho biết **điểm đến** → dự đoán đi/đến → đọc tiếp |
| 4 | 行きます | động từ → "đi" → xác nhận cả で và に ✅ |
| **Dịch** | | **Tanaka đi tàu điện đến công ty.** (chủ ngữ 田中さん từ は) |

---

```
毎朝 / 私は / コーヒーを / 飲みます。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 毎朝 | từ chỉ thời gian → "mỗi sáng" → dự đoán: đuôi sẽ là ます (thói quen) |
| 2 | 私は | は → chủ đề |
| 3 | コーヒーを | を → đối tượng → "cà phê" → sắp có hành động (uống? pha? mua?) |
| 🔒 | **đóng gói:** | "cà phê" → を cho biết **đối tượng bị tác động** → đọc tiếp |
| 4 | 飲みます | động từ → "uống" → xác nhận dự đoán ✅ |
| **Dịch** | | **Mỗi sáng tôi uống cà phê.** (chủ ngữ 私 từ は) |

## So sánh cách đọc: Không dự đoán vs Có dự đoán

```
田中さんは / 電車で / 会社に / 行きます。
```

**Không dự đoán (đọc rồi ghép lại):**
```
"Tanaka... tàu điện... công ty... đi..."
→ Đợi hết câu → sắp xếp lại → "Tanaka đi tàu điện đến công ty"
→ Chậm, dễ quên đầu câu khi câu dài hơn.
```

**Có dự đoán (đọc theo dòng chảy):**
```
田中さんは → "Tanaka, sắp có thông tin..."
電車で     → "bằng tàu, sắp di chuyển..."
会社に     → "đến công ty, chắc chắn là đi/đến..."
行きます   → "đi!" → đúng như dự đoán, xử lý ngay.
```

> **Trợ từ = biển báo.** Gặp を → chuẩn bị cho hành động. Gặp に → chuẩn bị cho di chuyển. Gặp で → chuẩn bị cho hành động tại địa điểm hoặc bằng phương tiện. Đến khi gặp động từ cuối câu, não chỉ cần **xác nhận** chứ không cần xử lý từ đầu.

---

## Dự đoán trong câu hành động

| Gặp | Dự đoán | Ví dụ |
|-----|---------|-------|
| [N]は | Chủ đề, sắp có thông tin | 私は... |
| [N]を | Sắp có hành động tác động (ăn, đọc, mua...) | 本を... → đọc? mua? |
| [Nơi]に | Sắp có di chuyển (đi, đến, về) | 学校に... → đi/đến |
| [Nơi]へ | Sắp có di chuyển (hướng) | 国へ... → về/đi |
| [Nơi]で | Sắp có hành động tại đây | レストランで... → ăn? uống? |
| [Công cụ]で | Sắp có hành động bằng cái này | バスで... → đi |
| [Thời gian] | Dự đoán thì (毎朝 → ます, 昨日 → ました) | 毎朝... → thói quen |
| ます | Kết thúc câu, hiện tại/tương lai | |
| ました | Kết thúc câu, quá khứ | |
