# Bài 12: Câu phủ định

> Phủ định trong tiếng Nhật nằm ở **đuôi câu**, giống hành động.
> Khi đọc, nếu không đọc đến cuối thì không biết câu khẳng định hay phủ định.
> Tuy nhiên, một số "biển báo" ở đầu/giữa câu giúp dự đoán phủ định sẽ xuất hiện.

---

## Phủ định động từ: ません

```
私は / コーヒーを / 飲みません。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 私は | は → chủ đề |
| 2 | コーヒーを | を → đối tượng → dự đoán: sắp có hành động với "cà phê" |
| 3 | 飲みません | ません → phủ định → "không uống" |
| **Dịch** | | **Tôi không uống cà phê.** |

---

```
田中さんは / 肉を / 食べません。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 田中さんは | は → chủ đề |
| 2 | 肉を | を → đối tượng → dự đoán: sắp có hành động với "thịt" |
| 3 | 食べません | ません → phủ định → "không ăn" |
| **Dịch** | | **Tanaka không ăn thịt.** |

---

## Phủ định danh từ: じゃないです / じゃありません

```
私は / 学生 / じゃないです。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 私は | は → chủ đề |
| 2 | 学生 | danh từ → "sinh viên" → dự đoán: sắp có です hoặc phủ định |
| 3 | じゃないです | じゃない + です → phủ định → "không phải sinh viên" |
| **Dịch** | | **Tôi không phải sinh viên.** |

---

```
今日は / 日曜日 / じゃありません。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 今日は | は → chủ đề |
| 2 | 日曜日 | danh từ → "chủ nhật" → dự đoán: sắp có です hoặc phủ định |
| 3 | じゃありません | じゃありません → phủ định (trang trọng hơn) → "không phải chủ nhật" |
| **Dịch** | | **Hôm nay không phải chủ nhật.** |

> **じゃないです vs じゃありません:** Cùng nghĩa, じゃありません nghe trang trọng hơn một chút. Khi đọc gặp cái nào cũng hiểu là phủ định.

---

## Phủ định tính từ い: くないです

Tính từ い bỏ い → thêm くない.

```
この本は / 面白くないです。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | この本は | は → chủ đề → dự đoán: sắp có mô tả về "cuốn sách này" |
| 2 | 面白くないです | くない + です → phủ định tính từ い → "không thú vị" |
| **Dịch** | | **Cuốn sách này không thú vị.** |

---

```
今日は / あまり / 暑くないです。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 今日は | は → chủ đề |
| 2 | あまり | biển báo → dự đoán: sắp có phủ định! |
| 3 | 暑くないです | くない → xác nhận phủ định → "không nóng" |
| **Dịch** | | **Hôm nay không nóng lắm.** |

> **Ngoại lệ:** いい (tốt) → よくない (không tốt). KHÔNG phải いくない.

---

## Phủ định tính từ な: じゃないです / ではないです

Giống phủ định danh từ.

```
この部屋は / 静かじゃないです。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | この部屋は | は → chủ đề → dự đoán: sắp có mô tả về "phòng này" |
| 2 | 静かじゃないです | じゃない + です → phủ định → "không yên tĩnh" |
| **Dịch** | | **Phòng này không yên tĩnh.** |

---

```
この問題は / 簡単ではないです。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | この問題は | は → chủ đề → dự đoán: sắp có mô tả về "vấn đề này" |
| 2 | 簡単ではないです | ではない + です → phủ định (trang trọng hơn) → "không đơn giản" |
| **Dịch** | | **Vấn đề này không đơn giản.** |

> **じゃないです vs ではないです:** Cùng nghĩa. じゃ là dạng rút gọn của では. Văn nói dùng じゃ, văn viết/trang trọng dùng では.

---

## Biển báo dự đoán phủ định

Một số từ ở đầu/giữa câu báo hiệu **đuôi câu sẽ là phủ định**:

```
あまり / 食べません。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | あまり | biển báo → dự đoán: phủ định sắp đến (không...lắm) |
| 2 | 食べません | ません → xác nhận → "không ăn" |
| **Dịch** | | **Không ăn mấy.** |

---

```
ぜんぜん / わかりません。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | ぜんぜん | biển báo → dự đoán: phủ định mạnh sắp đến (hoàn toàn không) |
| 2 | わかりません | ません → xác nhận → "không hiểu" |
| **Dịch** | | **Hoàn toàn không hiểu.** |

---

```
まだ / 届きません。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | まだ | biển báo → dự đoán: phủ định (chưa...) |
| 2 | 届きません | ません → "không đến/chưa đến" |
| **Dịch** | | **Chưa đến. / Chưa nhận được.** |

> **Lưu ý:** まだ không phải lúc nào cũng báo hiệu phủ định. Khi đi với khẳng định, まだ nghĩa là "vẫn còn": まだあります = vẫn còn. Chỉ khi まだ + phủ định mới có nghĩa "chưa".

---

```
めったに / 遅刻しません。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | めったに | biển báo → dự đoán: phủ định sắp đến (hiếm khi) |
| 2 | 遅刻しません | ません → xác nhận phủ định → "không đi muộn" |
| **Dịch** | | **Hiếm khi đi muộn.** |

---

```
ちっとも / わかりません。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | ちっとも | biển báo → dự đoán: phủ định mạnh sắp đến (chẳng chút nào) |
| 2 | わかりません | ません → xác nhận phủ định → "không hiểu" |
| **Dịch** | | **Chẳng hiểu gì cả.** |

> **ちっとも vs ぜんぜん:** Cả hai đều nghĩa "hoàn toàn không", nhưng ちっとも mang sắc thái cảm xúc hơn (bực bội, thất vọng).

> **Lưu ý:** Trong tiếng Nhật hiện đại, ぜんぜん đôi khi được dùng với nghĩa khẳng định: ぜんぜん大丈夫 (hoàn toàn ổn), ぜんぜんいい (hoàn toàn tốt). Đây là cách dùng phi truyền thống nhưng rất phổ biến. Ở giai đoạn này, nhớ quy tắc "ぜんぜん đi với phủ định" là đủ.

## Câu phủ định nhiều khối

```
私は / あまり / 日本語が / わかりません。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 私は | は → chủ đề |
| 2 | あまり | biển báo → dự đoán: sắp phủ định |
| 🔒 | **đóng gói:** | "biển báo phủ định" → giải phóng bộ nhớ → đuôi câu sẽ là phủ định → đọc tiếp |
| 3 | 日本語が | が → đối tượng năng lực → sắp có わかる/できる... |
| 🔒 | **đóng gói:** | "tiếng Nhật" → が cho biết **đối tượng năng lực** → dự đoán わかる/できる → đọc tiếp |
| 4 | わかりません | ません → xác nhận phủ định → "không hiểu" ✅ |
| **Dịch** | | **Tôi không hiểu tiếng Nhật lắm.** (chủ ngữ 私 từ は) |

---

```
田中さんは / 今日 / 会社に / 行きません。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 田中さんは | は → chủ đề |
| 2 | 今日 | từ chỉ thời gian → "hôm nay" |
| 3 | 会社に | に → điểm đến → dự đoán: sắp di chuyển đến "công ty" |
| 🔒 | **đóng gói:** | "đến công ty" → に cho biết **điểm đến** → dự đoán đi/đến → đọc tiếp |
| 4 | 行きません | ません → phủ định → "không đi" ✅ |
| **Dịch** | | **Hôm nay Tanaka không đi công ty.** (chủ ngữ 田中さん từ は) |

## Tổng hợp các dạng phủ định

| Loại | Khẳng định | Phủ định |
|------|-----------|---------|
| Động từ | 食べ**ます** | 食べ**ません** |
| Danh từ + です | 学生**です** | 学生**じゃないです** / 学生**ではないです** / 学生**じゃありません** / 学生**ではありません** |
| Tính từ い | 高**い**です | 高**くない**です |
| Tính từ な | 静か**です** | 静か**じゃないです** / 静か**ではないです** / 静か**じゃありません** / 静か**ではありません** |

> Ngoại lệ: いい → よくない

---

## Dự đoán trong câu phủ định

| Gặp | Dự đoán |
|-----|---------|
| あまり | Sắp có phủ định nhẹ (không...lắm) |
| ぜんぜん | Sắp có phủ định mạnh (hoàn toàn không) |
| まだ | Sắp có phủ định (chưa...) ⚠ まだ + khẳng định = "vẫn còn" |
| めったに | Sắp có phủ định (hiếm khi...) |
| ちっとも | Sắp có phủ định mạnh (chẳng chút nào) |
| ません | Phủ định động từ |
| じゃないです / ではないです / じゃありません | Phủ định danh từ / tính từ な |
| くないです | Phủ định tính từ い |
