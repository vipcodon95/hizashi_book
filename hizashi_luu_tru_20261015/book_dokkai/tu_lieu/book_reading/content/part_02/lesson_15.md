# Bài 15: Câu hỏi

> Bài 12 dạy phủ định, bài 13 dạy thì. Bài này giới thiệu cách tiếng Nhật đặt câu hỏi.
> Câu hỏi tiếng Nhật khác tiếng Việt ở chỗ: dấu hiệu hỏi nằm ở **cuối câu** (か), còn từ hỏi có thể nằm **bất kỳ đâu** trong câu.

---

## 1. Câu hỏi はい/いいえ (Có / Không)

Thêm か vào cuối câu khẳng định → thành câu hỏi.

```
田中さんは / 学生ですか。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 田中さんは | は → chủ đề → sắp có thông tin về "Tanaka" |
| 2 | 学生ですか | です + か → câu hỏi → "là sinh viên không?" |
| **Dịch** | | **Tanaka là sinh viên không?** |

---

```
明日 / 学校に / 行きますか。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 明日 | từ chỉ thời gian → "ngày mai" → dự đoán: tương lai |
| 2 | 学校に | に → điểm đến → dự đoán: sắp di chuyển đến "trường" |
| 3 | 行きますか | ます + か → câu hỏi → "đi không?" |
| **Dịch** | | **Ngày mai bạn đi học không?** |

---

```
この映画は / 面白かったですか。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | この映画は | は → chủ đề → "bộ phim này" → dự đoán: sắp có mô tả/nhận xét về bộ phim này |
| 2 | 面白かったですか | かったです + か → tính từ い quá khứ + hỏi → "có thú vị không?" |
| **Dịch** | | **Bộ phim này có thú vị không?** |

> **Dự đoán:** Khi gặp か cuối câu → đây là câu hỏi. Cấu trúc trước か cho biết nội dung hỏi.

---

## 2. Câu hỏi với từ hỏi (nghi vấn từ)

Từ hỏi đứng ở **vị trí của thông tin cần hỏi**, không phải đầu câu như tiếng Việt.

### Các từ hỏi cơ bản

| Từ hỏi | Nghĩa | Hỏi về |
|--------|-------|--------|
| 何 (なに/なん) | Gì / Cái gì | Sự vật |
| 誰 (だれ) | Ai | Người |
| どこ | Đâu / Ở đâu | Nơi chốn |
| いつ | Khi nào | Thời gian |
| どう | Thế nào | Cách thức / Ý kiến |
| どうして / なぜ | Tại sao | Lý do |
| いくら | Bao nhiêu (tiền) | Giá cả |
| いくつ | Bao nhiêu (số lượng) | Số lượng |
| どれ | Cái nào (trong nhóm) | Lựa chọn |
| どの + N | N nào | Lựa chọn cụ thể |
| どんな + N | N như thế nào | Loại / Tính chất |
| 何時 (なんじ) | Mấy giờ | Giờ giấc |
| 何曜日 (なんようび) | Thứ mấy | Ngày trong tuần |

> **Phân biệt なに và なん:**
> - **なん** + です/で/の/も/か → なんですか、なんで、なんの
> - **なに** + を/が/に → なにを食べますか、なにが好きですか
> - **Quy tắc nhớ:** Trước âm **d, n, t** (で, の, です...) → dùng **なん**. Trước **を, が, に** → dùng **なに**.

---

### 何 (なに/なん) -- Cái gì

```
これは / 何ですか。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | これは | は → chủ đề → "cái này" |
| 2 | 何ですか | 何 + です + か → hỏi sự vật → "là cái gì?" |
| **Dịch** | | **Cái này là gì?** |

---

```
昨日 / 何を / 食べましたか。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 昨日 | từ chỉ thời gian → "hôm qua" → dự đoán: quá khứ |
| 2 | 何を | 何 + を → hỏi đối tượng → "cái gì" → dự đoán: sắp có hành động |
| 3 | 食べましたか | ました + か → quá khứ + hỏi → "đã ăn?" |
| **Dịch** | | **Hôm qua bạn đã ăn gì?** |

---

### 誰 (だれ) -- Ai

```
誰が / 来ましたか。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 誰が | 誰 + が → hỏi chủ ngữ → "ai?" → dự đoán: sắp có hành động |
| 2 | 来ましたか | ました + か → quá khứ + hỏi → "đã đến?" |
| **Dịch** | | **Ai đã đến?** |

---

```
これは / 誰の / 本ですか。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | これは | は → chủ đề → "cái này" |
| 2 | 誰の | 誰 + の → hỏi sở hữu → "của ai?" → dự đoán: sắp có danh từ |
| 3 | 本ですか | danh từ + です + か → "sách?" |
| **Dịch** | | **Đây là sách của ai?** |

---

### どこ -- Ở đâu

```
銀行は / どこですか。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 銀行は | は → chủ đề → "ngân hàng" |
| 2 | どこですか | どこ + です + か → hỏi nơi chốn → "ở đâu?" |
| **Dịch** | | **Ngân hàng ở đâu?** |

---

```
どこで / 昼ご飯を / 食べますか。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | どこで | どこ + で → hỏi địa điểm hành động → "ở đâu?" |
| 2 | 昼ご飯を | を → đối tượng → "cơm trưa" → dự đoán: sắp có hành động |
| 3 | 食べますか | ます + か → hỏi → "ăn?" |
| **Dịch** | | **Bạn ăn trưa ở đâu?** |

---

### いつ -- Khi nào

```
いつ / 日本に / 来ましたか。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | いつ | hỏi thời gian → "khi nào?" → dự đoán: quá khứ hoặc tương lai |
| 2 | 日本に | に → điểm đến → "Nhật" → dự đoán: di chuyển |
| 3 | 来ましたか | ました + か → quá khứ + hỏi → "đã đến?" |
| **Dịch** | | **Bạn đến Nhật khi nào?** |

---

### どんな + N -- Loại nào / Như thế nào

```
どんな / 音楽が / 好きですか。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | どんな | hỏi loại/tính chất → dự đoán: sắp có danh từ |
| 2 | 音楽が | danh từ + が → "âm nhạc loại nào" → đối tượng cảm xúc |
| 3 | 好きですか | cảm xúc + です + か → "thích?" |
| **Dịch** | | **Bạn thích loại nhạc nào?** |

---

### どう -- Thế nào

```
日本語は / どうですか。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 日本語は | は → chủ đề → "tiếng Nhật" → dự đoán: sắp có nhận xét/đánh giá |
| 2 | どうですか | どう + です + か → hỏi ý kiến → "thế nào?" |
| **Dịch** | | **Tiếng Nhật thế nào?** |

---

### 何時 (なんじ) -- Mấy giờ

```
今 / 何時ですか。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 今 | từ chỉ thời gian → "bây giờ" → dự đoán: hỏi về thời điểm hiện tại |
| 2 | 何時ですか | 何時 + です + か → hỏi giờ → "mấy giờ?" |
| **Dịch** | | **Bây giờ mấy giờ?** |

## 3. Câu hỏi lựa chọn (A か B か)

```
コーヒーか / 紅茶か / どちらが / いいですか。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | コーヒーか | か → lựa chọn 1 → "cà phê hay..." |
| 2 | 紅茶か | か → lựa chọn 2 → "trà" |
| 🔒 | **đóng gói:** | "cà phê hay trà" → gom thành 1 cặp lựa chọn → giải phóng bộ nhớ → đọc tiếp |
| 3 | どちらが | hỏi lựa chọn + が → "cái nào?" |
| 🔒 | **đóng gói:** | "cái nào" → が cho biết **chủ ngữ** → dự đoán đánh giá/nhận xét → đọc tiếp |
| 4 | いいですか | tính từ い + です + か → "tốt?" ✅ |
| **Dịch** | | **Cà phê hay trà, cái nào tốt hơn?** |

## 4. Nghi vấn từ + か = Ai đó / Cái gì đó / Đâu đó (bất định)

Khi từ hỏi + か **KHÔNG ở cuối câu**, nó biến thành nghĩa bất định.

| Từ hỏi | + か | Nghĩa |
|--------|------|-------|
| 誰 (ai) | 誰か | Ai đó |
| 何 (gì) | 何か | Cái gì đó |
| どこ (đâu) | どこか | Đâu đó |
| いつ (khi nào) | いつか | Lúc nào đó |

```
誰か / 来ましたか。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 誰か | 誰 + か → bất định → "ai đó" → dự đoán: sắp có hành động |
| 2 | 来ましたか | ました + か (cuối câu) → quá khứ + hỏi → "đã đến không?" |
| **Dịch** | | **Có ai đó đến không?** |

> **Phân biệt:** 誰**が**来ましたか = **AI** đã đến? (hỏi cụ thể)
> 誰**か**来ましたか = Có **ai đó** đến không? (hỏi có/không)

---

```
何か / 食べませんか。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 何か | 何 + か → bất định → "cái gì đó" |
| 2 | 食べませんか | ません + か → phủ định + hỏi → mời mọc → "ăn không?" |
| **Dịch** | | **Ăn gì đó không?** |

---

```
どこかで / コーヒーを / 飲みましょう。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | どこかで | どこか + で → "đâu đó" + địa điểm hành động |
| 2 | コーヒーを | を → đối tượng → dự đoán: sắp có hành động với "cà phê" |
| 3 | 飲みましょう | ましょう → đề nghị → "uống nhé" |
| **Dịch** | | **Đi uống cà phê ở đâu đó nhé.** |

---

## 5. Câu hỏi mời mọc / đề nghị (ませんか / ましょうか)

### ませんか = Mời mọc (lịch sự)

Phủ định + か → không phải hỏi phủ định, mà là **mời mọc lịch sự**.

```
一緒に / 映画を / 見ませんか。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 一緒に | に → "cùng nhau" → dự đoán: sắp có hành động chung |
| 2 | 映画を | を → đối tượng → "phim" |
| 3 | 見ませんか | ません + か → mời mọc → "xem không?" |
| **Dịch** | | **Cùng xem phim không?** |

### ましょうか = Đề nghị giúp / Rủ rê

```
窓を / 開けましょうか。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 窓を | を → đối tượng → "cửa sổ" → dự đoán: sắp có hành động |
| 2 | 開けましょうか | ましょう + か → đề nghị giúp → "mở nhé?" |
| **Dịch** | | **Tôi mở cửa sổ nhé?** |

---

```
何時に / 会いましょうか。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 何時に | 何時 + に → hỏi thời điểm → "mấy giờ?" |
| 2 | 会いましょうか | ましょう + か → đề nghị/bàn → "gặp nhé?" |
| **Dịch** | | **Mấy giờ mình gặp nhau nhé?** |

### So sánh ませんか và ましょうか

| | ませんか | ましょうか |
|---|---------|-----------|
| **Nghĩa** | Mời mọc | Đề nghị giúp / Rủ rê |
| **Ai quyết định** | Đối phương tự quyết | Người nói chủ động |
| **Ví dụ** | 食べませんか (Ăn không?) | 食べましょうか (Tôi lấy đồ ăn nhé?) |

> **Cảnh báo:** ませんか KHÔNG phải hỏi phủ định. Trong tiếng Việt, "Bạn không ăn à?" là hỏi thật (hỏi phủ định). Nhưng trong tiếng Nhật, 食べませんか là **mời mọc**: "Ăn không?" chứ không phải "Bạn không ăn à?". Đây là khác biệt lớn giữa hai ngôn ngữ.

## 6. Câu hỏi tu từ (không cần trả lời)

Đôi khi câu hỏi không thực sự hỏi mà để nhấn mạnh hoặc suy nghĩ.

```
これは / 本当ですか。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | これは | は → chủ đề → "cái này" |
| 2 | 本当ですか | danh từ + です + か → câu hỏi → "là thật không?" |
| **Dịch** | | **Thật sao?** (ngạc nhiên -- khi đã biết là thật) |

---

```
誰が / こんなことを / しましたか。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 誰が | 誰 + が → hỏi chủ ngữ → "ai?" → dự đoán: sắp có hành động |
| 2 | こんなことを | を → đối tượng → "chuyện như thế này" |
| 3 | しましたか | ました + か → quá khứ + hỏi → "đã làm?" |
| **Dịch** | | **Ai đã làm chuyện này vậy?** (bực tức -- biết rồi nhưng muốn nhấn mạnh) |

> **Khi đọc:** Nếu ngữ cảnh đã cho câu trả lời, câu hỏi か có thể là tu từ -- nhấn mạnh cảm xúc (ngạc nhiên, bực tức, cảm thán).

## Dự đoán trong câu hỏi

| Gặp | Dự đoán |
|-----|---------|
| 何/なに/なん | Hỏi về SỰ VẬT → "cái gì?" |
| 誰/だれ | Hỏi về NGƯỜI → "ai?" |
| どこ | Hỏi về NƠI CHỐN → "ở đâu?" |
| いつ | Hỏi về THỜI GIAN → "khi nào?" |
| どう | Hỏi về CÁCH THỨC / Ý KIẾN → "thế nào?" |
| どんな + N | Hỏi LOẠI / TÍNH CHẤT → "N như thế nào?" |
| 何時/なんじ | Hỏi GIỜ GIẤC → "mấy giờ?" |
| A か B か | LỰA CHỌN giữa A và B |
| 誰か/何か/どこか | BẤT ĐỊNH → "ai đó / gì đó / đâu đó" |
| ませんか | MỜI MỌC lịch sự → "làm không?" |
| ましょうか | ĐỀ NGHỊ giúp / rủ rê → "làm nhé?" |
| ...か (cuối câu) | Xác nhận đây là CÂU HỎI |
