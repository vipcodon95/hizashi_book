# Bài 11: Câu mô tả - Tính từ い / な

> Bài 9 giới thiệu câu đơn với です. Bài này đi sâu vào tính từ -- cách tiếng Nhật mô tả tính chất.
> Tính từ tiếng Nhật **rất khác** tiếng Việt: nó biến đổi đuôi, đứng TRƯỚC danh từ, và chia thành 2 loại hoạt động khác nhau.

---

## Tính từ tiếng Nhật vs tiếng Việt

Tiếng Việt: Tính từ đứng **SAU** danh từ, không biến đổi.

```
Tiếng Việt:  Cuốn sách   thú vị
              N           Adj (sau N)
```

Tiếng Nhật: Tính từ đứng **TRƯỚC** danh từ, và có thể biến đổi đuôi.

```
Tiếng Nhật:  面白い      本
              Adj (trước N)  N
```

> **Khi đọc:** Gặp tính từ → biết ngay danh từ sắp đến phía sau. Đây là tín hiệu dự đoán quan trọng.

---

## 2 loại tính từ

Tiếng Nhật có 2 loại tính từ, hoạt động **hoàn toàn khác nhau**:

| | Tính từ い | Tính từ な |
|---|---|---|
| Đuôi | Luôn kết thúc bằng い | Thường không kết thúc bằng い (ngoại lệ: きれい, 嫌い là tính từ な dù có đuôi い) |
| Bổ nghĩa danh từ | Aい + N (gắn trực tiếp) | Aな + N (thêm な) |
| Vị ngữ | Aい + です | Aな + です |
| Ví dụ | 高い (cao), 大きい (lớn), 面白い (thú vị) | 静か (yên tĩnh), 有名 (nổi tiếng), きれい (đẹp) |

> **Cạm bẫy:** きれい (đẹp) và 有名 (nổi tiếng) KHÔNG phải tính từ い dù きれい kết thúc bằng い. Chúng là tính từ な: きれい**な**花, 有名**な**人.

---

## Tính từ い -- Làm vị ngữ (cuối câu)

```
この本は / 面白いです。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | この本は | は → chủ đề → sắp có mô tả về "cuốn sách này" |
| 2 | 面白いです | tính từ い + です → "thú vị" |
| **Dịch** | | **Cuốn sách này thú vị.** |

---

```
今日は / とても / 寒いです。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 今日は | は → chủ đề → "hôm nay" |
| 2 | とても | trạng từ → dự đoán: sắp có tính từ, mức độ "rất" |
| 3 | 寒いです | tính từ い + です → xác nhận → "lạnh" |
| **Dịch** | | **Hôm nay rất lạnh.** |

---

## Tính từ い -- Bổ nghĩa danh từ (đứng TRƯỚC danh từ)

Tính từ い gắn **trực tiếp** vào danh từ, tạo thành 1 khối.

```
新しい / かばんを / 買いました。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 新しい | tính từ い → dự đoán: sắp có danh từ được mô tả |
| 2 | かばんを | danh từ + を → "cặp mới" → dự đoán: sắp có hành động với "cặp" |
| 3 | 買いました | ました → quá khứ → "đã mua" |
| **Dịch** | | **Tôi đã mua cặp mới.** |

---

```
大きい / 公園で / 子供が / 遊んでいます。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 大きい | tính từ い → dự đoán: sắp có danh từ |
| 2 | 公園で | danh từ + で → "công viên lớn" + địa điểm hành động → sắp có hành động tại đây |
| 🔒 | **đóng gói:** | "công viên lớn" → で cho biết **địa điểm hành động** → dự đoán hành động tại đây → đọc tiếp |
| 3 | 子供が | が → chủ ngữ → "trẻ em" |
| 🔒 | **đóng gói:** | "trẻ em" → が cho biết **chủ ngữ** → dự đoán hành động/mô tả → đọc tiếp |
| 4 | 遊んでいます | ています → "đang chơi" → xác nhận dự đoán ✅ |
| **Dịch** | | **Trẻ em đang chơi ở công viên lớn.** (chủ ngữ 子供 từ が) |

---

```
おいしい / 料理を / 食べました。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | おいしい | tính từ い → dự đoán: sắp có danh từ |
| 2 | 料理を | danh từ + を → "món ngon" → dự đoán: sắp có hành động |
| 3 | 食べました | ました → "đã ăn" |
| **Dịch** | | **Tôi đã ăn món ngon.** |

---

## Tính từ な -- Làm vị ngữ (cuối câu)

```
この町は / にぎやかです。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | この町は | は → chủ đề → sắp có mô tả về "thị trấn này" |
| 2 | にぎやかです | tính từ な + です → "nhộn nhịp" |
| **Dịch** | | **Thị trấn này nhộn nhịp.** |

---

```
あの人は / とても / 親切です。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | あの人は | は → chủ đề → "người kia" |
| 2 | とても | trạng từ → dự đoán: sắp có tính từ, mức độ "rất" |
| 3 | 親切です | tính từ な + です → xác nhận → "tốt bụng" |
| **Dịch** | | **Người kia rất tốt bụng.** |

> **Lỗi người Việt hay mắc:** Đừng viết ×静かなです (thừa な khi làm vị ngữ). Đúng: **静かです**. Chữ な chỉ xuất hiện khi bổ nghĩa danh từ (静かな部屋), không dùng khi tính từ な đứng cuối câu làm vị ngữ.

---

## Tính từ な -- Bổ nghĩa danh từ (thêm な trước danh từ)

Tính từ な phải thêm **な** trước danh từ. Đây là dấu hiệu nhận biết.

```
静かな / 部屋で / 勉強します。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 静かな | tính từ な + な → dự đoán: sắp có danh từ được mô tả |
| 2 | 部屋で | danh từ + で → "phòng yên tĩnh" + địa điểm → sắp có hành động tại đây |
| 3 | 勉強します | ます → "học" |
| **Dịch** | | **Tôi học trong phòng yên tĩnh.** |

---

```
有名な / レストランで / 食べました。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 有名な | tính từ な + な → dự đoán: sắp có danh từ |
| 2 | レストランで | danh từ + で → "nhà hàng nổi tiếng" + địa điểm → sắp có hành động |
| 3 | 食べました | ました → "đã ăn" |
| **Dịch** | | **Tôi đã ăn ở nhà hàng nổi tiếng.** |

---

```
きれいな / 花が / 咲いています。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | きれいな | tính từ な + な → dự đoán: sắp có danh từ |
| 2 | 花が | danh từ + が → "hoa đẹp" + chủ ngữ → sắp có mô tả/hành động |
| 3 | 咲いています | ています → "đang nở" |
| **Dịch** | | **Hoa đẹp đang nở.** |

---

## Phân biệt tính từ い và な khi đọc

| Dấu hiệu | Loại | Ví dụ |
|-----------|------|-------|
| ...い + N (gắn trực tiếp) | Tính từ い | 高い山, 新しい本 |
| ...な + N (có な) | Tính từ な | 静かな部屋, きれいな花 |
| ...いです (cuối câu) | Tính từ い | 高いです, 面白いです |
| ...[không い]です (cuối câu) | Tính từ な | 静かです, 有名です |

> **Mẹo đọc:** Khi gặp な trước danh từ → đó chắc chắn là tính từ な đang bổ nghĩa.
> Khi gặp từ kết thúc bằng い trước danh từ (không có な) → đó là tính từ い.

## Nhiều tính từ mô tả cùng 1 danh từ

Tiếng Nhật có thể xếp nhiều tính từ trước danh từ:

```
大きくて / 新しい / 家
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 大きくて | tính từ い dạng て → "lớn, và..." → dự đoán: sắp có tính từ/danh từ tiếp |
| 2 | 新しい | tính từ い → "mới" → dự đoán: sắp có danh từ |
| 3 | 家 | danh từ → "nhà" |
| **Dịch** | | **Ngôi nhà lớn và mới.** |

---

```
静かで / きれいな / 町です。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 静かで | tính từ な dạng て → "yên tĩnh, và..." → dự đoán: sắp có tính từ/danh từ tiếp |
| 2 | きれいな | tính từ な + な → "đẹp" → dự đoán: sắp có danh từ |
| 3 | 町です | danh từ + です → "thị trấn" |
| **Dịch** | | **Thị trấn yên tĩnh và đẹp.** |

---

Nối chéo tính từ い + tính từ な:

```
広くて / 静かな / 部屋で / 勉強します。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 広くて | tính từ い dạng て → "rộng, và..." → dự đoán: sắp có tính từ/danh từ tiếp |
| 2 | 静かな | tính từ な + な → "yên tĩnh" → dự đoán: sắp có danh từ |
| 3 | 部屋で | danh từ + で → "phòng rộng và yên tĩnh" + địa điểm → sắp có hành động |
| 🔒 | **đóng gói:** | "phòng rộng và yên tĩnh" → で cho biết **địa điểm hành động** → dự đoán hành động tại đây → đọc tiếp |
| 4 | 勉強します | ます → "học" → xác nhận dự đoán ✅ |
| **Dịch** | | **Tôi học trong phòng rộng và yên tĩnh.** (chủ ngữ ẩn: 私) |

> **Cách nối tính từ:**
> - Tính từ い: bỏ い → thêm くて (大きい → 大きくて)
> - Tính từ な: bỏ な → thêm で (静かな → 静かで)
>
> **Ngoại lệ:** いい → よくて (không phải ~~いくて~~). Tính từ いい (tốt) trở về gốc よい khi biến đổi.

---

## Dự đoán trong câu mô tả

| Gặp | Dự đoán |
|-----|---------|
| [Aい] (trước N) | Sắp có danh từ được mô tả |
| [Aな] (trước N) | Sắp có danh từ được mô tả |
| とても / すごく | Sắp có tính từ (mức độ cao) |
| [Aい]くて / [Aな]で | Sắp có tính từ hoặc danh từ tiếp (nối nhiều tính từ) |
| [N]は + いです | Câu mô tả tính chất |
| [N]は + です (không い) | Câu mô tả tính chất (tính từ な hoặc danh từ) |
