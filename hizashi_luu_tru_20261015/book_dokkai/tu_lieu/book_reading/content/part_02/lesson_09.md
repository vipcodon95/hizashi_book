# Bài 9: Câu đơn - 2~3 khối

> Câu đơn giản nhất trong tiếng Nhật: chỉ có 2-3 khối.
> Áp dụng kiến thức trợ từ từ Part 1 vào đọc dịch câu hoàn chỉnh.

---

## Câu 2 khối

```
これは / ペンです。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | これは | は → chủ đề → sắp có thông tin về "cái này" |
| 2 | ペンです | です → khẳng định → "là bút" |
| **Dịch** | | **Cái này là bút.** |

---

```
今日は / 暑いです。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 今日は | は → chủ đề → sắp có thông tin về "hôm nay" |
| 2 | 暑いです | tính từ い + です → "nóng" |
| **Dịch** | | **Hôm nay nóng.** |

---

```
この部屋は / 静かです。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | この部屋は | は → chủ đề → sắp có thông tin về "phòng này" |
| 2 | 静かです | tính từ な + です → "yên tĩnh" |
| **Dịch** | | **Phòng này yên tĩnh.** |

---

```
田中さんは / 先生です。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 田中さんは | は → chủ đề → sắp có thông tin về "Tanaka" |
| 2 | 先生です | danh từ + です → "là giáo viên" |
| **Dịch** | | **Tanaka là giáo viên.** |

## Câu 3 khối

```
これは / 日本の / 本です。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | これは | は → chủ đề → sắp có thông tin về "cái này" |
| 2 | 日本の | の → bổ nghĩa → sắp có danh từ thuộc về "Nhật" |
| 3 | 本です | danh từ + です → "sách" |
| **Dịch** | | **Cái này là sách Nhật.** |

---

```
東京は / とても / 大きいです。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 東京は | は → chủ đề → sắp có thông tin về "Tokyo" |
| 2 | とても | trạng từ → sắp có tính từ, mức độ "rất" |
| 3 | 大きいです | tính từ い + です → "lớn" |
| **Dịch** | | **Tokyo rất lớn.** |

---

```
田中さんは / 日本語の / 先生です。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 田中さんは | は → chủ đề → sắp có thông tin về "Tanaka" |
| 2 | 日本語の | の → bổ nghĩa → sắp có danh từ thuộc về "tiếng Nhật" |
| 3 | 先生です | danh từ + です → "giáo viên" |
| **Dịch** | | **Tanaka là giáo viên tiếng Nhật.** |

## Câu có は + が (chủ đề + chủ ngữ cảm xúc)

```
私は / 花が / 好きです。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 私は | は → chủ đề → "về phần tôi thì..." |
| 2 | 花が | が → đối tượng cảm xúc → sắp có 好き/嫌い/わかる... |
| 3 | 好きです | cảm xúc + です → "thích" |
| **Dịch** | | **Tôi thích hoa.** |

---

```
田中さんは / 英語が / わかります。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 田中さんは | は → chủ đề → sắp có thông tin về "Tanaka" |
| 2 | 英語が | が → đối tượng năng lực → sắp có わかる/できる/上手... |
| 3 | わかります | năng lực + ます → "hiểu" |
| **Dịch** | | **Tanaka hiểu tiếng Anh.** |

---

```
象は / 鼻が / 長いです。
```

| Bước | Đọc | Xử lý |
|------|-----|-------|
| 1 | 象は | は → chủ đề → sắp có thông tin về "con voi" |
| 2 | 鼻が | が → bộ phận được mô tả → sắp có tính từ |
| 3 | 長いです | tính từ い + です → "dài" |
| **Dịch** | | **Voi thì mũi dài.** (Con voi có cái mũi dài.) |

> **は vs が trong cùng 1 câu:**
> - は đánh dấu **chủ đề lớn** (người, vật đang nói về)
> - が đánh dấu **đối tượng cụ thể** được mô tả (cảm xúc, năng lực, bộ phận, đặc điểm)
> - Mẫu cảm xúc/năng lực: [Người]は + [Đối tượng]が + 好き/嫌い/わかる/できる/上手/下手/欲しい
> - Mẫu đặc điểm: [Chủ đề]は + [Bộ phận/Đặc điểm]が + tính từ

## Lược bỏ は khi ngữ cảnh rõ ràng

Khi cả hai bên đã biết đang nói về gì, は thường được **lược bỏ**. Khi đọc, cần suy ra chủ đề từ ngữ cảnh.

### Trong hội thoại

```
A: この犬、かわいいね。    → Con chó này dễ thương nhỉ.
B: うん、目が大きい。      → Ừ, mắt to.
```

→ Câu B không có は. Chủ đề "con chó" đã rõ từ câu A.
→ Đầy đủ: この犬は目が大きい。

### Trong đoạn văn

```
象は大きい動物です。鼻が長いです。耳も大きいです。
```

→ Câu đầu có は (giới thiệu chủ đề "con voi").
→ Câu 2, 3 lược bỏ は vì chủ đề vẫn là "con voi".
→ Đầy đủ: 象は鼻が長いです。象は耳も大きいです。

> **Mẹo đọc:** Khi gặp câu không có は, nhìn lại câu trước để tìm chủ đề. Chủ đề thường được giới thiệu 1 lần rồi duy trì cho các câu tiếp theo.

---

## Dự đoán trong câu đơn

| Gặp | Dự đoán |
|-----|---------|
| [N]は | Sắp có thông tin / mô tả về N |
| [N]が | Sắp có cảm xúc / năng lực (好き, わかる, できる...) |
| [N]の | Sắp có danh từ tiếp theo |
| とても / すごく | Sắp có tính từ (nhấn mạnh mức độ cao) |
| です / ます | Kết thúc câu, khẳng định |
