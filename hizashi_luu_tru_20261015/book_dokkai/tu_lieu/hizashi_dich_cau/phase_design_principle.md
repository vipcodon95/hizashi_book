# Nguyên Tắc Thiết Kế Phase - Khóa Học N5

## Nguyên Tắc Cốt Lõi

> **3 phương pháp (Chunking, Anticipation, Semantic) LUÔN đi cùng nhau trong MỌI bài học, MỌI phase!**

### Tại sao không tách riêng 3 phương pháp thành các phase?

```
❌ SAI:
Phase 1: Học Chunking
Phase 2: Học Anticipation
Phase 3: Học Semantic

✅ ĐÚNG:
Phase 1-5: Mỗi phase đều áp dụng CẢ 3 phương pháp
           Chỉ khác nhau về ĐỘ PHỨC TẠP của nội dung
```

### Lý do:

1. **Chunking cần Anticipation**: Để chia câu thành khối, não phải DỰ ĐOÁN được vai trò của mỗi phần (qua trợ từ)

2. **Anticipation cần Semantic**: Để dự đoán chính xác, não phải có HÌNH ẢNH về ngữ cảnh

3. **Semantic cần Chunking**: Để hình dung, não phải hiểu được CẤU TRÚC câu

→ **3 cái này là MỘT HỆ THỐNG, không thể tách rời!**

## Cách Chia Phase Đúng: Theo ĐỘ PHỨC TẠP

### Phase 1: Câu Cơ Bản Nhất (1-2 khối)

**Cấu trúc câu:**
- `Xは Yです` - A là B
- `Nが あります/います` - Có N

**Ví dụ học từ りんご (táo):**
```
┌─────────────────────────────────────────────────────────────┐
│  📖 TỪ: りんご (táo)                                         │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  🧩 CHUNKING:                                               │
│     これは / りんごです                                       │
│     ─────   ──────────                                      │
│     khối 1    khối 2                                        │
│                                                             │
│  🎯 ANTICIPATION:                                           │
│     これは... → đang giới thiệu cái gì đó                    │
│                                                             │
│  🖼️ SEMANTIC:                                               │
│     [Hình quả táo đỏ] → Hiểu trực tiếp                      │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**Từ vựng:** Danh từ cơ bản, đại từ chỉ định
**Ngữ pháp:** です, あります/います, は, が, も

---

### Phase 2: Hành Động Cơ Bản (2-3 khối)

**Cấu trúc câu:**
- `Nを Vます` - Làm gì cái gì
- `Nに/で Vます` - Làm gì ở đâu

**Ví dụ học từ 食べます (ăn):**
```
┌─────────────────────────────────────────────────────────────┐
│  📖 TỪ: 食べます (ăn)                                        │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  🧩 CHUNKING:                                               │
│     りんごを / 食べます                                       │
│     ────────   ─────────                                    │
│      khối 1     khối 2                                      │
│                                                             │
│  🎯 ANTICIPATION:                                           │
│     りんごを... → を = sắp làm gì đó với táo                  │
│     → Đoán: ăn? mua? cắt?                                   │
│                                                             │
│  🖼️ SEMANTIC:                                               │
│     [Hình người đang ăn táo] → Hiểu trực tiếp               │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**Từ vựng:** Động từ ます形, địa điểm, thời gian
**Ngữ pháp:** を, に, で, へ, Vます/ません/ました

---

### Phase 3: Mô Tả & So Sánh (3-4 khối)

**Cấu trúc câu:**
- `Adj + N` - Tính từ bổ nghĩa
- `N1 より N2 のほうが Adj` - So sánh
- `N の中で N が 一番 Adj` - So sánh nhất

**Ví dụ học từ 大きい (to, lớn):**
```
┌─────────────────────────────────────────────────────────────┐
│  📖 TỪ: 大きい (to, lớn)                                     │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  🧩 CHUNKING:                                               │
│     大きい犬が / 公園で / 走っています                         │
│     ──────────  ──────   ────────────                       │
│       khối 1    khối 2      khối 3                          │
│                                                             │
│  🎯 ANTICIPATION:                                           │
│     大きい犬が... → が = chủ ngữ, sắp làm gì đó               │
│     公園で... → で = hành động diễn ra ở đây                  │
│                                                             │
│  🖼️ SEMANTIC:                                               │
│     [Hình con chó to đang chạy trong công viên]             │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**Từ vựng:** Tính từ い/な, số đếm, lượng từ
**Ngữ pháp:** Adj くない/じゃない, より, 一番

---

### Phase 4: Kết Nối Câu (4-5 khối)

**Cấu trúc câu:**
- `Vて、Vて、Vます` - Chuỗi hành động
- `Vてから Vます` - Làm xong rồi làm
- `から/ので` - Nguyên nhân kết quả

**Ví dụ học て形:**
```
┌─────────────────────────────────────────────────────────────┐
│  📖 NGỮ PHÁP: Vて (nối hành động)                            │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  🧩 CHUNKING:                                               │
│     朝 / 起きて / ご飯を食べて / 学校に行きます                 │
│     ──  ──────  ────────────  ──────────────                │
│     k1    k2        k3            k4                        │
│                                                             │
│  🎯 ANTICIPATION:                                           │
│     起きて... → て = còn hành động tiếp theo                  │
│     ご飯を食べて... → て = vẫn còn tiếp                       │
│     学校に... → に = điểm đến, sắp có động từ di chuyển       │
│                                                             │
│  🖼️ SEMANTIC:                                               │
│     [Hình chuỗi: thức dậy → ăn sáng → đi học]               │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**Từ vựng:** Động từ đa dạng, liên từ
**Ngữ pháp:** て形, てから, ても, から, ので, けど

---

### Phase 5: Hội Thoại Tự Nhiên (5+ khối)

**Cấu trúc câu:**
- `Vたら / Vば / Vと` - Điều kiện
- `〜んです` - Giải thích
- Câu phức tạp, hội thoại thực tế

**Ví dụ:**
```
┌─────────────────────────────────────────────────────────────┐
│  📖 NGỮ PHÁP: ～たら (nếu/khi)                               │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  🧩 CHUNKING:                                               │
│     明日 / 雨が降ったら / 家で / 映画を / 見ます               │
│     ───  ────────────  ────  ──────  ──────                │
│      k1       k2        k3     k4     k5                    │
│                                                             │
│  🎯 ANTICIPATION:                                           │
│     雨が降ったら... → たら = điều kiện, sắp có kết quả        │
│     家で... → で = hành động sẽ diễn ra ở đây                 │
│     映画を... → を = sắp làm gì với phim                      │
│                                                             │
│  🖼️ SEMANTIC:                                               │
│     [Hình: mưa → ở nhà → xem phim]                          │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**Từ vựng:** Từ vựng giao tiếp, cảm xúc
**Ngữ pháp:** たら, ば, と, んです, でしょう, かもしれません

## Tổng Kết

| Phase | Độ phức tạp | Số khối | Trọng tâm ngữ pháp |
|-------|-------------|---------|-------------------|
| 1 | Cơ bản nhất | 1-2 | です, あります/います |
| 2 | Hành động đơn | 2-3 | Vます, を/に/で |
| 3 | Mô tả, so sánh | 3-4 | Adj, より, 一番 |
| 4 | Nối câu | 4-5 | て形, から, ので |
| 5 | Hội thoại | 5+ | たら, ば, んです |

## Nguyên Tắc Khi Tạo Bài Học

Mỗi từ vựng/ngữ pháp mới **BẮT BUỘC** phải có:

1. **Câu ví dụ** được chia thành các khối (Chunking)
2. **Giải thích trợ từ** và cách dự đoán (Anticipation)
3. **Hình ảnh minh họa** để hiểu trực tiếp (Semantic)

```
KHÔNG BAO GIỜ dạy từ đơn lẻ như:
❌ 本 = sách
❌ 読みます = đọc

LUÔN dạy trong ngữ cảnh:
✅ 本を読みます = [本を] + [読みます]
   → を báo hiệu sắp có hành động
   → [Hình người đang đọc sách]
```
